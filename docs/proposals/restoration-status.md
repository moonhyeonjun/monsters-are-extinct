## 0. 요약

| 질문 | 현재 정본이 말하는 것 | 문제 |
|---|---|---|
| 복원 1~4단계는 성과인가 목표인가 | 단계 정의는 [초안] (0 자료 → 1 개체 탄생 → 2 시설 내 번식 → 3 야생 번식 → 4 장기 생태 정착). 도감은 종마다 **현재 단계**를 적는다 [초안]. 연표: 멸종력 271~312년 "제2차 복원기, 소형 종의 제한적 복원 성공" [초안] | 도감을 그대로 읽으면 **이미 야생에서 번식하는 환류종(3단계)과 장기 정착한 환류종(4단계)이 있다.** 그런데 원고와 개요는 "환류종은 멸종했다"는 인식 위에 서 있다 |
| 3~4단계 종 | 타르멜·펠루안·키르벨 3단계, 루켄 4단계 | '야생 번식'·'장기 생태 정착'은 살아 있는 개체군을 뜻한다 |
| 원종과 같은가 | 복원법 셋(보존생명 / 근연형질 / 생태기능 대체), 잠재형질은 "원종과 완전히 동일하다는 보장은 없다" [초안]. 루켄: "현존 계통과 복원 계통의 동일성 미확정" [초안] | 종마다 어떤 방법으로 복원했는지 정해져 있지 않다 |
| 멸종 판정 | 아우렐 멸종 판정 [확정] (D-005). 모레비는 "**야생 멸종** 판정, 복원 1단계" [초안]. 3~4단계 종에는 판정 표기가 없다 | 복원된 종의 공식 판정이 비어 있다 |

- **권장: B를 기본으로, 일부 종에 C를 적용한다.** 기존 [확정] 결정과 충돌하지 않는다. A는 도감·연표·마스터의 여러 [초안]을 고쳐야 한다 (§2).
- 제1~9화 원고는 고치지 않아도 된다. 다만 해석을 하나 정해 두어야 하고(§6-1), 제10화 이후에 다뤄야 할 이야기 구멍이 하나 있다(§6-3).

## 4. 질문별 답 [제안]

| 질문 | 답 |
|---|---|
| 복원 1~4단계는 성과인가 목표인가 | **정의는 연구의 진척 단계이고, 도감의 단계는 종별로 '현재 도달한' 성과다.** 4단계에 이른 종은 루켄 하나다. 3단계 셋(타르멜·펠루안·키르벨) |
| 3~4단계는 살아 있는 개체군인가 | **그렇다. 다만 모두 사람이 되살린 복원 계통이고, 보호구역 안팎의 한정된 곳에 있다.** 원래 야생 계통이 아니다 |
| 원종과 같은가 | 방법에 따라 다르다. 보존생명 복원(타르멜·펠루안)은 원종에 가깝다고 여겨진다. 근연형질·잠재형질 복원(키르벨·루켄)은 **원종과 같은지 논쟁 중**이다 (C) |
| 실제 환류기관을 갖는가 | 보존생명 복원종은 갖는다. 근연형질 복원종은 **부분적으로 발현**하고, 기능이 약하거나 불규칙하다 [제안]. 환류기관이 불안정하면 효과가 강해지거나 약해지거나 불규칙해질 수 있다는 정본([확정] D-036)과 맞는다 |
| 공식 멸종 판정은 어떻게 바뀌었나 | **바뀌지 않았다.** 312년 전 선언은 원래 야생 계통에 대한 것이고, 복원종은 그 위에 '복원 계통'으로 따로 기록된다. 그래서 '야생 멸종' 표기가 생겼다. 멸종 선언을 뒤집으려면 원래 야생 계통의 생존 확인이 필요하다 (D-012의 3단계) |
| 일반 시민은 얼마나 아는가 | 세르딘은 잘 안다(루켄, 박물관, 시민학교). 아르센 해안은 펠루안을 안다. 라스텐은 '쓸모없는 낭만'으로 여긴다(대체문명연맹). 하벨 농촌은 "학자들이 작은 것 몇을 되살렸다더라" 정도 |
| 하벨 겨울 배움터에서는 | [제안] 왕국 교본은 "옛짐승은 모두 사라졌다. 오늘날 학자들이 작은 짐승 몇을 되살리려 애쓰고 있다" 한두 줄 정도. **'환류종'·'복원 단계' 같은 학술 명칭은 쓰지 않는다.** 교본은 오래 바뀌지 않는다 (education-system.md §2: 순회 학무관이 몇 해에 한 번) |
| 리아가 '환류종'을 처음 듣는 설정과 충돌하는가 | **충돌하지 않는다.** 리아는 복원 소식을 막연히 들었을 수 있어도 학술 명칭은 배우지 않았다. 제4화의 "처음 듣는 말이었다. 환류종."은 그대로 성립한다 |
| 아우렐 야생 개체 발견의 충격은 유지되는가 | **유지되고 더 날카로워진다.** 복원종은 사람이 되살렸으니 멸종 선언과 모순되지 않는다. 그러나 **복원된 적 없는 종의 야생 개체**는 312년 전 선언이 틀렸을 수 있다는 첫 증거가 된다. 그래서 마르딘은 이름을 붙이지 못하고, 베르크는 서둘러 손에 넣으려 한다 |

## 6. 제1~9화에 미치는 영향

### 6-1. 원고는 고치지 않아도 된다 — 필요한 해석

| 회차 | 대사 | B를 따를 때의 해석 |
|---|---|---|
| 제3화 | 도아: "다 죽었다지만." | 아이의 통념. 그대로 |
| 제4화 | 다렌: "옛짐승 말이오? 그건 다 없어졌다고 배웠는데." | '옛짐승' = 원래 야생 계통(§5). 하벨 농부의 지식 수준과 맞음 |
| 제4화 | 카셀: "저도 그렇게 배웠습니다." | 카셀은 복원종이 있다는 것을 알 수 있다. 그가 말하는 것은 **야생 옛짐승**이다. 이어지는 "그래서 늑대 발자국을 보러 이 먼 데까지 걸어오는 거고요"와도 맞음 |
| 제4화 | 리아가 '환류종'을 처음 들음 | 하벨 교본에 학술 명칭 없음. 그대로 |
| 제9화 | 마르딘: "환류종일 가능성은 봅니다." | 복원 성과를 말하지 않음. 그대로 |

### 6-2. 오히려 좋아지는 것

- 아우렐 유사 개체가 '복원된 적 없는 종'이라는 점이 갈등의 무게를 더한다. 첫 모험이 확인 1단계까지 간다는 제안(Q-사건-06)의 의미가 커진다.
- 베르크가 왜 서두르는지가 독자에게 설명 없이 이해된다.

### 6-3. 다뤄야 할 이야기 구멍 (제10화 이후) [제안]

- **복원종이 존재하는 세계라면, 누군가는 "협회나 연구기관에서 기르던 것이 도망친 것 아니냐"고 물었어야 한다.** 제1~9화에는 이 가설이 나오지 않는다.
- 처리 방안 (원고 수정 없이):
  1. 마르딘이 협회 생육국 기록과 대조한다: **이 종(또는 비슷한 종)의 복원 계통은 기록에 없다.** 탈출한 복원 개체일 가능성이 낮아진다. → 야생 개체일 가능성이 커진다.
  2. 베르크가 이 가설을 이용할 수 있다: "우리 기관의 연구 개체가 운송 중 사라졌습니다." 위임장의 근거로 쓰면 그의 주장이 갑자기 설득력을 얻는다. 동시에 그것은 운송(F11)과 이어지는 위험한 말이 된다. (Q-사건-05, D-022 — 확정하지 않음)
  3. 마을 사람이 소박하게 묻는다: "어디서 기르던 게 도망친 거 아니오?"
- 이 구멍은 원고를 고쳐 메우기보다 **다음 회차의 질문으로 쓰는 편**이 낫다.

### 6-4. 쓰지 말아야 할 것 (승인 전)

- 마르딘이나 서술자가 복원 성과를 단정하는 말 (루켄이 몇 년째 정착했다, 키르벨은 원종이 아니다 등)
- 복원종의 구체적인 서식지 이름, 개체 수
- 보존생명 복원 재료의 기원 (D-047 [보류])

## 8. 사용자가 결정할 것

1. **기본 방향:** B+C (권장) / A / B만 / C만
2. **'야생 멸종'과 '멸종'의 구분 표기:** 채택할지. 채택하면 index.md의 판정 칸을 다시 쓴다
