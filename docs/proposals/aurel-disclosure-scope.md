## 0. 현재 상태 (D-071, 커밋 `9215e01`)

- 제9화(D+7) 해 질 녘 전, 마르딘이 마을 사람들 앞에서 "제가 아는 기록 가운데 한 종과 닮았습니다. **아우렐이라는 종이에요**"라고 말한다. 마을 사람들, 베르크, 로안, 카셀, 리아가 듣는다.

## 2. 두 안의 비교

| 기준 | **A. 공개 유지** | **B. 공개 범위 제한 (권장)** |
|---|---|---|
| 누가 아는가 (D+7) | 마을 사람들, 베르크, 로안, 카셀, 리아 | **마르딘**(짐작 칸), **카셀**(마르딘이 장부에 적어 줌), **리아**(마르딘의 공책 짐작 칸에서 우연히 읽음). 도아는 공책을 봤지만 "글씨 되게 작다" — 읽지 못함 |
| 베르크 | 복원 성공 기록이 없는 멸종종의 후보 이름을 안다. 그 가치를 그의 의뢰처가 곧바로 알 수 있다 | **후보가 있다는 것, 마르딘이 이름을 말하지 않는다는 것**만 안다. 이름을 알아내려는 동기가 생긴다 (제11화의 갈등) |
| 마을 소문 | '아우렐'이라는 종명이 소문에 오른다. 장터·마부를 통해 마을 밖으로 나간다 | "옛 기록에 있는 무슨 짐승을 닮았대"까지 |
| 외부 세력 | 이름이 마을 밖으로 퍼지면 밀매망(F13)이나 다른 기관이 움직일 근거가 일찍 생긴다. D-009의 정신(생존종 정보의 통제)이 약해진다 | 정보가 기록과 관계자 사이에 머문다. 베르크가 의뢰처에 무엇을 전하는지는 그가 아는 만큼으로 제한된다 |
| 마르딘의 인물상 | 의심스러운 민간 연구원과 마을 사람들 앞에서 검증 안 된 종명을 말하는 것은 '과보호 경향'과 어긋난다 | **이름을 말하지 않는 이유를 정직하게 밝힌다**: "확인 안 된 이름을 지금 말하면, 이 마을에는 그 이름만 남습니다. 그 이름을 듣고 찾아오는 사람도 생기고요." 숨기는 것이 아니라 **공개를 미루는 판단**이다. 질문에 거짓말하지 않는다 |
| D-071의 요구 | 충족 | 충족. 마르딘은 닮은 종이 있다는 것, 부족한 정보(어린 개체 기록, 표본 대조, 측정, 출신)를 구체적으로 말한다. 이름만 기록으로 돌린다 |
| 독자 | 이름을 안다 | **리아의 눈으로 이름을 안다.** 제한 시점이 자연스럽게 정보를 운반한다 |
| 제10화 이후의 정합성 검증 | 모든 인물의 반응(특히 베르크, 저지대 아저씨, 소문)을 '아우렐'을 안다는 전제로 다시 맞춰야 한다 | 제10화의 한 줄("아우렐은")만 바꾸면 된다 |
| 12장(증거 대조) | 베르크가 이미 이름을 알므로, 그의 서류가 그 이름을 담고 있으면 '어떻게 알았나'가 증거가 되지 못한다 | 베르크의 서류나 말에 그 종명이 나오면 **"어디서 그 이름을 알았는가"가 그 자체로 증거 후보**가 된다 (F13, 12장). 단, 이것은 가능성이며 확정하지 않는다 |
| 수정 범위 | 없음 | 제9화 2곳, 제10화 1곳 (§4) + 정본 문서 4곳 |

- **권장: B.** 기존 정본의 공개 계획(첫 모험 중 '닮음'의 확인)과 맞고, 마르딘의 인물상과 D-009의 정신을 지키며, 12장의 증거 대조에 쓸 수 있는 여지를 남긴다.

## 5. A를 택했을 때 해야 할 것

- 제10화 이후 모든 회차에서 베르크와 마을이 '아우렐'을 안다는 전제로 쓴다.
- 제11화 이후: 소문이 장터를 통해 마을 밖으로 나가는 경로, 베르크가 의뢰처에 종명을 전하는 것(확정하지 않되 가능성), 외부 인물의 등장 시점을 다시 설계한다.
- 12장의 증거 대조에서 '종명을 어떻게 알았나'를 쓰지 않는다.
