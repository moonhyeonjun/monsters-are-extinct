## 2. 원고 현상의 원인 구분

> A: 환류기관이 직접 일으킨 현상 / B: 자연환경이 주된 원인이고 기관이 일부 영향을 준 현상 / C: 원인을 아직 확정하면 안 되는 현상

| 현상 | 구분 | 판단 |
|---|---|---|
| 낮에도 뿔싹 끝에 맺힌 이슬 | **A** | 그늘진 다리 밑의 낮에는 하늘로의 복사 냉각이 거의 없다. 표면을 능동적으로 식히는 작용이 있어야 한다 |
| 털끝의 물방울 | **A + B** | 기관이 피부 쪽을 식힌다(A). 물가의 습한 공기가 이슬점에 가깝다(B) |
| 차가운 돌과 돌턱의 결로 | **A(닿은 자리) + B(다리 밑 전체)** | 짐승이 누운 돌턱은 몸이 닿은 면을 통해 식는다(A). 그늘, 물, 고인 찬 공기 때문에 다리 밑은 원래 서늘하다(B). 리아가 말한 "요즘 더 차가워진" 변화는 짐승이 온 뒤의 차이다 |
| 다리 아래 틈의 국지적인 안개 | **B** | 닫힌 틈에 찬 공기와 습기가 고인다(자연 미기후). 짐승의 따뜻하고 습한 날숨이 더해져 안개가 진다(일부 영향). 기관이 안개를 '만든' 것이 아니다 |
| 느린 박자 | **A(박자 자체), C(지각)** | 기관의 맥동이 몸을 거쳐 돌에 전해진다(A-2 설계 기준). 리아만 느끼는 까닭은 정하지 않는다(Q-감각-02·03) |
| 창유리의 떨림 | **C** | 집과 돌다리의 거리(Q-지리-03), 수차·바람·물문, 마렌의 반응(F15)이 얽혀 있다. 기관의 진동으로 정하면 '영향 반경'이 지나치게 커진다. 정하지 않는다 |
| 산 바위의 박자(제13화) | **C** | 짐승은 멀리 있었다. 천둥의 앞자락일 수도, 다른 것일 수도 있다. 아우렐의 기관으로 설명하지 않는다 |
| 리아의 제한적인 감각 | **C(원인)** | 감각의 대상 일부는 A(맥동)다. 감각의 기원은 정하지 않는다(D-004, D-022, D-125) |

- 영향 반경 [제안]
  - 기관의 직접 작용은 **짐승의 몸 표면과 닿은 자리, 둘레 몇 걸음**까지다.
  - 그 너머의 서늘함, 습기, 안개는 자연 미기후가 주된 원인이다.
  - 모든 현상을 기관 하나로 설명하지 않는다.

## 3. 해부 구조 후보 비교 [제안]

| 후보 | 구조 | 원고와의 맞음 | 박동 | 열 배출 | 약점 |
|---|---|---|---|---|---|
| ① 중심 조직 + 분지관 (C+B) | 목뿌리의 층판 중심 조직에서 관이 뿔싹 받침, 피부 밑, 배 쪽 피부로 뻗는다 | 높음. 뿔싹·털끝·닿은 돌을 한 기관으로 설명한다 | 중심 조직의 맥동 | 숨길(기관·허파) 곁이라 날숨으로 내보내기 쉽다 | 관이 길어 열 손실이 있다 |
| ② 뿔싹 국소형 | 뿔싹 밑에 한 쌍의 작은 층판 조직. 피부 쪽은 별도의 관 그물 | 중간. 뿔싹은 잘 맞지만 털끝·배 쪽은 따로 필요하다 | 두 곳의 맥동(리아의 '하나의 박자'와 덜 맞음) | 머리의 피로 열이 들어가 뇌가 데워질 위험 | 열을 버릴 길이 불리하다 |
| ③ 피부 전체형 | 중심 없이 피부 전체에 관 그물(B만) | 털끝은 잘 맞는다 | 박동의 근원이 약하다(A-2와 어긋남) | 피부로 흩어 보냄 | 느린 박자를 설명하지 못한다 |
| ④ ①에 수동 보조를 더함 | ① + 뿔싹·털끝의 수동 냉각 구조(열이 적은 가는 끝, 물방울이 붙기 쉬운 털끝) | 가장 높다. 밤에는 싸고 낮에는 비싸다 | ①과 같다 | ①과 같다 | 설명할 것이 늘어난다 |

- **권장: ④(C+B에 수동 보조를 더한 형태).**
  - D-124의 대표 해부 설계 기준(C+B)을 따르는 변형이다.
  - 다른 종이 C+B를 그대로 따른다고 정하지 않는다.

## 4. 권장 해부 구조 — 작가용 해부도 [제안]

| 항목 | 설계 | 표시 |
|---|---|---|
| 1. 중심 조직의 위치 | 목뿌리. 숨통 앞, 첫 갈비뼈 바로 위. 큰 혈관과 숨통 사이에 끼어 있다 | 가설 |
| 2. 뿔싹·털끝·피부와의 연결 | 굵은 관 둘이 턱 밑을 지나 목을 타고 올라가 **뿔싹 받침**(뿔싹 밑의 스펀지 같은 모세혈관 받침)에 닿는다. 가는 관들이 목·어깨·등 피부 밑으로 퍼져 털뿌리에서 솔처럼 끝난다. 배 쪽 피부에도 성긴 관 그물이 있다 | 가설 |
| 3. 열을 옮기는 조직 | 관 속에는 동맥·정맥과 따로 **용액관**이 나란히 간다. 찬 쪽(표면)에서 데워진 용액이 중심으로 와서, 중심의 층판이 그 열을 피로 넘긴다(§5 모델 M1) | 가설 |
| 4. 수분 응결 | 뿔싹 받침과 털끝이 공기의 이슬점 아래로 식으면 그 면에 물이 맺힌다. 털끝은 가늘고 열이 적어 빨리 식는다. 물방울이 잘 붙는 결이 있다 | 가설(털끝 결은 미결) |
| 5. 박동과 진동 | 중심 층판이 날숨과 맞물려 천천히 수축한다(호흡 같은 간격, aurel §2). 그 움직임이 갈비뼈와 누운 배·다리를 거쳐 돌에 미세하게 전해진다 | 가설 |
| 6. 대사 비용 | 밤에는 수동 냉각이 거들어 싸다. 낮에는 능동으로 식혀야 해 비싸다(§5-3) | 가설 |
| 7. 어린 개체의 발달 | 중심 조직이 작고 판이 얇다. 털끝 쪽 관이 아직 성기다. 뿔싹은 싹이다(성체의 긴 뿔은 미정) | 가설 / 성체는 미결 |
| 8. 굶주림·상처·스트레스 | 연료가 모자라면 맥동이 흐트러지고, 이슬이 갑자기 많아졌다가 끊긴다(D-036의 세 방향). 다친 다리는 기관 자체가 아니라 먹이와 움직임을 줄여 불안정을 키운다 | 확인(불안정, aurel §2) + 가설(모습) |
| 9. 적출 시 남는 것 | 중심 조직과 굵은 관 일부는 꺼낼 수 있다. 피부 밑 솔과 뿔싹 받침은 찢기거나 남지 않는다. 연조직이라 금방 썩는다(§6) | 가설 |
| 10. 다른 환류종과의 공통점·차이 | 공통: 층판 중심 조직과 분지관(설계 기준). 아우렐만의 것: 숨길 곁의 열 배출, 뿔싹 받침, 털끝의 수동 보조. 네피라(열이 갈 곳만 정함)나 카르녹(발바닥의 열 저장)과 다르다 | 가설 |

- 광물 조직에 대해
  - 아우렐의 중심 조직에는 오래 남는 광물층을 두지 않는 쪽을 권한다.
  - 용액관의 작동에 소금 같은 녹은 물질이 쓰일 수는 있다. 그러나 굳은 광물층은 기능상 필요하지 않다.
  - 그래서 아우렐의 기관은 **오래 남지 않는다**(§8의 역사적 뜻).

```
       └──────── 분지관(동맥·정맥·용액관이 나란히) ────────┘
                              │ 데워진 용액
                              ↓
          [중심 층판 조직 — 목뿌리, 숨통 앞] ⇄ [큰 혈관]
                              │ 피로 넘긴 열
                              ↓
          [숨통·허파 벽] → 따뜻하고 습한 날숨 → (찬 틈에서) 안개
  박동: 중심 층판의 느린 수축(날숨과 맞물림) → 갈비뼈·배·다리 → 돌·흙(리아가 느끼는 매질)
  비용: 먹이 → 대사 → 능동 수송의 일
```

## 5. 열 이동과 응결 기전 비교

### 5-1. 모델 M1 — 용액 순환 열펌프형 (능동)

- 열이 들어오는 곳: 뿔싹 받침, 털뿌리, 닿은 배 쪽 피부(표면을 이슬점 아래로 식힌다)
- 이동 경로: 표면의 열이 용액관의 용액으로 들어가 중심 조직으로 온다.
- 배출: 중심 층판이 그 열을 피로 넘긴다(찬 쪽에서 더운 쪽으로, 일이 든다). 열은 숨통·허파 벽을 거쳐 날숨으로 나간다.
- 능동 수송의 에너지: 층판의 이온 펌프가 먹이에서 온 에너지를 쓴다.
  - [실제 원리] 콩팥은 능동 수송과 역류 증폭으로 농도 차를 만든다.
  - [추정] 녹은 물질이 묽어질 때 열을 빼앗고 진해질 때 열을 내놓는 성질로 열을 옮기는 '용액 열펌프'는 창작상의 생리다. 실제 동물에서 알려진 기관은 아니지만, 일을 들이는 한 열역학과 어긋나지 않는다.
- 작동 조건: 공기가 습하고 서늘해 이슬점과의 차가 작을수록 적은 일로 맺힌다. 덥고 마른 공기에서는 거의 맺히지 않는다.
- 낮과 밤: 낮에는 모두 능동이라 비싸다. 밤에도 같은 방식이면 불필요하게 비싸다.
- 어린 개체의 한계: 중심 조직이 작아 펌프 능력이 낮고, 금방 지친다.
- 불안정할 때: 연료가 떨어지면 펌프가 들쭉날쭉해져 냉각이 갑자기 세졌다가 끊긴다.

### 5-2. 모델 M2 — 차단·복사형 (수동)

- 들어오는 곳: 없다. 몸의 열을 뿔싹과 털끝으로 **보내지 않는다**(역류 차단).
- 경로·배출: 가는 끝이 맑은 밤에 하늘로 열을 잃어 스스로 식는다(복사 냉각).
- 에너지: 거의 들지 않는다. [실제 원리] 순록 다리의 역류 차단, 풀끝 이슬과 같다.
- 조건: 맑고 바람 없는 밤에만 잘 된다. 그늘과 낮에는 거의 안 된다.
- 한계: 낮의 뿔싹 이슬(제1권 제3화)과 짐승이 닿은 돌의 냉각(제2화)을 설명하지 못한다.

### 5-3. 권장 — M3(M2 + 작은 M1)

- 밤과 새벽: 주로 M2. 싸다. 뿔싹과 털끝에 이슬이 잘 맺힌다.
- 낮의 그늘, 닿은 돌: M1이 조금 일한다. 비싸서 오래 못 한다. 그래서 낮의 이슬은 습한 그늘에서만, 적게 맺힌다.
- 불안정할 때: M1이 들쭉날쭉해진다. M2는 몸이 식어 갈 때 오히려 세질 수 있다(몸의 열을 아끼려 끝을 더 차단). 쇠약한 개체 둘레가 더 차가워 보일 수 있다.

### 5-4. 크기 어림

> 실제 물리량, 가정값, 창작상 추정을 나눈다.

| 구분 | 값 |
|---|---|
| [실제 원리] 물의 응결 숨은열 | 1g에 약 2.5kJ(0~10℃) |
| [실제 원리] 맑은 밤 지표의 복사 냉각 | 1m²에 수십~100W 안팎 |
| [실제 원리] 자연 이슬량 | 하룻밤 0.1~0.5mm 안팎(1m²에 0.1~0.5kg) |
| [실제 원리] 포유류 기초대사(클라이버 식) | 하루 약 70×(체중 kg)^0.75 kcal |
| [가정값] 어린 아우렐의 체중 | 40~60kg (정본 미정, Q-생물-02) |
| [가정값] 식는 면(뿔싹 받침, 털끝, 닿은 배)의 실효 넓이 | 0.05~0.1m² |
| [추정] 기초대사 | 체중 50kg이면 하루 약 1,300kcal = 약 5.5MJ, 평균 약 64W |
| [추정] 눈에 보이는 이슬(시간당 약 10g) | 숨은열 시간당 약 25kJ, 평균 약 7W. 기초대사의 약 10%에 해당하는 열을 치워야 한다. **2026-10-23 검증: 넓은 면을 가정한 과대 어림이다. 뿔싹처럼 작은 면은 시간당 0.1g 안팎으로도 눈에 보인다(§13-4)** |
| [추정] 밤의 수동 몫 | 0.1m²×약 60W/m² = 약 6W. 밤에는 거의 수동으로 감당한다 |
| [추정] 낮의 능동 몫 | 같은 양을 펌프로 옮기면 일이 수 W 안팎, 기초대사의 몇 %~10% 안팎. 쇠약한 어린 개체에게는 무겁다(불안정과 맞음) |
| [추정] 밭 1헥타르에 이슬 0.5mm | 물 약 5,000kg, 숨은열 약 12GJ. 기초대사 2,000일 이상. 불가능 |

- 결론
  - 몸과 닿은 돌, 둘레 몇 걸음의 습기는 감당할 수 있다.
  - 계절을 바꾸거나 밭에 이슬을 대는 일은 불가능하다(aurel §2, return-organ-design §11-1과 맞음).

## 6. 박동과 환류 감각의 관계 [제안]

- 박동의 빈도
  - 원고: 호흡 같은 느린 간격. [추정] 몇 초에 한 번.
  - [실제 원리] 수십 kg 포유류의 심박은 1분에 수십~백 번 안팎이다. 박자는 심장보다 느리고 숨에 가깝다.
  - 리아는 자기 심장과 숨이 아님을 확인했다(제1권 제12화). 짐승 자신의 날숨과 맞물린 박동이라는 설계가 원고와 맞는다.
- 전달: 중심 조직의 수축 → 갈비뼈 → 누운 배와 다리 → 젖은 돌과 흙 → 리아의 손바닥(뼈 전도: 팔꿈치, 어금니, 무릎뼈)
  - [실제 원리] 물을 머금은 돌과 흙은 낮은 진동을 잘 전하고, 거리에 따라 빠르게 약해진다(단기 규칙의 '수십 걸음'과 맞음).
- 다렌이 못 느끼는 것: 진동이 보통 사람의 감각 아래라는 데까지만 쓴다. 리아가 왜 느끼는지는 정하지 않는다.
- 이 설계가 정하지 않는 것
  - 창유리의 떨림(C)
  - 산 바위의 박자(C)
  - 감지 거리(Q-감각-01)
  - 다른 사람의 지각(Q-감각-02)
  - 감각의 기원(Q-감각-03)
- 이 설계가 리아의 감각을 혈통이나 몸속 기관으로 설명하지 않는다(D-125).

## 7. 어린 아우렐의 기관 외형 묘사 (작가용, 삽화 기준) [제안]

| 항목 | 묘사 |
|---|---|
| 위치와 크기 | 목뿌리, 숨통 앞. 어른 주먹만 하다(길이 8~10cm, 너비 약 6cm, 두께 약 4cm). 몸무게의 1~2% 안팎 |
| 전체 윤곽 | 조금 납작한 알 모양. 한쪽(숨통 쪽)이 오목하게 숨통을 감싼다. 위아래 끝에서 굵은 관이 뿌리처럼 나간다. 동그란 구슬이 아니다 |
| 색과 질감 | 살아 있을 때 포도주빛에서 밤색 바탕, 얇은 윤기 있는 껍질. 껍질 너머로 엷은 진주빛 띠가 비친다. 탄력 있게 단단하다. 만지면 몸보다 조금 서늘하다 |
| 표면 | 동심원 주름. 관이 나가는 자리에 혈관이 촘촘히 모인다 |
| 단면 | 얇은 판이 수십 겹 쌓였다. 판 사이에 모세혈관과 용액 칸이 있다. 판의 겹수는 나이에 따라 늘 수 있으나, 무엇을 기록하는지는 정하지 않는다 |
| 층판 조직 | 붉은 근육 판과 엷은 분비 판이 번갈아 있다 |
| 분지형 관 | 산호빛 분홍의 굵은 관 둘(손가락 굵기)이 위로 간다. 흰 실 같은 가는 관 수십 가닥이 피부 밑으로 간다. 끝은 거의 투명하다. 뿔싹 받침은 연분홍 스펀지 모양이다 |
| 주변 기관과의 연결 | 숨통 앞면에 붙어 있고 큰 혈관이 둘러싼다. 숨통 벽 쪽으로 얇은 관 그물이 나간다(열을 날숨으로) |
| 박동할 때 | 몇 초에 한 번, 아래 끝에서 위 끝으로 느린 수축 물결이 지나간다. 날숨에 맞춰 조금 오그라든다 |
| 죽은 뒤 | 몇 번 떨리다 멎는다. 검어지고 윤기가 사라진다. 관은 늘어진다. 며칠 안에 무르고 썩는다 |
| 오래 보존했을 때 | 소금에 절이거나 알코올에 담그면 색이 빠진 채 모양과 판의 결이 남는다. 말리면 쪼그라든 갈색 덩이와 소금 껍질이 된다. 오래 남는 광물 뼈대는 없다 |
| 그리지 않을 것 | 발광, 보석 같은 광택, 몸과 떨어진 구슬, 기계 같은 모양 |

## 8. 작중 도감과 작가용 해부도의 차이

### 8-1. A. 작중 공개 도감 (기록 카드 형식) [제안]

> 리아와 당시 연구자들이 실제로 확인할 수 있는 것만 적는다. 해부도는 넣지 않는다. 이 카드는 장래의 작중 문서(서식국 기록, 견습 공책의 정리 등)에 쓸 수 있는 틀이다. 제1권 인물이 아는 범위를 넘지 않는다.

| 칸 | 내용 |
|---|---|
| 이름 | 기록 속 종 '아우렐'과 닮은 미확인 개체(종 동정 보류, D-012·D-071·D-074) |
| 공식 판정 | 멸종 판정(D-005) |
| 겉모습 | 네 다리, 날개 없음, 이마에 짧은 뿔싹 한 쌍. 크기는 어림(몸통 약 90~110cm, 작업 가정) |
| 관찰된 현상 | 뿔싹 둘레의 이슬(낮에도, 습한 그늘에서). 털끝의 물방울. 누운 돌이 차가워지고 물방울이 맺힘. 둘레 몇 걸음의 습기 변화 |
| 관찰자 한 사람의 보고(검증 안 됨) | 낮은 울림(리아). 다른 관찰자는 느끼지 못함 |
| 행동 | 사람을 피한다. 서늘하고 습한 곳에 머문다. 다친 다리를 딛지 않는다(그 개체의 상태, 종의 성격으로 일반화하지 않음, D-039) |
| 주의 | 다가가지 않는다. 보관 시설의 습기에 영향을 줄 수 있다(카셀의 우려, aurel §2) |
| 근거 자료 | 오래된 글과 그림(다 자란 짐승), 이 개체의 관찰 기록. 어린 개체의 기록은 없다 |
| 알려지지 않은 것 | 몸속 구조, 기관의 위치, 원리, 성체 외형, 원래 서식지 |
| 기록의 한계 | 옛 그림과 기록은 정확한 종 동정이 아닐 수 있다(D-126) |

### 8-2. B. 작가용 해부도

- 위 §4·§5·§7. 각 줄의 표시를 따른다.
  - 확인: D-027, 원고 현상
  - 가설: 위치, 관, 용액 열펌프, 날숨 배출, 맥동과 날숨의 맞물림
  - 미결: 성체 구조, 털끝의 미세 구조, 판의 기록, 체중
  - 위험: §9
- 작가용 설계가 있다는 이유로 제1권 인물(마르딘, 카셀, 리아)이 이 내용을 알지 않는다. 원고의 마르딘은 "닮음과 동정은 다르다"까지만 말한다.

## 9. 대토벌 시대 식별과 보존 표본의 관계 [제안]

- **증표로 오인했을 수 있는 부위:** 뿔(뿔싹이 자란 것).
  - 이슬이 맺히는 자리라 '그 짐승의 힘이 있는 곳'으로 여겨지기 쉽다.
  - 오래 남는다.
  - 그러나 실제 기관은 목뿌리의 연조직이고, 뿔은 기관이 아니다.
  - 기관과 증표가 어긋난 대표 사례가 될 수 있다(D-126, hunt-era-identification §9-1). 어떤 장부에 그렇게 적혔는지는 정하지 않는다.
- **당시 기술로 내부 조직을 발견할 수 있었나:** 해체하던 백정이 목뿌리의 '처음 보는 덩이'를 볼 수는 있었다. 그러나 무엇을 하는지 몰랐다. 금방 썩어 증표로 쓰기 어려웠다.
- **진짜 기관과 대용 증표의 차이:** 진짜는 연조직이라 며칠 안에 썩는다. 대용 증표(뿔, 털가죽)는 남는다. 그래서 장부의 '아우렐'은 뿔의 수로 셌을 수 있고, 다른 뿔 가진 짐승이 섞였을 수 있다.
- **오래된 그림·뼈·말린 표본으로 알 수 있는 것의 한계**
  - 그림은 다 자란 짐승이고 과장이 섞인다(제1권 제4화의 긴 뿔).
  - 뼈와 뿔은 형태와 크기를 준다.
  - 말린 가죽은 털의 모양을 주지만 현상은 주지 않는다.
  - 기관 자체는 남지 않는다.
- **현재 분류학자가 오래된 표본으로 판별할 수 있는 것 (후보)**
  - 머리뼈와 뿔심의 형태. 나이대에 따른 차이.
  - 뿔 밑 뼈의 혈관 구멍과 홈(뿔싹 받침의 촘촘한 관이 드나든 자리)이 유난히 많은지
  - 털의 끝 모양
  - 위험: 이것들은 종 동정(D-012 둘째 단계)을 돕는 단서다. 공개 시점과 함께 정해야 한다.
- 실제 아우렐 표본의 존재와 소장 기관은 정하지 않는다(D-125).

## 10. 물리·생물학적 개연성 검증 요약

- 에너지 보존: 모든 냉각에 일이 들거나 하늘로의 복사가 쓰인다. 먹이로 치른다. 영향 반경은 몇 걸음이다.
- 실제 원리로 받치는 것: 이슬점과 숨은열, 복사 냉각, 역류 교환과 차단, 콩팥형 능동 수송, 날숨의 열·수분 배출, 뼈 전도, 몸 크기와 박동, 연조직의 부패와 액침 보존.
- 창작상 추정인 것: 용액 열펌프, 박동과 날숨의 맞물림, 털끝의 결.
- 어린 개체 하나의 한계: 시간당 수 g~십수 g의 이슬과 닿은 돌의 냉각. 쇠약하면 흔들린다.

## 11. 기존 원고와의 충돌 위험

| 위험 | 처리 |
|---|---|
| 창유리 떨림을 기관으로 정하면 영향 반경이 커진다 | C로 둔다 |
| 산 바위의 박자를 아우렐로 정하면 거리 규칙이 깨진다 | C로 둔다(원고도 '알 수 없었다') |
| 안개를 기관의 산물로 쓰면 '물을 만드는 짐승'이 된다 | B로 둔다(미기후 + 날숨) |
| 성체의 긴 뿔(옛 그림)과 어린 개체의 뿔싹 | 성체 구조는 정하지 않는다 |
| 마르딘이 기관을 아는 것처럼 보이는 장면 | 원고는 "닮음과 동정은 다르다"(D-071)에서 바뀌지 않는다 |
| 표본 단서가 종 동정을 앞당긴다 | §9의 위험 표시. 공개 시점은 승인 사항 |

### 13-3. 열을 옮기는 동력과 열교환 방식

- 콩팥에 대한 주의
  - [실제 원리] 콩팥은 능동 수송과 역류 배열로 **농도 차**를 쌓는다. 열을 옮기지 않는다.
  - 이 문서는 콩팥이 열펌프를 설명한다고 보지 않는다. 빌려 오는 것은 일반 원리 둘뿐이다.
    1. 막의 능동 수송은 먹이의 에너지로 농도 차를 만들 수 있다.
    2. 역류 배열은 관 속을 오가는 두 흐름 사이에 열(또는 농도)을 주고받게 해, 몸의 끝을 몸통의 열에서 떼어 놓는다.
- 동력 후보 비교 [제안]

| 후보 | 동력 | 식는 곳 | 물리적 근거 | 약점 |
|---|---|---|---|---|
| 가. 용액(삼투) 순환형 | 중심 조직이 능동 수송으로 용액을 진하게 만든다. 이때 중심에서 열이 나온다 | 뿔싹 받침. 진한 용액이 둘레의 물을 받아 묽어질 때 열을 빨아들인다 | [실제 원리] 섞임열(희석열)은 실제로 있다. 묽어질 때 열을 빨아들이는 용액이 있다 | 희석열은 1몰에 수 kJ 이하로 작다. 든 일에 비해 옮기는 열이 적다. 그런 용질을 몸이 쓴다는 것은 창작 가정이다 |
| 나. 탄성 열효과형 | 근육 판이 탄성 판을 늘였다 놓는다. 늘이면 데워지고 놓으면 식는다 | 놓인 판의 둘레(중심 조직 안) | [실제 원리] 고무 같은 탄성체의 열효과 | 식는 곳이 중심이다. 찬 기운을 뿔싹까지 관으로 보내야 해서 새는 열이 크다 |
| 다. 결정이 녹는 흡열 | 결정이 녹으며 열을 크게 빨아들인다 | 결정이 녹는 곳 | [실제 원리] 질산염 같은 소금은 녹을 때 열을 빨아들인다 | 결정이 쌓이는 조직이 있어야 한다. 채택한 '굳은 광물층 없음'과 어긋난다 → **제외** |

- 권고: **가(용액 순환형)를 작가용 1순위 가정으로 둔다.**
  - 일(진하게 만들기)은 중심에서, 식는 일(묽어지기)은 끝에서 일어난다. 냉장고의 압축기와 냉각부가 나뉜 것과 같다.
  - 채택한 구조(목뿌리 중심 조직 + 뿔싹 받침)와 맞는다. 결정을 쓰지 않아 연조직 모델과도 맞는다.
  - [창작 가정] 묽어질 때 열을 빨아들이는 용질을 아우렐이 몸에 지닌다. 무엇인지는 정하지 않는다.
- 열교환 방식
  - 용액관은 굵은 관 안에서 가는 흐름과 오는 흐름이 맞닿아 지나는 역류 배열이다. 끝으로 가는 따뜻한 용액이 돌아오는 찬 용액에 열을 넘기고, 식은 채 뿔싹 받침에 닿는다. [실제 원리] 순록과 물새의 다리에서 피가 이렇게 열을 주고받는다.
  - 뿔싹 받침과 머리뼈 사이에는 열을 막는 층(각질, 지방, 털)이 있어야 한다. 없으면 펌프가 몸의 열과 싸우게 된다.

### 13-4. 응결량과 비용 어림

- 계산 방법 [실제 원리]
  - 표면이 이슬점보다 낮으면 맺히는 물은 '공기와 표면의 수증기 밀도 차 × 물질 전달 계수'다. 계수는 바람 없는 공기에서 초속 0.5~1cm 안팎이다.
  - 표면에는 응결 숨은열(1g에 약 2.45kJ)과 공기에서 오는 열이 함께 들어온다. 이 둘을 치워야 응결이 이어진다.
- 가 후보의 효율(옮긴 열 ÷ 든 일)은 0.1~0.3으로 어림한다. 희석열이 작기 때문이다. [추정]

| 표면 | 조건 | 맺히는 물 | 치울 열 | 능동으로 할 때의 일 | 판단 |
|---|---|---|---|---|---|
| 뿔싹 두 개(약 30cm²) | 낮의 그늘. 공기보다 3℃, 이슬점보다 1~2℃ 낮게 | 시간당 약 0.1g. 작은 물방울 수십 개 | 약 0.2W + 몸에서 새어 드는 열 | 약 1~4W. 기초대사의 2~7% | **가능하다.** 건강할 때는 감당한다. 쇠약하면 가장 먼저 끊길 몫이다 |
| 털끝(약 0.05m²) | 낮의 그늘에서 능동으로 | 시간당 1~2g | 2~5W + 큰 누설 | 10~30W 이상. 기초대사의 15~50% | **어렵다.** 낮의 털끝 물방울은 B(포화에 가까운 공기, 털에 걸리는 안개 방울)로 읽는다 |
| 털끝, 하늘이 트인 맑은 밤 | 수동(복사 냉각 + 역류 차단) | 풀끝 이슬과 비슷하다 | 하늘이 가져간다 | 거의 없다 | **가능하다.** [실제 원리] 털이 두꺼운 짐승의 등에 이슬과 서리가 앉는 일은 실제로 있다 |
| 엎드린 배 아래의 돌(0.2~0.3m²) | 돌을 주변보다 2~3℃ 차게 유지 | (돌이 드러난 뒤 땀) | 돌의 깊은 쪽과 공기에서 오는 열 10~25W 이상 + 배로 새는 몸의 열 | 수십~백 W 이상. 기초대사를 넘는다 | **열펌프로는 불가능하다.** §13-5의 다른 설명이 필요하다 |
| 밭 1헥타르 | 이슬 0.5mm | 물 약 5,000kg | 약 12GJ | — | **불가능하다**(§5-4와 같음). 넓은 지역의 기후 조절을 쓰지 않는 근거 |

- §5-4의 "시간당 약 10g"은 넓은 면을 가정한 과대 어림이었다. 능동의 몫은 그보다 훨씬 작다.

### 13-5. 닿은 돌이 차가워지는 조건 [제안]

- 원고의 사실
  - [원고] 제1권 제1화 146~150행: "물이 아니라 돌이요." 돌다리 아래 돌이 요즘 더 차갑다.
  - [원고] 제1권 제2화 152행: 다른 돌도 빗물에 젖었지만 돌턱의 차가움은 달랐다. 표면에 작은 물방울이 촘촘했다. "돌이 안쪽에서 땀을 흘리는 것 같았다."
  - [원고] 제1권 제9화 379·405·421행: 짐승이 떠난 뒤에는 돌턱, 기둥, 개울가 돌이 같다(손과 환류계). "원인 모름."
  - 곧 **짐승이 그 자리를 쓰는 동안에만** 돌턱이 같은 다리 밑의 다른 돌보다 찼다.
- 열펌프 설명의 문제: 위 표대로 엎드린 몸으로 돌의 열을 빨아내려면 기초대사를 넘는 일이 든다. 쇠약한 어린 개체에게 맞지 않는다.
- 권고 설명 — **차단과 덮개** (수동. 비용이 거의 없다)
  1. 다리 밑 돌턱은 찬 개울물과 기초 돌에 이어져 원래 서늘하다(B).
  2. 보통 짐승은 엎드리면 배로 돌을 데운다. 아우렐은 배 쪽 피부로 가는 열을 역류 차단으로 막는다. 쇠약해서 몸의 열을 아낄 때는 차단이 더 세진다(§5-3).
  3. 그래서 엎드린 몸은 돌을 데우지 않는다. 오히려 위의 따뜻한 공기와 빛을 가려 덮개 노릇을 한다. 돌턱은 아래의 찬 쪽을 따라가 둘레의 다른 돌보다 몇 ℃ 차가워진다.
  4. 짐승이 틈으로 들어가 돌턱이 드러나면, 찬 돌이 습한 공기에 닿아 땀을 흘린다(제2화).
  5. 짐승이 아주 떠나면 몇 시간에서 하루 사이에 둘레의 돌과 같아진다(제9화).
- 이 설명의 뜻
  - 채택한 구분 'A(닿은 자리) + B(다리 밑 전체)'는 그대로다. 다만 A의 내용이 '열펌프'에서 '차단'으로 바뀐다.
  - 돌의 차가움은 힘의 표시가 아니라 **몸의 열을 아끼는 쇠약한 짐승의 흔적**이 된다. 첫 번째 침묵의 오해(굶주린 짐승의 현상이 더 무섭게 보였다)와 같은 원리다(first-silence-causality §11).
  - 이 수정을 받아들일지는 사용자 확인이 필요하다(§14 1번).

### 13-6. 날숨으로 열을 내보내는 경로의 한계

- 옮기는 열이 뿔싹 몫(수 W 이하)뿐이면, 중심에서 나오는 열(옮긴 열 + 든 일)은 기초대사의 몇 %다. 몸 전체의 평소 방열(피부, 숨)로 충분하다. **날숨이라는 특별한 출구가 꼭 필요하지 않다.**
- [실제 원리] 쉬고 있는 수십 kg 포유류의 숨은 기초대사의 10~20% 안팎의 열을 내보내고, 그 대부분은 물을 증발시키는 열이다. 숨으로 열을 더 버리려면 숨을 더 쉬어야 하고 물을 더 잃는다.
- 주의: 목뿌리는 뇌로 가는 동맥 곁이다. 중심 조직이 내놓는 열이 뇌로 가는 피를 데우면 안 된다. 열은 심장으로 돌아가는 정맥 쪽으로 넘겨야 한다. [실제 원리] 발굽 짐승 일부는 뇌로 가는 동맥 피를 코에서 식은 정맥 피로 식히는 그물(경동맥 그물)을 가진다.
- 권고: §4의 '숨통 벽으로 열을 넘김'은 **선택할 수 있는 설계**로 낮춘다. 원고에 쓰지 않는다. 틈의 안개(제1권 제1화 262행)는 그대로 B다(찬 틈 + 보통 짐승도 내쉬는 따뜻하고 습한 숨).

### 13-7. 박동의 기능 — 날숨과 맞물리지 않아도 되는 까닭 [제안]

- 혈관과 따로 도는 용액관 순환에는 제 펌프가 있어야 한다. 중심 층판의 근육 판이 그 순환의 심장 노릇을 한다고 두면, 느린 박동에 기능이 생긴다.
  - [실제 원리] 개구리·도롱뇽 같은 양서류와 일부 파충류에는 림프를 따로 밀어내는 '림프 심장'이 있다. 심장과 다른 박자로 뛴다.
- 이렇게 두면 박동과 날숨의 직접 동기화가 필요 없다. aurel §2의 '호흡 같은 간격'은 빠르기를 견준 말로만 읽는다.
- 쇠약해서 이 펌프가 흔들리면 박자가 고르지 않고, 뿔싹 이슬이 갑자기 늘었다가 끊긴다(D-036의 세 방향, §4 8번).
- 정하지 않는 것: 박동의 실제 간격, 리아가 이 박동을 느끼는 까닭(Q-감각-02·03).

### 13-8. 자연 미기후와 기관 작용의 구분

| 현상 | 자연 미기후만으로 생기는 조건 | 기관이 더하는 것 | 가르는 방법(작중 검증의 틀) |
|---|---|---|---|
| 다리 밑의 서늘함, 젖은 돌 | 그늘, 찬 개울물, 고인 찬 공기, 늦게 데워지는 돌 | 없다 | — |
| 돌턱만 더 찬 것 | 거의 없다(같은 다리 밑 기둥은 덜 차다) | 차단과 덮개(§13-5) | 짐승이 떠난 뒤 다른 돌과 같아지는가(제1권 제9화의 손·환류계 비교) |
| 털끝의 물방울 | 포화에 가까운 공기, 안개, 하늘이 트인 밤의 복사 냉각 | 밤의 차단(수동). 낮에는 거의 없다 | 같은 자리의 풀끝·거미줄에도 맺히는가 |
| 낮의 뿔싹 이슬 | 안개가 끼면 생길 수 있다 | 능동 냉각(작은 몫) | 안개 없는 그늘에서, 둘레 풀끝은 마른데 뿔싹에만 맺히는가 |
| 틈의 안개 | 찬 틈 + 습기 | 날숨의 물기(보통 짐승과 같다) | 기관과 무관 |
| 창유리 떨림, 산 바위의 박자 | — | — | C로 둔다 |

- 이 표는 장래의 작중 검증(테오의 측정, 서식국 기록)에 쓸 수 있다. 제1권 제9화에서 손과 환류계로 세 돌을 견준 장면이 이미 그런 검증이다.

### 13-9. 쇠약한 어린 개체의 대사 비용

| 일 | 비용(기초대사 대비) | 쇠약할 때 |
|---|---|---|
| 하늘이 트인 밤의 수동 냉각, 배의 차단 | 거의 없다. 오히려 열을 아낀다 | **세진다.** 몸의 열을 아끼려고 끝과 배를 더 막는다 → 둘레가 더 차가워 보이고 밤 이슬이 늘 수 있다 |
| 낮의 뿔싹 능동 냉각 | 2~7% | **먼저 끊긴다.** 연료가 모자라면 들쭉날쭉하다가 멎는다 |
| 털끝·돌의 능동 냉각 | 15%~100% 이상 | 하지 않는다(애초에 감당하지 못한다) |
| 박동(용액관 펌프) | 작다(1% 안팎으로 어림) | 흔들린다 → 박자가 고르지 않다 |

- 작은 몸은 몸집에 비해 겉넓이가 넓어 열을 빨리 잃고, 여분의 연료(지방)도 적다.
- 결론: 쇠약할수록 **능동 현상은 줄고 수동 현상은 늘어**, 겉으로는 오히려 '더 차갑고 더 이상한 짐승'이 된다.
  - aurel §2의 불안정(세졌다가 약해졌다가 끊김)과 맞는다.
  - D-036의 "예측할 수 없다는 점이 공포를 키웠다"에 생리적 근거를 준다.

## 14. 검증 뒤 권고와 남은 문제

| # | 항목 | 권고 | 상태 |
|---|---|---|---|
| 1 | 닿은 돌의 냉각 | A의 기전을 '열펌프'에서 '차단과 덮개'로 바꾼다(§13-5). A+B 구분은 유지한다 | **사용자 확인 필요** |
| 2 | 낮의 털끝 물방울 | B(포화 공기, 안개 방울)의 비중을 높인다. 밤에는 수동 A | **사용자 확인 필요** |

- 물리적으로 아직 약한 곳(억지로 메우지 않는다)
  - 묽어질 때 열을 빨아들이는 용질을 몸이 지닌다는 것은 창작 가정이다. 실제 동물에는 예가 없다.
  - 희석열이 작아 효율이 낮다. '뿔싹 몫만 감당한다'는 제한이 그 대가다.
  - 목뿌리에서 뿔싹까지 수십 cm의 관에서 새는 열은 역류 배열과 단열로 줄인다고만 두었다. 얼마나 막는지는 어림하지 않았다.
  - 털끝의 미세 구조(물방울이 붙는 결)는 정하지 않았다.
- 원고와 정본에 미치는 영향: 없다. 원고의 현상과 '원인 모름'은 그대로다. return-organ-design §11-1의 [미결]도 그대로다.
