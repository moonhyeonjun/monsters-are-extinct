# 제1~5화 문체 선택 편집 기록

> 관련 결정: D-052, D-053, D-054 · 지침: [style-guide.md](style-guide.md) §8~9 · 진단: [style-diagnosis.md](style-diagnosis.md)
> 상태: 원고에 적용함 (2026-10-20). 원고는 모두 초안이며 사용자 최종 승인 전이다.

## 0. 원칙

- 딱딱함이 두드러지는 장면만 고친다. 회차마다 긴장감과 감정 온도가 다르므로 제6화 문체로 통일하지 않는다.
- 사건, 설정, 복선, 회차 결말은 바꾸지 않는다. 새 사건이나 설정으로 문제를 풀지 않는다.
- 회차의 첫 문장과 마지막 문장, 기록장 복선(F17), 명장면의 주요 행동은 그대로 둔다.
- 새로 넣은 생활 세부(가재 잡기, 볶은 콩, 매미 허물 등)는 인물 관계를 보여 주는 장식이다. 설정이나 복선으로 관리하지 않는다.

## 1. 회차별 변경

### 제1화 〈두 번 핀 꽃〉 — 변경 없음

- 본문을 바꾸지 않는다 (D-011). 이 회차의 일상 말투가 이후 회차의 **기준**이다.
- 기준으로 삼는 목소리:
  - 마렌의 놀림: "새참 가져다 놓으랬지, 흙한테 질문하랬니?", "그럼 흙한테 빵도 먹여 보렴. 네 몫까지!"
  - 도아의 엉뚱함: "둘 중 하나가 더 게으른 거 아니야?", "이상하지. 네가 나보다 빵을 늦게 먹는 거."
  - 다렌의 설명과 농담: "물이 어디로 흘러가는지도 안 적혀 있으면, 그건 지도를 만든 사람이 일을 덜 한 거니까."
  - 리아의 말대꾸: "흙이 대답하려던 참이었는데!", "어른들이 다 보는 건 아니잖아요."

### 제2화 〈닫혀야 할 물문〉 — 조사와 발견 사이

| 장면 | 바뀐 것 | 이유 |
|---|---|---|
| 서쪽 밭 | 다렌의 설명이 길어지고 농담이 붙음: "큰비가 아니면 열 일이 없어서… 열어 두면 물보다 개구리가 먼저 드나들거든." / 관리인에게 "얘는 그냥 물어보는 게 하루에 백 개요." | 다렌의 개성(물길 설명, 농담), 아버지로서의 생활감 |
| 서쪽 밭 | 서술자의 정리 문장("리아는 정말로 알고 있었다. 다만 아는 것과 확인한 것은 다른 일이었다")을 손톱 밑의 흙을 문지르는 행동과 짧은 생각으로 바꿈 | 결론 문장 줄이기 |
| 옛 배수로 | 도아의 흥정: "대신 돌아오는 길에 가재 잡는 거 도와." / "그건 네가 소리를 질러서잖아." | 두 아이가 평소 장난치던 사이임을 보여 줌 |
| 발견 뒤 | "돌아오는 길에 가재 이야기는 둘 다 꺼내지 않았다." | 발견의 무게를 장난이 끊기는 것으로 |
| 첫 목격 | "리아가 아는 것은 하나뿐이었다"를 "울림을 읽을 줄도 몰랐다. 그래도 젖혀진 귀와 떨리는 몸이 하는 말은 알아들을 수 있었다"로 바꿈 | 회차마다 되풀이되는 "~하나뿐이었다" 줄이기, 감각의 한계(D-034) |
| 유지 | 마렌의 "물 두 동이", 이미 깨끗한 솥 가장자리, 경이의 장면, "처음으로 서로를 바라보았다" | — |

### 제3화 〈손을 뻗지 않는 법〉 — 첫 돌봄 실패와 마렌·도아의 반응

| 장면 | 바뀐 것 | 이유 |
|---|---|---|
| 장화 | 마렌이 지나가며 리아의 머리카락을 한 줌 쥐었다 놓음. 아직 덜 말라 있음 | 마렌의 다정함과 의심이 손으로 나옴 |
| 장화 | "어머니는 왜 더 묻지 않았을까. 리아는 혼나는 것보다 그게 더 마음에 걸렸다" → "솔이 같은 자리를 몇 번이나 지나갔다. 차라리 혼이 났으면 했다. 어머니는 끝내 더 묻지 않았다." | 감정 분석을 행동과 아이다운 바람으로 |
| 돌봄 실패 | "자신이 무슨 짓을 했는지, 그제야 알았다 / 떨어뜨릴 뻔한 것은 리아였다" → 돌턱을 짚은 손이 떨어지지 않음, 차가운 돌, "도와주러 온 거였다. 그런데 방금, 저 짐승이 돌턱에서 떨어질 뻔했다. 리아 때문에." | 깨달음은 같고, 도착하는 길을 몸과 끊기는 생각으로 |
| 도아의 소문 | 도아가 두 손을 갈퀴처럼 세우고 으르렁거림. 다른 날이었으면 리아도 같이 으르렁거리며 쫓아갔을 것 | 평소의 장난, 그것이 오늘은 통하지 않음 |
| 도아의 반응 | 거짓말을 들은 뒤 볶은 콩을 혼자 먹으며 걸음. 평소라면 절반은 리아 손바닥에 먼저 쏟아 주었을 콩 | 도아의 서운함을 말 대신 행동으로 (style-guide §8 도아: 농담이 끊기는 것) |
| 마지막 | "아는 것은 하나뿐이었다"를 빼고 "당분간은 아무에게도 말하지 않을 것이다" | 반복 구문 줄이기 |
| 유지 | 첫 문장, 뒷걸음질, 엉덩방아, 물음표 두 개, "내가 너무 가까웠다", '돌다리' → '그곳.' 장면 전체와 마지막 문장 | D-043 유지 항목 |

### 제4화 〈봄이 두 번 찾아오는 자리〉 — 도아의 경구, 카셀의 정보 대사

| 장면 | 바뀐 것 | 이유 |
|---|---|---|
| 빨래터 | "그건 나한테도 말해 주는 사람이 있으니까" → "방앗간 아주머니는 물어보면 대답이라도 해 주거든." | 경구 대신 구체적인 비꼼 |
| 농서 | 마렌: "삽을 꺼내 오랬더니 책을 꺼내 왔구나." | 마렌의 짧고 날카로운 놀림 |
| 카셀 등장 | 자기소개와 신고 목록을 한 호흡에 말하던 대사를 다렌의 질문("조사원이 이런 데까지 무슨 일로.")과 장부를 넘기는 대답으로 나눔. 방앗간 아주머니가 "그것 보라는 듯" 끄덕임 | 정보 전달용 대사를 대화로 |
| 카셀의 신중함 | "아니라는 걸 확인하는 것도 제 일입니다" → "그래서 늑대 발자국을 보러 이 먼 데까지 걸어오는 거고요." / "다렌이 이번에는 정말로 웃었다." | 마른 농담. 신중함은 그대로 (D-045 2) |
| 옛 물문 | 보고형 서술("언제 마지막으로 열었는지…")을 대화로 바꿈. 다렌이 길게 설명함: "열면 물이 옛 배수로로 한꺼번에 빠지오. 다리 밑을 지나서 개울로… 문짝이 우리 할아버지보다 나이가 많아서, 열 때마다 기도부터 하게 되지만." | 다렌의 개성. 물길 작동은 D-030·D-033과 같음 |
| 카셀과 리아 | "그거 둘 다 네가 드는 거냐." / "……끌고 가는 거예요." | 카셀이 아이에게 말하는 방식, 리아의 말대꾸 |
| 카셀이 떠남 | 쓰러진 물동이를 바로 세움. "그 사람이 나빠 보이지 않는다는 것이 오히려 더 무서웠다" → "차라리 그 사람이 무섭게 생겼으면 좋겠다고 생각했다." | 감정 분석을 아이다운 바람으로 |
| 밤 | "할 수 있는 것은… 뿐이었다" 반복을 한 문장으로 | 반복 구문 줄이기 |
| 도아의 마지막 말 | "처음 들은 것부터 다." → "나는 다 말했잖아." 목소리가 갈라짐 "듣자마자 제일 먼저 너한테 뛰어갔잖아. 제일 먼저." | 원칙의 문장 대신 아이의 항변 |
| 결산 문단 | "숨겼다는 사실은 숨길 수 없었다…" 문단을 뺌. 대신 함께 찾아다니던 기억: 허물을 벗다 만 매미, 두 갈래로 자란 무, 돌다리 밑 가재 굴, "그게 뭐가 대단한데" | 결론 대신 관계의 역사로 |
| 유지 | 첫 문장, 농서 문구, "그것도 거짓말이었다", 등불을 낮추는 도아, "나도 어른들한테 말할 줄 알았구나", 화해 없는 이별, 마지막 문장 | D-044·D-045 유지 항목 |

### 제5화 〈떠내려온 물병〉 — 도아의 항변, 마렌의 질문, 감정 해설

| 장면 | 바뀐 것 | 이유 |
|---|---|---|
| 카셀 조사 | "그 숨이 오래가지 않으리라는 것을 알았다. 오늘이 아니면 내일이었다" → "오늘은 아니었다. 오늘만은." | 짧게 |
| 도아의 항변 | "고맙긴 뭐가." / "물어봤으면 했어." / "나 거짓말 안 해." / "그러니까 나한테 거짓말해 달라는 얼굴 하지 마." / "그런 얼굴 안 했어." / "지금도 하고 있거든." / 돌멩이를 참 | 원칙을 항변과 장난 섞인 말다툼으로. 제6화 "나 거짓말 안 한다고 했잖아"의 근거 유지 |
| 마렌의 질문 | 마렌이 리아 앞에 앉아 콩을 대신 고름. 증거를 대구로 정리하던 대사를 빈정거림과 질문으로: "장화는 밤새 혼자 산책을 다녀오고… 엄마가 언제까지 모르는 척해야 하니." 콩 한 알이 튀어도 줍지 않음. "마렌의 손이 멈췄다." | 마렌은 일을 시키면서(하면서) 말한다. 제3화의 장화 농담을 되받음. 직접 질문은 유지 (D-049) |
| 베르크 | 말이 길고 매끄러워짐, 높여 부름, '안전', '보존' | style-guide §8 베르크 |
| 마을 회의 | 카셀의 복원사 편지 언급을 주민의 질문에 대한 대답으로: "편지가 저보다 빨리 걷기를 바라야지요." | 정보 대사를 대화로, 카셀의 마른 농담 |
| 회의 뒤 | "아버지는 옳았다… 카셀도 옳았다. 그래서…" → "아버지는 틀린 말을 하지 않았다. 카셀도… 리아는 누구에게도 아니라고 말할 수 없었다." | 정리 문장 줄이기 |
| 밤의 계산 | 경우의 수를 정리하던 리아의 생각을 "생각을 차례대로 해 보려 했다. 잘되지 않았다."로 시작해 밧줄, 미끄러짐, 제3화의 드러난 돌 같은 장면에 붙잡히는 생각으로 바꿈 | 열두 살의 생각 (진단 2-7) |
| 결산 문단 | "비밀이 지키는 것은 리아 하나뿐이었다" 문단 → 젖은 무릎을 끌어안고 사람들을 차례로 떠올림: "입을 다물고 있어서 괜찮은 사람은 그중에 하나도 없었다. 리아 말고는." | D-049 편집 메모 반영 |
| 유지 | 첫 문장, 물병의 인과, "잘 구분했구나", "부탁이 아니었다", 창문을 넘는 장면, 감각이 아무것도 말해 주지 않는 두려움, 일곱 글자 장면, 마지막 문장 | D-048·D-049 유지 항목 |

## 3. 남은 문제

- 니오 벨른은 아직 등장하지 않는다. 첫 등장은 따로 설계한다 (Q-원고-05).
- 제2화 첫 목격과 제3화 기록장 장면의 서술자 정리 문장 일부("저 짐승은 리아를 무서워하고 있었다", "달라진 것은 리아와 짐승 사이의 거리였다")는 회차의 핵심 문장이라 남겼다.
- 제1화와 제2~6화 사이에 아직 말투 온도 차이가 있다. 제1화가 가장 가볍다. 이는 사건의 무게 때문이기도 하므로 억지로 맞추지 않는다.
