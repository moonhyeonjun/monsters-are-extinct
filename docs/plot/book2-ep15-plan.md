## 0. 제14화 승인과 국소 확인 (사용자, 2026-10-23)

### 0-1. 승인과 채택

- 제14화 〈다리목〉의 장면 구성을 1차 승인했다. 분량(본문 약 7,400자)은 그대로 둔다.
- 집필 기준으로 채택한 것(그 회차에서 관찰한 사실이다. 꽃가루를 먹은 양, 건강이 나아지는지, 무리 비행의 원리는 정하지 않는다):
  - D+78 아침 마르딘이 공방 주인에게 조사 계획을 알림
  - 공방 주인의 “나는 허락한 적 없다”
  - 핀이 나무에 오르지 않고 장대로 채취함
  - 라니가 냄새와 껍질 상태를 판단하는 역할
  - 병이 의심되는 가지 하나를 현장에서 뺌
  - 야생 꽃의 꽃가루를 실제로 봄
  - 해 질 녘 그물 마당에 본 무리 일곱이 나옴, 나머지는 따뜻한 방에 남음
  - 꽃에 다가가 꽃가루가 몸에 묻음
  - 넷이 서로의 가슴 털을 핥음

### 0-2. 국소 확인

| 점검 | 확인 | 처리 |
|---|---|---|
| A. 다리목의 숯 표시 | 관리인이 다리목 돌에 숯으로 그은 표시를 “금”이라 불렀다. 10~13화의 온도 기준 '숯 금'과 같은 말이라 헷갈릴 수 있었다. 밧줄에 그은 것이 아니라 돌에 그은 한계선이다 | 14화 원고 세 곳을 '숯으로 가로줄', '그 줄', '숯 줄'로 바꿨다. 온도 기준은 바꾸지 않았다 |
| B. 병든 가지 처리 | 옛길 돌 위에서 태움, 재를 돌 틈에 쓸어 넣고 흙을 덮음, 칼날을 불에 지남 | 원고 그대로 둔다. 이 조치로 병의 원인이 다 없어졌다는 말은 원고에도 기록에도 없다. 다리목 나무의 병(줄기의 아문 흉터 포함)은 15화 이후에도 조심할 대상이다 |
| C. 그물 마당의 개체 수 | 나온 것은 일곱. 가로대의 넷과 물통 가장자리의 하나, 다섯은 마르딘이 손으로 건넸다. 나머지 둘은 꽃을 떠나 장대로 갔다가 땅으로 내려와 작은 문으로 기어 들어갔다 | 초고의 “몇은 저절로”를 “둘은 저절로”로 밝혔다. 본 무리 전체의 수는 정하지 않는다. 헛간의 아홉과는 섞이지 않았다 |

## 2. 세 번째 연습의 장소와 까닭

- 선택: **그물 틀을 다시 끼운 따뜻한 방 안의 연습.** 핀과 마르딘은 13화처럼 그물 마당 쪽에서 작은 문과 바닥 온도계를 맡는다. 설계의 '그물 마당, 밤'은 이 두 사람의 자리로 지킨다.
- 그물 마당이어야만 하는 인과가 15-1에 있는가: 없다.
  - 15-1의 발견(끝까지 조여짐, 돌기, 떨기, 긴 김, 덩이 자리의 온도)은 무리가 방 안에 있어도 보인다.
  - 그물 마당이 꼭 필요한 것은 꽃이 기온을 따라 열려야 하는 장면(14-4)과 첫 비행(19-3·19-4)이다.
- 방 안을 고른 까닭:
  - 14화에서 이미 그물 마당 먹이 시간을 썼다. 되풀이하지 않는다.
  - 13화와 같은 차림이라 결과를 견줄 수 있다. 테오는 표도 13화와 똑같이 둔다.
  - 헛간의 아홉과 본 무리를 계속 가를 수 있다.
  - 관리인이 꼭지 옆을 떠나지 않는 원칙을 그대로 지킨다.

| 무엇이 13화와 같고 무엇이 다른가 | 15화 |
|---|---|
| 같게 둔 것 | 표(문을 열고 삼백, 그다음 오백마다 한 칸), 그물 틀, 자리, 숯 금 둘, 판자 |
| 달라진 것 (원고에서 적힌 것) | 해 질 녘에 일곱이 다리목 꽃 앞에 갔다 왔다. 다리목 꽃 냄새가 그물 마당 구석에 있다(*다리목 꽃 냄새(먼 구석)*). 맑고 바람 없는 밤이라 바깥이 더 빨리 식는다(핀). 세 번째다 |
| 테오의 말 | “같게 한 건 하나뿐이야.” |

## 6. 네피라의 새 행동 (관찰만)

| 행동 | 원고 | 13화와 다른 점 |
|---|---|---|
| 끝까지 조여짐 | 털과 털이 더 바짝 붙고 겉이 매끈하게 다져짐 | 13화는 둥글게 오래 버텼지만 다져지지는 않았다 |
| 자리 돌기 | 겉의 하나가 머리를 들이밀고 옆의 몸 밑으로 파고듦, 곁에서 하나가 밀려 나옴, 나온 애가 겉을 기다가 다른 틈에 머리를 묻음 | 따뜻한 방의 무리에서 처음 보임(5화는 헛간의 늦게 온 무리) |
| 털끝의 떨림 | 날개 막은 접힌 채, 가장자리 털끝만 가늘게 쉬지 않고 | 처음 |
| 긴 김 | 끊기지 않고 피어올라 등잔 빛 속에서 흩어짐, 등잔 기름 한 마디 넘게 | 11·13화의 김은 가늘다가 끊겼다 |
| 덩이 자리의 온도 | 실 온도계가 벽의 숯 금보다 한참 위에서 머묾, 벽은 칸마다 줄어듦 | 11·13화에는 실이 반 눈금 오르내렸다 |
| 데운 뒤 | 김 → 떨림 → 돌기의 차례로 멎고, 틈, 갈고리, 한 뼘 | — |
| 리아의 손바닥 | 작은 것들의 사이가 좁아졌지만 하나로 오지는 않음 | 19-3 '박자가 하나로 맞춰진다'를 남겨 둠 |

- 결과가 달라진 까닭은 정하지 않는다. 원고의 마르딘: “해 질 녘에 꽃 앞에 갔다 와서인지, 세 번째라서인지, 바깥이 달라서인지.” 핀: “바깥은 안 똑같았어. 냄새도.” 테오: “같게 한 건 하나뿐이야.”
- 작가 쪽에서 가르는 것:
  - 관찰은 조여짐, 돌기, 떨림, 김, 실 숫자, 멈춘 때다.
  - 해석은 '스스로 데운다'인데, 원고의 누구도 말하지 않는다.
  - 원인은 꽃, 세 번째, 바깥, 냄새, 표의 맞음 가운데 무엇인지 미정이다.

## 7. 꽃가루를 먹었는가 — 관찰과 해석

| 질문 | 15화에서 | 판정 |
|---|---|---|
| 1. 꽃가루와 같은 것을 찾았나 | 테오: “돋보기로 봤어. 네 손끝에 묻었던 거랑 같은 알갱이야.” | 같아 보이는 알갱이를 봤다 |
| 2. 언제 먹었는지 가를 수 있나 | “어제 저녁 말고는 먹을 데가 없었으니까 어제겠지. 어떻게 먹었는지는 몰라.” / 리아: “꽃에서 먹은 거야, 핥아서 먹은 거야?” | 때는 짐작이다. 꽃에서인지 털을 핥아서인지 모른다 |
| 3. 모두 먹었나 | 문 가까운 장대(14화 저녁에 관리인이 다섯을 걸어 준 장대) 밑 쟁반에서만, 다른 쟁반엔 없음 | 모두가 아니다. 어느 애인지 모른다 |
| 4. 양을 아나 | “조금. 셀 만큼은 아니야.” | 모른다 |
| 5. 먹었다는 것으로 건강이 나아졌다고 할 수 있나 | 리아: “그럼 이제 괜찮은 거야?” / 테오: “그건 똥으로는 몰라.” | 아니다 |

- 장부: 관리인이 처음으로 *있음*을 쓴다. *꽃가루 — 있음(문 옆 장대 쟁반). 다른 쟁반 — 없음.*(테오가 베껴 온 쪽지). 9화의 해마다 *없음*, 10화의 빈칸을 잇는다.
- 꽃가루가 먹이라는 것(9화 마르딘)은 그대로다. 꽃가루 하나로 문제가 풀린다고 쓰지 않았다. 4단계의 '몸무게가 는다'는 쓰지 않았다.

## 8. 쓴 꽃가지의 처리

| 점검 | 원고 |
|---|---|
| 연습 동안 | 마르딘이 그물 마당의 가장 먼 구석으로 옮김. 냄새는 남음(표에 적음). 네피라에게 다시 주지 않음(그물 틀) |
| 꽃이 닫혔나 | 아침에 다 오므림(테오의 기록) |
| 남은 꽃가루 | 문 가까이 놓였던 꽃은 노란 실이 거의 비었고, 구석으로 옮긴 뒤 아무도 안 간 꽃은 아직 노람 |
| 어느 꽃에 다가갔나 | 문 가까이 놓였던 꽃(14화에 물통이 작은 문에서 열 걸음쯤) |
| 병의 의심 | 테오는 시큼한 냄새를 못 맡음. “내 코는 네 코가 아니지만.” 라니: “내가 맡았어야 했는데.” 확정하지 않는다 |
| 폐기 | 관리인이 아침에 아궁이에 태움. 다른 무리(헛간의 아홉)와 정원에는 닿지 않았다 |
| 다음 회차에 필요한가 | 아니다. 17-4의 꽃가루 종이는 14화에서 따로 받아 두었고, 19화의 가지는 어미 나무 가지다 |

- 남은 일: 물통의 물을 어디에 버렸는지는 쓰지 않았다(정원 쪽 도랑은 피해야 한다. 3단계 §4-4).

## 9. 리아·핀·테오

| 누구 | 15화에서 | 해결되지 않은 것 |
|---|---|---|
| 리아 | 더 보고 싶은 마음을 누르는 것은 되풀이하지 않는다(이번에는 멈춤에 흔들리지 않는다). 대신 모르는 것을 말로 인정한다(“그게 뭔지는 저는 몰라요.”). 약속대로 라니에게 본 것과 모르는 것을 다 전한다(“다 말해 준다고 했잖아. 모르는 것도.”). 테오에게 다섯 가지를 묻는다. 도아에게 값으로 칠 수 없는 것을 쓴다 | 제 감각과 떨림의 뜻 |
| 테오 | 냄새라는 변수를 치우자고 하고, 표를 똑같이 두고, 남은 변수를 적는다. 숫자 두 줄을 말없이 내민다. 똥을 보고 뛰어온다. 가지의 상태를 적어 둔다 | “같게 한 건 하나뿐이야.” |
| 핀 | 하늘을 읽고, 바닥을 읽고, 김을 보고도 한마디만 한다. “바깥은 안 똑같았어. 냄새도.” | 바깥은 같게 할 수 없다 |
| 핀–테오 | 서로 비난하지 않는다. 테오는 핀의 말을 “……알아.”로 받는다. 함께해도 풀리지 않는 문제(바깥과 냄새)가 남는다 | — |
| 라니 | 꽃철이 끝난 정원에서 낫을 든다. 리아의 이야기에 처음으로 조금 웃는다. 가지의 병을 자기 코로 못 맡은 것을 아쉬워한다 | 아빠, 겨울 |

## 10. 생태 — 드러낸 것과 보류한 원리

- 드러낸 것 (5단계 §4의 15-1):
  - 끝까지 조여진 덩이
  - 따뜻한 방 무리의 자리 돌기
  - 접힌 날개 털끝의 떨림
  - 오래 이어진 김
  - 덩이 자리의 온도가 벽보다 높게 머묾
  - 꽃가루가 똥에 나옴 (15-2)
- 보류한 원리:
  - 떨기와 체온 조절의 원리 (“떠는 걸 봤다는 것까지요.”)
  - 자리 돌기의 목적
  - 덩이가 어떻게 데우는지(김과 숫자만 썼다)
  - 꽃가루가 몸에서 하는 일과 필요한 양
  - 기울기와 건강의 관계
  - 무리 비행의 조건 (19화)
  - 리아 감각의 정체
  - 가슴 고리
  - 사라진 둘의 생사
  - 장기 비밀은 나오지 않는다

## 13. 문체 자체 검수

| 점검 | 판정 |
|---|---|
| 11·13화의 되풀이 | 오르기와 덩이 생기기는 “어제와 같았다”로 넘겼다. 새로 쓴 것은 다져짐, 돌기, 노란 얼굴의 행방, 털끝, 긴 김, 숫자 두 줄, 데운 뒤의 차례다 |
| 연구 보고서처럼 이어지는 대화 | 테오의 똥 보고는 숨찬 짧은 문답이다. 리아의 다섯 질문은 한 줄씩이다. 마르딘의 정리는 한 번뿐이다 |
| 관찰이 뜻대로 안 되는 순간 | 실이 날개 속에 묻혀 어느 애인지 모름, 같은 애인지 모름, 냄새를 못 막음, 바깥을 같게 못 함, 시큼한 냄새를 맡을 코가 없음 |
| 설명 없이 드러나는 감정 | 숨을 언제부터 참았는지 모름, 손바닥이 아직 뜨거움, 라니의 빨간 눈과 처음의 웃음, 노래하지 않는 일꾼들, 도아의 꾹꾹 눌러 쓴 글씨 |
| 아이들다운 말 | “그래도 와.”, “내 코는 네 코가 아니지만.”, “내가 맡았어야 했는데.”, 손가락이 모자라 곱셈을 그만둠 |
| 짧은 문장과 도치 | 서술의 짧은 쌍 “꽃은 하얗지 않았다. 갈색이었다.”를 한 문장으로 묶었다. 남은 짧은 쌍은 대화와 수 세기다. 도치는 없다 |
| 장면 끝 | 테오의 “같게 한 건 하나뿐이야.” 뒤의 리아의 기록 / 라니의 “내가 맡았어야 했는데.” / 답장의 외상 줄. 교훈 해설은 없다. 초고의 “적은 것보다 모르는 것이 더 많았다.”를 뺐다 |
| 반복 표현 | '한참' 7번을 3번으로, '같았다' 5번을 3번으로 줄였다 |

- 분량: 본문 약 5,600자, 공백 제외 약 4,100자. 장면 넷(연습 전은 짧다).

## 14. 이 회차로 확정하면 안 되는 설정

- 덩이가 끝까지 조여진 까닭
- 털끝 떨림과 돌기의 뜻
- 실 숫자가 머문 까닭과 눈금
- 똥의 꽃가루가 어느 애의 것인지, 양
- 일꾼의 수(마흔 남짓)와 하룻밤 바구니 수
- 병의 해와 떠난 집의 수, 빈집의 수
- 물통의 물을 버린 곳
- 도아의 처마 장사의 다음

## 15. 제16화로 이어지는 것 (원고에서 나열하지 않음)

- D+79 해 지기 전, 관리인이 보낸 심부름(16-1)
- 남은 야생 꽃은 다리목 한 그루뿐이고, 그 가지는 위험하고 적다
- 공방 주인의 겨울과 '한꺼번에 다 잃는 것'을 리아가 막 알았다
