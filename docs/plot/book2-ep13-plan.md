## 0. 제12화 승인과 채택 (사용자, 2026-10-23)

- 제12화 〈옛 이름〉의 장면 구성을 1차 승인했다. 분량(본문 약 6,400자)은 그대로 둔다.
- 집필 기준으로 채택한 것 (현행 제2권의 작업 기준이다):
  - 옛길의 닳은 돌과 수레바퀴 홈
  - 고사리의 서리 피해 차이
  - 다리목 쪽 옛길에서 주운 마른 꽃 (출처와 꽃가루 유무는 정하지 않는다)
  - 묘지기의 생계와 이해관계 (공방 집의 빵)
  - 라니가 만들 향의 이름 '옛 이름' (이름 자체는 쓰지 않는다)
  - D+77 아침의 단계적 접촉 제한 해제
- 4단계의 '묘지기가 몫 나무 가지를 내준다'는 되살리지 않는다.
- 옛 지명과 비석은 D-107의 공개 제한을 따른다. 13화에서도 이름을 쓰지 않았다.

## 3. 리아의 보고 — 갈라서 말한 것

| 갈래 | 리아의 말 | 마르딘의 받음 |
|---|---|---|
| 제 눈으로 본 것 | 옛길 끝의 골, 무너진 다리, 양쪽 돌만 남은 다리목, 건너편 돌을 뿌리로 움켜쥔 살아 있는 나무, 오므린 꽃(꽃잎을 셀 수 있음, 몫 나무와 같은 모양, 보이는 데만 스물 넘음), 서리를 안 맞은 고사리, 그루터기(열일곱까지 세다 멈춤), 비석에 길돌에서 옮겨 적은 이름 하나 | 고개만 끄덕인다. 비석의 이름에서 “그 이름은 리아 기록장에만 있던 거죠.” |
| 남이 맡은 것 | 라니: 맵다, 몫 나무 것보다 더. 리아 자신은 '맵다는 것까지만' | — |
| 들은 것 | 묘지기: 옛 이름, 옛길이 고개 너머까지, 어릴 때 길 따라 나무 몇 그루, 그루터기는 병이 돌던 해. 라니: 아빠가 벴다, 아빠가 그 나무를 알 것이다 | “그건 라니의 말이죠.” / “네. 라니 말이에요.” |
| 모르는 것 | 꽃가루, 마른 꽃이 어디서 왔는지, 나무가 아픈지, 어떻게 건너가는지 | 마른 꽃을 집지 않고 들여다보기만 한다. “이걸로는 말 못 해요. 말랐고, 어디서 왔는지도 모르니까요.” |
| 남의 부탁 | 묘지기: 어디를 가르쳐 줬다고는 하지 말아 달라 | “그건 지킬게요.” |

- 마르딘은 리아의 말을 답으로 받지 않는다(라니의 말과 리아의 말을 가르고, 마른 꽃으로는 말하지 않는다).

## 4. 핀과 테오

| 누구 | 잡는 것 | 13화에서 놓친 것을 인정함 | 관계의 움직임 |
|---|---|---|---|
| 테오 | 숫자. 말뚝, 벽, 실, 수 세기 | 바닥 줄의 괄호에 *핀*을 적는다(11화의 빈 괄호). 김을 제 눈으로 처음 본다(“……보인다.”). “또 한꺼번에 여러 개 바꿨네.” | 핀에게 읽는 법을 가르친다. 핀이 부른 “금이야”를 되묻지 않는 관리인 곁에서 테오도 따지지 않는다 |
| 핀 | 몸과 바깥. 땅의 미지근함, 발밑부터 식음, 차오름 | “바람이 없으니까 괜찮다고 한 거, 나야.” / “그날 네가 공방까지 뛴 거. 그거 아니었으면 못 찾았어.” | 숫자를 배워 그물 틀 너머로 부른다. “판으로 읽혀.” 투덜거림은 남는다 |
| 리아 | 둘의 차이 | 그날 밤 테오의 숫자를 듣지 않은 것을 사과한다 | 세 줄을 나란히 적는다. *차올라*가 숫자보다 먼저라는 순서를 본다 |

- 화해를 말로 선언하지 않는다. 의자의 거리가 '한 자리 비우고'(10화) → '반 팔쯤'(11화) → '리아 하나만 사이에'(13화)로 줄어든다. 탁자 위로 셋이 머리를 맞댄다.
- 남은 것: 핀은 숫자를, 테오는 몸의 말을 아직 다 믿지는 않는다. 테오가 핀의 이름을 쓰는 손은 서툴다(구멍 난 종이).

- 라니가 올지 (라니 엄마에게 물음)
