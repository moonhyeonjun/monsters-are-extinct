# 제1권 전체 퇴고 목록 [메모]

> 상태: **퇴고 메모 (2026-10-22 작성).** 제1권 초고 완성 뒤의 전체 편집에서 쓴다. 여기 적힌 항목은 **지금 원고에 반영하지 않는다.** 승인된 원고의 수정은 퇴고 때 사용자 승인을 거쳐 진행한다.
> 근거: D-081(제7~12화 반복 정리는 초고 완성 후), D-091(제12화 서명의 연호), D-088·reverse-foreshadowing(제12화 말다툼 검토), D-096(섭취 기록의 보완)

## 1. 섭취 기록과 건강 상태 (D-096, [proposals/aurel-intake-review.md](../proposals/aurel-intake-review.md) §7)

| # | 회차 | 위치 | 내용 | 방향 |
|---|---|---|---|---|
| R1 | 제9화 | 270, 406 (마르딘) | 마르딘의 섭취 관련 발언("밤에만 조금 먹고 낮에는 먹지 않았습니다")이 카셀 장부의 실제 기록(D+5 밤 *풀을 뜯음, 얼마나 먹었는지는 모름*, D+6 아침 "입도 안 댔고요")과 맞지 않는다. 270은 로안의 말을 먹이의 근거로 잘못 잇는다 | 장부의 근거와 일치시키고, 로안을 먹이의 출처에서 뺀다. 예: "밤에 한 번 풀을 뜯는 걸 봤고, 다음 날 아침엔 입을 대지 않았다고 장부에 있습니다. 얼마나 먹는지는 모릅니다." |
| R2 | 제12화 | 66 (D+10 아침, 마르딘) | 먹이를 제공했는지, 먹었는지가 없다 | 먹이를 놓았으나 섭취 여부를 모르는 상황을 구분한다. 예: "풀은 반쯤 그대로예요. 밤에 조금 먹은 것 같은데, 짚에 섞였는지도 몰라요." |
| R3 | 제13화 | 246 (마르딘의 상태 요약) | 서기·걷기·젖은 데·눕기·다리만 있고 먹이와 몸 상태가 없다 | 밤에 조금씩 먹는다는 관찰과 건강 상태를 간결하게 보완한다. 예: "풀은 밤에 조금씩 줄어요. 얼마나인지는 몰라요. 들어올 때보다 등뼈가 도드라졌어요." (선택: 구유를 벽 옆에 둘 때 풀도 벽 쪽으로 옮김) |
| R5 | 제15화 | 404 부근 (전야의 짐) | 이송 짐에 먹이가 없다 | 이송 짐에 먹이가 포함되었음을 자연스럽게 반영한다. 예: "짐 꾸러미에는 아주머니가 아침에 벤 어린 잎 한 자루." 제16화의 "마을에서 가져온 어린 잎"과 맞춘다 |

- 제16화(R6)는 1차 승인 전이어서 D-096으로 이미 반영했다.
- 섭취량·건강 상태를 정본의 생리 규칙으로 승격하지 않는다. 수치·병명을 쓰지 않는다.

## 2. 반복과 절차 (D-081)

- 제7~12화의 절차 반복과 중복 설명을 정리한다.

## 3. 연호 (D-089, D-091)

- 제12화 374행 제출용 사본의 서명에 멸종력 날짜를 한 번 넣는다. 예: *여기까지 옮겨 적음. 멸종력 312년 여름, 밀바람에서. — 카셀* 544행에는 넣지 않는다.

## 4. 복원 인식 (D-088)

- 제12화 맷돌질 장면에 복원사의 평판을 드러내는 짧은 말다툼(①과 ③을 섞는 마을 사람 둘)을 넣을지 검토한다.
