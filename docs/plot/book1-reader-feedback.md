# 제1권 직접 독서 피드백 기록

> 상태: **누적 기록 (2026-10-22 시작).** 작가가 원고를 직접 읽으며 발견한 혼란과 어색함을 모은다. 자동 검수에서 P0·P1·P2가 없다고 판정한 곳도 따로 다룬다.
> 쓰는 법: 피드백이 들어올 때마다 차수를 하나 늘린다. 항목마다 회차, 문제 문장, 독자가 느낀 문제, 실제 원인, 수정 전후, 처리 상태를 적는다. 결정 번호는 decisions.md에 짧게 남기고, 자세한 내용은 이 문서에 둔다.
> 회차 번호는 현재 21화 번호다.

### 1차-5. 짧은 문장 리듬 조사

- 기준: 같은 문단 안에서 세 단어 이하 서술문 뒤에 두 단어 이하 서술문이 이어지는 쌍. 대사와 기록장 인용은 뺐다.
- 회차별 쌍의 수:
  - 제1~5화: 1화 0, 2화 2, 3화 1, 4화 0, 5화 1
  - 제6~7화: 6화 6, 7화 7
  - 제8~14화: 8화 4, 9화 5, 10화 4, 11화 1, 12화 4, 13화 6, 14화 3
  - 제15~21화: 15화 6, 16화 3, 17화 3, 18화 2, 19화 2, 20화 5, 21화 7
  - 합계 72
- 판단 기준: 긴장이 필요한 순간인가, 반복 자체가 뜻을 만드는가, 가까운 장면에 같은 구조가 다시 나오는가, 독자가 기법을 의식하게 되는가.

제1~7화에서 유지한 것

- 제6화 "오른쪽 앞다리가 꺾였다. 몸이 물 쪽으로 기울었다.", "물문이 움직였다. 한 번에, 끝까지.", "물이 쏟아졌다.", 돌턱이 차례로 잠기는 문단: 구조와 개방의 절정에서 속도를 만든다.
- 제6화 "한 번 더 셌다. 다리 밑을 돌아보았다. 아무도 없었다.": 카셀이 사람 수를 다시 확인하는 박자다.
- 제7화 "또 밀려났다. 또 돌아왔다.": 바람이 천을 미는 반복 동작 자체다.
- 제7화 "주먹을 들었다가 내렸다. 다시 들었다.": 부모 방문 앞의 망설임이다.
- 제7화 "문은 금방 열렸다. 마렌이었다.", "창문은 닫혀 있었다. 빗장도 그대로였다.": 장면의 열고 닫음이다.
- 제2화 "어제보다 희미했다. 그래도 분명했다.", 제3·7화 마렌의 "보았다. 오래 보았다.", 제5화 "발바닥에 신경을 모았다. 물소리뿐이었다.": 드물고 뜻이 있다.
