## 0. 제17화 승인과 국소 확인 (사용자, 2026-10-23)

### 0-1. 승인과 채택

- 제17화 〈씨앗 값〉의 장면 구성을 1차 승인했다. 분량(본문 약 5,400자)은 그대로 둔다.
- 집필 기준으로 채택한 것(제2권에서 확인한 사실과 인물의 판단으로 한정한다. 씨앗의 발아 여부와 이번 손 꽃가루의 성공은 정하지 않는다):
  - 공방 주인이 스스로 찾아와 제한된 협력을 제안함
  - 그날 공방 주인이 직접 꺾는 어미 나무 가지, 하룻밤 몫
  - 다리목 꽃가루를 어미 나무 꽃 다섯 송이에 묻히는 시도, 붓질은 라니와 가족
  - 어미 나무의 묵은 씨앗
  - 씨가 맺히려면 다른 나무의 꽃가루가 필요하다는 공방의 경험
  - 형의 나무를 한 겨울 동안 남기는 협상, 겨울 숯 값과 온도계 구매 연기, 아이들의 장작 쌓기
  - 공방 주인이 끝내 허락하지 않는 접순·정원 곁 야생 나무·방사

## 1. 제17~19화의 시간 순서

| 때 | 회차 | 일 |
|---|---|---|
| D+80 아침 | 17-1 | 공방 주인의 조건(“어느 밤인지는 너희가 정해라. 정해지면 해 지기 전에 와서 말해라. 그날 꺾는다.”) |
| D+80 낮~오후 | 17-2·17-3 | 형네 마당. 해가 서쪽 비탈에 닿기 전에 시설로 |
| D+80 해 질 녘 (해가 서쪽 비탈에 걸림) | 17-4 | 라니가 봉투를 받아 감. 리아는 문간 |
| 해가 진 뒤 | 17-4 끝 | 공방 뒤뜰의 등불(붓질) |
| 해가 진 뒤 | **18-1** | 해 지기 전에 말뚝을 읽은 테오가 올라옴 → 그물 마당 → 언제 쓸지 의논 |
| D+80 밤 | **18-2** | 따뜻한 방 앞, 부엌 옆 방의 창가 |
| D+81 새벽 | **18-2 끝** | 서리가 바위 턱 밑까지, 공방 뒤뜰의 불이 꺼짐 |
| D+81 오후 | 19-1 | 얇은 높은 구름, 마르딘이 오늘로 정함 → 해 지기 전에 공방에 알림 |
| D+81 오후~해 질 녘 | 19-2·19-3 | 공방 주인이 꺾음 → 가지 보관 → 그물 마당 |
| D+82 새벽 | 20-1 | 중턱에도 서리 |
| D+83 | 20-4 | 역참 |

- 공방 주인의 “해 지기 전에 와서 말해라. 그날 꺾는다.”는 **쓰기로 한 날의 사전 통지 조건**으로 읽는다. D+80 당일에 연락해야 한다는 뜻이 아니다.
- 18화에는 'D+80 밤에 쓸지'를 고르는 장면이 없다. 해가 이미 졌다. 핀의 “오늘 아침에 말했으면 오늘 밤 할 수 있었는데. 하루를 그냥 보냈어.”로 그 하루가 지나갔다는 것만 남긴다(제목).
- 18화의 선택은 '내일(D+81)로 미리 정할지, 그날 하늘을 보고 정할지'다.
- 설계 18-1의 “오늘 쓰면 내일은 없다”, 핀의 “오늘이 마지막일지 몰라. 해 보자.”를 바꿨다. 핀의 말은 “내일 아침에 바로 공방에 말하자고. 내일 밤에 하자.”이고, 한 번뿐이라는 것은 리아의 “공방 아저씨가 내년에도 가지를 준다는 말은 안 했어.”로 썼다. 19·20화의 날짜는 바뀌지 않는다.

## 4. 리아가 실제로 선택한 것

- 18화의 선택: '내일로 미리 정하지 말고, 그날 하늘을 보고 정하자'를 말한다. 그 결과 잃을 수 있는 것을 스스로 말한다.
  - 할머니 나무 꽃(손 꽃가루를 묻힌 꽃 포함)
  - 다리목 꽃
  - 이번 철
  - 내년의 가지가 약속되지 않았다는 것
- 그 선택은 혼자 알아낸 답이 아니다. 이은 것들:
  - 핀의 하늘(별이 많고 바람이 없음)
  - 테오의 숫자(연습한 어느 밤보다 낮음)
  - 관리인의 시험 밤(10화 “그날도 맑았지. 바람도 없고.”)
  - 리아 자신의 7화의 밤
  - 엄마의 말(2화)
- 정한 것은 관리인과 마르딘이다.
- 선택을 지키는 것: 핀의 “늦을까 봐 무서워”에 대답하지 못하지만 말을 거두지 않는다. 새벽에 서리가 높이 왔어도 “안 했으니까 몰라.”라며 제 선택을 옳았다고 말하지 않는다.
- 감각: 그물 마당 땅에 대 본 손바닥은 차가운 것뿐이다. 따뜻한 방의 작은 것들은 어제와 같다. 감각으로 내일이나 개체의 상태를 읽지 않는다.

| 창가 | 부엌 옆 방의 창, 덧문을 손바닥 하나만큼 엶, 담요 | 3화의 작은 방 |
| 공방 뒤뜰의 불 | 질항아리 불 셋, 엷은 연기, 밤새 꺼지지 않음, 그 둘레는 하얗지 않음, 새벽에 하나씩 꺼짐 | 3·8화의 연기 불. 누가 피웠는지는 쓰지 않았다(“누가 밤새 장작을 넣었다”) |
| 서리의 오름 | 굽은 데 아래 → 굽은 데 말뚝의 머리 → 바위 턱 밑 말뚝과 바위 턱의 흰 테 → 멈춤. 바위 턱 위 말뚝과 시설 앞마당은 서리를 맞지 않음 | 5단계 18-3, 3단계 §4-1 |
| 테오의 기록 | 숫자 대신 서리가 어디까지 왔는지와 등잔 기름. *새벽 — 바위 턱 밑까지. 위 말뚝은 아직(핀: 밀물).* “아침에 가서 읽어도 아침 숫자밖에 안 남아.” | 새 세부 |
| 핀의 고향 | 바위 마당에 밤마다 물이 한 뼘씩 소리 없이 들어왔다가 아침에 빠짐 | 2단계 §8-2(바다의 감각) |

## 6. 인물의 역할

| 누구 | 18화에서 |
|---|---|
| 핀 | 하늘(별, 바람 없음)과 지형(서리의 밀물)을 읽는다. 늦을까 봐 무섭다고 말한다. 결정에 끄덕이지 않지만 따른다(장대를 잡고 오르지 않음). 바다의 감각을 골짜기의 말로 고친다 |
| 테오 | 해 지기 전에 말뚝을 읽는다. “내 숫자는 오늘 밤 거야. 내일 밤이 어떨지는 이걸로 몰라.” 밤에는 숫자를 못 읽어 서리가 어디까지 왔는지를 적는다. 아침 숫자로는 밤의 가장 낮은 때를 모른다 |
| 리아 | §4 |
| 관리인 | 개체의 안전과 시설 운영의 최종 판단. 헛간의 돌, 코끝 허연 애, 작은 문 빗장, 밤 순찰, 아이들의 데운 돌. 시험 밤의 자리(꺼진 자리 셋)를 내려다본다 |
| 마르딘 | 현장 책임. 숫자를 따라 읽는다. 절차를 정하고 비용을 아이들에게 그대로 말한다(“그러다 철이 끝나면, 끝나는 거예요. 그것까지 알고 정하는 거예요.”) |

- 네 번째 온도 시험은 없다. 표도 없다. 이야기를 움직이는 것은 선택이다.

## 7. 기다림의 이유와 비용

| 항목 | 원고 |
|---|---|
| 맑고 바람 없는 밤이 위험한 까닭 | 서리가 바닥부터 차오른다(2화 엄마, 7화의 밤, 핀의 밀물). 관리인의 시험 밤도 그랬다(10화). 테오의 숫자가 연습한 어느 밤보다 낮다. 실제로 그날 밤 서리가 바위 턱 밑까지 올라온다 |
| 너무 빨리 쓰면 잃는 것 | 한 번뿐인 가지. 시험 밤처럼 애들을 잃을 수 있다(원고에서는 관리인이 꺼진 자리 셋을 내려다보는 것으로) |
| 너무 오래 기다리면 잃는 것 | 서리가 중턱까지 오르면 할머니 나무 꽃과 다리목 꽃이 끝나고, 이번 철이 끝난다(핀, 리아) |
| 다시 구할 수 있다는 보장이 없는 까닭 | 공방 주인은 하룻밤 몫만 준다. 내년 이야기는 하지 않았다. 형의 나무는 봄에 베인다 |
| 기다림의 불확실성 | “내일 밤이 어떨지는 이걸로 몰라.”(테오), “어젯밤에 했으면.” / “몰라. 안 했으니까 몰라.” |
| 기다리는 동안 생긴 비용 | 하루가 그냥 지나감. 공방 사람들이 겨울 장작으로 밤새 어미 나무 둘레에 불을 피움. 관리인이 밤새 헛간을 오감 |

## 8. 서리와 네피라 — 새로 본 것

- 서리:
  - 바닥(골짜기, 정원, 강가) → 굽은 데 → 바위 턱 밑까지 오르고, 새벽에 멈춘다. 15화 된서리 때보다 높다.
  - 소리가 없다.
  - 공방 뒤뜰의 불 둘레는 하얗지 않다.
  - 둘이 흘러간 비탈도 하얀 것에 잠긴다(생사는 그대로 모름).
- 본 무리: 데움을 낮추지 않은 따뜻한 방에서는 다시 한 뼘씩 떨어져 매달린다. 수다쟁이와 할머니 사이에도 한 뼘. 사흘의 연습이 간격을 없애지 않았다는 것을 보이되, 까닭은 쓰지 않았다.
- 헛간의 아홉: 격리 그대로다. 관리인이 돌을 더 넣고 밤에 두 번 살핀다.
- 코끝 허연 애: “막대에 붙어 있다. 오늘은 돌을 하나 더 넣었다.” 12화의 “올라붙긴 했다. 아직 제일 가볍다.”와 이어진다. 회복했다고 쓰지 않았다.
- 시설의 모든 네피라가 나아졌다는 말은 없다.

## 9. 생태 — 드러낸 것과 보류한 것

- 드러낸 것:
  - 맑고 바람 없는 밤의 찬 공기가 바닥부터 고여 오른다는 것(핀의 말, 2단계 §4-2와 3단계 §4-1의 따뜻한 띠와 찬 공기)
  - 연기 불이 그 둘레의 서리를 막는다(3·8화의 공방 관행)
- 보류한 것:
  - 무리 비행의 조건(19화)
  - 떨기와 체온
  - 자리 돌기의 목적
  - 꽃가루의 생리적 영향
  - 따뜻한 방에서 간격이 돌아온 까닭
  - 사라진 둘
  - 장기 비밀(나오지 않음)

## 10. 제19화를 위한 준비 (앞당기지 않음)

| 항목 | 18화가 남긴 것 | 19화에서 정할 것 |
|---|---|---|
| 날을 정하는 법 | 그날 하늘을 보고 정한다. 그날 해 지기 전에 공방에 말한다 | 19-1 핀이 얇은 높은 구름을 읽고, 마르딘이 오늘로 정함 |
| 가지 | 아직 꺾지 않았다. 어미 나무 꽃은 공방 사람들의 불로 지켜졌다 | 19-2 공방 주인이 제 손으로 꺾어 셈 |
| 가지 보관 | 17-1 관리인 “가지는 헛간에 안 들입니다.” | **그물 마당 북쪽 구석의 별도 보관을 권한다**(14화와 같음, 찬물 물통과 젖은 자루). 헛간과 닿지 않음, 정원 쪽 물길을 피함, 그물 틀은 끼운 채 두어 네피라가 미리 닿지 않게 함, 관리인이 지킴, 쓴 뒤에는 태우고 연장은 씻음(17-1) |
| 무리 | 따뜻한 방에 둔다 | 19-3 데움을 낮추고 해 질 녘 그물 마당 |
| 관리인의 규칙 | 맑고 바람 없는 밤엔 안 내보낸다 | 19-1 얇은 구름, 바람이 잦아듦(그 밤은 '맑고 바람 없는 밤'이 아니다) |

- 18화는 19화의 결과를 보장하지 않는다. 비행 조건을 정리하지도, 성공을 예언하지도 않았다.

## 11. 시간표·동선·안전

| 때 | 누가 어디에 |
|---|---|
| D+80 해 지기 전 | 테오가 비탈의 남은 말뚝 둘을 읽음(해 지기 전, 시설 바로 아래) |
| 해 진 뒤 | 시설 문간(리아) → 그물 마당(관리인, 마르딘, 핀, 테오, 리아). 관리인은 헛간을 두 번 오감 |
| 밤 | 따뜻한 방 안쪽 문 앞(리아 잠깐), 부엌 옆 방의 창가(리아, 핀, 테오). 관리인의 헛간 순찰 두 번 |
| D+81 새벽 | 창가 |

- 아이들은 해가 진 뒤 시설 밖에 나가지 않는다. 그물 마당은 시설 안이고 어른이 있다. 창은 덧문 틈으로만 본다.
- 아홉은 헛간 상자 그대로다. 그물 틀은 끼운 채, 작은 문은 빗장.

## 12. 문체 자체 검수

| 점검 | 판정 |
|---|---|
| 처지는 기다림 회차가 되지 않는가(설계의 위험) | 서리가 소리 없이 오르는 장면을 경이로 두었다. 별빛에 반짝이는 잎끝, 돌 모서리, 굽은 데 말뚝의 머리, 바위 턱의 흰 테 |
| 실제 의견 차이 | 핀의 “내일 바로 하자” / 리아의 “기다려요”, “잘못될까 봐” / “늦을까 봐” |
| 기다리는 동안 변하는 상황 | 서리의 높이, 공방 뒤뜰의 불, 관리인의 순찰, 새벽의 꺼지는 불 |
| 리아의 교훈 | 리아는 성장을 말하지 않는다. 새벽에도 “안 했으니까 몰라.”뿐이다 |
| 마법이 되지 않는가 | 서리는 찬 공기가 고여 오르는 것으로만, 핀의 비유는 고향의 바위 마당으로 썼다. 리아의 손바닥은 차가운 것뿐이다 |
| 대화 | 말꼬리 '말했다'를 24번에서 18번으로 줄였다. '맞는 말이었다'는 한 번만 남기고 “어느 쪽 무서움이 더 큰지 알 수 없었다.”로 바꿨다. '한참'은 4번에서 1번으로 |
| 짧은 문장과 도치 | 서술의 짧은 쌍 “차가웠다. 그것뿐이었다.”를 “차가운 것뿐이었다.”로 묶었다. 도치는 없다 |
| 장면 끝 | 핀과 리아가 말없이 마당을 건넘 / 아무도 먼저 자러 가지 않음. 주제 해설은 없다 |

- 분량: 본문 약 4,700자, 공백 제외 약 3,400자. 장면 둘(그물 마당과 마당, 밤과 새벽). 설계의 위험('기다림만 있는 회차라 처질 수 있다')에 따라 서리 장면을 늘렸고, 다른 사건은 보태지 않았다.

## 13. 이 회차로 확정하면 안 되는 설정

- 서리가 오른 높이의 수치, 말뚝 사이의 거리
- 공방 뒤뜰의 불을 누가 몇 번 피웠는지, 장작의 양
- 연기 불이 어미 나무를 얼마나 지켰는지(19화에서 꽃이 있음으로만)
- 관리인의 '맑고 바람 없는 밤엔 안 내보낸다'가 언제부터의 규칙인지
- 핀의 고향 바위 마당의 모양
- 따뜻한 방에서 간격이 돌아온 까닭

## 14. 제19화로 이어지는 것 (원고에서 나열하지 않음)

- D+81 오후의 하늘(얇은 높은 구름, 바람이 잦아듦)
- 그날 해 지기 전에 공방에 말하기
- 공방 주인이 꺾는 가지, 그물 마당 북쪽 구석의 보관
- 해 질 녘 그물 마당, 데움을 낮춤
