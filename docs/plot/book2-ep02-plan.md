## 3. 장면 요약

1. **씨 거두기 (D+48 오후, 뒤꼍):**
   - 리아는 달을 세어 보고 씨가 여물기 전에 떠난다는 것을 안다.
   - 니오에게 부탁하자 니오가 조건 셋을 건다(“마르딘 아줌마 흉내야. 엄마는 다섯 개가 넘잖아.”).
   - 거두는 법 넷째 줄을 두고 다툰다. 리아는 지우지 않고 옆에 *살살*을 적는다. “내 거 고치지 말고, 네 건 옆에 그려.”
   - 봉숭아 꼬투리가 톡 터진다. 마렌은 아침에 따라고 하고, 콩 털기는 자기가 하겠다고 한다. “콩이 네 날짜 맞춰 마르는 거 아니다.”
2. **도아의 겨울 자리 (D+54 장날):**
   - 도아가 소금 장수와 처마 밑 자리를 흥정한다(“처마는 반으로 안 잘려.” / “그럼 과자 값을 반으로 잘라 드릴게요.”).
   - 행상의 골짜기 꽃물. 도아는 값을, 리아는 냄새를 본다. 달기만 하고 매운 것이 없다. “역참 나무? 그런 건 향이 안 돼. 골짜기 정원 꽃이 진짜지.”
   - 도아의 처마 첫날에 리아는 없다. “그날은 내가 틀려도 네 탓 못 하는 게 아깝지.” 외상 쪽지(*갚는 날: 서리 지나고*).
3. **편지 (D+66):** 꽃이 피기 시작했다. 되도록 빨리. 보름 치 짐, 겨울옷, 연필은 넉넉히. 다렌: “모레 아침에 떠나자.”
4. **떠나기 전날 저녁 (D+67):**
   - 맑고 바람이 없다. 빨래가 안 흔들린다. 마렌과 짚을 덮으며 서리 이야기를 듣는다(경험담과 배춧값).
   - 조건을 일하며 듣는다(밤엔 시설 안, 남의 꽃엔 손대지 말고 물어보기, 밤에 일하면 낮에 자기, 아프면 바로).
   - 다렌의 수문 일과 왕복 날수, 목수 연필.
   - 리아는 끝 줄을 대충 덮고 저녁 먹으러 뛰어 들어간다.
5. **새벽 (D+68):**
   - 마당이 하얗다. 덮은 줄은 살았고, 리아가 덮은 끝 줄의 틈에서 한 포기가 까매졌다. “이불도 틈이 있으면 소용없다.”
   - 리아가 '본 것'에 적는다. 니오의 그림 봉투 여섯.
   - 고갯길에서: “골짜기에도 서리가 왔을까요?” 다렌의 찬 기운 이야기. 서서 다시 적은 기록 *골짜기 바닥 — 서리가 먼저 옴(아빠). 꽃은 가서 볼 것.*

## 5. 자체 검수

### 5-1. 독서 피드백 1·2차 기준

| 점검 | 판정 |
|---|---|
| 뜬금없는 장면 전환 | 장면마다 첫 줄에 시간을 둔다: “역참에서 돌아온 지 엿새째”, “엿새 뒤는 장날”, “그로부터 열이틀 뒤”, “떠나기 전날 저녁”, “새벽에” |
| 청자가 불분명한 대사 | 모든 대사의 화자와 청자가 분명하다. 마렌의 말은 리아에게(짚을 덮으며), 니오에게(꼬투리), 다렌의 말은 가족에게(“모레 아침에 떠나자”) |
| 이유를 뒤에 붙이는 어순의 반복 | 자연스러운 구어 한두 곳뿐이다(“덜 춥다. 이상하지. 바람 불면 더 추울 것 같은데.”) |
| 한 단어 선언형 | 없다. “이제 가자.” 뒤에 까닭을 붙였다(“해 뜨기 전에 고개를 넘어야 한다”) |
| '동사. 오래 동사.' 두 박자 | 초고의 “달았다. 아주 달았다.”를 “숨이 막힐 만큼 달았다.”로 고쳤다. 남은 짧은 쌍은 봉숭아의 “톡. 또 하나. 톡.”(소리의 리듬)뿐이다 |
| 서술자의 의미 설명 | 없다. 마렌의 “이불도 틈이 있으면 소용없다.”는 일하며 하는 말로 두고, 서술은 리아가 본 것만 적는다 |
| 기록장과 동작의 혼합 | 기록 줄은 모두 따로 세웠다. *살살*과 *톡*은 짧은 표시라 문장 끝에 두었다 |
| '그럼 됐다' 반복 | 도아의 “그럼 됐어.”를 “그럼 네가 증인이야.”로 고쳤다 |

### 5-2. 원고 평가 기준 (style-guide §7)

| 기준 | 메모 |
|---|---|
| 인물의 개성 | 니오의 조건 셋과 *톡*, 도아의 흥정과 장갑, 마렌의 배춧값, 다렌의 “봄에 네가 와서 녹여라” |
| 감정의 설득력 | 리아의 아쉬움은 콩 꼬투리가 달그락거리는 소리로, 도아의 섭섭함은 “네 탓 못 하는 게 아깝지”로, 마렌의 걱정은 짚을 눌러 펴는 손으로 |
| 장면의 생동감 | 예상 밖의 일 셋: 봉숭아가 터짐, 행상의 꽃물이 다른 냄새, 틈 하나로 한 포기 |
| 문장의 리듬 | 씨 장면은 가볍게, 장터는 빠르게, 전날 저녁은 느리게, 새벽은 짧게 |
| 대사의 자연스러움 | 마렌의 서리 말은 소리 내어 읽어도 이어지는 생활의 말이다. 다렌은 물길을 말할 때만 길어진다 |
| 흡입력 | 장면 끝: *톡* / 연필을 깜빡함 / “모레 아침에 떠나자.” / 끝 줄을 대충 / 서리 밟히는 소리 |
| 서사적 재미 | 니오의 흉내, 소금 장수와 도아, “네 좌판 통째로”, “넌 냄새도 셈을 해?”, 목수 연필 |

### 5-3. 자체 수정 (한 차례)

- “아빠가 다렌에게 맡긴 것까지” → “다렌이 보탠 것까지”(같은 사람이었다).
- 마르딘 편지의 “모레 아침”은 쓴 날과 받는 날이 달라 기준이 흐렸다. “이 편지를 받으면 되도록 빨리”로 고치고, 날짜는 다렌이 정한다(“모레 아침에 떠나자.”).
- 다렌의 왕복 날수를 시간표에 맞췄다(데려다주고 오는 데 사흘, 데리러 역참 가는 데 이틀).
- 연필을 못 산 일을 다렌의 목수 연필로 이었다.
- 떠나는 장면에서 마렌의 손 흔들기를 뺐다. 제1권 제21화의 장면을 되풀이하지 않는다.
- 끝 문장(“아직 한 번도 가 보지 않은 길이 있었다”)이 제1권 마지막과 겹쳐서, 서서 다시 적는 기록과 서리 밟히는 소리로 바꿨다.

## 6. 이 회차로 확정하면 안 되는 설정

- 밀바람의 첫서리 날짜, 계절의 길이
- 서리의 생활 지식을 세계의 기후 규칙으로 보는 것(마렌의 경험이다)
- 골짜기 꽃물, 행상의 말(역참 나무와 정원 꽃), 향의 값
- 도아의 겨울 자리와 그 조건
- 마르딘 편지의 정확한 도착 날짜, 골짜기 꽃이 피기 시작한 날
