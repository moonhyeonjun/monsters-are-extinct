## 1. 집필 전 점검

### 1-1. 기존 세부 기획 (5단계 5화)

| 장면 | 목표 | 인과 |
|---|---|---|
| 5-1 수레의 상자 | 새 무리를 본다 → 털 열매처럼 한 덩이, 숨에 따라 부풀고 줄어듦, 옅은 김 | 리아가 *새 무리 — 한 덩이 / 여기 무리 — 따로따로*를 적는다. 뜻은 모른다 |
| 5-2 비어 있는 칸 | 무게가 줄었다. *처음 들여온 곳*이 비었다. 테오 “온도 차이겠지” | 리아가 빈칸을 빈칸으로 옮긴다(20화) |
| 5-3 냄새 맞추기 | 마르딘이 며칠 곁에 두어 냄새를 섞고 병을 본 뒤 합친다. 까닭은 자세히 말하지 않는다 | 리아는 헛간 밤 당번을 맡는다. 핀의 밤 바깥 관찰은 거절된다 |
| 5-4 첫 헛간 당번 | 해 질 녘 덩이가 조여지고 겉이 돈다(자리 돌기) | 리아가 간격을 적는다. 관리인 “보기만.” 리아의 마음이 이 무리에 묶인다 |

- 뒤 회차와의 연결 조건 (6·7화 설계에서 확인):
  - 6-3: 덩이가 비탈 위쪽으로 기운다. 문틈으로 매운 기운이 내려온다 → 헛간에 **비탈 위쪽으로 난 문**이 있어야 한다.
  - 7-1: 관리인이 꿀물을 늘리고 **데운 돌**을 넣는다 → 5화에서 '데우지 않는다'를 규칙으로 못 박지 않는다. 숯이 모자란 사정으로만 둔다.
  - 7-3: 리아가 상자를 들고 나간다 → 상자는 아이가 안을 수 있는 크기, 손잡이.
  - 7-3: 본관의 데움 관이 터진다 → 4화의 이음매는 관리인이 조였다. 터지는 관이 그것인지, 왜 터지는지는 정하지 않는다.

### 1-2. 제4화 끝에서 제5화로

| 제4화 끝 | 제5화 첫머리 |
|---|---|
| 밤, 리아가 혼자 “지금.” 하고 웃음. 마르딘: “내일 아침에 상자가 하나 와요.” | 새벽, 관리인이 다렌이 일러 둔 이음매를 쇠 집게로 조인다. “너희 아버지 귀가 밝더라.” 그리고 아침에 상자가 온다 |
| 다렌은 D+70 저녁 집에 닿음(작업 기준) | 수레꾼: “어제 한낮에 역참에서 보따리 멘 농사꾼 하나가 고개 쪽으로 가더라.” 리아는 아빠가 어젯밤 집에 닿았을 것이라고 생각한다 |
| 핀과 테오의 '세 번 보면' | 핀이 해 질 녘 따뜻한 방을 대신 지켜보고 보고한다. “세 번째는 내일 보는 걸로 치자.” |
| 핀이 너무 높이 달아 못 읽은 나무 위 온도계 | 핀이 낮에 읽었지만 때가 맞지 않아 쓸 수 없다. 해 질 녘에는 리아 대신 따뜻한 방을 보기로 하고, 나무는 다시 미룬다 |
| 라니가 이틀 치 가지를 가져옴 | 오늘은 가지가 들어오지 않는다(“가지 넣을 일도 없었고”). 라니는 등장하지 않는다 |

- 중심의 새 질문 (원고에서 묻지는 않는다):
  - 같은 생물이 왜 이쪽에서는 한 덩이이고 저쪽에서는 따로따로인가
  - 왜 바로 합치지 않는가
  - 처음에는 어디서 왔는가
- 실제 선택:
  - 빈칸을 비워 두기
  - 밤 당번을 맡고 문 앞을 포기하기
  - 느낌을 본 것과 섞지 않기
  - 데운 돌을 청하기
  - 핀이 나무 대신 리아의 부탁을 고르기

## 6. 자체 검수

### 6-1. 사용자 지시의 원칙

| 원칙 | 판정 |
|---|---|
| 1. 4화의 *꽃가루: 없음*과 감각 시험을 해답으로 만들지 않는다 | 꽃가루는 나오지 않는다. 감각은 리아가 스스로 본 것과 나누어 물음표로만 남긴다 |
| 2. 세 아이의 관찰 방법이 다르다 | 테오는 셈(종이의 무게를 빼서 추 두 개, 같은 때 읽어야 비교가 된다), 핀은 몸과 주변(젖은 천, 마른 접시, 나무, 문을 열어 보자는 실험), 리아는 질문과 기록 방식(한 마리예요?, 빈칸 옮기기, 관 없는지 먼저 확인, 속으로 센 간격) |
| 3. 관찰과 해석을 구분한다 | 서술은 '숨을 맞춘다'를 단정하지 않는다(“한꺼번에 부풀고 한꺼번에 줄었다”). 마른 까닭은 두 짐작으로 남고, 테오와 핀이 서로 “너도 짐작이잖아”라고 한다. 리아는 숫자가 고르지 않은 까닭을 모른다고 한다 |
| 4. 7화 이후 발견 순서 | §5 표대로다 |
| 5. 새 생리 규칙, 기관, 번식 | 만들지 않았다. 보낸 곳의 이름도 쓰지 않았다 |
| 6. 관 이음매 | 관리인이 조였다. 밤에 본관 쪽에서 관이 한 번 울린다. 원인이나 앞일은 쓰지 않았다 |
| 7. 시설 규칙은 작업 관행으로 | 냄새 섞기, 헛간 당번 조건, 문을 열지 않는 것, 데운 돌을 누가 정하는지 모두 이 시설 사람들의 일하는 방식이다 |
| 8. 설명 대사·재해설·습관적 짧은 쌍 | 마르딘의 계획 설명 한 번뿐이고, 까닭은 말하지 않는다. 기록 뒤에 뜻을 짚던 문장(“왜 다른지는 적지 않았다. 리아도 몰랐다.”)을 지웠다. 짧은 쌍은 종이의 칸 읽기와 리아의 셈뿐이다 |
| 9. 웃음과 경이, 억지 사고 없음 | 웃음: “한 마리예요?”, “둘 다면 둘 다라고 적어” / “너도”, “선생님은 바쁠 때 순서라고 해”, 리아의 숨이 덩이를 앞지름, 핀의 하늘 손가락. 경이: 숨 쉬는 털 뭉치와 김, 기울었다 돌아오는 덩이, 천천히 도는 덩이와 한 바퀴 도는 딸깍 소리, 목을 늘여 먹는 애. 사고는 없다 |

### 6-2. 연속성

- 날짜: D+71. 다렌은 D+70 새벽 출발, 그날 저녁 귀가(수레꾼의 말과 맞음). 수레꾼은 밤길로 와서 아침에 닿았다.
- 라니가 4화에 가져온 이틀 치 가지 → 5화에는 가지가 들어오지 않고 라니도 나오지 않는다.
- 날개 팬 개체: 3화 문 쪽을 봄 → 4화 안 봄(문을 열지 않음) → 5화 안 봄(문을 열지 않음, 핀의 보고).
- 핀의 나무 위 온도계: 4화 못 읽음 → 5화 낮에 읽었으나 때가 맞지 않음 → 다시 미룸.
- '밤 — 시설 안': 리아의 당번은 헛간 안, 관리인과 함께. 핀도 밤에는 시설 안.
- 3화 판자의 “문은 하나 닫고 하나 연다”를 핀이 따지고, 관리인은 “찬 바람 들어간다”로 답한다(3화 끝과 같은 말).

### 6-3. 문체 (독서 피드백 1·2차 기준)

| 점검 | 판정 |
|---|---|
| 장면 첫 줄의 연결 | “새벽에 부엌 쪽 벽에서”, “상자는 골짜기 바닥의 안개가 다 걷히기 전에”, “헛간은 따뜻한 방과 벽 하나를”, “마르딘은 점심 전에”, “해가 지자 헛간은” |
| 화자·청자 | 모든 대사의 화자가 분명하다. 관리인의 말 “상자가 좋은 데는 아니다…”는 “리아가 들으라는 듯이”로 청자를 밝혔다. 핀이 셈하는 속은 리아의 시점이라 쓰지 않고(“무슨 셈을 하는지 리아는 알 수 없었다”), 나중에 핀의 말로 드러나게 했다 |
| 같은 표현의 반복 | 4화에서 쓴 '등잔 기름이 줄어드는' 시간 표현을 이번에는 쓰지 않았다. '밤이 깊어질 무렵'이 겹친 곳을 '얼마 뒤'로 바꿨다 |
| 뜻이 둘로 읽히는 말 | “적은 게 아니라는”('적다'의 두 뜻) → “가벼운 일이 아니라는” |
| 복선 강조 | 첫 장면 끝의 앞당긴 문장(“그날 밤 리아의 방 벽은 조용했지만…”)을 지웠다. 이음매 수리의 결과를 미리 말하지 않는다 |
| 지나친 신비화 | 리아가 덩이의 숨을 따라 쉬자 '저절로 맞춰졌다'던 초안을 리아의 숨이 더 빨라 앞지르는 웃음으로 바꿨다. 19화의 맞춰지는 박자를 앞당기지 않는다 |
| 기록장 | 리아의 기록은 두 번(아침 한 줄, 해 진 뒤 두 줄)이고 편지는 따로다. 해석은 없다 |

### 6-4. 분량

- 본문 약 7,400자, 공백 제외 약 5,400자. 장면 다섯(첫 장면은 짧다).
- 1~4화(약 8,400~10,400자)보다 짧다. 5단계의 위험 메모(“무게와 기록 장면은 짧게 쓴다”)를 따랐다. 두 번째 원고에서 리아의 편지, 핀의 선택, 해 질 녘 문 앞 대화, 데운 돌, 관리인의 '네 해'를 보탰다. 더 늘리면 관찰의 반복이 된다고 판단했다.
