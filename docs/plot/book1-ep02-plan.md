## 1. 회차의 시작과 끝

- **시작** [확정 방향] (D-031): 제1화 밤의 **낯선 울음**에서 출발한다.
  - [제안] D+1 아침, 리아가 기록장에 밤의 소리('쾅', 짧고 가는 울음, 수차가 멈춘 뒤에도 이어진 울림)를 적는다. 바람 소리가 아니었다는 확신이 조사의 동기가 된다. 창밖 돌다리 아래에는 어젯밤 같은 안개가 없고 물이 불어 있다.
- **끝** [확정] (D-028): D+1의 비 오는 밤, 돌다리 아래 돌턱 부근.
  - 개체는 경계하며 일어서려 하지만 다친 앞다리 때문에 제대로 움직이지 못한다.
  - 리아는 다가가려다 개체의 두려움을 알아차리고 멈춘다.
  - **서로를 바라보는 첫 만남**으로 회차를 닫는다.
  - 학술적인 종 확인은 없다. 리아가 숨기기로 결심하는 장면은 제3화 이후로 넘긴다.

## 2. 리아의 행동 목표

| 구간 | 목표 | 장애 |
|---|---|---|
| 아침 | 밤의 울음이 무엇이었는지 알아낸다 | 어른들은 바람이나 짐승 소리로 넘긴다. 마렌의 금지("돌다리 근처에 혼자 가지 마") |
| 낮 | 울림과 울음이 나는 물길을 직접 조사한다 (새 수문 → 옛 우회 배수로 → 돌다리) | 수문은 어른들의 영역이다. 울림은 리아만 선명하게 느낀다 |
| 밤 | 약해진 울림의 자리로 가서 직접 확인한다 | 비, 어둠, 불어난 물, 어머니와의 약속 |

- 리아는 아직 생물의 존재를 모른다. 전반의 동력은 호기심과 "내가 틀리지 않았다"는 확인 욕구다. (리아의 결함: 자신의 확신에 집착, [lia-veln.md](../characters/lia-veln.md) §2)
- 회차 전체에서 리아는 **스스로 묻고, 가 보고, 기록한다.** 어른이 답을 주는 장면보다 리아가 단서를 찾는 장면을 앞에 둔다. (D-031)

## 3. 주요 사건 (7개)

### 3-1. 사건 구성 [제안]

1. **낯선 울음의 기록.** 아침, 리아가 밤의 울음을 기록장에 적는다. 울음이 바람이 아니었다는 확신으로 조사를 결심한다. 마렌은 아무 일 없었다는 듯 행동하고, 리아의 질문을 다른 일로 돌린다. (F15의 반복, 과거는 공개하지 않음)
2. **수문 조사 ① 새 관개 수문.** 다렌이 제1화에서 예고한 서쪽 밭 배수로 작업을 한다(작업 가정). 리아는 새참을 나르며 수문과 물길에 대해 묻는다. 다렌은 새 수문과 옛 우회 배수로가 서로 다른 수로이고 이어지지 않는다고 설명한다. 옛 배수로는 평소 닫혀 있다. (D-030, 제1화 발언 유지)
3. **수문 조사 ② 옛 우회 배수로와 돌다리.** 리아는 '혼자 가지 말라'는 말의 틈을 이용해 도아와 함께 옛 배수로를 따라 돌다리로 간다. 닫혀 있는 옛 물문, 그 아래 돌다리 밑의 높은 돌턱. 비에 젖은 다른 돌과 달리 돌턱 주변만 차갑고 이슬이 맺혀 있다. 울림은 리아에게만 선명하고, 도아는 물쥐나 수달 탓으로 넘긴다.
4. **이상 흔적.** 돌턱 근처에서 리아가 출처를 알 수 없는 **섬유 한 가닥**을 발견한다(D-029). 리아는 그것이 무엇인지 모른 채 기록장 사이에 끼워 둔다. 개체는 보이지 않는다.
5. **비가 다시 온다.** 저녁에 비가 다시 내린다. 어른들 사이에서 "비가 계속되면 옛 물문을 열어야 할지도 모른다"는 말이 나온다. 리아는 낮에 본 돌턱이 그 물길 옆에 있다는 것을 떠올린다. (D-024의 위협을 예고만 하고, 개방 일정은 정하지 않는다)
6. **약해진 울림.** 밤, 수차가 멈춘 뒤에도 울림이 이어지지만 전날보다 약하고 불규칙하다. 리아는 등불을 들고 비 속으로 나간다. 제1화에서 문고리에서 손을 거둔 장면과 대조된다.
7. **첫 만남.** 돌다리 아래 돌턱 부근에서 어린 미확인 개체를 처음 목격한다. 개체는 일어서려다 다친 앞다리 때문에 주저앉는다. 리아는 다가가려다 멈추고, 둘은 서로를 바라본다. (D-028)

## 6. 외형 특징

### 결정된 것 (D-027)

| 항목 | 내용 |
|---|---|
| 체형 | 네 다리로 걷는 초식동물형 |
| 날개 | 없음 |
| 머리 | 이마에 한 쌍의 짧은 뿔싹 |
| 부상 | 오른쪽 앞다리 |
| 신비로운 특징 | 뿔싹 주변에 맺히는 이슬, 털끝의 응결 |
| 크기 | 잠정: 몸통 길이 약 90~110cm, 어깨높이 약 65~75cm (작업 가정) |

- 원고에서는 수치를 쓰지 않고 리아와의 비교로 그린다. [제안] 예: 어깨가 리아의 허리께에 닿는 정도.
- 이 크기는 리아가 혼자 안아 옮길 수 없다는 뜻이다. 이후의 '숨김'은 개체를 데려가는 것이 아니라 **은신처의 위치를 숨기는 것**이 된다. (D-018과 일치)

### 아직 정하지 않은 것

| 항목 | 제2화에서의 처리 |
|---|---|
| 정확한 크기 수치 | 쓰지 않는다 (D-027) |
| 성체의 외형 | 다루지 않는다 (D-026) |
| 털의 색과 질감 | 원본 '창백한' [초안]. 어둠과 등불 속 인상으로만 쓴다 |
| 눈 | 등불에 비치는 인상으로만 쓴다 |
| 귀·꼬리 등 세부 | 두려움을 몸짓으로 보여줄 때 필요하면 정한다 (Q-생물-01) |
| 상처의 형태와 정도 | '디디지 못한다' 수준으로만 쓴다 [초안] |

## 7. 제1화와의 연결 및 설정 충돌 검토

### 연결

| 제1화 | 제2화 |
|---|---|
| 짧고 가는 울음 | 시작(사건 1)과 첫 만남의 소리(사건 7) |
| 다렌: "서쪽 밭은 내일 배수로를 한 번 더 열어 볼 거다" | 사건 2 (D+1 배수로 작업, 작업 가정) |
| 다렌: "그쪽은 오래된 수문이잖니. 새 물길하고는 이어지지 않아" | 사건 2에서 그대로 맞는 말로 다시 확인된다 (D-030) |
| 리아: "아래에서 이어질 수도 있잖아요" | 옛 우회 배수로라는 다른 물길이 있다 (F12 후보). 다렌의 말과 충돌하지 않는다 |
| 마렌: "그 돌다리 근처에 혼자 가지 마" | 낮에는 도아와 함께 가고, 밤에는 혼자 나가 금지를 어긴다 |
| 다리 아래 검은 틈에서만 흘러나오는 안개 | 돌다리 아래 돌턱 (작업 가정) |
| 창을 서둘러 닫는 마렌 | 아침에 질문을 돌리는 마렌 (F15 후보) |
| 책상 위의 작은 등불, 기록장 | 밤의 외출, 섬유를 끼워 두는 기록장 |
| 수차의 일정한 소리와 울림의 구별 | 수차가 멈춘 밤에 약해진 울림 (F16 후보) |
