# 장기 창작 원칙 — 시작과 결말을 먼저, 그 사이는 인물에게

> 상태: **편집 원칙 [확정] (2026-10-21, D-086).** 이 문서는 **창작 방식**을 정한다. 결말, 악역의 진실, 인물의 숨겨진 과거 같은 **내용**은 정하지 않는다. 내용은 §6의 단계별 작업을 거쳐 사용자 승인 뒤에만 정본이 된다.
> 관련: [adventure-engagement-design.md](adventure-engagement-design.md) (서사적 재미와 비전투 모험의 설계, §8의 자세한 판), [style-guide.md](style-guide.md) (문체와 대화), [series-arc.md](series-arc.md) (장기 구조 [초안]), [foreshadowing.md](foreshadowing.md) (복선 공개 관리), [key-scenes.md](key-scenes.md) (장기 명장면 후보), [../proposals/memorable-lines.md](../proposals/memorable-lines.md) (명대사와 장기 감정 회수 [제안]), [characters/](../characters/), AGENTS.md (공통 규칙)

## 1. 창작 철학

- 작품의 **시작과 최종 결말을 먼저 설계**한다. 그 사이에서는 **인물들이 각자의 욕망과 신념에 따라 자유롭게** 행동하게 한다.
- 참고하는 것은 작가가 가장 좋아하는 두 작품, 《강철의 연금술사》와 《진격의 거인》의 **완성도 높은 결말**과 **입체적인 인물**이다. 액션의 규모나 어두운 분위기가 아니다.

| 참고하는 특성 | 출처 |
|---|---|
| 처음 제시한 주제와 마지막 결말의 연결 | 강철의 연금술사 |
| 초반 설정과 작은 사건이 후반에 의미를 갖는 구성 | 강철의 연금술사 |
| 중요한 선택에는 그에 상응하는 대가가 따르는 구조 | 강철의 연금술사 |
| 인물마다 서로 다른 가치관과 행동의 이유 | 강철의 연금술사 |
| 주요 갈등을 해결하면서도 감정적 여운을 남기는 결말 | 강철의 연금술사 |
| 새로운 진실이 과거 사건의 의미를 바꾸는 구조 | 진격의 거인 |
| 일차원적인 선악 구분을 넘어서는 인물 | 진격의 거인 |
| 신념과 이해관계의 충돌 | 진격의 거인 |
| 초기부터 심어진 복선의 장기적 회수 | 진격의 거인 |
| 이야기 전체를 다시 돌아보게 하는 반전 | 진격의 거인 |

- **모방하지 않는다.** 두 작품의 구체적인 사건, 설정, 캐릭터, 결말을 가져오지 않는다. 잔혹함과 비극의 규모를 따라가는 것도 목표가 아니다.
- **정체성을 지킨다.** 《괴물은 멸종했습니다》는 어린이·청소년이 읽을 수 있는 판타지 모험이다. 경이와 재미, 생활의 온기를 유지한다 (AGENTS.md 7, style-guide §1).

## 2. 독자가 시리즈를 다 읽었을 때 느껴야 할 것

1. 처음부터 하나의 큰 이야기로 연결되어 있었다.
2. 초반의 작은 장면들이 마지막에 중요해졌다.
3. 반전이 놀랍지만 다시 읽어 보면 납득된다.
4. 악역에게도 자기만의 이유가 있었다.
5. 주인공의 마지막 선택은 그동안의 경험이 있었기에 가능했다.
6. 결말이 끝난 뒤에도 인물들의 선택을 생각하게 된다.

## 3. 반드시 구분할 세 가지

| 구분 | 내용 |
|---|---|
| **확정할 것** (§6 작업과 사용자 승인을 거쳐) | 세계의 근본 규칙 / 역사적으로 실제 일어난 핵심 사건 / 최종적으로 밝혀질 진실 / 시리즈 전체의 핵심 갈등 / 리아의 마지막 선택이 갖는 의미 / 중요한 인물들의 서사적 귀결 / 반드시 회수할 핵심 복선 |
| **유연하게 둘 것** | 중간 사건의 순서 / 모험의 구체적인 경로 / 인물들이 갈등을 해결하는 방법 / 대화와 관계의 변화 / 예상 밖의 사건과 새로운 발견 / 전체 권수와 회차 수 |
| **피할 것** | 결말을 위해 인물에게 부자연스러운 행동을 강요하는 것 / 놀라운 반전만을 위해 뒤늦게 설정을 추가하는 것 / 모든 인물이 주인공을 돕거나 방해하기 위해서만 존재하는 것 / 완벽한 정본 관리를 위해 이야기의 재미를 희생하는 것 |

- 함께 지킬 금지: 최종 반전만을 위해 기존 정본을 무효화하지 않는다. **리아의 혈통이나 선택받은 운명으로 갈등을 해결하지 않는다** (lia-veln.md §6, D-004).

## 4. 인물 설계 원칙

주요 인물마다 다음 여덟 가지를 검토한다. 모든 인물을 선하거나 악한 한 가지 특성으로만 정의하지 않는다.

| # | 항목 | 질문 |
|---|---|---|
| 1 | 겉으로 드러나는 목표 | 이 인물은 무엇을 하려 한다고 말하는가 |
| 2 | 내면의 욕망 | 본인도 인정하기 어려운, 정말로 원하는 것은 무엇인가 |
| 3 | 가치 | 무엇을 가장 중요하게 여기는가 |
| 4 | 그 가치 때문에 저지르는 잘못 | 그 가치가 어디서 사람이나 생물을 다치게 하는가 |
| 5 | 이해 가능한 이유 | 독자가 "나라도 그랬을지 모른다"고 느낄 근거는 무엇인가 |
| 6 | 바꾸지 못하는 부분 | 끝내 놓지 못하는 것은 무엇인가 |
| 7 | 변화의 계기와 대가 | 변한다면 무엇이 계기이고 무엇을 잃는가 |
| 8 | 최종 결말에서의 역할 | 마지막에 이 인물의 선택이 무엇을 완성하거나 무너뜨리는가 |

- **베르크:** 단순한 방해자 이상의 동기와 논리가 필요하다. D-055("처음부터 명백한 악당처럼 행동하지 않는다")를 장기 설계로 확장한다.
- **마렌, 마르딘:** '비밀을 숨기는 어른', '신중한 전문가'라는 기능적 역할을 넘어, 자신의 신념과 잘못된 선택을 가질 수 있어야 한다.
- 이미 있는 장치와 이어진다: 카이런 벨도르를 "과거의 죄가 있고도 마지막 순간 생명을 구한 복합적 인물"로 보존하는 원칙(series-arc §3), "명장면을 만들기 위해 인물의 행동을 작위적으로 바꾸지 않는다"(key-scenes §0, D-045).

## 5. 결말 설계 원칙

- 장기 구조를 검토할 때는 **최종 결말에서 거꾸로** 사건을 설계한다.
- 최종 결말은 **아직 확정하지 않는다.** 서로 다른 철학을 가진 결말 후보를 여러 개 설계하고 비교한 뒤, **사용자 검토와 승인 후에만** 정본으로 확정한다.

### 5-1. 핵심 검토 질문

1. 시리즈 마지막에 리아가 내려야 할 가장 중요한 선택은 무엇인가?
2. 그 선택을 어렵게 만드는 서로 충돌하는 가치는 무엇인가?
3. 선택에는 어떤 대가가 따르는가?
4. 첫 권의 사건은 그 선택과 어떻게 이어지는가?
5. 멸종, 복원, 보호, 자유라는 주제가 어떻게 발전하는가?
6. 이르바넬의 비밀은 전체 이야기를 어떻게 새롭게 해석하게 만드는가?
7. 주요 인물의 결말은 각각의 욕망과 선택에 대한 결과인가?

### 5-2. 결말 후보의 평가 기준

| 기준 | 질문 |
|---|---|
| 주제적 완결성 | 첫 권의 주제(무엇이 '안전한 곳'인가, 소유하지 않는 보호)가 마지막에 완성되는가 |
| 리아의 선택이 갖는 무게 | 그 선택은 리아만이, 리아의 경험 때문에 할 수 있는 것인가. 대가가 있는가 |
| 인물별 갈등과 귀결 | 각 인물의 결말이 자기 욕망과 선택의 결과인가 |
| 초반 설정의 회수 가능성 | 제1권의 장면들(기록장의 빈칸, 물러서기, 두 번 핀 꽃, 지도에 없는 물길 등)이 다시 의미를 얻는가 |
| 장기 미스터리의 설득력 | 공정성 규칙(foreshadowing §1)을 지키는가 |
| 경이와 감정적 여운 | 어린이·청소년 독자에게 경이와 여운이 남는가 |
| 반전의 질 | 예상하기 어렵지만 다시 읽으면 납득되는가 |

- 어느 단계도 기존 원고와 확정 설정을 임의로 바꾸지 않는다. 바꿀 필요가 생기면 비교안을 내고 승인을 받는다.

## 8. 서사적 재미와 비클리셰 원칙 (사용자 지시 2026-10-24, 결정 번호 없음)

> 자세한 판: [adventure-engagement-design.md](adventure-engagement-design.md). 이 절은 요약이다. §1~7(D-086)의 내용은 바꾸지 않는다.

- **목표:** 배틀물이 아닌 모험 판타지로서, 배틀 판타지가 주는 긴장·승부·강자에 대한 동경·역전의 쾌감을 이 작품만의 방식으로 구현한다. 전투를 억지로 넣지 않는다.
- **비클리셰 원칙**
  1. 흔한 판타지·소년물의 전개 공식을 무비판적으로 반복하지 않는다.
  2. 독자가 다음 사건이나 인물의 선택을 쉽게 예측하지 못하게 한다.
  3. 반전은 인물의 욕망, 선택, 기존 복선과 인과에서 나온다.
  4. 반전을 위한 반전이나 갑작스러운 설정 변경을 피한다.
  5. 주인공의 성공이 반드시 긍정적인 결과만 낳지는 않는다.
  6. 적대하거나 대립하는 인물도 때로 옳은 판단을 한다.
  7. 선한 인물에게도 실제 결함과 잘못된 판단의 대가가 있다.
  8. 이미 알고 있던 사실의 의미가 달라지는 반전을 적극 쓴다.
  9. 예상 밖의 전개와 함께 충분한 감정적 보상과 경이를 준다.
  10. 처음과 결말을 정교하게 이어 다시 읽을 때 새 의미가 드러나게 한다.
  - '무조건 클리셰를 뒤집는다'는 규칙이 아니다. 익숙한 전개라도 감정적으로 가장 효과적이면 쓴다.
- **비전투 모험의 재미:** 강자는 뛰어난 전문가의 활약으로, 실력 경쟁은 발견·검증·탐사·공로의 승부로, 능력 상성은 현장·문헌·장치·환경 이해의 차이로, 전술적 역전은 기존 정보와 전문성의 새 활용으로, 강대한 상대는 낯선 생태계와 탐사 조건으로 바꾼다. 강함에는 읽고 기다리고 물러서는 힘도 들어간다(series-arc §3·§5).
- **복원사의 매력:** 탐험, 보호와 판단, 기록의 검증([../world/restoration.md](../world/restoration.md) §7)이 행동으로 드러나게 한다. 만능 인물을 만들지 않는다. 새 능력의 각성보다 기존 지식의 창의적 활용을 중시한다. 리아의 감각을 혈통이나 운명과 잇지 않는다(§3, D-004).
- **모험 구조:** 권마다 한 문장 목표, 강한 압박, 실제 변화, 결정적 실력, 선택의 대가, 보상, 이전 권과 다른 모험 방식을 확인한다. 모든 권을 '탐사 → 사고 → 구조 → 기록' 공식으로 만들지 않는다.
- **경이:** 긴장만큼 낯선 생물, 독특한 자연, 도감 밖의 발견, 오래된 세계의 흔적을 쓴다. 대형 생물과 새 장소는 환류기관 규칙과 공개 순서에 맞춰 따로 설계·검증한다.
- **인물의 매력:** §4의 여덟 항목에 더해, 장면에서 욕망·실력·예상 밖의 선택·일관된 기준·대가·관계 변화·재등장의 기대가 보이는지 본다. 인물들이 '정직한 관찰과 기록'을 같은 말과 같은 방식으로 표현하지 않게 한다.
- **검수:** 예측 가능성, 반전의 설득력, 선택의 차별화, 실력의 체감, 긴장과 승부, 실제 변화, 경이와 보상, 패턴 반복을 본다(자세한 판 §7). 모든 회차에 반전·액션·위기를 강제하는 체크리스트로 쓰지 않는다. 회차 원고의 평가는 [style-guide.md](style-guide.md) §7(D-052)이 그대로 기준이다.
