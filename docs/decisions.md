# Decisions — 설정 결정 및 변경 이력

이 문서는 《괴물은 멸종했습니다》 정본에 반영된 결정과, 원본 자료의 어느 부분이 어떤 결정으로 대체되었는지를 기록한다.

## 운영 규칙

### 판단 우선순위 (AGENTS.md)

1. 사용자가 명시적으로 승인한 최신 결정
2. 확정 설정 문서와 승인된 변경 기록
3. 최신 상세 기획 문서
4. 이전 작업 초안
5. AI가 제안한 새로운 아이디어

### 상태 표기

| 표기 | 의미 |
|---|---|
| `승인` | 사용자가 명시적으로 승인함. 정본에 반영한다. |
| `승인(원본)` | 원본 자료에 '사용자 승인'으로 표시되어 있고 PROJECT_CONTEXT에서도 승인 설정으로 다룸. |
| `승인(방향)` | 사용자가 현행 기획의 방향으로 승인함. 방향은 정본에 `[확정]`으로 반영하되, 결정에 적히지 않은 세부 묘사·수치·대사는 `[초안]` 또는 작업 가정으로 둔다. |
| `제안` | 이관 중 정리한 권장안. 사용자 승인 전에는 정본에 `[초안]`으로만 반영한다. |
| `대체됨` | 이후 결정으로 무효가 됨. 원본은 보존하되 정본에 옮기지 않는다. |

각 결정은 `결정 / 출처 / 대체하는 원본 / 반영 위치 / 남은 문제`를 적는다. `마스터`는 `imports/chatgpt/세계관 마스터 v1.3.md`다. `§I-n`은 마스터 첫머리 통합 본문(v0.5, 0~10절), `§5-n`은 그 안의 제5장, `§n-m`은 제6~13장의 절이다. 자세한 규칙은 [canon.md](canon.md) 참조.

  2. **결말:** 야간 반출은 저지되지만 **베르크의 서류와 마을의 의견 대립은 해결되지 않는다.** 마르딘 로웰은 등장하지 않는다. 로안 스콜은 D+6에 첫 등장한다.

  5. **카셀:** 발자국 신고가 수상하다는 가능성을 인식하지만 실제 위험일 수 있어 무시하지 못한다. 떠나기 전 ① 다렌·수로 관리인·마을 주민 1명의 대리 경계, ② 개체를 임의로 옮기거나 인도하지 말라는 명시적 지시, ③ 문제가 생기면 사람을 불러 현장을 보존하는 절차를 마련한다. 대리 경계자에게 카셀과 같은 법적 권한이 있는 것처럼 쓰지 않는다. 카셀이 돌아오기 전까지 반출을 막는 것은 서류의 최종 판단이 아니라 **미확인 상태의 유지**다.

## D-065. 제9화 〈원본〉 집필 결정

- 상태: `승인` (2026-10-21)
- 결정: D-063의 검수 반영과 제8화 1차 승인 상태를 유지한다. 제9화 기획의 기본 방향을 승인한다.
  1. 제목 **〈원본〉**, 기본 작중 시점 **D+7 정오~밤**. 서사 중심은 **무엇을 증거로 삼는가.** 전문가 한 명이 갈등을 해결하는 이야기가 아니라, 인물들이 서로 다른 증거와 이해관계를 내세우며 진실을 확인하려는 회차다. 제1~8화 원고는 바꾸지 않는다.
  2. **마르딘의 도착:** 하벨 내 협회 협력 보호시설에 머물고 있었다는 기본안을 쓴다. D+7 정오 도착이 성립하는지 먼저 검증한다(검증 결과는 기획서 §14-1, 작업 가정). 무리한 이동이 필요하면 대안을 보고하되 임의로 확정하지 않는다. 첫 대면은 **장터 어귀에서 짧게**, 본격적인 기록 검토는 **벨른 가 식탁**에서 한다. 마르딘은 리아를 특별한 아이로 알아보거나 숨은 재능을 간파하지 않는다.
  3. **기록장 전달 (감정적 중심):** 카셀은 기록의 소유자가 리아임을 존중하고, 리아가 직접 마르딘에게 건네게 한다. 마르딘은 직접 본 사실, 들은 사실, 추측, 아직 알 수 없는 것, 환류 감각에서 시작된 가설을 구분해 질문한다. 지운 장소와 물음표를 검토하되 무조건 칭찬하거나 비난하지 않는다. 리아의 잘못과 기록의 가치를 함께 인정한다. 필요한 내용을 옮긴 뒤 **당일 반환**한다.
  4. **정체와 보호:** 환류종일 가능성을 검토하지만 종과 생존 여부를 공식 확정하지 않는다. '미확인 환류종 개체 1, 생존'을 확정된 공식 판정으로 기록하지 않는다. 현장 관찰 사실과 분류 가설을 분리한다. 새 생리·행동 능력, 먹이 선호, 정체를 더하지 않는다. 마르딘은 당장 옮기지 않는다는 **임시 보호 판단**을 내리고, 그 근거로 리아의 기록·카셀의 장부·현장 측정·로안의 관찰을 쓰되 출처를 밝힌다. 임시 보호 판단과 법적 소유·인도 권한을 구분한다.
  5. **위임장과 보상:** 마르딘은 협회 인장이 없음을 확인하되 그것만으로 위조라고 단정하지 않고, 기존 **감찰국**에 조회를 요청한다. 새 법적 기관이나 자격 제도를 만들지 않는다. 베르크는 조회를 반대하지 않는다. 마르딘은 보상 지급을 약속할 수 없다. 카셀은 피해 장부를 상부에 전달할 수 있지만 실제 보상 여부는 확정하지 않는다. 마을의 의견 분열은 한 회차에서 해결되지 않는다.
  6. **마르딘의 한계:** 수로와 주변 변화에 대해 불완전한 가설을 세울 수 있다. 틀린 사실로 단정하지 않고 추가 확인이 필요한 임시 판단으로 쓴다. 수정의 여지를 남긴다.
  7. **도아·리아·로안:** 두 아이는 함께 질문할 수 있지만 신뢰가 완전히 회복되거나 어른의 결정을 대신하지 않는다. 로안은 여전히 베르크에게 삯을 받는 길잡이다. 마르딘이 산길 재조사를 요청할 수 있으나 실제 조사는 다음 회차로 미룬다. 로안이 누구 편인지 확정하지 않는다.
  8. **절정 A+C:** A — 해 질 녘, 현재 상태에서는 어느 짐마차로도 옮기지 않는다는 임시 보호 판단. C — 밤, 마르딘이 협회 일지에 무언가를 기록하는 조용한 마지막 장면. 내용은 작위적인 행동 없이 자연스러운 시점 제한으로 남긴다.
