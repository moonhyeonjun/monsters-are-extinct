지금 작가가 승인할 것

1. 감응자 식별

추천

환류종 가까이에서 눈이 박동에 맞춰 저절로 떨리고 균형이 흔들림(평형 기관 가설) + 보는 관습·징집 검사 + 기록과 계보. 신체 표식은 쓰지 않음. 귀결: 멸종 뒤엔 가문만 감응자를 가려낼 수 있음.

2. 집결의 목적

추천

박동의 재동기화와 번식. 혼자 지내면 박동이 어긋나고, 진동을 모으는 지형에 모여 다시 맞춘 뒤 번식. 대안: 번식만 / 기관의 갱신 / 극한기의 피난.

3. ‘아르바넬만 살아남았다’의 범위

추천

마지막으로 기능하는 집결지 + 그곳을 쓰는 집결형 종의 마지막 번식 집단. 떠도는 개체와 비집결형 종은 따로. ‘모든 종이 이곳에만’은 쓰지 않음.

4. 아르바넬 생존의 인과

추천

가문 조상의 ‘조용한 땅’ 곁 집결지 + 다른 집결지는 군에 넘기고 이곳만 숨김(보호이자 계산) + 갈 곳 잃은 무리가 머물러 위험이 상시.

5. 봉인·선언 제도 보강

추천

봉인령과 관리 위임, 면제 규정, 고요한 철의 바깥 점검, 마지막 원정 = 다른 집결지의 실제 학살 + ‘세상의 마지막’이라는 허위, 실무자가 손수 쓰는 거짓 보고.

함께 확인

이름

‘아르바넬’(지시서 표기)을 공식 명칭으로 쓸지. W 자료는 ‘이르바넬’.

승인된 것 (P결정-001~004)

작업 방식 · 단일 가문

W 보존, P를 처음부터. 가문이 은폐·기록 말살·선언 조작을 주도. 아는 사람은 극소수. 백지 연표. 인물 전면 재창조.

영웅 가문의 역사

유전병처럼 차별받던 감응자 집안 → 대토벌의 실제 공로 → 영웅·순결의 명문 → 비밀 연구와 집결지 → 위험지역 → 멸종 뒤의 연구·훈련·독점.

P결정-004 채택

  • 가문 성장 구조
  • 첫 번째 침묵 = 기록과 실제가 다름
  • 선언 = 제도의 빈틈 + 마지막 원정
  • 국가 봉인 구역, 가문은 관리권
  • 두 겹 비밀(핵심 진실 / 영웅적 보호 활동)
  • 감응 기술은 탐지와 해석까지

P결정-004 새 요구

  • 감응자가 자기 뜻과 관계없이 드러나는 식별 구조
  • 집결지는 원래 여러 곳, 대토벌로 사라짐
  • 아르바넬은 가문이 숨겨 살아남은 마지막 온전한 집결지

감응자는 어떻게 드러나는가 후보

공존 시대 · 떨리는 눈

무리가 지나는 철, 아이의 눈이 저절로 떨리고 휘청거림 → 병, 낙인, 혼인 거부

→
대토벌 시대 · 보는 눈

같은 떨림이 숨은 무리를 가리키는 바늘 → 징집, 수색, 공로

하나의 현상, 두 개의 해석. 차별받은 이유와 쓸모 있어진 이유가 같은 몸의 반응입니다.

유형요지판단
A 비자발적 생리 반응평형 기관이 박동에 흔들려 눈이 박자에 맞춰 떨리고 균형이 흔들림. 본인 협조 없이 보임. 다른 어지럼과 헷갈려 누명도 생김핵심 추천
B 선천적 신체 특징태어날 때 보이는 표식제외 혈통 표식처럼 됨
C 환경 반응과 사회적 판별무리 철의 ‘떨림 보기’ 관습, 대토벌의 징집 검사추천(제도)
D 가족·공동체 기록떨림 아이의 기록과 계보 → 낙인이 대를 넘음 → 뒤에 명문의 족보로추천(지속)

신호와 기관의 가설

기관의 주기적 수축 → 매질의 낮은 진동 → 감응자의 예민한 평형 기관 → 박자의 지각과 저절로 일어나는 눈 떨림. 훈련으로 해석이 정확해지고, 눈을 고정해 떨림을 줄일 수 있음(완전히 감추진 못함).

할 수 없는 것

생물에 영향 주기멀리서 부르기집결지 바꾸기마음 읽기

멸종 뒤의 귀결

환류종이 없으면 떨림도 없음 → 누가 감응자인지 아무도 모름. 살아 있는 개체를 가진 가문만 가려낼 수 있음(식별의 독점). 지금의 감응자는 처음 살아 있는 개체 곁에 설 때 비로소 드러남.

다중 집결지와 긴 주기의 집결 후보

모델집결의 목적판단
1번식과 유전 교류4와 결합
2기관의 갱신대안
3극한기의 피난과 회복대안
4박동의 재동기화: 혼자 지내면 박동이 어긋남 → 진동을 모으는 지형과 많은 동족이 있어야 다시 맞음 → 맞춰진 상태에서 번식추천

왜 여러 곳이었나

진동을 모아 울리는 지형과 물이 있는 곳마다. 종마다 쓰는 곳과 주기가 다름. 모든 종이 한꺼번에 모이지 않음. 집결하지 않는 종도 많음.

첫 번째 침묵의 실제

여러 집결형 종의 주기가 드물게 겹친 해. 많은 무리의 박동이 한꺼번에 약해지고(‘조용해졌다’), 한꺼번에 사람의 땅을 지나 집결지로 향함 → 충돌 → 대토벌의 명분.

다른 집결지가 사라진 방식

집결 중 매복과 학살(가장 효율적인 사냥터) · 샘을 메우고 물길을 돌림 · 길을 아는 늙은 개체의 죽음 · 사람의 정착. 가문이 그 정보를 군에 줌.

‘아르바넬만’의 범위

마지막으로 기능하는 집결지 + 집결형 종의 마지막 번식 집단. 바깥엔 떠도는 개체(박동이 어긋난 채 옛 터를 찾아 헤매는 마지막 개체)가 있을 수 있음 — 첫 경이 후보.

아르바넬만 살아남은 이유 후보

순서사건
1차별 시대, 가문의 조상이 물러난 ‘조용한 땅’ 곁에 집결지가 있었다. 주기 사이엔 비어 조용하고, 수십 년마다 견딜 수 없는 ‘울림의 해’가 왔다
2대토벌 중 연구로 그 울림이 집결이라는 것을 깨달음
3다른 집결지는 군에 알려 공을 세우고, 자기 땅의 집결지만 숨김 — 보호이자 계산
4집결의 해에 원정대가 그 땅에 들어가 겹친 박동의 재난(‘흰 골의 참사’). 가문이 막을 수 있었는지는 미결정
5가문의 권고로 국가 봉인 구역 지정, 위험의 해를 미리 아는 집안이라는 이유로 관리권 위임
6멸종 선언에서 봉인 구역은 면제 규정으로 빠짐
7갈 곳 잃은 무리가 흩어지지 않고 머묾 → ‘상시 집결’ → 위험이 늘 진짜 → 봉인 유지의 근거

머무는 무리의 비용

쉬는 시기가 없어 지침, 번식 리듬의 흐트러짐, 병의 확산, 다양성 감소. 가문의 관리(골짜기 나누기, 겨울 먹이, 격리)로도 쇠약을 되돌리지 못함.

영웅적 선택이었나

실제로 무리를 지켰다. 아르바넬이 없었다면 집결형 종은 모두 사라졌다. 동시에 다른 집결지를 내준 공로, 숨긴 곳에서 얻을 지식과 지위, 식별의 독점이라는 계산이었다. 어느 한쪽으로 정리하지 않음.

국가 봉인 구역과 멸종 선언 구조 승인 보강 후보

관리권

참사 → 조사 → 가문의 권고 → 봉인령(소유 왕실) → 관리 위임 칙허(연례 보고, 감시 초소, 위험의 해 예고, 몇 년마다 갱신).

면제 규정

“봉인 구역은 조사단의 생명을 위해 조사에서 제외하고, 관리 기관의 보고로 갈음한다.” 참사 직후의 안전 규칙으로 받아들여짐. 반대한 학자의 의견서는 각주로.

감사와 점검

재정관은 장부만. 현장 점검은 몇 년마다 고요한 철에, 가문이 정한 길로, 바깥만. 측정도 감시소 직원이 해 순환 검증.

마지막 원정

사실: 다른 집결지의 마지막 무리를 친 실제 학살. 허위: ‘세상의 마지막 무리’. 원정 보고서에서 아르바넬 방향의 정찰 기록이 빠짐.

두 겹 비밀 — 실무자의 지식과 책임

핵심 (직계 일부·원로 일부·집사장)다른 집결지를 넘긴 일, 원정의 허위, 면제 규정의 경위, 연구의 실체—
안쪽 사육·관리 직원무리가 살아 있다, 수·건강·위험. 무리의 생존을 실제로 책임짐영웅 가문이 마지막 무리를 몰래 지킨다
감시소 기록관두 벌의 장부. 국가 보고서를 쓰는 손(법적 공범)공개하면 사냥꾼이 덮친다
바깥 초소 직원위험의 날짜와 세기땅이 위험하다(진실의 일부)
비밀은 ‘아는 사람의 수’가 아니라 ‘아는 것의 의미’로 지켜집니다. 실무자는 무리가 살아 있다는 것을 압니다.

지금 흔들리는 계기 (후보)

새 측정 기술이 흔들림에서 생물의 박자를 찾아냄 · 주기의 해와 갱신 심사 · 복원 산업의 출입 요구 · 떠도는 개체 · 실무자의 이탈 · 예산 다툼

가문의 네 시대와 사회 방향 승인

시대 A

차별과 은둔

떨리는 눈 → 병, 혼인 거부 → 강요된 내혼, 조용한 땅.

시대 B

대토벌과 영웅

징집 검사와 강제 동원 → 사슬 수색의 실제 공로 → 징집법과 보상 규정으로 작위.

시대 C

연구와 봉인

집결의 이해 → 다른 집결지를 넘기고 아르바넬을 숨김 → 봉인과 관리권.

시대 D

멸종 뒤의 독점

식별의 독점, 감응 면허(후보), 연구와 훈련.

‘병든 피’ → ‘순결한 피’뒤집힘(후보)
법감응자 징집법, 공훈 보상 규정, 가문이 맡은 감응 면허
제도징집 검사 → 가문의 공인 검사 → 면허. 판정 권한이 가문으로
기록낙인의 명부가 가문의 족보와 공훈록으로. 평민 감응자는 ‘병자 명부’에 남음
행동같은 떨림이 가문 사람에겐 ‘보는 눈’, 평민에겐 ‘떨리는 눈’

현재 가문 안

공인 감응자는 존경받지만 삶을 가문이 정함 · 비감응 직계는 실제 힘을 쥐지만 선전에서 감춰짐 · 비감응 계승자는 숨김 · 몰래 입양된 감응자는 가장 묶임(후보)

가문 밖 감응자

지금은 자기가 감응자인지 모름. 살아 있는 개체 곁에서 처음 드러날 때 누가 보았느냐에 따라 운명이 갈림.
