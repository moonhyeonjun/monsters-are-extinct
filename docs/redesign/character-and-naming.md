# 인물 재창조와 작명 기준

> 상태: **작업 지침** (2026-10-30, 추가 지시 “등장인물 재창조 및 고유한 작명”). 규칙의 요지는 [AGENTS.md](../../AGENTS.md) §12에 있다.
> 이 문서는 기준과 절차만 정한다. 실제 인물을 지우거나 이름을 바꾸지 않는다. 이름 후보를 만들지 않는다.

---

## 1. 인물 재창조 원칙

- **기존 인물을 유지할 의무가 없다.** 리아를 포함한 모든 인물의 이름, 성격, 외형, 나이, 관계, 서사적 역할을 다시 검토할 수 있다.
- 기존 인물마다 다섯 가지 중 하나로 판정한다.

| 판정 | 뜻 |
|---|---|
| 유지 | 이름과 핵심을 그대로 씀 |
| 핵심 매력만 보존하고 재설계 | 독자가 좋아할 핵심(말버릇, 관계의 결, 가치)만 남기고 나머지를 새로 짬 |
| 통합 | 기능이 겹치는 인물을 하나로 합침 |
| 삭제 | 새 줄거리에 자리가 없음 |
| 대체 | 같은 서사적 기능을 완전히 새 인물이 맡음 |

- 목표는 삭제나 개명이 아니라 **전체 줄거리의 재미와 인과에 가장 맞는 인물 구성**이다.
- 판정은 3단계(인물·관계 설계)에서 하고, 작가 승인을 받는다. 판정마다 이유를 적는다(무엇을 얻고 무엇을 잃는가).

## 2. 인물 수와 관계망

- 주요 인물 수는 미리 정하지 않는다. 필요한 사건과 관계를 먼저 설계하고, 그 사건을 가장 흥미롭게 만드는 인물 조합을 고른다.
- 학생 집단은 남녀 비율을 대체로 균형 있게 한다. 숫자를 맞추려고 인물을 만들지 않는다. 각자 독립된 목표와 역할이 있어야 한다.
- 관계의 갈래: 우정, 경쟁, 동경, 짝사랑, 상호 호감, 오해, 결별, 재회, 연애로 이어지지 않는 깊은 우정, 처음 예상한 상대와 다른 인물에게 마음이 움직임
- 독자가 여러 관계의 발전을 기대하게 하되 모든 관계를 연애로 잇지 않는다.
- 로맨스는 독자의 관심을 높이는 요소로 쓰되, 인물의 독립된 목표와 생태 복원 서사를 희생시키지 않는다. 청소년의 나이와 성장 단계에 맞게 다룬다.
- 관계마다 시작, 주요 변화, 갈등, 마지막 상태를 정한다([checklist.md](checklist.md) G).

## 3. 인물 설계의 순서

> **서사적 역할 → 욕망과 결함 → 결정적 선택 → 관계망 → 출신 문화 → 이름 후보 → 작가 승인**

- 이름부터 많이 만들지 않는다.
- 인물의 주요 비밀과 최종 운명은 전체 줄거리가 확정될 때 함께 정한다.
- 인물마다 채울 항목은 [checklist.md](checklist.md) F(F1~F13)다.
- 비밀은 비밀 원장과 맞춘다(아는 것, 잘못 아는 것).

## 4. 작명 원칙

1. 주요 인물의 이름은 **한 번 들으면 기억에 남을 만큼 독특하고, 그 인물과 강하게 어울리게** 짓는다.
2. 흔한 판타지 이름과 유명 작품의 대표 인물 이름을 무비판적으로 다시 쓰지 않는다.
3. 낯설기만 한 이름, 너무 길거나 발음하기 어려운 이름은 피한다.
4. 주요 인물의 첫소리, 음절 수, 어미가 지나치게 비슷하지 않게 짠다.
5. 인물이 속한 지역과 문화의 작명 규칙을 먼저 설계한다.
6. 같은 세계의 이름이라는 일관성을 지키면서 인물마다 고유한 인상을 준다.
7. 성과 이름의 결합, 별명, 가까운 사람의 호칭까지 함께 정한다.
8. 이름의 뜻을 인물의 운명이나 혈통의 비밀을 노골적으로 암시하는 장치로 남용하지 않는다.
9. 기존 이름을 유지할 때도 새 후보와 비교해서 정한다.

## 5. 작명 검증 절차

1. **지역별 작명 규칙표**: 지역·문화마다 소리의 결, 음절 수, 성의 유래(지명·직업·조상 등), 별칭 문화, 가족 안의 호칭을 적는다. 기존 D-038의 ‘국가별 작명 문화의 기본 체계’는 출발 자료로 쓸 수 있다.
2. **후보 비교표**: 주요 인물마다 후보를 여럿(셋 안팎) 낸다. 칸은 이름 / 성과의 결합 / 별명·호칭 / 인상 / 장점 / 단점 / 비슷한 기존 고유명사.
3. **혼동 검사**
   - 첫소리 표: 주요 인물과 주요 지명·종명의 첫소리를 한 표에 놓고 몰림을 찾는다.
   - 음절 수와 어미 표: 같은 장면에 자주 나오는 인물끼리 겹치는지 본다.
   - 소리 내어 읽기: 대사 속에서 서로 부를 때 헷갈리지 않는지 본다.
   - 비슷한 쌍 목록: 한 음절 차이, 같은 어미, 같은 받침을 적는다.
   - 다른 고유명사와의 충돌: 지명, 종명, 기관명.
   - 유명 작품 이름 검사: 대표 인물 이름과 같거나 지나치게 가까운지.
4. **뜻 검사**: 이름의 뜻이나 어원이 결말이나 비밀을 미리 말해 버리지 않는지 본다.
5. **승인**: 작가가 고른 이름만 `[재설계 승인]`으로 적는다. 정본 이름을 바꾸는 경우 새 결정으로 기록한다.

- 기존 [great-hunt-and-naming.md](../proposals/great-hunt-and-naming.md) §3-3의 ‘소리 겹침 관리 규칙’(‘-딘’, ‘카-’, ‘로-’, ‘오르-’, ‘벨-’, ‘-렌’ 몰림)은 혼동 검사의 참고 사례로 쓸 수 있다.

## 6. 기존 정본과의 관계와 승인 절차

- D-010(이름·지명 통일), D-038(작명 규칙, 기존 확정 이름 유지), D-128(성별), 유진 몬트(사용자 결정, 번호 없음)는 **W의 정본으로 그대로 유효**하다.
- P에서 이 내용과 다르게 정하려면 충돌을 [conflicts.md](conflicts.md) §1에 적고, 작가 승인 뒤 새 결정 번호로 기록한다.
- 승인 전에는 원고·정본·인물 문서의 이름을 바꾸지 않는다.

## 7. 이번 단계에서 하지 않은 것

- 실제 인물의 삭제·통합·개명
- 새 인물과 이름 후보의 생성이나 확정
- 관계와 로맨스의 확정
- 정본과 인물 문서의 수정
