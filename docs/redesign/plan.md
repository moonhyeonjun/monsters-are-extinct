> 상태: **작업 지침** (2026-10-30, 작가 결정 “전면 백지 재집필 전환 및 설계 체계 정비”와 추가 지시 “등장인물 재창조 및 고유한 작명”). 결정 번호는 아직 없다. 이 결정을 decisions.md에 새 번호로 기록할지는 작가가 정한다(AGENTS.md §3).
> 기준 HEAD: `b72f598`. 공통 규칙은 [AGENTS.md](../../AGENTS.md) §9~§12에 있다.
> 이 문서는 절차와 문서 체계만 정한다. 세계관, 결말, 권수, 인물, 이름은 정하지 않는다.
> 함께 보는 문서: [checklist.md](checklist.md)(설계 누락 점검 목록), [conflicts.md](conflicts.md)(기존 결정·제안서와의 충돌), [character-and-naming.md](character-and-naming.md)(인물 재창조와 작명 기준)

## 1. 작가 결정의 요지

- 기존 W1~W6(작업 원고, `manuscript/book1`~`book6`, W6은 제12화까지)은 **초고로 보존**한다. 고치거나, 지우거나, 덮어쓰지 않는다.
- 새 출간본(P)은 **새 세계관과 새 전체 줄거리를 기준으로 처음부터** 다시 쓴다.
  - W의 사건 순서, 권수, 장면 배치, 인물 구성은 P를 구속하지 않는다.
  - W의 좋은 장면은 참고할 수 있지만 그대로 옮길 의무는 없다.
- 부분 개정이나 장면 이식형 재집필(2026-10-30 읽기 전용 검토의 권고)은 **채택하지 않았다.**
- **전체 설계가 끝나고 작가가 승인할 때까지 소설 집필을 중단한다.**

## 2. 용어

| 용어 | 뜻 |
|---|---|
| W | 작업 원고. `manuscript/book1`~`book6`. 보존 초고 |
| P | 새 출간본. 권수 미정. 경로는 집필 승인 때 정함(후보 `manuscript-p/`) |

| `[재설계 승인]` | 작가가 승인한 P 설계. 정본에 반영할지는 따로 정함 |

## 3. 공식 작업 절차와 관문

> 세계관 설계 → 설정 간 모순 검증 → 인물·관계 설계 → 최종 결말 확정 → 전체 시리즈 줄거리 → 권별·장별 사건 배치 → 재미와 속도 검증 → 작가 승인 → 집필

| 단계 | 하는 일 | 산출 문서(§4) | 끝나는 조건(관문) |
|---|---|---|---|
| 0. 기반 정비 | AGENTS.md 정비, 이 계획, 점검 목록, 충돌 목록, 인물·작명 기준 | 이 문서들 | 작가 확인(이번 작업) |
| 1. 세계관 설계 | 역사·사회, 환류종, 감응과 마녀, 이르바넬과 세력 | `candidates/history.md`, `factions.md`, `creatures.md`, `sensing.md` | checklist A~D의 필수 항목에 답이 있음 |
| 2. 설정 모순 검증 | 1단계 결과끼리, 그리고 현행 정본과의 모순 확인. 비밀 원장 작성 | `secrets-ledger.md`, `conflicts.md` 갱신 | 해소되지 않은 모순이 ‘작가 결정 필요’로 묶여 있음 |
| 3. 인물·관계 설계 | 역할 → 욕망·결함 → 결정적 선택 → 관계망 → 출신 문화 → 이름 후보 | `cast.md`, `relationships.md`, `naming.md` | checklist F·G 필수 항목. 이름은 후보와 비교까지 |
| 4. 최종 결말 확정 | 결말과 수미상관의 목표, 최종 선택, 인물의 귀결 | `ending.md` | **작가 승인** |
| 5. 전체 시리즈 줄거리 | 권수 비교, 중심 목표, 돌이킬 수 없는 첫 사건, 중반의 이해 전환, 후반의 결정적 손실, 최종 갈등 | `series-outline.md` | **작가 승인**(권수 포함) |
| 6. 권별·장별 사건 배치 | 대사 없이 사건과 인과. 장마다 사건·목표·결과·다음 연결 | `volumes/P{n}.md` | 모든 장에 네 항목이 있음 |
| 7. 재미와 속도 검증 | checklist I의 질문으로 줄거리만 읽고 판단 | `fun-check.md` | 실패 항목이 있으면 5~6단계로 되돌아감 |
| 8. 작가 승인 | 1~7의 결과 전체 | `p-canon/`, `p-canon/decisions.md` | **작가 승인** |
| 9. 집필 | 승인된 장별 설계로 P 원고 | P 원고 경로 | 장별 검증과 승인 |

- **왕복:** 단계 사이를 오가는 것은 허용한다. 예를 들어 1단계에서 결말에 필요한 조건을 거꾸로 확인할 수 있고, 6단계에서 인물이 모자라면 3단계로 돌아갈 수 있다. 되돌아간 내용은 해당 문서에 이력으로 남긴다.
- **집필 진입 조건:** 핵심 설정, 비밀 원장, 인물과 관계, 결말, 전체 줄거리, 장별 배치가 모두 승인되어야 한다.
- **재미가 모자라면** 원고로 메우지 않고 구조를 고친다.
- 어느 단계에서도 미승인 제안서를 자동으로 정본에 넣지 않는다.

- **작성 순서의 원칙**
  - 1단계 안에서는 역사와 이르바넬 → 환류종(이야기에 필요한 종부터) → 감응과 마녀 → 세력 순서를 권한다. 감응과 세력은 역사와 생물의 사실 위에서만 정해진다.

  - 인물(3단계)은 결말(4단계)과 왕복한다. 인물의 최종 운명은 4·5단계에서 확정한다.
- **각 문서의 공통 머리:** 상태(`[재설계 후보]`/`[재설계 승인]`), 근거, 현행 정본과의 관계, 작가 결정 필요 항목
- 승인 기록은 `p-canon/decisions.md`의 P결정으로 남긴다(처음 계획의 `approval-log.md`를 대신함).

## 6. 승인 절차

1. 단계 산출 문서를 `[재설계 후보]`로 저장하고 보고한다. 보고에는 작가가 결정할 항목을 최대 다섯 개로 묶는다.
2. 작가가 승인한 범위만 `p-canon/`으로 옮기고 `p-canon/decisions.md`에 P결정 번호로 적는다([README.md](README.md) §3).
3. 현행 정본을 바꿔야 하면 바꾸기 전후와 영향 범위를 conflicts.md에 적고, 작가 승인 뒤 새 결정 번호로 decisions.md에 기록한다. 옛 결정은 지우지 않는다.
4. 승인되지 않은 항목은 다음 단계의 전제로 쓰지 않는다. 쓸 수밖에 없으면 ‘작업 가정’으로 표시하고 보고한다.

## 7. 인물 재창조 원칙 (요약)

- 기존 인물을 유지할 의무는 없다. 선택지는 유지 / 핵심 매력만 보존하고 재설계 / 다른 인물과 통합 / 삭제 / 새 인물로 대체다.
- 목표는 전체 줄거리의 재미와 인과에 가장 맞는 인물 구성이다. 삭제나 개명 자체가 목표가 아니다.
- 주요 인물 수는 미리 정하지 않는다. 학생 집단은 남녀 비율을 대체로 균형 있게 한다.
- 관계는 여러 갈래로 설계하되 모두 연애로 잇지 않는다. 로맨스가 독립된 목표와 생태 복원 서사를 희생시키지 않는다.
- 설계 순서: 서사적 역할 → 욕망과 결함 → 결정적 선택 → 관계망 → 출신 문화 → 이름 후보 → 작가 승인
- 세부 기준과 작명 검증: [character-and-naming.md](character-and-naming.md)
