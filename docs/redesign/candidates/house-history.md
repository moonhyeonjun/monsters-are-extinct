## 0. 추천 인과 구조 한눈에 보기

```
[시대 A 차별과 은둔]
 공존 사회는 이미 철과 무리를 아는 관습이 있었다 → 감응은 쓸모없고, 무리 곁에서 발작처럼 보이는 과부하만 남았다
 → ‘울림병’(임시 이름)이라 불린 유전병 취급 → 혼인 거부 → 감응자 집들이 서로 혼인해 무리가 적은 ‘조용한 땅’으로 물러남
 → 굴욕의 기억: ‘우리 피는 병이 아니다’ → 훗날 ‘순결’이라는 이미지로 뒤집힌다
   ↓ (환류종의 이상 현상이 시작되고, 사람의 눈과 군대로는 숨은 무리를 찾을 수 없게 됨)
[시대 B 대토벌과 영웅의 탄생]
 한 감응자가 안개 속 숨은 무리를 찾아 마을(또는 군대)을 구함 → 변경 지휘관이 가문을 기용
 → 혼자서는 수십 걸음뿐인 감각을 사람의 사슬로 넓힌 ‘사슬 수색’ → 실제 공로와 실제 구조
 → 토지·작위·법적 권한 → ‘병든 피’가 ‘순결한 피’가 됨
   ↓ (포획한 개체로 원인을 캐는 연구 → 무리들이 한 곳으로 몰린다는 발견)
[시대 C 비밀 연구와 금지 구역]
 집결지에서 실제 재난이 일어남(몰린 무리의 기관 작용) → 가문이 ‘봉인’을 권하고 그 땅의 관리권을 받음
 → 위험은 일부 진짜, 일부 과장 → 국가가 비용을 대는 감시 체계가 곧 가문의 비밀 시설이 됨
   ↓ (멸종 선언: 가문의 권위와 제도의 빈틈이 만남 — declaration-v3)
[시대 D 멸종 이후의 독점]
 연구는 ‘보호’와 ‘이용’ 사이를 오감 → 감응 훈련이 ‘이점을 얻는 기술’로 바뀜
 → 가문의 이름으로 나가는 약·기술·재료·후원 → 영웅의 이름이 독점을 감춤
   ↓ (지금: 생물의 다음 움직임, 가문 안 균열, 바깥의 분석 — 은폐가 흔들림)
```

- 핵심 장치: **‘병든 피’라는 낙인이 ‘순결한 피’라는 명예로 뒤집힌다.** 차별받던 사람들이 그 낙인을 다시는 겪지 않으려고, 이번엔 자기 구성원과 생물을 통제한다. 피해자가 가해 구조를 만드는 인과가 여기서 나온다.
- 가문의 명성은 거짓만이 아니다. 실제로 사람을 구했다. 그래서 무너뜨리기 어렵다.

## 1. 시대 A. 차별과 은둔

| 질문 | 설계(후보) |
|---|---|
| 실제 불이익 | 혼인 거부, 일감과 마을 공동 일에서 배제, 아이를 숨김, 감응 아이가 난 집은 ‘병든 집’으로 불림, 일부 지역에선 마을 밖으로 내보냄 |
| 일상의 어려움 | 환류종 무리 곁에서 과부하(두통, 잠 못 듦, 귀울림, 갑자기 굳거나 귀를 막는 반응). 공존 사회는 무리 곁에서 살았기에 감응자는 늘 아팠다. 남들에게는 발작이나 미친 증세로 보였다 |
| 왜 가치가 없었나 | 공존 사회는 이미 철과 징후로 무리의 움직임을 알았다(달력, 민속, 짐승의 길). 감응은 기계·물소리와 혼동되어 믿을 수 없었고, 설명할 말이 없었다 |
| 가문은 어떻게 유지되었나 | 감응자가 난 집들이 서로 혼인할 수밖에 없었다(강요된 내혼). 무리가 드문 땅(‘조용한 땅’)으로 물러나 과부하를 피했다. 숯·소금·약초 같은 외딴 일로 살았다 |
| 가족과 공동체 안의 대우 | 가문 안에서도 감응자는 짐이자 보호 대상. 감응이 없는 가족은 낙인을 같이 짊어짐. 몇몇 감응자는 ‘듣는 이’로 존중받는 작은 전통을 만들었다 |
| 차별받은 이들이 억압 구조를 만든 이유 | ①‘다시는 병자로 불리지 않겠다’는 집단의 다짐 → 결점(과부하, 이상 행동)을 숨기는 규율 ② 바깥의 혼인을 막던 사회의 규칙을 가문 스스로 이어받아 혼인 통제로 굳힘 ③ 대토벌 뒤 얻은 지위를 잃을 수 있다는 공포 → 구성원의 일탈을 가문의 위협으로 다룸 |
| 구분 | 가문 구성원 모두가 감응자는 아니다. 감응자가 모두 이 가문에 속하지도 않는다(가문 밖에 흩어져 숨어 사는 감응자들이 있었다). ‘유전병 취급’은 사회의 인식이며, 실제 의학적 실체는 정하지 않는다([sensing-tech.md](sensing-tech.md) §1) |

## 2. 시대 B. 대토벌과 영웅의 탄생

### 2-1. 공적 역사와 실제 사건

| 항목 | 공적 역사(대중이 아는 것) | 실제 사건(후보) |
|---|---|---|
| 대토벌의 명분 | ‘첫 번째 침묵’ 뒤 환류종이 병들고 미쳐 사람을 덮쳤다. 나라를 지키려 토벌했다 | 이상 현상과 충돌은 실제였다. 그러나 원인은 짐승의 광기가 아니었다([anomaly-and-gathering.md](anomaly-and-gathering.md)). 왕실은 땅과 통합, 환류기관의 값 때문에 토벌을 넓혔다 |
| 최초 사건 | ‘안개의 밤’(임시 이름): 가문의 한 감응자가 숨은 무리를 찾아 마을을 구했다 | 실제로 구했다. 그날 그 감응자는 무리가 공격하려던 것이 아니라 어딘가로 가려 했다는 것을 느꼈지만, 말하지 않았다(또는 말했으나 묻혔다) |
| 처음 인정한 사람 | 변경의 지휘관(뒤에 왕실의 장군) | 같음. 지휘관은 감응자를 ‘살아 있는 사냥개’처럼 썼다 |
| 감응자의 권력이 커진 과정 | 공을 세운 순서대로 작위와 땅을 받았다 | ‘사슬 수색’([sensing-tech.md](sensing-tech.md) §2의 3단계)으로 토벌 성과가 몇 배가 되자, 군은 감응자 없이는 움직이지 못하게 됨 → 가문이 감응자 배치를 독점 → 가문의 협상력 |
| 기존 귀족의 견제와 이용 | 영웅을 시기한 자들이 있었다 | 귀족은 ‘병든 피’ 혈통과의 혼인을 거부하면서도 감응자를 빌려 썼다. 가문은 혼인 대신 땅과 법적 권한(사냥 허가, 수색 지휘권)을 요구 |
| 공로가 자산으로 바뀐 과정 | 왕이 감사의 땅을 내렸다 | 토벌 보상금, 수색 지휘권, 몰수된 공존 마을의 땅, 그리고 뒤의 집결지 관리권 |
| 대표적인 구조 사건 | 큰 강가 도시를 덮칠 뻔한 무리를 미리 찾아 사람들을 피신시켰다 | **실제로 일어난 구조다.** 다만 그 무리의 이동은 집결을 향한 것이었고, 토벌은 그 길목을 막아 더 큰 충돌을 불렀을 수 있다 |
| 같은 시기의 비윤리적 행위 | — | 포획한 개체의 생체 실험, 어린 감응자를 수색에 투입(과부하로 망가짐), 반대한 감응자의 추방, 공존 마을의 땅 몰수에 가담 |
| 대토벌의 실제 결과 | 괴물을 몰아내고 나라를 지켰다 | 바깥 무리 대부분이 사라짐. 생태 기능 상실. 남은 무리는 집결지에 몰림 |

### 2-2. ‘순결’이라는 이미지가 생긴 이유

- 가문은 ‘병든 피’라는 낙인을 지우려고 공로를 ‘순결한 혈통의 증거’로 이야기했다. 흰 옷, 엄격한 혼인, 공개 의례, 자선이 그 이미지를 받쳤다.
- 대중은 ‘괴물에게서 나라를 지킨 깨끗한 집안’이라는 이야기를 좋아했다. 왕실도 토벌의 정당성을 그 가문의 이미지에 기댔다.
- 이 이미지는 가문이 통제를 정당화하는 무기가 된다(‘가문의 피를 더럽히는 일’ = 규율 위반).

## 3. 시대 C. 비밀 연구와 금지 구역

### 3-1. 왜 연구했나 (복수의 동기)

| 동기 | 누구 |
|---|---|
| 무리가 왜 이상해졌는지 알고 싶다(수색 성과를 높이려고) | 군과 함께 일한 가문 지휘부 |
| 감응이 왜 생기는지 알고 싶다(‘병’이 아님을 증명하려고) | 감응자 학자들 |
| 환류기관의 값과 쓸모 | 가문의 재산 담당 |
| 무리가 향하는 곳 | 사슬 수색을 지휘한 감응자들 |

- 연구는 포획한 개체를 쓰는 생체 실험이었다. 세부와 결과: [sensing-tech.md](sensing-tech.md) §3.

### 3-2. 집결지의 발견과 위험지역 선포

| 질문 | 설계(후보) |
|---|---|
| 무엇을 발견했나 | 여러 무리가 같은 방향, 같은 철에 한 지역(임시 이름 ‘모이는 땅’)으로 향한다. 원인은 후보([anomaly-and-gathering.md](anomaly-and-gathering.md)) |
| 위험의 근거 | 몰린 무리의 기관 작용이 겹쳐 생기는 실제 재난(갑작스러운 냉기·짙은 안개·물의 솟구침·땅의 흔들림, 정확한 현상은 생태 설계). **위험의 일부는 진짜다** |
| 계기가 된 사건 | 토벌 원정대가 그 땅에 들어갔다가 재난으로 크게 잃은 일(임시 이름 ‘흰 골의 참사’). 가문은 그 위험을 미리 알았을 수도 있다(비밀 후보) |
| 지정 권한 | 왕실(또는 왕실 위임 기관)이 ‘봉인 구역’으로 지정. 그 땅의 위험 징후를 읽을 수 있는 것이 감응자뿐이라는 이유로 **관리권을 가문에 맡김** |
| 대토벌 공로의 작용 | 영웅 가문의 권고라서 반대가 적었다. 원정대의 참사를 막지 못한 군은 책임을 피하려 가문의 권고를 받아들였다 |
| 주민과 토지 소유자 | 몇 마을이 옮겨졌다(보상과 강제가 섞임). 일부 소유자는 가문에 땅을 넘기고 작위를 받았다. 원한도 남았다 |
| 출입 통제와 보급, 인력 | 국가가 비용을 대는 ‘감시소’(임시 이름)를 가문이 운영. 감시소가 곧 비밀 연구 시설이 된다([refuge-secrecy.md](refuge-secrecy.md)) |
| 드러날 위험 | 감시소의 보급 장부, 옮겨진 주민의 증언, 국가의 정기 점검, 재난 기록의 불일치 |
| 전능하지 않음 | 지정은 왕실의 결정이고 해마다 갱신·감사를 받는다. 가문은 근거(재난 기록)를 계속 내놓아야 한다. 국가 예산이 끊기면 운영이 어렵다 |

## 4. 시대 D. 멸종 이후의 독점

| 질문 | 설계(후보) |
|---|---|
| 살아 있다는 사실을 감추는 방식 | 봉인 구역은 공식적으로 ‘남은 환류 작용 때문에 위험한 땅’. 그 안의 현상은 ‘죽은 무리가 남긴 흔적’으로 보고됨. 감시소는 국가 기관이고 관리자는 영웅 가문 |
| 무엇을 연구하나 | 기관 작용과 박동의 관계, 번식, 병, 개체에게서 얻을 수 있는 것(구체는 생태 설계) |
| 감응 훈련의 목적 변화 | 수색 → 위험 징후 읽기 → **이점을 얻기 위한 기술**(박동의 위상에 맞춰 다루고 거두기) |
| 경제적·정치적·기술적 이점 | 가문의 이름으로 나가는 약과 재료, 땅을 살리는 기술, 복원 산업 후원과 공급, 감시소 예산, 영웅 가문의 정치적 발언권 |
| 외부에 제공하는 명목 | ‘가문 문서고의 옛 기록’, ‘보존된 옛 재료’, ‘감응자의 전통 지식’ |
| 살아 있는 개체를 드러내지 않고 이익을 얻을 수 있나 | 가공된 결과물(약, 시약, 기술, 지식)만 내보내면 가능하다. 다만 **양이 늘면** ‘옛 재료’로는 설명되지 않는 틈이 생긴다(인과 구멍) |
| 생물과 감응자를 통제하는 비용 | 평생 묶인 인력, 감응자의 과부하와 상처, 무리의 쇠약, 이중 장부, 들킬 위험, 가문 안 균열 |
| 지지와 반대 | 아래 §5 |

## 5. 가문의 두 얼굴과 구성원

| 공적 이미지 | 은폐된 모습 |
|---|---|
| 대토벌의 영웅 | 살아 있는 환류종의 존재를 앎 |
| 사람들을 구한 집안 | 그 생물을 쓰는 잔혹한 연구 |
| 고귀하고 순결한 명문 | 감응자의 선별과 통제 |
| 감응의 가치를 입증한 집단 | 기록 말살과 정보 조작 |
| 나라와 사회에 공헌 | 멸종 선언의 왜곡, 연구 성과의 독점, 반대자에 대한 압박 |

| 구성원 유형 | 무엇을 믿나 |
|---|---|
| 공적 이상을 믿는 후손 | 가문은 사람을 구했고 지금도 나라를 지킨다 |
| 가문의 이익을 우선하는 사람 | 비밀이 곧 가문의 생존 |
| 내부 연구에 반대하는 사람 | 생물과 감응자를 소모하는 것을 견디지 못함 |
| 사실을 모르는 구성원 | 평범한 명문가의 삶 |
| 과거의 공로에 자부심을 가진 사람 | 차별을 이겨 낸 역사가 정체성 |

- **공적 이미지가 지금까지 유지되는 이유:** 실제 공로가 있었다 / 왕실과 국가의 정당성이 그 이미지에 기대고 있다 / 가문이 실제로 자선과 공헌을 계속한다 / 감시소가 국가 기관이라 의심이 국가로 향하지 않는다 / 비판자는 ‘영웅을 시기하는 자’로 몰린다

## 6. 이야기의 긴장과 반전 가능성 평가

| 가능성 | 평가 | 근거 |
|---|---|---|
| 공적 기록에서 가문의 실제 선행을 발견 | 강함 | 실제 구조 사건이 있었기에 공정한 출발점 |
| 그 선행이 잔혹한 연구와 이어져 있음을 깨달음 | 강함 | ‘안개의 밤’의 감응자가 느낀 것, 구조와 포획이 같은 날이었다는 기록 |
| 가문을 존경하는 인물이 진실로 선택을 바꿈 | 강함 | 공적 이상을 믿는 후손 유형이 바로 그 인물 |
| 서로 다른 비밀을 아는 사람들의 충돌 | 중간~강함 | 비밀 관리 체계에 달림([refuge-secrecy.md](refuge-secrecy.md)) |
| 집결의 이유가 인간의 예상과 다름 | **가장 강함** | ‘미쳐서 덮쳤다’ → ‘어딘가로 가고 있었다’ → 그 이유(후보에 따라 번식, 피난, 주기) |
| 감응 훈련의 성과를 누가 소유하나 | 강함 | 가문 밖 감응자의 존재와 맞물림 |
| 독점을 끝내려는 행동이 생물에 새 위험을 만듦 | 강함 | 봉인을 열면 무리가 사냥꾼과 시장에 노출됨. 폭로가 곧 보호는 아니다 |

- 모든 비밀을 한 설명으로 한꺼번에 풀지 않는다. 공개는 여러 겹으로 나눈다(줄거리 단계).

## 7. 정하지 않은 것

- 가문의 이름, 설립자, 가계
- ‘울림병’, ‘조용한 땅’, ‘안개의 밤’, ‘흰 골의 참사’, ‘모이는 땅’, ‘감시소’ 같은 임시 이름
- 대토벌의 정확한 명분 문구와 기간
- 연구의 세부(생태 설계와 함께)
- 지정 절차의 법적 세부
