# 마지막 집결지 — 끝나지 않는 산실과 새 억류 구조 `[P 후보]` `[작가 전용]`

> **[일부 유지 · 2026-10-31 · P결정-009]** ‘끝나지 않는 산실’은 생태적 순환이 오래 멈춘 집결지라는 큰 방향으로만 유지된다(‘산실’은 임시 표현). ‘새끼 웅덩이의 문’은 채택되지 않았다. 새 후보는 [last-site-v3.md](last-site-v3.md).

> 상태: **P 설계 후보 · 미승인 · 정본 아님.** 작성 2026-10-31(6단계).
> 유지할 방향: 가문이 은폐해 살아남았다. 원래 여러 집결지가 있었고 다른 곳은 대토벌로 무너졌다. 생물이 정상적으로 떠나지 못하는 비정상 상태가 이어졌다. 장기 체류로 생태계가 크게 바뀌었다. 독자는 경이와 불안을 함께 느껴야 한다.
> 집결 전제(후보): [gathering-purpose.md](gathering-purpose.md)의 ‘함께 낳는 골’ — 어른들이 모여 번식의 때를 맞추고, 한꺼번에 낳고, 새끼가 따뜻한 광천에서 첫 몇 달 기관 벽을 굳힌 뒤, 어미가 새끼를 데리고 떠난다.
> 금지: 5단계의 ‘안쪽 고향’, 4단계의 ‘떠나는 길을 지운다’를 이름만 바꿔 쓰지 않는다. 미승인 감응 기술을 쓰지 않는다.

## 0. 결론 먼저

- **마지막 집결지는 ‘끝나지 않는 산실’이다.** 정상이라면 몇 달 붐비고 수십 년 쉬는 낳는 골이, 무리가 떠나지 못해 해마다 새끼가 태어나는 곳이 되었다.
- **추천 억류: 안 1 ‘새끼 웅덩이의 문’.** 어미는 새끼를 두고 떠나지 않는다. 가문은 떠날 철(산길이 열리는 짧은 때)마다 새끼들이 든 따뜻한 웅덩이의 문을 닫는다. **큰 어미를 가두는 것이 아니라 작은 새끼를 붙잡는다.** 철이 지나면 산길은 다시 닫히고, 어미들은 한 해를 더 머물며 다시 낳는다.
  - 소를 붙잡아 두려고 송아지를 매어 두는 목동의 오래된 방식과 같은 원리다(현실의 목축 관행).
- **틈:** 새끼가 없는 어른(수컷, 새끼를 잃은 어미)은 혼자 떠날 수 있다. 대부분 바깥에서 죽는다. 이들이 P결정-005의 ‘떠도는 개체’다. 큰물이나 문의 고장으로 새끼와 어미가 함께 빠져나가는 일은 드물지만 가장 큰 사건이 된다.
- **문을 열어도 해방이 아니다:** 새끼와 어미가 한꺼번에 떠나도 갈 고원은 이제 사람의 땅(광산과 목초지)이고, 일부는 국경 너머다.

## 1. 정상 집결지의 작동과 비정상 상태

| 항목 | 정상 | 마지막 집결지 |
|---|---|---|
| 붐비는 기간 | 몇 해마다 몇 달 | 해마다, 끝없이 |
| 번식 | 때를 맞춰 한꺼번에 한 번 | 해마다 다시 낳음. 어미가 쉬지 못함 |
| 새끼의 웅덩이 | 한 철 쓰고 수십 년 쉼 → 광물이 다시 차오름 | 쉬지 못해 광물이 바닥남 → 새끼의 기관 벽이 덜 굳음 → 세대마다 약해짐 |
| 떠남 | 산길이 열리는 철에 어미가 새끼를 데리고 고원으로 | 문 때문에 못 떠남. 새끼 없는 어른만 혼자 떠남 |
| 분지 | 쉬는 동안 식고 풀이 돌아옴 | 수많은 기관이 내놓는 열로 겨울에도 눈이 쌓이지 않음 |

## 2. 경이와 불안 — 생물의 활동에서 나온 장면

| 장면 | 원인 | 경이 | 불안 |
|---|---|---|---|
| 눈 속의 요람 웅덩이 | 해마다 태어나는 새끼들이 따뜻한 광천 웅덩이 수백 곳에 몸을 담금 | 눈 덮인 산맥 한가운데 김이 오르는 계단 웅덩이, 그 안에 떼 지어 잠긴 새끼들 | 너무 많은 새끼, 덜 굳은 몸 |
| 물결 치는 수면 | 어미들의 기관이 천천히 수축할 때마다 땅이 떨려, 고요한 웅덩이 수면에 같은 박자의 잔물결이 번짐 | 바람 없는 밤, 수백 개의 웅덩이가 함께 떨림 | 감응자 아이에게는 깊은 잠의 자리 |
| 하얀 가장자리 | 광물이 바닥난 웅덩이 가장자리에 남은 마지막 결정을 어미들이 핥아 냄 | 웅덩이마다 하얀 고리 | 바닥나는 요람 |
| 문 앞의 어미들 | 떠날 철이 오면 어미들이 닫힌 웅덩이 문 앞에 모여 서성임 | — | 떠나려는 생물과 붙잡는 사람이 가장 가까이 마주하는 곳 |
| 눈 없는 분지 | 기관들이 내놓는 열 | 겨울에도 푸른 골 | 쉬지 못한 땅, 지친 무리 |

- 불필요한 생태 법칙을 더하지 않았다: 모든 장면이 ‘기관이 열과 물을 다룬다’와 ‘새끼는 광천에서 기관 벽을 굳힌다’ 두 규칙에서 나온다.

## 3. 새 억류 구조 세 가지

| 질문 | **안 1. 새끼 웅덩이의 문(추천)** | 안 2. 늦게 굳는 새끼 | 안 3. 어긋난 산실 |
|---|---|---|---|
| 무엇인가 | 떠날 철마다 새끼가 든 웅덩이의 문을 닫음. 어미는 새끼를 두고 떠나지 않음 | 웅덩이에 찬물을 섞어 광물을 묽게 함 → 새끼의 기관 벽이 늦게 굳음 → 떠날 철에 새끼가 준비되지 않음 | 수컷을 따로 두고 조금씩 풀어 낳는 때를 흩뜨림 → 무리가 한꺼번에 준비되는 때가 오지 않음 → 함께 떠나지 못함 |
| 집결 원리에서 어떻게 나오나 | 어미와 새끼의 결속, 떠날 수 있는 짧은 철 | 새끼의 기관이 광천에서 굳는다는 규칙 | 번식의 때를 함께 맞춘다는 규칙(재동기화)을 거꾸로 씀 |
| 가문이 실제로 통제하는 것 | 웅덩이의 문(새끼만 가둘 크기) | 웅덩이의 물(수로와 수문) | 수컷의 골짜기와 그 문 |
| 생물이 다른 길로 못 나가는 이유 | 장벽이 아니라 어미가 새끼를 두고 가지 않음 | 새끼가 아직 살 수 없음 | 무리가 함께 떠날 때가 오지 않음 |
| 종별 이동 능력 | 새끼를 오래 돌보는 종에 잘 듣음 | 모든 낳는 종에 | 무리 지어 떠나는 종에 |
| 유지 비용 | 적음. 웅덩이 문과 떠날 철의 감시 | 중간. 물길 공사 | 큼. 큰 수컷을 다루는 위험한 일 |
| 실패율 | 큰물·문의 고장 때. 드묾 | 자연 광천이 솟는 웅덩이는 묽힐 수 없음 | 수컷이 문을 부숨 |
| 인력과 노출 위험 | 적음 / 낮음(모두 안쪽) | 중간 / 낮음 | 많음 / 중간 |
| 탈출 | 새끼 없는 어른이 혼자 떠남(대부분 바깥에서 죽음 → 떠도는 개체). 드물게 어미와 새끼가 함께 | 진한 웅덩이에서 굳은 새끼의 가족 | 동조된 작은 무리 |
| 가문의 발견 | 머릿수, 감응자의 읽기(탐지·해석) | 같음 | 같음 |
| 생물에게 주는 피해 | 어미의 쉼 없는 출산, 새끼의 덜 굳은 몸(광물 고갈) | **새끼를 일부러 약하게 만듦** | 무리의 혼란, 다툼 |
| 해제 때 | 아래 §4 | 진한 물로 돌아가도 이미 약하게 자란 세대는 남음 | 수컷을 풀면 한꺼번에 번식 → 그다음 해 한꺼번에 떠남 |
| 새 감응 기술 | 필요 없음 | 필요 없음 | 필요 없음 |
| 이전 후보와의 차이 | 5단계 ‘볼모가 된 어른’은 우두머리를 가뒀다. 이것은 어미와 새끼의 결속에서 나오며 새끼만 붙잡는다 | 새 집결 원리에서만 나옴 | 새 집결 원리에서만 나옴 |

- **추천 이유:** 가장 단순하고(문 하나), 생물의 본능(어미가 새끼를 두고 가지 않음)으로 설명되며, ‘문 앞의 어미들’이라는 강한 장면을 만든다. 시작은 보호였을 수 있다: 대토벌 직후 바깥으로 나간 가족은 모두 죽었으니, 문은 처음엔 새끼를 지키려고 닫혔다.

## 4. 억류를 끝냈을 때의 위험

| 하는 일 | 결과 |
|---|---|
| 떠날 철에 문을 모두 엶 | 어미와 새끼가 한꺼번에 산길로. 갈 고원은 이제 사람의 땅(광산·목초지)이고 일부는 국경 너머(을) → 마을과의 충돌, 국경 문제, 덜 굳은 새끼들의 죽음 |
| 문을 열고 웅덩이를 쉬게 함 | 분지가 식고 광물이 수십 년에 걸쳐 돌아옴. 그동안 이곳에서 낳을 수 없음 |
| 그대로 둠 | 웅덩이가 바닥나 새끼가 세대마다 약해짐 |

## 5. 작가가 고를 것

2. 억류를 안 1 ‘새끼 웅덩이의 문’으로 둘지(안 2·3은 쓰지 않거나 시대별로 더함)
