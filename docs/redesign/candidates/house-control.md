# 마지막 생존지의 여성들과 가문의 통제 `[P 후보]` `[작가 전용]`

> **[방향 유지 · 2026-10-31 · P결정-011]** 마지막 생존지의 여성 공동체는 유지된다. 세부는 [last-site-v5.md](last-site-v5.md)에서 보강한다.

> 상태: **P 설계 후보 · 미승인 · 정본 아님.** 작성 2026-10-31(8단계).
> 작가 제안 방향([P결정-010](../p-canon/decisions.md)): 마지막 생존지에는 강한 감응 반응을 가진 여성들이 모여 있고, 환류종이 그곳에 머무는 이유는 그들의 존재와 이어진다. 가문은 여성들의 이동과 생활을 통제하고, 후속 세대를 위해 임신·출산을 강요하며 감응 훈련을 이어 간다. **세부는 후보.**
> 다루는 원칙: 강제 임신·출산은 피해자의 신체적 자율성과 삶을 침해하는 행위이며, 가문의 목적이 그것을 정당화하지 않는다. **성적 폭력과 임신 과정을 선정적·노골적으로 묘사하지 않는다.** 제도·권한·피해·저항·은폐·세대 간 영향에 집중한다. 여성들을 이름 없는 집단이나 생물학적 자원으로 다루지 않는다.
> 감응 훈련은 탐지·해석의 범위를 벗어나지 않는다. 끌림을 강화·약화하는 새 능력은 쓰지 않는다.

## 0. 결론 먼저

- **가문이 강제 출산에 매달린 실제 이유는 ‘익숙해짐’이다.** 같은 여자의 되울림을 거듭 들은 어른 개체는 익숙해져 덜 온다. 무리를 붙잡아 두려면 **새로운 울림, 가장 깊게 끌려가는 어린 딸**이 계속 필요했다. 가문은 이것을 ‘피를 잇는다’는 말로 감쌌다.
- **가문의 통제는 생각만큼 듣지 않는다.** 증상으로 골라 낳게 한 딸들은 끌어들이는 힘은 세지만 듣는 힘은 약해졌다. 딸들은 어릴수록 위험했다. 익숙해짐은 세대마다 빨라졌다. 제도는 해마다 더 많은 것을 요구했다.
- **여자들은 서로 다르다.** 가문의 설명(‘마지막 생명을 지키는 딸들’)을 믿는 사람, 믿는 척하는 사람, 딸에게 마른 돌침상에서 자는 옛 고원 풍습을 몰래 가르치는 사람(끌림을 줄이는 소극적 저항), 달아나는 사람.
- **떠나는 것 자체가 위험하다.** 깊이 끌려가는 여자가 달아나면, 그를 쫓던 어른 개체가 따라 나간다. 탈출은 비밀을 바깥으로 끌고 나간다. 그래서 가문은 여자들의 이동을 가장 엄하게 통제한다.

## 1. 여성 공동체의 구조

| 질문 | 답(후보) |
|---|---|
| 언제부터 | 대토벌 말기. 가장 센 미끼 여자들을 ‘전쟁 중 사망’으로 기록한 뒤 가문 고향 곁의 겨울 터로 옮김 |
| 자발이었나 | 섞였다. ‘마지막 무리를 지키는 일’이라는 설명을 믿고 온 사람, 갈 곳이 없던 사람, 강제로 끌려온 사람 |
| 어떻게 모았나 | 전쟁 중의 미끼 부대, 보호령(임시)의 후견, 그 뒤로는 안에서 태어난 딸과 둘레 마을에서 들인 아이 |
| 왜 많은 환류종이 머무나 | 혹한기의 겨울 터에 남은 무리 + 다른 겨울 터를 잃고 떠돌던 어른들 + 새끼를 잃은 어른들이 여자들의 되울림에 붙잡힘([last-site-v4.md](last-site-v4.md)) |
| 여자 수가 줄면 | 되울림이 약해지고 익숙해진 어른부터 떠남 |
| 가문은 반응을 어떻게 재나 | ‘밤 장부’: 밤마다 각 방 둘레로 모인 개체 수, 깊은 잠의 시간, 물결의 세기. 듣는 힘은 따로 시험(해석의 정확도) |
| 감응이 센 사람과 끌림이 센 사람이 다르면 | 둘은 다른 자리에 놓인다. 끌림이 센 사람은 ‘물방’(젖은 돌바닥의 밤 방)에, 듣는 힘이 센 사람은 ‘듣는 자리’(무리의 상태와 탈출 조짐을 읽는 일)에. 듣는 사람은 조금 더 나은 대우를 받지만 수가 적다 |
| 거주지와 서식지의 분리 | 여자들의 마을은 골짜기 한가운데의 돌담 안. 무리는 그 둘레를 돈다. 밤에는 물방의 벽 밖으로 어른 개체들이 모여 눕는다 |
| 떠나려 하면 | 끌림이 센 사람이 움직이면 어른 개체가 따라와 곧 드러남. 붙잡히면 더 깊은 물방으로. 따라 나간 개체는 되몰아 들이거나 잃음 |
| 가문의 설명을 믿는 사람 | 있다. 특히 안에서 태어나 자란 딸들. ‘우리가 없으면 저들은 굶어 흩어져 죽는다’ — 일부는 사실이다 |
| 진실을 알고 저항하는 사람 | 있다. 바깥에서 온 여자, 딸을 잃은 어머니, 기록을 본 듣는 자리의 여자 |
| 가문 밖에서 들어온 여성 | 처음엔 낮은 자리(물방), 나이가 들면 아이들을 돌보는 자리. 바깥의 기억을 가진 사람으로서 저항의 씨앗 |
| 남성 가족·자녀·직원 | 아들은 어릴 때 밖으로 보내져 가문의 일꾼이나 직원이 됨(어머니를 모른 채). 남편이라 불리는 사람은 가문이 정한 사람. 직원은 둘레 마을 출신으로 일부만 앎 |

## 2. 강제 임신·출산과 훈련의 제도 (비선정적 설계)

| 질문 | 답(후보) |
|---|---|
| 1. 왜 다음 세대가 필요하다고 믿나 | 가문의 말: 피를 이어 마지막 무리를 지킨다. 실제 이유: 익숙해짐 때문에 새로운, 가장 깊게 끌려가는 어린 울림이 계속 필요함 |
| 2. 감응 강도는 유전되나 | 일부만. 끌어들이는 힘(증상)은 어느 정도 이어지지만, 듣는 힘과 따로 움직이고 나이와 몸 상태에 크게 흔들림([sensing-heredity-v3.md](sensing-heredity-v3.md)) |
| 3. 신뢰할 만한 방법인가 | 아니다. 딸이 태어날지, 감응이 드러날지, 얼마나 셀지 모두 불확실함 |
| 4. 실패 가능성 | 크다. 약한 딸, 아들, 어릴 때 깊은 잠의 사고로 잃는 아이, 익숙해짐의 가속 |
| 5. 여성에게 주는 명분 | ‘마지막 생명을 지키는 딸들의 의무’, ‘너희의 딸만이 저들을 살린다’ |
| 6. 법적·사회적 권한 | 갑의 보호령(후견), 봉인 구역의 비밀, 가문이 받아 온 혼인 특면. 바깥 법은 들어오지 않음 |
| 7. 외부 국가와 종교는 아나 | 갑의 왕실: 보호령의 여자들이 있다는 것만. 교단 중앙: 특면을 내 주지만 내용은 묻지 않음. 고원 교구: 소문으로 앎. 을·병: 모름 |
| 8. 시설·가족·교육·훈련의 연결 | 물방(밤), 아이들의 집(젖먹이를 함께 키움 — 여자들끼리 서로의 딸을 돌봄), 훈련(어른이 되면 해석과 숨 고르기, 몸을 어디에 두느냐) |
| 9. 아이들은 자기 처지를 어떻게 아나 | ‘지키는 딸’로 자람. 바깥을 모름. 사춘기에 물방의 뜻을 알게 되며 갈라짐 |
| 10. 협조하는 직원이 아는 것 | 무리가 산다는 것, 여자들이 무리를 붙잡는다는 것. 출산의 강제는 ‘가문의 혼인 관습’으로만 앎 |
| 11. 저항과 탈출 | 마른 돌침상에서 자는 옛 풍습(끌림을 줄여 장부의 숫자를 낮춤), 몰래 쓰는 편지, 서로의 딸을 지키는 약속, 직원과의 연대, 탈출(따라 나가는 개체 때문에 거의 실패) |
| 12. 수 세대 유지될 수 있나 | 가능하지만 해마다 비용이 커짐: 더 많은 딸, 더 어린 나이, 더 엄한 통제 |
| 13. 예상하지 못한 장기 결과 | 끌어들이는 힘은 세지고 듣는 힘은 약해짐. 익숙해짐이 빨라짐. 어른 개체의 진짜 새끼가 방치됨(최종 진실 후보 3). 어머니와 딸 사이의 깊은 연대와 상처 |

- **다루는 법:** 장면은 제도와 그 안의 사람들(돌보는 손, 숨기는 편지, 마른 침상, 밤 장부를 쓰는 직원, 떠나보내진 아들)로 보여 준다. 강제의 순간과 신체적 고통은 묘사하지 않는다.

## 3. 작가가 고를 것

1. 강제 출산의 실제 동기를 ‘익숙해짐 때문에 새 울림이 필요함’으로 둘지
2. ‘물방’과 ‘듣는 자리’로 나뉜 여성들의 지위 구조
3. 마른 돌침상 풍습을 소극적 저항으로 쓰는 구조
