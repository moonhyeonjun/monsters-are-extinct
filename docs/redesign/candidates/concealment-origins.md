# 가문의 은폐 기원안 비교 `[P 후보]` `[작가 전용]`

## 0. 요약

| 안 | 한 줄 | 추천 |
|---|---|---|
| A. 보호에서 독점으로 | 마지막 무리를 지키려 숨겼고, 세대가 지나며 소유로 변했다 | 부분 채택 |
| B. 처음부터 자산 독점 | 살아 있는 환류종과 감응 훈련장을 독점하려 숨겼다 | 단독으로는 비추천 |
| C. 죄의 은폐 | 대토벌에 앞장선 죄를 숨기려고 마지막 증거(살아 있는 무리)와 기록을 함께 묻었다 | 부분 채택 |
| D. 번영의 사슬 (새 안) | 숨긴 무리가 가문 땅을 되살리면서, 숨기는 일이 가문의 부와 하나가 되었다 | 부분 채택 |
| **E. 복합안: 속죄로 시작해 번영에 묶이고 독점으로 굳은 은폐 (추천)** | C로 시작해 A의 얼굴을 하고, D로 묶이고, 마지막에 B가 된다. 세대마다 숨기는 이유가 달라진다 | **추천** |

- 원칙: 한 가지 악행으로 모든 역사를 설명하지 않는다. 세대마다 은폐를 이어 간 이유가 달라야 독자가 마지막에 ‘누구의 잘못이었나’를 한 사람에게 돌리지 못한다.

## 1. 안 A. 보호에서 시작해 독점으로 변질

| 검토 항목 | 내용 |
|---|---|
| 최초로 은폐를 선택한 사람 | 대토벌 말기 가문의 수장(또는 수장의 딸). 감응자 |
| 그 사람이 알던 사실 | 바깥 무리가 거의 사라졌다는 것. 가문 땅 위쪽 골짜기에 마지막 무리가 몰렸다는 것. 알리면 토벌대가 온다는 것 |
| 당시 가능한 다른 선택 | 왕실에 알리고 보호를 청함(당시 왕실은 토벌의 주체라 불가능에 가까움) / 아무것도 안 함(무리가 들킬 위험) / 무리를 더 먼 곳으로 몰아냄(살아남지 못할 수 있음) |
| 실행할 수 있던 자원 | 골짜기가 가문 땅이라는 것, 길을 아는 사람, 토벌대의 길잡이 자리(가문이 길잡이였다면) |
| 첫 번째 피해 | 바깥에 남은 몇 무리를 구하지 못하고 버림. 가문 안에서 거짓말을 시작함 |
| 다음 세대가 이어 간 이유 | 지키고 있다는 자부심. 알려지면 무리가 죽는다는 두려움 |
| 기록 말살의 계기 | 골짜기를 가리키는 옛 기록(목격, 길) 정리 |
| 멸종 선언과의 연결 | 수색을 끝내려고 선언을 바람 |
| 현대 가문 내부 갈등 | ‘지킨다’는 이름으로 사람(딸들)과 생물을 묶어 두는 통제 |
| 반전 잠재력 | 중간. 독자가 가문을 처음부터 ‘선한 보호자’로 짐작하기 쉬움 |
| 약점 | 너무 깨끗하다. 왜 지금 그렇게 집요하게 통제하는지 설명이 약하다 |

## 2. 안 B. 처음부터 자산 독점을 위한 은폐

| 검토 항목 | 내용 |
|---|---|
| 최초로 은폐를 선택한 사람 | 가문의 재산을 맡은 사람(감응자가 아닐 수도 있음) |
| 알던 사실 | 살아 있는 환류종은 곧 사라질 귀한 자원(기관, 감응 훈련의 대상)이라는 것 |
| 다른 선택 | 팔아 버림 / 왕실에 바침 |
| 자원 | 땅, 돈, 길잡이 |
| 첫 번째 피해 | 무리를 가두고 골라 씀 |
| 다음 세대가 이어 간 이유 | 이익 |
| 기록 말살의 계기 | 남들이 찾아오지 못하게 |
| 멸종 선언과의 연결 | 희소성을 높이고 수색을 끊음 |
| 현대 갈등 | 이익을 나누는 다툼 |
| 반전 잠재력 | 낮음. 동기가 단순한 탐욕이라 인물이 납작해짐 |
| 약점 | ‘하나의 단순한 악행’ 그 자체 |

## 3. 안 C. 대토벌에 관여한 죄를 숨기기 위한 은폐

| 검토 항목 | 내용 |
|---|---|
| 최초로 은폐를 선택한 사람 | 대토벌 동안 가문 감응자들을 토벌대의 ‘찾는 이’로 보낸 수장 |
| 알던 사실 | 가문의 감응자가 무리를 찾아 주었기에 토벌이 그렇게 빨랐다는 것. 마지막 무리가 남아 있다는 것 |
| 다른 선택 | 죄를 고백함(가문의 몰락) / 마지막 무리까지 넘김(완전한 멸종) |
| 자원 | 토벌대 안의 지위, 길잡이 자리, 땅 |
| 첫 번째 피해 | 고백하지 않은 거짓. ‘찾는 이’였던 딸들의 침묵 강요 |
| 다음 세대가 이어 간 이유 | 가문의 이름과 땅을 지키려고. 살아 있는 무리가 드러나면 죄도 드러남 |
| 기록 말살의 계기 | 토벌 보상 장부에 남은 가문의 이름 |
| 멸종 선언과의 연결 | 조사가 길어질수록 장부를 뒤지게 되므로 빨리 끝내고 싶음 |
| 현대 갈등 | 진실을 아는 사람과 모르는 사람의 단절 |
| 반전 잠재력 | 높음. 자랑스러운 가문 이야기가 뒤집힘 |
| 약점 | 죄만으로는 수백 년의 정교한 관리(생물 돌봄)를 이어 갈 동력이 약함 |

## 4. 안 D. 번영의 사슬 (새 안)

> 공존 시대의 사실(환류종의 기관 작용이 둘레의 땅·물·온도를 바꾸어 농사와 정착을 이롭게 했다)을 P에서도 쓴다는 가정이다.

| 검토 항목 | 내용 |
|---|---|
| 최초로 은폐를 선택한 사람 | 마지막 무리를 가문 골짜기에 숨긴 사람(동기는 A나 C) |
| 알던 사실 | 숨긴 것까지만. 그 결과는 몰랐다 |
| 그 뒤에 일어난 일 | 대토벌 뒤 다른 지방의 땅은 기능을 잃고 메말라 갔는데, 가문의 골짜기 아래 땅만 샘이 마르지 않고 서리가 늦고 수확이 좋았다. 숨긴 무리의 기관 작용 때문이었다 |
| 다음 세대가 이어 간 이유 | **가문의 부가 숨긴 무리에 달려 있다는 것을 알게 됨.** 드러나면 무리를 빼앗기고 땅도 시든다 |
| 기록 말살의 계기 | ‘왜 저 집 땅만 멀쩡한가’라는 의심을 지우려고. 땅의 번영을 다른 이유(물길 공사, 비법 농사, 신앙)로 설명하는 이야기를 퍼뜨림 |
| 멸종 선언과의 연결 | 조사관이 가문 땅의 기이한 번영에 눈을 돌리지 않게 하려고 |
| 현대 갈등 | 땅을 부치는 사람들과 가문 경제 전체가 비밀 위에 서 있다. 비밀을 깨면 수백 명의 생계가 흔들린다 |
| 반전 잠재력 | 높음. 첫 장면부터 보이는 ‘이상하게 풍요로운 땅’이 단서가 된다. 생태(기능)가 음모의 원인이자 단서가 된다 |
| 약점 | 기관 작용의 생태 설계가 먼저 정해져야 함(다음 단계와 맞물림) |

## 5. 안 E. 복합안 — 속죄로 시작해 번영에 묶이고 독점으로 굳은 은폐 (추천)

| 세대 | 숨기는 이유 | 하는 일 | 대가 |
|---|---|---|---|
| ① 토벌 이전 | (숨기기 전) 이익 | 가문의 감응자들이 환류기관 거래의 길잡이, 대토벌 때는 토벌대의 ‘찾는 이’ | 무리의 급감에 손을 보탬 |
| ② 대토벌 말기의 수장 | **속죄와 보호(C+A)** | 마지막 무리를 가문 골짜기로 몰아 숨김. 왕실에는 ‘다 끝났다’고 보고 | 바깥의 남은 무리를 버림. 딸들에게 침묵을 강요 |
| ③ 다음 두세 세대 | **번영(D)** | 골짜기 아래 땅만 살아남는 것을 보고 비밀이 곧 가문의 부임을 깨달음. 땅의 번영을 다른 이야기로 덮음. 토벌 장부와 ‘찾는 이’ 기록을 지움 | 소작인과 이웃을 속임 |
| ④ 멸종 선언 무렵 | **조사의 종결** | 조사단의 길잡이와 증거 경로를 조작해 선언을 앞당김([extinction-declaration.md](extinction-declaration.md)) | 바깥에 혹시 남았을 개체가 보호받지 못함 |
| ⑤ 복원 시대 | **독점(B)** | ‘오래된 보존 재료’라며 숨긴 무리의 재료를 복원 산업에 공급. 감응 훈련을 독점 | 무리를 자원으로 다루기 시작함 |
| ⑥ 현재 | 네 이유가 모두 겹쳐 아무도 멈추는 법을 모름 | 계승자는 무엇을 지키는지조차 하나로 말하지 못함 | 무리의 쇠퇴(고립), 가문 안 균열 |

- **최초로 은폐를 선택한 사람(②):** 대토벌 말기의 가문 수장. 감응자. 자기 딸들을 ‘찾는 이’로 보낸 사람.
  - 알던 사실: 가문이 토벌을 빠르게 했다는 것, 마지막 무리가 몰린 자리, 알리면 끝난다는 것
  - 몰랐던 사실: 숨긴 무리가 땅을 살린다는 것, 수백 년 뒤의 결과
  - 다른 선택: 고백, 넘김, 방치. 그 사람은 ‘아무도 모르게 지키는 것’을 고름. 고백하면 가문과 무리 둘 다 끝난다고 믿었다
  - 자원: 골짜기가 가문 땅임, 토벌대의 길잡이 자리, 딸들의 감응
  - 첫 번째 피해: 바깥의 남은 무리를 버린 일, 딸들의 입을 막은 일
- **반전 잠재력:** 독자는 가문을 차례로 ‘수상한 부자’ → ‘몰래 지킨 보호자’ → ‘토벌의 앞잡이였다’ → ‘지킨 것이 곧 돈이었다’ → ‘그래도 무리는 실제로 살아 있다’로 다시 보게 된다. 한 번에 뒤집지 않고 여러 겹으로 벗길 수 있다.
- **안전장치:** 가문은 왕국을 조종하지 않는다(선언은 증거 경로를 건드렸을 뿐). 무리의 쇠퇴와 땅의 번영은 생태의 원리로 일어난다. 혈통이 아니라 땅·돈·비밀·통제가 가문의 힘이다.

## 6. 작가가 고를 것

1. 기원안: A / B / C / D / **E(추천)** / 다른 안
2. E를 고른다면, 숨긴 무리가 땅을 살린다(D)는 생태 장치를 쓸지 — 다음 단계(생태 설계)에서 기관 작용을 함께 정해야 한다
3. ① 토벌 이전에 가문이 환류기관 거래의 길잡이였는지(=가문의 죄가 토벌보다 앞서는지)
