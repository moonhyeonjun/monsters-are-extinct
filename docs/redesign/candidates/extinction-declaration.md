# 공식 멸종 선언 조작의 인과 구조 `[P 후보]` `[작가 전용]`

> 상태: **P 설계 후보 · 미승인 · 정본 아님.** 작성 2026-10-30(1단계 개정). 전제: [P결정-002](../p-canon/decisions.md)(가문이 공식 멸종 선언의 조작을 주도).
> ‘가문이 조작했다’로 끝내지 않는다. 기관의 독립적 판단과 가문의 의도적 조작을 나눈다.
> 기관 이름과 인물 이름은 정하지 않는다. 연대는 [timeline-options.md](timeline-options.md)를 따른다.

---

## 0. 두 구조의 비교

| 구조 | 내용 | 판단 |
|---|---|---|
| 가. 기관 장악 | 판정 기관이 가문의 꼭두각시였다 | 비추천. 가문이 전능해지고, 기관 안의 사람들이 납작해진다 |
| **나. 증거 경로의 조작 (추천)** | 기관은 선의로, 당시의 방법과 범위 안에서 판단했다. 가문은 기관이 아니라 **기관에 들어가는 증거의 길**을 건드렸다. 제한된 조사 결과가 과도하게 일반화되어 잘못된 결론이 났다 | 추천 |
| 다. 조작 없음 | 기관의 실수였을 뿐 | P결정-002(가문이 조작을 주도)와 맞지 않음 |

## 1. 질문별 설계 (구조 나)

| 질문 | 답 |
|---|---|
| 어떤 기관이 판정을 내리나 | 왕실이 맡긴 **학술 판정 기구**(이름 미정). 대토벌의 보상 장부를 정리하고, 남은 개체를 조사해 ‘끝’을 선언하는 일을 맡음 |
| 왜 그 판단이 받아들여졌나 | 왕실의 권위, 학자들의 명성, 수십 년 동안 확인된 목격이 없었다는 사실. 그리고 사회 전체가 끝나기를 바랐다(보상금 부담, 전쟁 같은 토벌의 피로) |
| 조사의 범위와 기술 | 사람이 걸어 닿는 지역의 표본 조사, 목격 신고의 검증(몸·기관·발자국 같은 물증만 인정), 보상 청구의 끊김. **감응은 증거로 인정되지 않음.** 사유지와 고산 금지 구역은 소유자의 길잡이를 통해서만 조사 |
| 남은 개체군은 어디에 | 가문 땅 위쪽의 높은 골짜기(생존지, [house-world.md](house-world.md) §4). 바깥 개체는 실제로 사라졌거나 극소수 |
| 가문이 감춘 것 | 생존지의 존재. 골짜기로 가는 길. 가문 땅의 번영이 무리 때문이라는 것. 토벌 때 ‘찾는 이’였던 기록 |
| 가문이 조작한 것 | ① **길잡이:** 조사단이 가문 땅과 산을 지날 때 가문 사람이 길잡이를 맡아 골짜기를 비켜 가게 함 ② **마지막 개체의 증거:** 숨긴 무리에서 죽은 늙은 개체의 몸(또는 기관)을 ‘먼 산에서 쓰러진 마지막 개체’로 내놓음 ③ **목격 신고의 흐림:** 영지 안의 목격 신고를 지주의 권한으로 ‘헛것’으로 처리하거나 신고자를 달램 ④ **기록:** 보상 장부와 조사 기록 가운데 가문 땅을 가리키는 쪽을 빼거나 고침 ⑤ **사람:** 가문과 가까운 학자 한 사람이 조사 보고서를 정리하는 자리에 있었음(영향이지 통제가 아님) |
| 가문이 통제할 수 없는 독립 증거 | 아래 강줄기의 물 기록(마르지 않는 샘, 늦은 서리), 다른 지방과 대비되는 가문 땅의 수확 장부, 외지 상인과 소작인의 말, 토벌 시기 병사의 편지, 판정 기구의 원본 조사 일지(학자 개인 소장), 가문을 떠난 사람 |
| 은폐에 실패할 뻔한 사건 | **후보:** 판정 몇 해 전, 젊은 조사원 한 사람이 길잡이 없이 홀로 골짜기 어귀까지 들어가 발자국과 이상한 안개를 보고 기록했다. 가문은 그 사람을 해치지 않았다. 대신 그의 표본이 운송 중 ‘사라졌고’, 그의 보고는 ‘조사 범위 밖, 물증 없음’으로 묶였으며, 그는 웃음거리가 되었다. 그의 일지는 어딘가에 남아 있다 |
| 공표 이후의 제도와 산업 | 보상 제도 종료, 환류기관 거래 금지, 사람이 생태 기능을 메우는 대체 시설의 시대, 이어서 복원학과 복원 산업. **복원 산업은 ‘오래된 보존 재료’에 기대어 시작했고, 그 재료의 일부는 가문이 공급했다** |
| 오랫동안 진실이 밝혀지지 않은 이유 | 선언이 왕실과 학계의 권위가 됨 / 생존지가 사유지 안의 고산 / 아는 사람이 극소수 / 가문 경제와 복원 산업이 모두 진실을 묻는 쪽에 이익 / 감응이 증거가 아님 / 남은 독립 증거가 흩어져 있어 아무도 이어 보지 않음 |
| 지금 흔들리는 이유 (후보, 여럿이 겹침) | ① 위쪽 물길 사업이 골짜기의 물을 바꿈 ② 고립된 무리의 쇠약(근친, 병) ③ 복원 산업의 재료 수요 급증(공모) ④ 계승 다툼 ⑤ 무리의 한 개체가 골짜기 밖으로 나옴(첫 경이 후보, 비밀-13과 연결) ⑥ 보존 재료를 분석하는 독립 연구자 |

## 2. 의도적 조작과 기관의 판단 구분

| 결론에 들어간 것 | 기관의 독립적 판단 | 가문의 의도적 조작 |
|---|---|---|
| 수십 년 동안 확인된 목격 없음 | 사실(공개 지역에서는 실제로 없었음) | 영지 안 목격 신고를 흐림 |
| ‘마지막 개체’의 확인 | 받은 증거를 믿음 | 숨긴 무리의 죽은 개체를 증거로 내놓음 |
| 조사 범위 | 사유지·고산은 소유자 길잡이를 통함(당시 관행) | 길잡이로 골짜기를 비켜 감 |
| 결론의 일반화 | ‘조사한 곳에 없다’를 ‘어디에도 없다’로 넓힘(기관의 실수) | — |
| 보고서 문안 | 학자들의 합의 | 가까운 학자 한 사람의 영향 |

- 결론: 선언은 **기관의 선의와 한계 + 가문이 고른 몇 개의 증거 조작**이 만나서 나왔다. 기관 안에는 의심한 사람도 있었다(실패할 뻔한 사건의 조사원).

## 3. 작가가 고를 것

1. 구조: **나(증거 경로 조작, 추천)** / 가(기관 장악)
2. ‘마지막 개체의 증거’를 숨긴 무리의 죽은 개체로 할지(가문의 가장 큰 거짓이 됨)
3. 실패할 뻔한 사건의 조사원을 쓸지, 그 일지를 현재의 단서로 쓸지
4. 복원 산업의 ‘오래된 보존 재료’를 가문이 공급했다는 축을 쓸지
