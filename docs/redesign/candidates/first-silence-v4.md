## 0. 결론 먼저

- **첫 번째 침묵 = 수백 년 만의 무리 짓기 + 그 길 위에 세워진 사람의 땅.** 좋은 기후가 길게 이어진 세기에 여러 종이 수십 년 사이에 차례로 밀도 문턱을 넘었다. 혼자 살던 개체들이 평소의 터에서 사라졌고(감응자와 마을 사람들이 느낀 ‘침묵’), 몇 해 뒤 몸과 행동이 바뀐 무리가 고개 앞의 분지로 행진했다. **그런데 그 분지와 길목에는 수백 년의 고요 동안 사람이 마을과 도시를 세워 두었다.**
- **이전 집결과 다른 점은 생물이 아니라 사람이었다.** 무리는 늘 그 길로 갔다. 이번엔 그 길이 사람의 땅이었다.
- **피해는 실제였다:** 짓밟힌 밭과 마을, 막힌 물길, 무리를 막으려던 사람들과 무리 짓는 형태의 사나움이 부딪쳐 생긴 죽음, 분지 도시의 굶주림.
- **감응자 여성들의 관여는 국지적이었다:** 무리 사이에서 새끼를 잃은 어미들이 길목 마을의 소녀 곁으로 왔다(근거리 되울림). 사람들은 그것을 ‘마녀가 괴물을 불렀다’로 기억했다. 무리 짓기 자체와는 무관.
- **대토벌의 정치적 계기:** 한 나라의 큰 분지 도시(교단의 큰 성당이 있는 곳 후보)가 행진하는 무리에 무너졌다. 왕실과 교단 중앙이 ‘정화’를 선포했고, 무리의 길이 국경을 넘으므로 이웃 나라들이 연합했다.

## 1. 반드시 구별할 것

| 구분 | 내용(후보) |
|---|---|
| 초장주기 집결 자체의 원인 | 밀도 문턱(느린 번식이 수백 년에 걸쳐 땅을 채움) |
| 첫 번째 침묵에서만의 특수 조건 | ① 좋은 기후가 길어 여러 종이 비슷한 때에 문턱을 넘음 ② **사람이 길목과 분지에 정착해 있었음** |
| 사람의 대응으로 커진 피해 | 무리를 막으려는 둑과 불, 길목의 학살이 무리를 흩뜨려 더 넓은 땅으로 번지게 함 |
| 감응자 여성들의 관여 | 국지적: 새끼를 잃은 어미들이 소녀 곁으로(근거리). 무리 짓기를 일으키지 않음 |
| 당시 사람들이 관찰한 것 | 짐승들이 사라짐(침묵) → 모습이 바뀐 짐승 떼가 행진 → 마녀 곁의 짐승 |
| 공식 역사의 잘못된 해석 | ‘괴물들이 병들어 조용해졌다가 미쳐 돌아왔다’(상 변화를 광기로) |
| 가문이 나중에 조작한 부분 | 가문의 기록: ‘마녀의 피가 괴물을 불렀다’(가문이 피를 다룰 명분). 첫 번째 침묵과 대토벌 초기의 가문의 역할을 키움 |

## 2. 열 가지 질문

| 질문 | 답(후보) |
|---|---|
| 1. 왜 그 시기에 시작됐나 | 수백 년 전의 무리 짓기 뒤로 개체 수가 천천히 회복되어, 좋은 기후의 세기에 문턱에 닿음 |
| 2. 이전과 무엇이 달랐나 | 사람이 길목에 정착해 있었다 |
| 3. 왜 여러 지역에서 혼란이 | 여러 종, 여러 분지, 국경을 넘는 길 |
| 4. 실제 피해 | 밭과 마을, 물길, 사람과 가축의 죽음, 분지 도시의 무너짐과 굶주림 |
| 5. 감응자 여성들이 이동에 영향을 주었나 | 무리의 행진에는 아니다. 근거리에서 새끼를 잃은 어미를 끌어들였을 뿐 |
| 6. 새끼를 잃은 어미들의 역할 | 무리 짓기와 행진 속에서 새끼를 많이 잃음 → 길목 마을의 소녀 곁에 나타남 → 마녀 박해의 불씨 |
| 7. 국가와 종교의 해석 | 국가: 재난과 침략. 교단 중앙: 땅의 흔들림, 정화의 필요. 고원 교구: 옛 노래의 ‘걷는 해’를 떠올린 몇 사람(무시됨) |
| 8. 대토벌의 결정적 계기 | 큰 분지 도시의 무너짐과 정화의 선포 |
| 9. 잘못된 판단을 피할 수 있었나 | 일부. 고원의 옛말(‘산이 걸으면 길을 비켜라’)을 따랐다면 길목을 비우고 기다릴 수 있었다. 그러나 정착한 도시를 비우는 일은 쉽지 않았다 |
| 10. 지금 다시 조사할 수 있나 | 있다. 세 조사 경로([deep-time-evidence.md](deep-time-evidence.md)) |

## 3. 되울림과 대토벌의 산 미끼

| 과정 | 수행자와 기술 | 위험과 실패 |
|---|---|---|
| 원거리 탐지 | **어른 감응자의 감응**(되울림이 아님): 무리의 낮은 울림을 수백 걸음 밖에서 느끼고 방향과 상태를 읽음 | 지침, 잘못 읽기 |
| 이동 경로 추정 | **가문의 연구**: 무리 짓는 무리가 고개 앞 분지로 간다는 것, 지형이 길을 정한다는 것 | 지형을 잘못 읽은 해 |
| 근거리 접근 유도 | **산 미끼**: 감응자 소녀를 매복지 가까운 얕은 물이나 젖은 땅에 둠 → 무리 속에서 새끼를 잃고 헤매던 가족형 어미가 수십 걸음 안으로 옴 | 효과는 그 어미에게만, 소녀의 위험(깔림, 추위) |
| 포획과 토벌 | **각국 군**: 길목과 고개 앞 분지의 매복, 불과 함정 | 큰 희생 |

- **산 미끼로 잡지 못하는 대상:** 무리 짓는 행진 그 자체(길목 매복으로), 무리형(분지 매복으로), 단독형(감응자의 탐지와 사냥개로).
- **기록:** 길목 예측과 매복의 공은 ‘가문의 청취와 예측’으로, 산 미끼는 ‘장비’로 적힘. 공로는 실제였으나 그 일부는 소녀들의 희생 위에 섰다.
