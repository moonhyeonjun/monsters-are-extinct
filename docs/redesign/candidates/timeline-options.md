# P 백지 연표 후보와 계산 근거 `[P 후보]` `[작가 전용]`

> 상태: **P 설계 후보 · 미승인 · 정본 아님.** 작성 2026-10-30(1단계 개정). 전제: [P결정-002](../p-canon/decisions.md)(W 연표에 얽매이지 않음).
> 사건을 먼저 놓고, 사건마다 필요한 시간을 계산한 뒤 연표를 짰다. 연도는 ‘현재로부터 몇 년 전’으로만 쓴다. 연호와 달력은 정하지 않는다.
> 사건의 순서는 [concealment-origins.md](concealment-origins.md) 안 E와 [first-silence-review.md](first-silence-review.md) 안 3을 작업 가정으로 썼다.

## 1. 사건별로 필요한 시간

| 사건 | 필요한 시간 | 근거 |
|---|---|---|
| 가문의 성립과 권력 축적 | 3~5세대(약 75~150년) | 감응자 집들이 혼인으로 묶이고, 직능의 보수로 땅을 모아 지주 가문이 되려면 여러 세대가 필요 |
| 거래 사냥(‘침묵’의 실체) | 20~40년 | 무리가 눈에 띄게 줄어 ‘조용해졌다’고 느낄 만큼의 기간 |
| 대토벌 | 15~40년 | 나라가 벌이는 사업은 한두 세대 안에 끝나거나 지침. 수백 년짜리 토벌은 근거가 약함 |
| 은폐의 시작 | 토벌 말기, 몇 해 | 마지막 무리를 골짜기에 몰아넣는 일 |
| ‘번영’의 발견 | 은폐 뒤 10~30년 | 다른 지방이 메마르고 가문 땅만 살아남는 차이가 눈에 띄기까지 |
| 멸종 선언 | 토벌 종결 뒤 20~50년 | 확인된 목격이 끊긴 채 한 세대가 지나고, 조사와 정치적 결단이 필요 |
| 대체 시설의 시대 | 선언 뒤 30~100년 | 잃은 생태 기능을 사람이 메우는 체계가 서는 시간 |
| 복원 산업의 성립 | 복원학의 시작에서 40~80년 | 학문 → 실험 → 시설 → 산업 |
| 비밀의 전달 | 한 세대 25~30년마다 한 번 | 계승자의 교체 횟수 = 비밀이 샐 기회의 횟수 |

## 2. 환류종의 수명과 세대가 연표에 주는 영향

> 수명과 번식 주기는 다음 단계(생태 설계)에서 정한다. 연표 후보는 이 값에 따라 달라진다.

| 가정 | 한 세대 | 은폐 뒤 100년이면 | 200년이면 | 400년이면 |
|---|---|---|---|---|
| 짧은 수명 | 약 5년 | 20세대 | 40세대 | 80세대 |
| 중간 | 약 10~15년 | 7~10세대 | 13~20세대 | 27~40세대 |
| 긴 수명 | 약 30년 이상 | 3세대 | 6~7세대 | 13세대 |

- 작은 무리(수십~백 남짓)가 고립되면 세대가 지날수록 근친과 병의 위험이 커진다. **현재의 쇠약**을 이야기의 압력으로 쓰려면 은폐 뒤 세대 수가 어느 정도 쌓여야 한다. 너무 길면 무리가 이미 사라졌어야 자연스럽다.

## 3. 연표 후보 셋

### 후보 1. 가까운 과거 (선언 약 100년 전)

| 사건 | 현재로부터 |
|---|---|
| 가문 성립 | 약 300~250년 전 |
| 거래 사냥(‘침묵’) | 약 190~160년 전 |
| 대토벌 | 약 160~130년 전 |
| 은폐 시작 | 약 130년 전 |
| 멸종 선언 | 약 100년 전 |
| 복원 산업 성립 | 약 40년 전 |

- 계승자 교체: 은폐 뒤 약 4~5번
- 장점: 비밀 유지가 현실적이다. 살아 있는 기억이 가깝다(원로의 조부모가 선언을 겪음). 조사원의 일지, 병사의 편지 같은 증거가 아직 다락에 있을 만하다. 복원 산업이 젊어 재료 수요가 막 커지는 때와 맞는다.
- 단점: ‘멸종’이 사회의 상식으로 굳기에 조금 짧다. 복원학이 60년 만에 산업이 되려면 빠른 발전이 필요하다. 전설 같은 깊이가 약하다.

### 후보 2. 중간 과거 (선언 약 200년 전, 추천)

| 사건 | 현재로부터 |
|---|---|
| 가문 성립 | 약 450~380년 전 |
| 거래 사냥(‘침묵’) | 약 300~270년 전 |
| 대토벌 | 약 270~240년 전 |
| 은폐 시작 | 약 240년 전 |
| 멸종 선언 | 약 200년 전 |
| 대체 시설의 시대 | 약 200~110년 전 |
| 복원 산업 성립 | 약 70~50년 전 |

- 계승자 교체: 은폐 뒤 약 8~9번
- 장점: ‘멸종’이 두세 세대를 넘어 누구도 의심하지 않는 상식이 된다. 복원학이 차근차근 자랄 시간이 있다. 은폐 뒤 세대 수가 쌓여 현재의 쇠약(근친, 병)이 자연스럽다. 비밀이 여러 번 손을 건너며 덮개 이야기가 시대마다 바뀐 흔적이 생긴다(이야기의 재료).
- 단점: 8~9번의 전달 동안 새지 않은 이유를 계층 구조로 설득해야 한다([house-world.md](house-world.md) §2). 산 증인은 없고 문서만 남는다.

### 후보 3. 먼 과거 (선언 약 300년 전, 대토벌 약 500년 전, W와 비슷)

- 계승자 교체: 은폐 뒤 약 16~20번
- 장점: 신화 같은 깊이.
- 단점: 작은 골짜기의 무리가 수백 년을 버티려면 무리가 크거나 수명이 아주 길어야 한다. 20번 가까운 전달 동안 새지 않은 이유가 약하다. 대토벌이 백 년 넘게 이어지는 것도 근거가 약하다. **계산 근거 없이 수백 년을 유지하는 셈이 된다.**

## 4. 현재 인물들의 나이와 가족 관계 (후보 2 기준 예시, 인물은 정하지 않음)

| 위치 | 나이대 | 연표와의 관계 |
|---|---|---|
| 가문의 원로 | 70대 | 복원 산업이 서는 것을 젊어서 봄. 재료 공급을 시작한 세대 |
| 현재 계승자 | 40~50대 | 수요 급증과 무리의 쇠약을 함께 짊어짐 |
| 가문을 떠난 사람 | 30~40대 | 15~25년 전 떠남. 덮개 이야기만 알고 떠났을 수 있음 |
| 이야기의 중심 세대(학생) | 10대 중반 | 무리의 쇠약이 위기로 바뀌는 때를 만남 |

## 5. 작가가 고를 것

1. 후보 1(선언 약 100년 전) / **후보 2(약 200년 전, 추천)** / 후보 3(약 300년 이상)
2. 환류종의 수명 범위(생태 단계와 함께)
3. 달력과 연호를 쓸지(‘멸종력’ 같은 연호는 W의 것이며 P에서 다시 정함)
