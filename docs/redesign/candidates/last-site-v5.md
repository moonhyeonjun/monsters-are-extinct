# 마지막 생존지 — 여성 공동체, 환류종 생태, 새 억류 후보 `[P 후보]` `[작가 전용]`

> 상태: **P 설계 후보 · 미승인 세부 · 정본 아님.** 작성 2026-10-31(9단계).
> 승인된 방향([P결정-011](../p-canon/decisions.md)): 마지막 생존지의 감응자 여성 공동체 유지, 장기간의 비정상 생태, 억류 방식은 다시 설계(8단계 안 불채택).

## 0. 결론 먼저

- **생물이 머무는 이유는 셋이 겹친다:** ① 그곳에 남은 열매 풀숲(먹이와 터 — 모든 유형) ② 안에서 태어나 바깥을 모르는 개체들 ③ 되울림이 떠날 철에 어미들의 발을 묶음(유형 1의 일부).
- **추천 억류: 안 1 ‘떠날 철을 놓치게 하는 밤’ + 안 3 ‘여자들이 끄는 길’.** 가문이 실제로 통제하는 것은 **풀숲, 여자들의 자리와 밤, 그리고 출구의 감시**이지 생물의 마음이 아니다.
- **안 2 ‘끝나지 않는 열매의 해’(풀숲을 나이대별로 가꿔 해마다 열매가 열리게 함)는 강하지만, 거절된 ‘늘 열린 해’와 구조가 닮았다(끝없는 철을 인위로 만듦).** 그래서 추천에서 빼고 비교로만 둔다.
- **여자들은 서로 다르고, 그중 몇은 생물을 개체로 안다.** 어떤 어미가 언제 오는지, 어느 어미가 새끼를 잃었는지. 이 지식은 가문의 장부에 없다.

## 1. 여성 공동체

| 역할 | 삶과 선택 |
|---|---|
| 감응자 소녀 | 아이들의 집에서 함께 자람. 밤의 물방은 열 살 무렵부터. 어른들의 말과 다른 것을 일찍 눈치챔 |
| 성인 감응자 | 물방의 밤(끌림이 센 사람), 듣는 자리(듣는 힘이 센 사람) |
| 혈통 관리의 대상이 된 여성 | 가문이 정한 혼인과 출산. 아이를 잃거나 빼앗긴 상처. 딸에게 무엇을 물려줄지의 고민 |
| 아이들을 돌보는 사람 | 나이 든 여자들, 감응하지 않는 여자들. 공동체의 실제 중심 |
| 가문의 설명을 믿는 사람 | ‘우리가 없으면 저들은 굶어 흩어진다’ — 일부는 사실(바깥에 풀숲이 없다는 것을 아무도 모르지만) |
| 능력을 숨기는 사람 | 듣는 힘을 숨겨 듣는 자리에 가지 않으려는 사람, 반대로 몸의 반응을 숨겨 물방을 피하는 사람 |
| 탈출을 준비하는 사람 | 바깥의 돌침상 사람들과 이어지려는 사람 |
| 환류종과 교류해 본 사람 | 어미들을 개체로 아는 사람. 문간의 먹이를 받는 아침, 곁에 누운 어미의 숨. 그 지식을 장부에 쓰지 않음 |
| 감응하지 않는 구성원 | 그 피의 딸이지만 반응이 없는 사람. 가장 낮은 자리이자, 바깥에 나갈 가능성이 가장 큰 사람 |
| 바깥과 정보를 주고받는 사람 | 보급을 나르는 직원, 복원 협회 현장 인력과 닿는 사람 |

## 2. 환류종 생태

| 항목 | 설계(후보) |
|---|---|
| 되울림에 반응하는 개체 | 유형 1의 어미(특히 새끼를 잃은 어미), 유형 1의 어린 개체 |
| 반응하지 않는 개체 | 유형 2·3, 유형 1의 수컷, 제 새끼가 곁에 있는 어미 |
| 어미와 새끼 | 안에서도 평소처럼 번식. 새끼를 잃은 어미가 꾸준히 생김(밀집, 병, 가문의 연구) |
| 먹이와 영역 | 남은 열매 풀숲. 열매의 해가 아닌 해에는 모자라 다툼 |
| 번식과 성장 | 열매의 해 뒤 번식이 늚. 그 밖의 해엔 줄어듦 |
| 자연스러운 이동 욕구 | 열매가 끝나면 흩어지려 함. 바깥의 다른 풀숲을 찾아 |
| 장기 밀집의 변화 | 풀숲 주변 흙이 굳고, 다음 세대 풀이 덜 자람. 같은 길이 깊은 고랑이 됨. 문간의 먹이, 물방 벽 밖의 둥근 자리 |
| 쇠약과 회복 가능성 | 풀숲이 지치면 무리도 지침. 풀숲이 쉬고 다시 자랄 넓은 땅이 있으면 회복 가능(그 땅이 바깥에 있는가가 최종 진실 후보 1과 이어짐) |
| 가문이 실제로 통제하는 것 | 풀숲(베기·태우기 금지, 일부 가꾸기), 여자들의 자리와 밤의 시간표, 출구의 감시, 보급 |

## 3. 새 억류 후보 세 가지

| 질문 | **안 1. 떠날 철을 놓치게 하는 밤(추천)** | 안 2. 끝나지 않는 열매의 해 | **안 3. 여자들이 끄는 길(추천 보조)** |
|---|---|---|---|
| 무엇인가 | 열매가 끝나 흩어질 철(짧음)에 가문이 물방의 밤을 늘림 → 새끼를 잃은 어미들이 ‘새끼가 아직 여기 있다’며 떠나지 못함 → 철을 놓치면 산길이 닫혀 다음 해까지 머묾 | 풀숲을 나이대별로 나눠 가꿔 해마다 어딘가 열매가 열리게 함 | 철마다 여자들을 골짜기 안의 정해진 자리로 옮김 → 따르는 어미들이 그 길로 움직임(골짜기 밖으로 나가지 않게) |
| 붙잡으려는 개체 | 유형 1의 어미(그리고 그 어미를 따르는 새끼) | 모든 유형 | 유형 1의 어미 |
| 새끼·어미·성체·단독종을 같게 붙잡나 | 아니다. 유형 2·3은 먹이 때문에 머물거나 떠남 | 그렇다(먹이) | 아니다 |
| 끌림과 무관한 개체는 | 풀숲 때문에 머묾. 떠나는 개체도 있음 | 머묾 | — |
| 여성 공동체와의 연결 | 물방의 밤 | 약함 | 철마다의 이동 |
| 떠나는 행동을 실제로 어떻게 막나 | 막지 않는다. **떠날 철을 놓치게 한다** | 떠날 이유를 없앤다 | 움직임의 방향을 안쪽으로 |
| 유지 비용 | 물방의 밤을 견디는 여자들(가장 큰 비용은 사람) | 넓은 풀숲 가꾸기 | 여자들의 고된 이동 |
| 실패 상황 | 어미가 익숙해짐, 진짜 새끼가 생김, 배고픔이 셈, 철이 길어진 해 | 풀숲의 병 | 따르던 어미가 길을 벗어남 |
| 실패의 은폐 | 떠난 개체는 바깥에서 대개 굶어 돌아오거나 죽음. 바깥 목격은 복원 협회의 신고 창구로([restoration-society.md](restoration-society.md)) | 같음 | 같음 |
| 여자가 탈출하면 | 그 여자에게 익숙하지 않은, 새끼를 잃은 어미 몇만 따라감 → 바깥 목격과 사건 | — | 같음 |
| 해제하면 생물이 움직이는 순서 | 물방의 밤을 멈추면: 다음 흩어질 철에 유형 1의 어미들이 새끼와 함께 먼저 떠남 → 유형 2는 열매가 끝날 때 → 유형 3은 마지막. **그러나 바깥에 풀숲이 있는가가 결과를 정함** | 가꾸기를 멈추면 열매가 몇 해 끊기고 모두가 흩어지려 함 | — |
| 거절된 안과의 관계 | 새 구조(사람의 밤이 떠날 철을 늦춤) | **‘늘 열린 해’와 닮음** — 추천에서 뺌 | 새 구조 |
| 판단 | 추천 | 비교만 | 추천 보조 |

- **생물 자신의 선택이 사건을 만든다:** 익숙해진 어미가 처음으로 물방을 지나쳐 산길로 오르는 밤, 진짜 새끼를 찾은 어미가 여자들을 돌아보지 않고 떠나는 아침, 배고픈 무리가 출구의 감시를 밀고 나가는 해.

## 4. 작가가 고를 것

1. 생물이 머무는 이유를 ‘풀숲 + 안에서 태어남 + 떠날 철의 발 묶기’로 둘지
2. 억류를 안 1 ‘떠날 철을 놓치게 하는 밤’ + 안 3 ‘여자들이 끄는 길’로 둘지
3. 안 2(늘 열린 해와 닮음)를 버릴지
