# 첫 번째 침묵 — 유지·변형·삭제 비교 `[P 후보]` `[작가 전용]`

> 상태: **P 설계 후보 · 미승인 · 정본 아님.** 작성 2026-10-30(1단계 개정). 전제: [P결정-002](../p-canon/decisions.md)(첫 번째 침묵은 존재 여부부터 재검토).
> W의 첫 번째 침묵(대토벌 이전 수십 년의 환경 변화, 환류종의 이동 이탈)은 P를 구속하지 않는다.
> **원칙:** 공식 멸종 선언이 거짓이라는 사실만으로는 실제 생태 위기와 대토벌의 원인을 설명할 수 없다. 아래 세 질문에 각 안이 따로 답해야 한다.
> - 질문 1. 환류종의 개체 수는 실제로 왜 줄었는가?
> - 질문 2. 대토벌은 누가 왜 시작했는가?
> - 질문 3. 멸종 판정 때 공개된 지역에서 왜 생존 개체를 찾지 못했는가?

## 1. 안 1. 삭제

| 질문 | 답 |
|---|---|
| 1. 왜 줄었나 | 대토벌 그 자체. 그리고 그 전부터 이어진 개간과 환류기관 거래(사냥) |
| 2. 누가 왜 시작했나 | 왕실과 개간 세력. 땅을 넓히려는 압력, 실제로 늘어난 충돌과 피해, 환류기관의 값, 나라를 하나로 묶을 공동의 적 |
| 3. 왜 못 찾았나 | 바깥 개체는 실제로 사라짐. 남은 무리는 가문 골짜기에 숨겨짐 |

- 장점: 가장 단순하다. 인과가 선명하다. 독자가 따라가기 쉽다.
- 약점: 사람만 나쁜 이야기로 기울 수 있다(공존하던 사회가 왜 갑자기 등을 돌렸는지 설명이 짧다). 역사에 ‘이해가 바뀌는’ 장치가 하나 줄어든다.
- 생태의 자리: 대토벌의 결과(기능 상실)와 현재의 물길 위기에서만 다룬다.

## 2. 안 2. 변형 — 실제 생태 변화를 새로 설계

| 질문 | 답 |
|---|---|
| 1. 왜 줄었나 | 일부 지역의 실제 물길·기후 변화로 몇 종의 무리가 흩어지고 약해짐(작고 지역적) + 그 뒤의 대토벌(대부분의 감소) |
| 2. 누가 왜 시작했나 | 흩어진 무리가 마을로 내려와 생긴 실제 피해를 명분으로, 왕실과 개간 세력이 토벌을 넓힘 |
| 3. 왜 못 찾았나 | 안 1과 같음 |

- 장점: 생물이 사람의 음모에 종속되지 않는다. 사람 쪽에도 이해할 만한 이유(실제 피해)가 생긴다.
- 약점: 설정이 하나 더 늘어난다. 원인을 다시 설계해야 한다(생태 단계와 맞물림). W의 구조를 닮아 새로움이 적다.

## 3. 안 3. 이름과 기록은 있지만 실제와 다름 (추천)

| 항목 | 내용 |
|---|---|
| 기록된 사건 | 대토벌 몇십 년 전, 여러 지방에서 환류종이 ‘조용해지고’ 보이지 않게 된 신비한 시기. 공식 연대기는 이것을 ‘짐승들이 스스로 쇠하고 병들어 위험해진 징조’로 적었고, 대토벌의 명분이 되었다 |
| 실제 사건 | **사람이 만든 감소.** 가문의 감응자들이 길잡이가 된 환류기관 거래(사냥)와 개간이 무리를 흩고 줄였다. 무리가 줄자 사람 눈에 ‘조용해진’ 것처럼 보였다 |
| 이름을 퍼뜨린 사람 | 가문. ‘침묵’이라는 말은 감응자의 말이다(박동이 들리지 않게 되었다). 가문은 감소를 자연의 신비로 설명해 거래 길잡이로서의 책임을 피했다 |
| 질문 1. 왜 줄었나 | 거래 사냥과 개간(침묵의 실체) → 대토벌(대부분의 감소) |
| 질문 2. 누가 왜 시작했나 | 왕실과 개간 세력이 ‘쇠하고 위험해진 짐승’이라는 기록을 명분으로 토벌을 공식화. 실제 동기는 땅, 값, 통합. 가문은 ‘찾는 이’로 고용되어 이익을 봄 |
| 질문 3. 왜 못 찾았나 | 바깥 개체는 실제로 사라짐. 남은 무리는 가문 골짜기에 숨겨짐([extinction-declaration.md](extinction-declaration.md)) |
| 남는 흔적 | 연대기의 ‘침묵’ 기록과, 같은 시기의 거래 장부·길잡이 보수 기록의 어긋남. 감응자의 말이 공식 기록에 들어간 경로 |

- 장점
  - 가문이 기록을 다룬 첫 사례가 된다. 기록 말살과 선언 조작으로 이어지는 **같은 손버릇**이 처음부터 보인다.
  - 독자가 처음에는 ‘자연의 신비’로 받아들인 사건을 나중에 ‘사람이 만든 일’로 다시 읽는 반전이 생긴다.
  - 공존하던 사회가 토벌로 기운 이유(쇠하고 위험해졌다는 믿음)가 생긴다.
- 약점: 가문의 책임이 무거워져 가문 전체가 악당처럼 보일 위험 → 가문 안에서 거래를 반대한 감응자, 침묵의 실체를 몰랐던 세대를 함께 둔다. ‘찾는 이’만으로 대토벌이 일어난 것이 아니라 왕실과 개간 세력의 선택이었음을 분명히 한다.
- 생태의 자리: 감소의 결과로 생긴 기능 상실(메마르는 땅)은 실제 생태 원리로 일어난다. 이것이 가문 골짜기의 번영과 대비된다([concealment-origins.md](concealment-origins.md) 안 D).

## 4. 판단

- 안 1로도 이야기는 선다. **첫 번째 침묵이 꼭 필요하지는 않다.**
- 그러나 안 3은 사건을 하나 더 만드는 것이 아니라, 이미 필요한 대토벌의 명분과 가문의 기록 조작을 **한 장치로 묶는다.** 설정을 늘리지 않고 반전을 늘린다. 그래서 추천한다.
- 안 3을 고르지 않는다면 안 1(삭제)을 권한다. 안 2는 W의 구조를 닮고 설정이 늘어난다.

## 5. 작가가 고를 것

1. 안 1(삭제) / 안 2(변형) / **안 3(기록과 실제가 다름, 추천)**
2. 안 3이라면 ‘침묵’이라는 이름을 그대로 쓸지, 새 이름을 지을지
3. 가문의 거래 길잡이 활동이 대토벌보다 앞서는지([concealment-origins.md](concealment-origins.md) 안 E ①)
