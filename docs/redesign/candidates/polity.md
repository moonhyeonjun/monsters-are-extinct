# 세계의 정치 질서·국가·가문·기관 — 전면 재설계 `[P 후보]` `[작가 전용]`

> 상태: **P 설계 후보 · 미승인 · 정본 아님.** 작성 2026-10-30(4단계).
> 작가 결정([P결정-006](../p-canon/decisions.md)): 세계 정치와 세력 구조를 전면 다시 설계한다. ‘비워진 땅’과 완충지 분할 조약은 전제로 쓰지 않는다. 종교와 신앙은 주요 영역이다([faith.md](faith.md)).
> 이름: 국가·가문·기관·종교의 이름은 정하지 않는다. 아래는 모두 **기능을 설명하는 임시 표기**다.
> 원칙: 조직은 세계관에 실제로 필요한 만큼만 둔다. 모든 세력이 하나의 음모를 공유하지 않는다. 모든 가문이 서로 싸우거나 음모를 꾸미지 않는다 — 혼인, 재산, 교육, 명예, 사업, 오래된 약속으로도 엮인다.

---

## 0. 결론 먼저

- **추천: 모델 4 ‘두 개의 권위’.** 땅을 다스리는 **왕권**(중심 왕국 + 이웃 왕국 + 자치 지역)과, 국경을 넘어 출생·혼인·장례·학교·치유를 맡는 **교단**이 나란히 선다.
  - 대토벌은 왕권이 군과 세금을 내고, 교단이 ‘정화’라는 이름을 붙인 전쟁이었다.
  - 멸종 선언도 둘이었다: 왕실의 법적 선언과 교단의 ‘끝맺음’ 의례. **둘 다 그것이 필요했다** — 왕실은 백성들이 지긋지긋해하던 토벌세를 끝내야 했고, 교단은 정화의 시대를 교리로 닫아야 했다. 가문은 그 필요에 맞춰 마지막 원정을 내놓았다.
  - 그래서 생존 사실이 드러나면 흔들리는 것은 한 가문만이 아니다. 왕실의 세금 정당성과 교단의 교리가 함께 흔들린다.
- **가문은 여섯으로 시작한다:** 영웅 가문, 대토벌로 커진 수로 가문, 대토벌로 몰락한 샘 영주 가문, 경쟁하는 무공 가문, 진실의 일부를 아는 ‘철 피난’ 가문, 독립된 목표를 가진 학교 가문.
- **가문이 무너져도 세계는 움직인다:** 철도와 소금 값, 교육권 다툼, 복원 사업과 성소의 온천 경쟁, 처리 사무소의 존재 이유, 고원 자치령의 신앙과 자치.

## 1. 정치 질서 모델 비교

| 기준 | 모델 1. 경쟁하는 여러 왕국 | 모델 2. 강한 중심 왕국 + 자치 지역·주변 세력 | 모델 3. 귀족·상업 과두(왕은 상징) | **모델 4. 두 개의 권위(추천: 모델 2 + 국경을 넘는 교단)** |
|---|---|---|---|---|
| 요지 | 대등한 왕국 셋 이상이 경쟁·동맹 | 한 왕국이 우세, 자치령과 이웃 나라가 주변에 | 실권은 대가문과 상회의 회의체 | 세속 왕권과 국경을 넘는 교단이 서로 기대고 견제 |
| 국가 봉인 구역과 맞나 | 맞음. 다만 어느 나라의 것인지가 큰 문제 | **잘 맞음** | 약함(국가가 약하면 ‘국가 봉인’의 무게가 없음) | **잘 맞음.** 봉인은 왕권, 정당성은 교단 |
| 대토벌의 구조 | 연합 전쟁 | 왕국 주도 | 가문들의 사업 | 왕권의 군 + 교단의 명분 |
| 멸종 선언의 이해관계 | 나라마다 다름 | 왕국 하나에 몰림 | 상업 이해 | **왕실(세금)과 교단(교리)이 함께 필요로 함** |
| 가문 밖 갈등 | 전쟁과 외교 | 자치와 중앙 | 시장과 계약 | 교육·혼인·장례를 둘러싼 왕권과 교단의 경계 다툼, 자치, 산업 |
| 종교의 자리 | 나라마다 다른 교회 | 국가 교회가 되기 쉬움 | 후원 대상 | **독립된 큰 권력**(국가의 하부가 아님) |
| 이야기의 규모 | 큼(전쟁 서사로 기울기 쉬움) | 알맞음 | 작고 촘촘함 | 알맞음. 일상(학교·장례·혼인)까지 닿음 |
| 전능 구조 회피 | 쉬움 | 중앙이 모든 것을 쥐기 쉬움 | 쉬움 | **쉬움.** 두 권위가 서로 다른 것을 앎 |
| 약점 | 초점이 흩어짐 | 왕국 하나의 이야기가 됨 | ‘왕국’ 체감이 약함 | 실제 역사의 교회·왕권 구도를 닮을 위험 → 교단의 교리와 제도를 이 세계의 생태에서 나오게 설계해 피함 |

## 2. 추천 구조의 나라와 지역

| 세력(임시) | 기원 | 지금의 권한·자산 | 원하는 것 | 할 수 없는 것 |
|---|---|---|---|---|
| 중심 왕국 | 대토벌로 여러 영지를 하나로 묶은 왕권 | 봉인 구역 소유, 관리 위임, 군, 세금 | 세금 없이 돌아가는 재정, 철도로 나라 묶기, 교단과의 균형 | 선언 철회(세금과 위신), 교단 없이 혼인·장례 다스리기 |
| 이웃 왕국 | 같은 교단을 믿는 작은 왕국. 대토벌에 군을 보냄. 자기 땅의 집결지들을 잃음 | 강 상류의 물, 산의 광물 | 물길 권리, 중심 왕국과의 대등함 | 교단의 공동 선포를 혼자 뒤집기 |
| 고원 자치령 | 옛 집결지 여러 곳이 있던 고원. 대토벌 뒤 중심 왕국에 반쯤 복속 | 자치 의회, 옛 신앙의 근거지, 옛 집결지 터 | 자치, 메마른 샘과 습지의 회복, 옛 신앙의 인정 | 왕국의 군과 맞서기 |
| 하구 자유시 | 강 하구의 교역 도시. 왕권에 세금을 내되 스스로 다스림 | 상회, 신문, 학회, 복원 회사 | 교역과 복원 산업, 학문의 자유 | 왕국 법 밖에서 움직이기 |
| 봉인 구역 둘레 마을들 | 봉인으로 옮겨 간 마을 | 감시 일자리, 쉼터 시설(제염소·요양소)의 품팔이 | 일자리와 땅, 아이들의 안전 | 봉인 구역 출입, 직접 청원 |

## 3. 가문들

| 가문(임시) | 유형 | 기원 | 자산·권한 | 영웅 가문과의 관계 | 아는 것 | 독립 목표 |
|---|---|---|---|---|---|---|
| 영웅 가문 | 감응자 명문 | 차별받던 ‘물결 집’ → 대토벌의 공로 | 작위, 봉인 구역 관리권, 쉼터 시설의 소유·후원 | — | 전부(핵심 일부만) | 독점과 생존의 유지 |
| 수로 가문 | 대토벌로 커진 가문 | 대토벌 공병과 수리 공사 | 운하·수로·철도 사업. 봉인 초기의 지하 수로 시공 | 오랜 동업자. 혼인으로도 묶임 | 수로가 물을 ‘엉뚱한 골’로 보낸다는 것(이유는 모름) | 철도망. 영웅 가문 없이도 서는 사업 |
| 샘 영주 가문 | 대토벌로 몰락한 가문 | 옛 집결지 곁의 물 많은 영지 | 오래된 이름뿐. 메마른 영지 | 정중한 거리. 몰락의 원인이 영웅 가문이 넘긴 집결지 정보였다는 것을 모름 | 자기 땅의 샘이 대토벌 뒤에 멎었다는 것 | 영지의 물을 되살리기(복원 회사와 손잡음) |
| 무공 가문 | 경쟁 가문 | 대토벌 초기의 군 지휘 | 군과 치안대, 처리 사무소에 대한 영향력 | 공과 지휘권을 빼앗겼다는 오래된 원한. 그러나 같은 기념식에 서는 사이 | 대토벌 초기 기록(아이 징발의 실상) | 군의 위상, 처리 사무소의 존속 |
| ‘철 피난’ 가문 | 진실의 일부를 아는 가문 | 무리 철마다 감응자 아이를 도시로 피신시켜 한 번도 들키지 않은 부유한 귀족 | 재산, 왕실 안의 인맥 | **오래된 약속**: 대대로 혼인하며 ‘서로의 아이를 묻지 않는다’ | 귀족에게도 감응자가 있다는 것, ‘순결한 피’ 선전이 거짓이라는 것, 영웅 가문이 아이를 시험한다는 것 | 자기 집의 감응자 혈통을 끝까지 숨기기 |
| 학교 가문 | 독립 목표의 가문 | 학자 관료 집안 | 교단 밖의 학교 재단, 장학, 관료 인맥 | 후원을 주고받지만 깊지 않음 | 거의 없음 | 교단 밖의 교육 확대(교육권을 둘러싼 교단과의 다툼) |

- **가문 사이의 비전투 관계 예:** 수로 가문과 영웅 가문의 혼인, 샘 영주 가문이 딸·아들을 혼인으로 내보내 버팀, 학교 가문의 장학생이 무공 가문의 치안대에 들어감, 철 피난 가문과 영웅 가문의 약속.

## 4. 기관 (필요한 만큼)

| 영역 | 기관(임시) | 역할 | 이야기에서의 쓸모 |
|---|---|---|---|
| 군사·치안 | 왕실군 / 지방 치안대 | 국방과 치안. 치안대엔 무공 가문의 영향 | 첫 만남 마을에 오는 공권력 |
| 법 집행 | **처리 사무소** | 대토벌 때 ‘괴물 처리 규정’을 집행하던 관청. 지금은 유골 신고와 밀거래 단속만 하며 존재 이유를 증명하려 함. 규정은 폐지되지 않았다 | 공개 = 사살 의무. 생존 사실을 가장 원하는(죽이려고) 관청 |
| 행정 | 봉인청 / 왕실 기록소 | 관리 위임 감독과 갱신 / 국가 기록 | 감사의 빈틈, 베낀 문장 |
| 교육·학계 | 왕립 학원 / 교단 학교 / 학교 가문의 재단 / 자유시 학회 | 국가 서사 / 신앙 교육 / 세속 교육 / 복원학과 측정 기술 | 학생의 교육 기회, 역사 해석 논쟁 |
| 상업·운송 | 수로 가문의 운하·철도 / 자유시 상회 | 물류 | 소금 값의 변화(첫 만남의 원인), 철도 노선 |
| 복원 산업 | 자유시의 복원 회사들 + 샘 영주 가문의 영지 사업 + 고원 자치령의 샘 되살리기 | ‘사라진 생태’를 되살리는 사업 | **모르는 채로 쉼터를 되살려 억류의 그물을 끊음** |
| 기록·정보 | 왕실 기록소 / 교단 등록부 / 애도파의 숨은 연대기 / 자유시 신문 | 공식사 / 출생·사망·혼인 / 학살의 기록 / 소문의 증폭 | 진실의 조각이 흩어진 곳 |
| 법률 | 괴물 처리 규정(존속), 봉인령과 관리 위임, 매장 유예 규정, 토벌세 폐지령 | — | 공개가 곧 보호가 아닌 이유, 장례 관습의 법적 흔적 |

## 5. 정치·경제의 인과 (새 설계)

| 질문 | 답(후보) |
|---|---|
| 대토벌의 비용 | 왕국의 **토벌세**, 교단의 **정화 헌금**, 수로 가문과 자유시 상회의 대출. 고원 자치령과 길목 마을은 징발과 전장을 떠맡음 |
| 누가 실제 이익을 얻었나 | 중심 왕국(통합된 왕권), 교단(국경을 넘는 권위의 확대), 수로 가문(공사와 운하), 영웅 가문(작위와 관리권). 무공 가문은 초기 공 뒤에 밀려남 |
| 영웅 가문이 권력을 얻자 | 무공 가문은 원한, 샘 영주 가문은 몰락 중이라 무관심, 철 피난 가문은 혼인으로 손잡음, 수로 가문은 동업. 교단은 영웅 가문을 ‘정화의 손’으로 높이며 후원을 받음 |
| 집결지 파괴가 바꾼 환경과 경제 | 집결 때마다 솟던 샘과 데워지던 골이 사라져 고원 자치령과 샘 영주 가문의 땅이 마름. 이웃 왕국의 상류 습지도 마름 → 농업 쇠퇴, 물길 권리 다툼 |
| 멸종 선언은 왜 필요했나 | 토벌세 폐지를 요구하는 백성의 압력, 교단이 정화를 교리로 닫을 의례의 필요. 둘 다 ‘끝’이 필요했고, 가문이 그 끝을 공급했다 |
| 쇠퇴한 산업 | 토벌 용역, 갓 적출한 기관의 시장, 무리 길목의 목축 |
| 생긴 산업 | 운하와 철도, 개간, 치유 온천 순례, 유골·표본 시장, 복원 산업 |
| 복원 산업의 주도자 | 자유시 상회의 자본 + 학회의 기술 + 샘이 마른 지역의 절박함. 교단의 치유 성소와 온천을 두고 경쟁 |
| 가문의 비밀 연구가 외부 산업에 준 영향 | 가문이 쉼터 시설(제염소·요양소)을 운영하며 소금과 온천 시장에 들어와 있음. 수로 기술은 수로 가문의 운하 사업으로 이어짐. 연구 자체는 바깥에 나가지 않음 |
| 생존 사실이 드러나면 | 왕실: 세금의 정당성과 위신(숨기자 / 가문을 벌하고 국유화하자로 갈림). 교단: 교리의 위기(정화파 / 개혁파 / 애도파로 갈림). 이웃 왕국: 공동 선포의 책임 추궁, 자기 땅의 옛 집결지 회복 요구. 고원 자치령: 신앙의 정당성, 자치의 지렛대. 처리 사무소: 규정대로 처리. 복원 산업: 전시·번식 사업. 무공 가문: 영웅 가문 몰락의 기회. 샘 영주 가문: 몰락의 진짜 원인을 알게 됨 |
| 공개가 곧 보호가 아닌 이유 | 처리 규정의 존속, 시장 가치, 교단 정화파의 교리, 대중의 공포(깊은 잠과 산 채 묻힌 아이들의 이야기), 억류를 갑자기 풀 때의 재난(도는 물길), 보호할 법과 기관이 없음 |

## 6. 가문 없이도 일어나는 갈등

1. **소금과 철도:** 수로 가문의 철도가 값싼 소금을 실어 오며 내륙 제염 마을들이 무너진다(첫 만남 추천안의 배경, [first-encounter-v2.md](first-encounter-v2.md)).
2. **온천 전쟁:** 복원 회사가 되살린 온천과 교단의 치유 성소가 순례객과 환자를 두고 다툰다.
3. **교육권:** 학교 가문의 세속 학교 확대에 교단이 반발. 학생의 장학과 진로가 걸림.
4. **고원의 자치:** 고원 자치령이 메마른 샘의 책임을 묻고 옛 신앙의 의례를 공식화하려 하자 왕실과 교단이 함께 경계.
5. **처리 사무소의 폐지 논쟁:** 예산을 줄이려는 왕실과 존속을 원하는 무공 가문.

## 7. 작가가 고를 것

1. 모델 4 ‘두 개의 권위’를 정치 질서로 둘지
2. 멸종 선언의 필요를 ‘토벌세 폐지 압력 + 교단의 끝맺음 의례’로 둘지
3. 가문 여섯 가운데 줄이거나 합칠 것
