## 비밀-01. 첫 번째 침묵의 원인 — 후보 있음 · 승인 대기

| 칸 | 내용 |
|---|---|
| 실제 진실 | 지하수·기후·바닥 환경의 장기 변화가 바탕이고, 일부 지역에서는 사람의 초기 물길 사업이 그 변화를 거들었다(추천안 ‘나’, [history.md](history.md) §2-2) |
| 발생 원인 | 자연의 장기 변화 + 국지적 물길 사업 |
| 최초 사건 | 북부 고산과 해안의 몇몇 종이 이동 경로를 벗어남 |
| 아는 쪽 | 아무도 전체를 모름. 옛 관찰 수첩과 수위표에 증상만 남음 |
| 잘못 아는 쪽 | 당시 사람들과 감응자 가문(‘짐승이 미쳐 간다’), 공식 역사(괴물이 위험해서 토벌했다) |
| 남은 기록·증거 | 관찰 수첩의 이동 방향 일치, 수위표, 옛 물길 공사 기록, 가문의 경고 장부 조각 |
| 공개 시 실제 갈등 | ‘괴물이 위험했다’는 토벌의 명분이 흔들림. 지금의 물길 사업을 하는 쪽이 같은 실수를 되풀이하고 있음이 드러남 |
| 줄거리에서 필요한 이유 | 생태 이야기의 뿌리. 현재 위기(산록 물길)와 과거를 잇는 거울 |

## 비밀-02. 마지막 토벌은 추격을 멈춘 사건이었다 — 후보 있음 · 승인 대기

| 칸 | 내용 |
|---|---|
| 실제 진실 | ‘마지막 괴물 토벌’로 기념되는 일의 실체는 추격 중지와 길 폐쇄였고, 왕국에는 거짓 승전이 보고되었다 |
| 발생 원인 | 현장 지휘관·기록자·변경 주민(그리고 후보: 토벌을 거부한 감응자)의 상충하는 동기 |
| 최초 사건 | 마지막 원정에서 새끼와 늙은 개체가 산으로 들어가는 것을 본 일 |
| 아는 쪽 | 은폐 조직의 일부 집(선대 결정 기록) |
| 잘못 아는 쪽 | 왕국과 대중(영웅담), 토벌 영웅의 후손 |
| 남은 기록·증거 | 전투일지의 모순, 미사용 보급품, 무명 병사의 편지 |
| 공개 시 실제 갈등 | 영웅담과 기념비의 의미가 뒤집힘. 판정의 권위가 흔들림 |
| 줄거리에서 필요한 이유 | 중반의 이해 전환 후보(기록 대조로 드러남) |

## 비밀-03. 길을 닫은 날 바깥에 처진 무리의 희생 — 후보 있음 · 승인 대기

| 칸 | 내용 |
|---|---|
| 실제 진실 | 피난처를 지키려고 길을 닫으면서, 아직 바깥에 처진 무리를 버렸다. 일부는 마을로 내려와 피해를 내고 토벌되었고, 그중 일부가 ‘마지막 승리’로 기념되었다 |
| 발생 원인 | 추격대가 먼저 닿을 수 있다는 판단(세 선택지 가운데 하나를 고름) |
| 최초 사건 | 길을 닫은 날의 결정 |
| 아는 쪽 | 은폐 조직 수호파의 노인들(감춘 기록) |
| 잘못 아는 쪽 | 은폐 조직의 젊은 세대(선대는 생물을 모두 지켰다고 믿음) |
| 남은 기록·증거 | 닫는 날의 결정 기록, 바깥 무리의 목록 |
| 공개 시 실제 갈등 | 은폐 조직의 자기 이야기(수호자)가 무너짐. 수호파의 도덕적 권위가 흔들림 |
| 줄거리에서 필요한 이유 | 최종부의 두 번째 반전 후보. ‘지키는 일’에도 대가가 있음을 보여 줌 |

## 비밀-04. 공식 멸종 판정의 사정 — 후보 있음 · 승인 대기

| 칸 | 내용 |
|---|---|
| 실제 진실 | 판정은 설계된 거짓이 아니라 정치적 종결과 불완전한 조사의 산물이다. 은폐 조직의 목격담 흐림과 가문의 침묵이 판정을 쉽게 만들었다 |
| 발생 원인 | 목격 감소, 예산 종결, 종결의 정치 |
| 최초 사건 | 선언 |
| 아는 쪽 | 조사 기록의 일부(누구도 전체를 정리하지 않음) |
| 잘못 아는 쪽 | 대중(완전한 멸종), 일부 음모론자(누군가 일부러 꾸몄다) |
| 남은 기록·증거 | ‘확인 불가’로 묶인 목격 보고 |
| 공개 시 실제 갈등 | 판정 정정의 범위를 두고 기관과 복원계가 맞섬 |
| 줄거리에서 필요한 이유 | 결말에서 ‘지우지 않고 긋는다’(멸종 위에 줄을 긋고 살아 있다를 쓰는 일)의 근거 후보 |

## 비밀-05. 이르바넬의 존재와 위치 — 존재는 후보 있음 · 위치는 생태 단계

| 칸 | 내용 |
|---|---|
| 실제 진실 | 노르바 쪽 고산 수계 뒤에 피난 조건이 남은 계곡군이 있고, 몇몇 종이 살아 있다 |
| 발생 원인 | 자연의 피난 조건 + 길 폐쇄 |
| 최초 사건 | 마지막 무리의 피난(E5) |
| 아는 쪽 | 은폐 조직(길까지), 가문(존재와 훈련 구역만), 일부 산마을 일꾼 |
| 잘못 아는 쪽 | 세상 전체(멸종), 일부 연구자(가장자리 공급원만 앎) |
| 남은 기록·증거 | 물길 수량 이상, 출처 빈칸, 확인 불가 목격담 |
| 공개 시 실제 갈등 | 밀렵의 쇄도, 판정 정정, 산마을의 생계와 책임 |
| 줄거리에서 필요한 이유 | 시리즈의 대발견. 결말의 무대 |

## 비밀-06. 모계 가문의 ‘찾는 이’ 협력과 기록 말살 — 후보 있음 · 승인 대기

| 칸 | 내용 |
|---|---|
| 실제 진실 | 가문의 일부가 대토벌 때 ‘찾는 이’로 고용되어 몰이를 빠르게 했다. 뒤에 가문은 그 기록을 지웠다. 말살을 이끈 사람도 감응자 여성이었고, 보호로 시작한 결정이 통제로 굳었다(역설 후보) |
| 발생 원인 | 생존과 재산, 낙인에 대한 두려움, 기술 독점 |
| 최초 사건 | 토벌대의 첫 고용 계약 |
| 아는 쪽 | 가문의 ‘아는 사람’(조각으로), 은폐 조직(가문이 토벌을 도왔다는 사실만) |
| 잘못 아는 쪽 | 가문의 젊은 구성원(우리는 늘 존중받던 직능), 민간(마녀는 미신) |
| 남은 기록·증거 | 다른 기관의 보상 장부, 원정 보급 장부의 ‘길잡이’ 보수, 병사의 편지, 은폐 조직 자료의 여백 |
| 공개 시 실제 갈등 | 가문 안의 분열이 터짐. 가문 출신 인물이 자기 뿌리를 다시 봄. 낙인이 되살아날 위험 |
| 줄거리에서 필요한 이유 | 가문 축의 핵심 반전. 생태 축과 ‘기록을 어떻게 남기는가’라는 주제로 만남 |

## 비밀-07. 은폐 조직과 가문의 훈련권 타협 — 후보 있음 · 승인 대기

| 칸 | 내용 |
|---|---|
| 실제 진실 | 〈닫힌 골의 겨울〉 뒤, 가문은 침묵과 감응 경보를, 은폐 조직은 제한 구역의 훈련 출입을 내주었다. 떠난 딸들의 후손이 본가에 다시 흡수되었다 |
| 발생 원인 | 감응이 피난처 보호에 쓸모 있다는 증명 + 본가의 발견과 압박 |
| 최초 사건 | 밀렵꾼의 침입과 감응자 후손의 경고 |
| 아는 쪽 | 양쪽 지도부, 훈련받은 가문 감응자(구역만 앎) |
| 잘못 아는 쪽 | 가문의 젊은 감응자(훈련 구역은 가문의 권리라고 믿음), 은폐 조직의 젊은 세대(가문은 손님일 뿐) |
| 남은 기록·증거 | 출입 장부, 훈련 자료의 구역 표시, 혼인 기록 |
| 공개 시 실제 갈등 | 사업파가 이 권리를 거래 수단으로 씀. 수호파가 약속 파기를 주장할 수 있음 |
| 줄거리에서 필요한 이유 | 가문 축과 이르바넬 축이 만나는 고리. 현재 거래의 원천 |

## 비밀-08. 보존 재료의 출처 위조 — 후보 있음 · 범위 미정

| 칸 | 내용 |
|---|---|
| 실제 진실 | 일부 시설 계통의 ‘오래된 보존분’은 최근 가장자리 샘에서 채집한 자연 잔존 계통의 재료였다 |
| 발생 원인 | 복원 시대의 재료 수요, 은폐 조직의 공급 관행 |
| 최초 사건 | 첫 ‘보존분 이관’ 서류 |
| 아는 쪽 | 사업파, 사설 보존원 |
| 잘못 아는 쪽 | 받는 시설과 협회(정말 오래된 보존분이라고 믿음) |
| 남은 기록·증거 | 이관 날짜가 계절길이 열린 직후에 몰림, 너무 높은 발생률, 운송 짐표, 통 바닥의 모래와 작은 생물 |
| 공개 시 실제 갈등 | 복원 기록 전체의 신뢰 위기 |
| 줄거리에서 필요한 이유 | 기록 대조로 드러나는 첫 반전 후보(중반) |

## 비밀-10. 감응 소인의 가족성과 가문 밖 감응자 — 후보 있음 · 승인 대기

| 칸 | 내용 |
|---|---|
| 실제 진실 | 감응 소인은 드물게 가족 안에서 이어질 수 있지만 가문 밖에도, 남성에게도 있다. 가문의 힘은 피가 아니라 훈련, 기록, 선별, 두려움이었다 |
| 발생 원인 | 기전은 정하지 않음(드문 선천적 소인) |
| 최초 사건 | 공존 시대의 감응자들 |
| 아는 쪽 | 거의 아무도 정리해 알지 못함. 가문 밖 감응자 개인은 자기 경험만 앎 |
| 잘못 아는 쪽 | 가문(어머니에서 딸로만, 피가 섞이면 흐려진다는 혈통 신화) |
| 남은 기록·증거 | 가문 기록 속 ‘약하다’고 적힌 아들들, 가문 밖 감응자의 존재 자체 |
| 공개 시 실제 갈등 | 가문의 혼인 통제와 선별의 근거가 무너짐 |
| 줄거리에서 필요한 이유 | 주인공이 ‘선택받은 혈통’으로 기울지 않게 하는 핵심 장치 |

## 비밀-11. 어머니 계열 인물의 출신과 반대 — 후보 있음 · 인물 재창조에 달림

| 칸 | 내용 |
|---|---|
| 실제 진실 | (역할 단위) 주인공의 보호자 한 사람이 감응자 가문에서 선별과 통제에 반대해 탈출했다. 주인공의 출발을 실제로 막으려 했다가 위험을 비교해 보냈다 |
| 발생 원인 | 딸을 도구로 쓰는 가문의 요구 |
| 최초 사건 | 탈출 |
| 아는 쪽 | 그 인물 자신(일부), 도운 사람 |
| 잘못 아는 쪽 | 주인공(걱정 많은 보호자로 앎), 가문(죽었거나 사라졌다고 앎) |
| 남은 기록·증거 | 우편 장부, 옛 연락선의 편지, 가문 족보의 지워진 이름 |
| 공개 시 실제 갈등 | 주인공의 배신감, 가족의 위험, 가문의 접근 |
| 줄거리에서 필요한 이유 | 가문 축을 주인공의 집으로 가져오는 고리 |
| 메모 | 이 역할을 맡을 인물은 인물 재창조에서 정한다(W의 마렌을 유지할 의무 없음) |
