## 0. 결론 먼저

- **교단은 여자들을 기록했고, 그 기록으로 여자들이 찾아졌다.** 교단 등록부는 출생 때 어머니의 이름을 적었다. 그것이 딸의 줄을 쫓는 지도가 되었다.
- **교단 중앙과 고원 교구가 갈렸다.** 중앙은 ‘흔들리는 피’를 정화의 언어로 설명하고 동원과 수용에 구실을 줬다. 고원 교구는 여자들을 숨기고, 매장을 미루는 규칙으로 깊은 잠에 든 아이를 지켰다.
- **‘순결한 영웅 가문’의 이미지는 마녀의 소멸과 함께 만들어졌다.** 가문의 감응은 ‘정화의 시련’이 되었고, 같은 증상의 바깥 여자들은 ‘흔들리는 피’로 남았다.

## 1. 영역별 설계

| 영역 | 설계(후보) |
|---|---|
| 감응자 여성의 사회적 지위 | 공존 시대: 무리 철에 앓는 집의 딸. 혼인 기피. 대토벌: 징집되거나 팔려 감. 지금: 대부분 자기 줄을 모름 |
| 혼인 제한 | 교단 중앙은 ‘흔들리는 피’의 여자와의 혼인에 특면을 요구했다. 가문만 대대로 특면을 받았다 |
| 가문의 혈통 관리 | 강한 딸은 집 안에(데릴사위), 약한 딸은 밖으로. 전쟁 뒤엔 강한 바깥 여자를 새 이름으로 며느리·양녀로 들임 |
| 교단의 출생·신분 기록 | 출생 때 어머니 이름. 고원 교구는 어머니의 어머니까지 적는 관습(후보) |
| 종교의 증상 해석 | 중앙: 땅의 흔들림이 몸에 든 것, 정화가 필요한 피. 고원 교구: 무리의 숨을 듣는 몸, 짐이자 재주 |
| ‘마녀’라는 말의 발생과 변형 | 마을의 별명 → 첫 번째 침묵 뒤 중앙 설교의 ‘괴물과 통하는 여자’ → 전쟁 뒤 사라진 여자들의 이름. 지역마다 다른 말(§2) |
| 강제 동원을 지지·반대한 종교 세력 | 지지: 중앙(정화의 의무, 수용소). 반대: 고원 교구 일부(여자들을 숨김), 을의 교구(을 군 장교와 함께 인도를 막음) |
| 순결한 영웅 가문의 이미지 | 중앙이 가문을 ‘정화의 손’으로 높이고, 가문의 딸들에게 흰 옷을 입힌 의례를 축복함. 바깥 여자들의 같은 증상은 ‘흔들리는 피’로 남음 |
| 현대의 종교와 감응자 차별 | 감응자 자체는 드러나지 않음. 그러나 ‘마녀’라는 말과 혼인 특면의 옛 규정, 고원 교구의 등록부가 남아 있음 |
| 다른 나라의 기억 | 을: 숲으로 간 여자들의 추모(교구가 기억함). 병: 수용소의 미친 여자 이야기 |
| 보호와 박해를 함께 한 역사 | 매장을 미루는 규칙(보호)과 등록부의 제공(박해)이 같은 교단에서. 고아원은 소녀들의 피난처이자 징집의 통로 |

## 2. 지역별 ‘마녀’

| 지역 | 말의 결(임시) | 뜻 |
|---|---|---|
| 갑의 산마을 | 괴물을 부른 여자 | 공포. 아이를 겁주는 이야기 |
| 갑의 도시 | 옛날 미신 | 거의 잊힘 |
| 을의 고원 | 숲으로 간 여자들 | 슬픔과 존경. 몇몇 집의 할머니 이야기 |
| 병 | 미친 여자 | 교단 수용소의 기억 |

## 3. 나라와 교단의 독립 목표 (가문과 무관하게)

| 세력(임시) | 독립 목표 | 마녀 역사와의 관계 |
|---|---|---|
| 갑의 왕실 | 재정과 위신 | 징집법의 책임 |
| 을의 정부와 군 | 고원의 회복, 갑과의 대등함 | 급여 장부를 가진 나라. 가문에 대한 오랜 원한 |
| 병 | 교역과 산업 | 수용소의 책임을 교단에 미룸 |
| 교단 중앙 | 신분 등록과 교육의 권한 | 정화 신학의 책임 |
| 고원 교구 | 고원 공동체의 보호 | 숨긴 여자들의 기억 |
