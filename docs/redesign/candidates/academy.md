# 아카데미 — 공개된 목적과 숨겨진 목적, 그리고 복원 협회와의 관계 `[P 후보]` `[작가 전용]`

> 상태: **P 설계 후보 · 미승인 · 정본 아님. 세부 조직 구조와 이름, 인물은 확정하지 않는다.** 작성 2026-10-31(9단계).
> 작가 요구([P결정-011](../p-canon/decisions.md) B): 명확한 설립 목적, 가문의 비밀과의 연결, 모든 구성원이 아는 것은 아님. 흔한 능력자 학교로 만들지 않는다. 학교 전체를 비밀 연구 시설로 단정하지 않는다. **인물들의 자율적 목표와 관계, 우정, 경쟁, 배신이 생기는 곳이어야 한다.**
> 나라는 임시로 갑·을·병. 협회는 [restoration-society.md](restoration-society.md).

## 0. 결론 먼저

- **추천 설립 모델: ‘연합의 학원’(모델 2 + 모델 3).** 대토벌을 함께 치른 세 나라가 전쟁 뒤 평화 협약으로 세운 국제 학원. 세 나라의 젊은이를 함께 가르쳐 다시는 서로 싸우지 않게 하고, 무너진 땅을 다시 세울 행정가·의사·기술자·자연 연구자를 길렀다. 평민 장학생과 외국 학생이 있다.
- **영웅 가문과의 관계:** 가문은 학원을 세우지 않았다. 대신 **이사회의 세습 자리, ‘영웅 장학금’, 그리고 현장 연구 과정(봉인 구역 둘레의 실습)**으로 영향력을 얻었다.
- **숨겨진 목적은 셋:** ① 장학 위원회와 현장 실습을 통해 감응자 후손 소녀를 찾아냄(반응을 보이는 아이) ② 닫힌 서고로 위험한 역사 자료의 접근을 막음 ③ 논문 심사로 멸종 선언을 의심하는 학자를 일찍 알아봄. **대부분의 교사와 학생은 학원의 공개된 목적을 믿고 산다.**
- **두 기관의 관계: 모델 B.** 협회는 가문이 깊이 관여해 세웠고, 학원은 따로 세워졌지만 가문이 후원·인사·사업으로 영향력을 얻었다. 둘은 현장 실습과 연구 인력으로 이어진다. 그러나 각자의 이해가 다르고, 비밀이 드러나면 서로 다르게 움직인다.

| 위험한 역사 자료의 접근 통제 | **채택** | 닫힌 서고(공개 명목: 전쟁 기록의 보존) |
| 멸종 선언을 의심하는 학자의 조기 파악 | **채택** | 논문 심사와 출판 승인 |

## 3. 핵심 질문

| 질문 | 답(후보) |
|---|---|
| 1. 어떤 나라와 법률 아래 | 갑의 땅에 있으나 세 나라의 평화 협약으로 세운 국제 이사회가 운영. 교단이 감독 자리 하나 |
| 2. 누가 설립·운영 | 세 나라 왕실과 교단. 운영은 이사회와 학장 |
| 3. 영웅 가문과의 관계 | 이사회의 세습 자리, 영웅 장학금, 현장 연구 과정 후원 |
| 4. 입학 기회 | 귀족 정원, 평민 장학생, 외국 학생(을·병) |
| 5. 실제 선발 기준 | 시험과 추천. 장학 위원회의 숨은 우선순위(옛 지역의 소녀) |
| 6. 여성 감응자와 후손의 발견 | 장학 위원회의 지역 우선, 현장 실습에서의 ‘건강 조사’. 바깥에는 환류종이 없으므로 **봉인 구역 둘레에서만** 반응이 드러날 수 있음 |
| 7. 감응 능력 없는 학생의 역할 | **중요함.** 식물학·기록학·공학·행정·의학. 최종 진실 후보 1은 감응이 아니라 식물학과 기록에서 드러남 |
| 8. 교사와 연구자가 아는 것 | 대부분 모름. 현장 연구 과정 책임자와 이사 몇은 앎. 서고 관리인은 ‘닫는 규정’만 앎 |
| 9. 비밀 연구의 공간·제도·명목 | 봉인 구역 둘레의 현장 연구 분원(공개 명목: 위험 감시와 복원 연구), 협회와 공동 운영 |
| 10. 공식 역사에 의문을 가질 기회 | 역사 세미나, 을에서 온 학생들의 다른 이야기, 현장 실습에서 본 번호 묘비, 닫힌 서고의 목록 |
| 11. 졸업 후 경로 | 협회, 각국 행정, 교단, 현장 연구 분원, 을의 대학 |
| 12. 가문의 통제를 벗어난 사람들이 할 수 있는 것 | 을의 학술지에 발표, 협회 을 지부와 연대, 서고의 사본 반출, 고원 교구와의 연결 |

## 4. 인물 역할 (이름 미정)

| 역할 | 혈통·비밀과 무관한 욕망과 관계 |
|---|---|
| 주인공 | (인물 설계에서) 학원에서 이루고 싶은 것 — 예: 복원 일을 하고 싶다, 집안을 일으키고 싶다 |
| 서로 다른 배경의 학생 | 장학생과 귀족 자제의 경쟁과 우정, 졸업 뒤 자리를 둘러싼 다툼 |
| 학원의 목적을 믿는 교사 | 평화와 재건의 이상 |
| 비밀 연구에 관여하는 교사 | 연구자로서의 야심과 가문에 진 빚 |
| 다른 나라에서 온 학생 | 을의 끌려간 딸들의 이야기를 아는 집안 |
| 영웅 가문과 이해관계가 있는 인물 | 가문의 먼 친척, 장학금 수혜자 |
| 학원의 역사에 의문을 품는 인물 | 닫힌 서고를 노리는 학생 |
| 복원 협회와 연결된 인물 | 비탈 숲을 자랑하는 산림 감독의 자녀나 제자 |

## 5. 두 기관의 관계

| 모델 | 요지 | 판단 |
|---|---|---|
| A. 가문이 둘 다 설립 | 완벽한 음모 장치가 되기 쉬움 | 비추천 |
| **B. 협회는 가문이 깊이 관여해 설립, 학원은 따로 세워졌으나 가문이 영향력을 얻음** | 협회는 현장, 학원은 교육·연구. 가문의 자리가 다름 | **추천** |
| C. 둘 다 독립 설립 후 이해가 맞아 협력 | 가문의 영향이 약해짐 | 대안 |

| 관계 | 내용(모델 B) |
|---|---|
| 연구 성과와 시료의 이동 | 현장 연구 분원(공동 운영)에서 학원 연구실로. 일부는 가문으로 |
| 학생의 현장 실습 | 협회의 숲과 물길 현장, 봉인 구역 둘레 |
| 지원금과 장학금 | 협회의 연구 지원금, 가문의 영웅 장학금 |
| 연구자의 채용과 이동 | 학원 졸업생이 협회로, 협회 기술자가 학원 강사로 |
| 국제 사업을 통한 정보 수집 | 을·병의 현장 사업에서 목격 신고와 기록이 신고 창구로 |
| 교단과 국가의 감독 | 교단 감독 자리(학원), 왕실의 감사(협회) — 비밀까지는 못 봄 |
| 내부 고발과 유출 | 협회 기록 담당, 학원 서고 관리인, 을 지부 |
| 이해 충돌 | 협회는 숲을 넓히고 싶고, 학원 연구자는 발표하고 싶고, 가문은 덮고 싶음 |
| 비밀이 공개되면 | 협회: 복원파·안전파·가문파로 갈림. 학원: 학문의 자유를 내세운 다수와 이사회의 충돌. 둘의 대응이 서로 부딪힘 |

## 6. 작가가 고를 것

1. 학원을 ‘연합의 학원’(세 나라의 평화 협약, 행정·의학·기술·복원)으로 둘지
2. 숨겨진 목적을 장학·현장 실습의 선별, 닫힌 서고, 논문 심사의 셋으로 좁힐지
3. 두 기관의 관계를 모델 B로 둘지
