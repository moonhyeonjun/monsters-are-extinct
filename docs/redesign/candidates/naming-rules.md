> 상태: **P 설계 후보 · 미승인.** 작성 2026-10-31(5단계).
> 작가 결정([P결정-007](../p-canon/decisions.md)): 마지막 집결지의 이름은 지리·언어 체계 설계 뒤 확정한다. 새 지명 후보를 양산하지 않는다. 이번에는 나라·지역·가문·학교·인물의 작명이 일관되도록 **기본 규칙만** 정한다. 본격적인 작명은 인물과 세계 지리 구조가 확정된 뒤.

## 1. 언어 층위 (임시)

| 층위 | 쓰는 곳 | 소리의 결(규칙) | 쓰임 |
|---|---|---|---|
| 평야말 | 중심 왕국 | 두 음절 중심, 받침이 적고 부드러움 | 평민 이름, 마을, 강과 들 |
| 산말 | 이웃 왕국과 고원 | 거센소리·된소리가 섞이고 받침이 많음. 두세 음절 | 산과 고개, 이웃 왕국의 사람 |
| 옛말 | 공존 시대 길목 마을, 고원의 옛 신앙 | 땅의 생김과 소리를 그대로 붙인 합성어(우리말 느낌) | 오래된 지명, 별칭, 풍습의 이름 |
| 교단 말 | 교단의 기록과 의례 | 모음이 많고 ‘ㄹ’이 잦은 세 음절 안팎 | 성직자 이름, 교구, 의례 |
| 상인말 | 자유시 동맹 | 짧고 실용적. 직업과 별명이 성이 됨 | 상회, 시민 |

## 2. 이름의 종류별 규칙

| 대상 | 규칙 |
|---|---|
| 나라 | 그 나라 말의 결을 따름. 두 왕국의 이름은 첫소리가 겹치지 않게 |
| 지역 | 같은 곳에 층위별 이름이 겹칠 수 있음(옛말 이름, 교단 기록 이름, 행정 이름). 이름의 차이가 역사의 단서가 될 수 있음 |
| 가문 | 귀족 가문의 성은 영지 이름에서. 영웅 가문은 작위와 함께 받은 이름과 옛 ‘물결 집’ 시절의 이름이 따로 있을 수 있음(감춰진 옛 이름) |
| 학교 | 세운 가문의 이름이나 땅 이름. 교단 학교는 교단 말 |
| 인물 | 평민은 이름 + 아버지·어머니의 이름이나 마을 이름. 귀족은 이름 + 가문의 성. 성직자는 서품 때 교단 말 이름을 더함. 상인은 별명이 성이 됨 |
| 환류종 | 종명은 층위마다 다름(옛말의 생김 이름, 교단 기록의 이름, 학회의 이름). 정하지 않음 |

## 3. 검증 절차 (작명할 때)

1. 첫소리 표: 주요 인물·지명·가문·종명의 첫소리를 한 표에 놓고 몰림을 찾는다.
2. 음절 수와 어미 표: 같은 장면에 자주 나오는 이름끼리 겹치지 않게.
3. 층위 표: 이름이 어느 언어 층위에서 왔는지 적는다. 한 지역 안에서 층위가 섞이면 이유가 있어야 한다.
4. W 이름과의 거리: P는 W를 잇지 않으므로 W의 대표 이름(하벨, 세르딘, 이르바넬 등)과 혼동되지 않게.
5. 흔한 판타지 이름과 유명 작품의 대표 이름을 피한다.

## 4. 작가가 고를 것

1. 다섯 언어 층위(평야말·산말·옛말·교단 말·상인말)를 작명의 바탕으로 둘지
2. 한 곳에 층위별 여러 이름을 허용할지
