# 종교와 신앙 `[P 후보]` `[작가 전용]`

> 상태: **P 설계 후보 · 미승인 · 정본 아님.** 작성 2026-10-30(4단계).
> 작가 결정([P결정-006](../p-canon/decisions.md)): 종교와 신앙을 주요 세계관 영역에 넣는다. 장식이나 악역 조직으로 추가하지 않는다. 종교는 국가나 가문의 하부 조직이 아닐 수 있고, 내부에서도 의견이 달라야 한다.
> 이름: 종교·종파·의례의 이름은 정하지 않는다. 아래는 기능을 설명하는 임시 표기다.
> W와의 관계: W의 신앙 설정(세 지역 생활 문화, D-094 등)은 W에서 그대로다. P는 그것을 참고만 했고, 사제나 교단이 없다는 W의 원칙을 P에 옮기지 않았다.
> 정치 구조(후보): [polity.md](polity.md)의 ‘두 개의 권위’.

## 0. 결론 먼저

- **추천: 모델 4 ‘층을 이룬 신앙’.**
  1. 바닥에 **옛 흐름 신앙** — 공존 시대 무리 길목 마을의 믿음. 무리가 땅의 숨(물과 열)을 옮긴다고 봤다. 지금은 이유를 잊은 풍습으로만 남음(문간의 소금, 길가의 돌무더기).
  2. 그 위에 국경을 넘는 **교단** — 땅의 고요와 질서를 가르친다. 출생·혼인·장례 등록과 학교, 치유 성소를 맡는다. 첫 번째 침묵 뒤 ‘정화’의 교리가 주류가 되어 대토벌에 이름을 주었다.
  3. 교단 안의 **개혁파** — 치유와 자선을 앞세우고, 정화 뒤 메마른 땅을 보며 교리를 다시 읽으려 한다.
  4. 교단에서 갈라진 소수 **애도파** — 대토벌을 ‘숨을 끊은 죄’로 기록한다. 사라진 집결지들의 위치와 최후를 적은 **숨은 연대기**를 지킨다.
  5. 종교는 아니지만 종교처럼 작동하는 **영웅 의례** — 왕실이 주관하고 교단이 축복하는 ‘끝맺음의 날’.
- **초자연은 실재하지 않는다(추천).** 신앙이 기적이라 부른 것은 모두 생태와 감응으로 설명된다: 깊은 잠에서 깨어난 아이, 숨 쉬는 샘, 성소의 밤 짐승. 작가는 그 설명을 안다.
- **같은 교단이 아이를 지켰고, 같은 교단의 등록부가 아이를 징발에 넘겼다.** 공존 시대에 깊은 잠에 든 아이를 산 채로 묻지 않도록 ‘사흘 밤샘’을 정한 것도 교단이었고, 대토벌 때 ‘물결 든 아이’ 등록부를 군에 내준 것도 교단이었다.

| 진실의 조각을 품나 | 등록부 | 풍습 | 없음 | 등록부(교단), 풍습(옛 신앙), 숨은 연대기(애도파) |

## 2. 각 신앙의 설계

### 2-1. 옛 흐름 신앙 (공존 시대의 민간 신앙)

| 항목 | 설계(후보) |
|---|---|
| 형성 배경 | 무리의 길목에서 무리와 함께 살던 마을들. 무리가 지나간 뒤 샘이 솟고 골이 데워지는 것을 대대로 봄 |
| 교리와 윤리 | 무리는 땅의 숨(물과 열)을 옮기는 것이다. 길을 비켜 주고, 몫을 남겨라. 이 믿음은 **절반쯤 맞는 관찰**이었다(기관은 실제로 열과 물을 옮긴다) |
| 의례 | 무리 철의 밤에 문간에 소금을 놓음(쉼터의 흔적), 무리 길가의 돌무더기, 물결 든 아이를 ‘숨 듣는 아이’로 부르며 무리 철엔 집 안에 둠 |
| 국가와의 관계 | 없음. 대토벌 때 교단과 왕권이 미신으로 금함 |
| 감응자에 대한 입장 | 두 갈래. ‘숨을 듣는 귀한 아이’이자 ‘무리에게 데려가질 아이’. 존중과 두려움이 함께 |
| 대토벌의 해석 | 땅의 숨을 끊은 재앙 |
| 멸종 선언에 대한 태도 | 신앙 공동체가 남아 있지 않아 공식 입장 없음. 고원 자치령의 노인들은 ‘숨이 끊긴 해’로 기억 |
| 영웅 가문과의 관계 | **영웅 가문의 조상이 이 전통의 ‘물결 집’이었다.** 가문은 지금 이를 부정한다 |
| 영향력·경제 기반 | 집과 마을. 조직 없음 |
| 내부 갈등·변화 | 일부 풍습은 교단 의례에 섞여 들어감(이유를 잊은 채) |
| 비신자에게 미치는 영향 | 이유 모를 풍습으로 남아 누구나 따라 함 |
| 줄거리의 사건 | 소금 마을의 문간 소금 풍습([first-encounter-v2.md](first-encounter-v2.md)). 고원 자치령이 이 신앙을 공식화하려는 정치 |

### 2-2. 교단 (국경을 넘는 제도 종교)

| 항목 | 설계(후보) |
|---|---|
| 형성 배경 | 공존 시대 후기, 여러 왕국에 퍼진 ‘땅의 고요’를 가르치는 수도 공동체들이 하나로 묶임. 등록과 치유와 학교로 일상에 뿌리내림 |
| 교리와 윤리 | 사람의 땅은 고요하고 질서 있어야 한다. 절제, 경계, 돌봄, 기록. 처음엔 무리와 사람 땅 사이에 **경계를 지키라**는 가르침(공존의 계율)이었다. 첫 번째 침묵 뒤 ‘흔들림이 땅을 해친다’는 **정화의 교리**가 주류가 됨 |
| 의례 | 출생·혼인·사망 등록, **사흘 밤샘**(매장 전 사흘을 기다리는 장례. 깊은 잠에 든 아이를 산 채로 묻은 일 뒤에 정해짐), 치유 성소의 목욕, ‘끝맺음의 날’ 축복 |
| 국가와의 관계 | 서로 기대고 견제. 교단은 왕권의 정당성(‘정화의 왕’)을 축복하고, 왕권은 교단의 등록과 학교를 법으로 인정. 혼인·장례·교육의 경계를 두고 늘 다툼 |
| 감응자에 대한 입장 | 시대마다 바뀜: 공존 시대 ‘돌봐야 할 물든 아이’(보호 시설과 등록) → 대토벌 ‘흔들림에 물든 피’(등록부를 징발에 내줌) → 영웅 가문의 부상 뒤 ‘흔들림을 견디는 자’로 영웅 가문만 성화 → 지금은 지나간 일. 개혁파는 조용히 사과를 말함 |
| 대토벌의 해석 | 정화. 땅을 해치는 흔들림을 걷어 낸 거룩한 의무 |
| 멸종 선언에 대한 태도 | **교단이 함께 선포했다**(‘끝맺음’ 의례). 정화의 시대가 끝났다는 교리적 마침표. 뒤집히면 교리가 흔들림 |
| 영웅 가문과의 관계 | 영웅 가문은 큰 후원자이자 ‘정화의 손’. 가문이 바친 샘 몇 곳이 치유 성소가 되었다(교단은 그것이 억류의 쉼터라는 것을 모름, [containment-v2.md](containment-v2.md)) |
| 영향력·경제 기반 | 십일조, 치유 성소와 온천의 수입, 학교, 땅, 등록 수수료. 대토벌 때의 정화 헌금으로 크게 불어남 |
| 내부 갈등·개혁 | **정화파**(교리 수호, 선언 옹호) vs **개혁파**(치유·자선 중심. 정화 뒤 샘과 습지가 마른 것을 보고 ‘고요’가 ‘메마름’이 되었다고 의심). 성소의 ‘밤 짐승’ 목격을 기적으로 볼지 저주로 볼지도 두 파가 갈림 |
| 비신자에게 미치는 영향 | 등록이 곧 법적 신분. 혼인과 장례가 교단 의례를 거침. 학교와 치유의 큰 몫 |
| 줄거리의 사건 | 성소의 밤 짐승 논쟁, 옛 등록부의 ‘물결 집’ 표기가 한 집안의 과거를 드러냄, 개혁파 성직자의 조용한 조사, 생존 사실이 드러날 때의 분열 |

### 2-3. 애도파 (소수 종파)

| 항목 | 설계(후보) |
|---|---|
| 형성 배경 | 대토벌 말기, 집결지 학살을 직접 본 교단 성직자 몇과 고원의 살아남은 옛 신앙인들이 함께 만듦. 한때 박해받음 |
| 교리와 윤리 | 대토벌은 ‘숨을 끊은 죄’다. 잊지 않는 것이 속죄다. 기록하고, 이름 없는 것을 기억하라 |
| 의례 | 마른 샘가에 물을 붓는 추모, 사라진 무리를 위한 밤 기도, **숨은 연대기**(사라진 집결지들의 위치와 최후, 목격자의 증언)의 필사와 전승 |
| 국가와의 관계 | 감시받지만 허용됨. 공개 활동은 제한됨 |
| 감응자에 대한 입장 | ‘들은 자’. 학살을 들을 수밖에 없었던 증인으로 존중 |
| 대토벌의 해석 | 죄. 다만 그 시대 사람들의 공포도 기록함 |
| 멸종 선언에 대한 태도 | 의심하지 않는다. 모든 무리가 죄로 죽었다고 믿음. **살아 있다는 것을 모른다** |
| 영웅 가문과의 관계 | 숨은 연대기에 ‘물결 집 출신의 길잡이들이 군을 집결지로 이끌었다’는 증언이 있음. 그 길잡이가 영웅 가문이라는 것까지는 잇지 못함(위험한 조각) |
| 영향력·경제 기반 | 작음. 고원 자치령의 후원, 샘 영주 가문의 은근한 동정 |
| 내부 갈등·개혁 | 조용히 기억하자는 쪽 vs 교단의 공개 참회를 요구하자는 쪽 |
| 비신자에게 미치는 영향 | 거의 없음. 일부 학자가 연대기를 찾음 |
| 줄거리의 사건 | 연대기가 다른 집결지 파괴와 영웅 가문의 역할을 증명하는 열쇠. 살아 있는 개체를 알게 된 애도파의 혼란(속죄할 대상이 살아 있음) |

### 2-4. 영웅 의례 (국가 의례)

| 항목 | 설계(후보) |
|---|---|
| 형성 배경 | 멸종 선언 뒤 왕실이 ‘끝맺음의 날’을 정함. 교단이 축복 |
| 교리와 윤리 | 신앙이 아니라 시민의 덕: 희생, 순결, 경계 |
| 의례 | 해마다의 행렬, 학교의 낭송, 영웅 가문의 흰 옷 |
| 국가와의 관계 | 왕권의 정당성의 중심 |
| 감응자에 대한 입장 | 영웅 가문의 감응자만 기림. 평민 감응자는 없음 |
| 대토벌의 해석 | 인류를 지킨 승리 |
| 멸종 선언에 대한 태도 | 의례의 근거 |
| 영웅 가문과의 관계 | 중심 |
| 영향력·경제 기반 | 왕실 예산, 기념지 순례 |
| 내부 갈등·개혁 | 무공 가문이 자기 몫의 영광을 요구 |
| 비신자에게 미치는 영향 | 모든 백성이 참여 |
| 줄거리의 사건 | 의례의 장면이 비밀이 드러나는 무대가 될 수 있음 |

## 3. 초자연에 대한 작가의 답 (추천)

| 신앙이 말하는 것 | 작가가 아는 실제 |
|---|---|
| 깊은 잠에서 깨어난 아이(기적 또는 저주) | 겹친 박동에 끌린 몸이 신호가 멀어지자 돌아옴 |
| 숨 쉬는 샘(땅의 숨) | 겹친 박동이 지하수층을 누름 |
| 성소의 밤 짐승(환영) | 쉼터를 찾아온 탈출 개체 |
| 종을 치면 흔들림이 물러간다 | 효과 없음. 우연히 무리가 지나간 뒤였을 뿐 |
| 기도와 축복 | 사람 사이에 의미가 있을 뿐 물리적 효과는 없음 |

- 종교의 존재가 신이나 마법의 실재를 뜻하지 않는다. 작가가 다르게 정하려면 이 표를 바꾼다.

## 4. 종교가 인물과 사회에 닿는 곳

| 영역 | 닿는 방식 |
|---|---|
| 학생의 교육 기회 | 교단 학교의 장학과 학교 가문의 세속 학교. 옛 등록부에 ‘물결 집’으로 남은 집안의 아이는 지금도 일부 교구에서 성직 입문이 어려움(폐지되었지만 관행이 남음) |
| 가문 사이의 혼인 | 혼인 등록에 집안 내력이 따라감. 영웅 가문은 대대로 교단의 ‘특면’을 받아 왔다(위선의 흔적) |
| 감응자의 사회적 지위 | 지금은 화제가 아님. 드러나는 순간 옛 교리와 새 교리 사이에 놓임 |
| 장례와 추모 | 사흘 밤샘이 모두의 관습. 이유를 아는 사람은 거의 없다 |
| 지역 공동체의 갈등 | 고원 자치령의 옛 신앙 부흥 vs 교단 교구 |
| 환류종의 보호와 처분 | 정화파: 처분 / 개혁파: 보호 / 애도파: 속죄의 대상 / 처리 사무소: 법대로 |
| 정치적 정당성 | ‘정화의 왕’ 칭호와 끝맺음의 날 |

- 인물의 신앙을 선악 판별 장치로 쓰지 않는다. 정화파 성직자도 아이를 돌보고, 애도파도 사실을 왜곡할 수 있다.
