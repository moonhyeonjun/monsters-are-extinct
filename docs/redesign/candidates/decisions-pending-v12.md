## 1. 작가가 승인할 핵심 사항 (다섯)

| 순위 | 결정 | 추천 | 근거 |
|---|---|---|---|
| 1 | 초장주기 집결의 원리와 주기 범위 | **‘가득 찬 땅의 무리 짓기’**(밀도 문턱과 상 변화, 메뚜기처럼). 주기 300~500년(변동). 새 규칙 1~2(모두 현실에 있는 현상). ‘재동기화와 번식’ 문구의 처리 포함 | [long-cycle.md](long-cycle.md) |
| 2 | 처음이라고 믿은 이유와 조사 경로 | 다섯 겹(옛 왕국, 흩어진 기록, **두 형태의 오인**, 비어 있던 분지에 세운 마을, 교단의 비유). 세 조사 경로(학원 자연사·협회 지질·을의 고문서)를 합쳐야 드러남 | [deep-time-evidence.md](deep-time-evidence.md) |
| 3 | 첫 번째 침묵과 유인술 | **수백 년 만의 무리 짓기 + 그 길 위에 세워진 사람의 땅.** 대토벌의 네 과정(원거리 탐지·경로 추정·근거리 유도·토벌) | [first-silence-v4.md](first-silence-v4.md) |
| 4 | 마지막 생존지의 생태와 억류 | **가득 찼지만 무리 짓지 못하게 묶인 분지.** 억류 = ‘문턱 아래에 묶어 두기’(젊은 개체를 거두는 밀도 관리). 장면 = 터의 무늬 + 문턱의 밤 행진 | [last-site-v6.md](last-site-v6.md) |
| 5 | 최종 진실 | **‘대답이 무리를 깨운다’:** 되울림도 무리 짓기의 마주침으로 세어져, 가문의 제도가 막으려던 무리 짓기를 깨우고 있었다. 해결은 여자들이 함께 대답을 거두는 것(대답하지 않는 밤이 결말의 모형). 바탕 후보: 눌린 무리 짓기, 사람도 그 길 위에 | [final-truths-v6.md](final-truths-v6.md) |

- 함께 확인: 협회의 실패 ‘이주 마을이 옛 길목에 세워짐’([institutions-v2.md](institutions-v2.md)), ‘복원이 지운 풀숲’의 처리(모델 1과 맞지 않음).

## 2. 기존 설정과의 충돌

| 항목 | 처리 |
|---|---|
| P결정-005·007 ‘재동기화와 번식’(보류) | 무리 짓기를 ‘재동기화’로 읽을 여지. 번식은 평소에도 하고 무리 짓기 중에도 이어짐. **문구는 그대로, 작가 결정** |
| P결정-005 ‘마지막 번식 집단’(보류) | 건드리지 않음. 생존지 안에서 번식이 이어짐 |
| P결정-004 B ‘마지막으로 온전히 기능하는 집결지’ | 생존지 = 남은 마지막 고개 앞 분지. 맞음 |
| P결정-006 ‘흩어짐의 충동’ | 터를 찾아 나가려는 젊은 개체, 무리 짓기 뒤의 흩어짐. 맞음 |
| 거절된 억류안과의 유사성 | ‘고리 길’은 ‘도는 물길’과 닮아 추천에서 뺌 |
| ‘복원이 지운 풀숲’ | 모델 1과 맞지 않음. 흔적만 남기거나 버림 |
| 약 200년 | 분지가 다시 차는 시간과 억류의 시작을 맞춰야 함(표시) |

## 4. 다른 설계에 넘길 사항

| 받을 설계 | 넘길 것 |
|---|---|
| 생태 | 무리 짓는 종의 수, 두 형태의 구체적 차이(몸 색·크기·행동), 문턱의 밀도, 분지가 다시 차는 속도 |
| 역사 | 옛 왕국과 이전 무리 짓기, 이주 마을의 위치, 연대 |
| 인물 | 자연사관의 학생, 지질학자, 을의 학생과 언어 연구자, 협회 산림 감독과 신고 창구 직원, 생존지의 여자들(돌침상을 지키는 사람, 거두는 일을 거부하는 사람) |
| 줄거리 | 세 조사 경로의 배치, 교류 장면, 최종 진실의 공개 사건(돌침상을 지킨 터와 아닌 터의 비교) |
