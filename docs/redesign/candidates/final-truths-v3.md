## 0. 결론 먼저

- **추천: 진실 1 ‘갈이터를 지키던 여자들’.**
  - 세상이 믿는 것: 괴물은 멸종했다. 마녀는 괴물을 부른 여자들이었다.
  - 두 번째 층(가문의 비밀): 가문은 마지막 집결지를 숨기고, 감응자 여자들을 쓰고 지웠다.
  - **세 번째 층(가문도 모른 것):** 공존 시대의 갈이터는 자연만으로 유지된 곳이 아니었다. 감응자 여자들은 ‘열린 해’가 오는 것을 먼저 느끼고, 막힌 광천을 뚫고 물길을 고르고 웅덩이를 다듬었다. 수백 년에 걸쳐 갈이터는 **사람의 손이 있어야 열리는 곳**이 되었다.
  - 대토벌 한 세대 전, 교단 중앙의 첫 박해가 여러 골짜기에서 그 여자들을 몰아냈다. 손을 잃은 갈이터들은 막혀 갔고, 그다음 ‘열린 해’에 갈이에 실패한 무리들이 굶주린 채 헤맸다. **그것이 첫 번째 침묵의 재난이었다.** 대토벌은 여자들을 몰아낸 사람들이 그 결과를 괴물의 탓으로 돌려 일으킨 전쟁이었다.
  - 마지막 집결지가 살아남은 이유도 다르다. 가문이 숨겨서가 아니라, **그 골짜기의 여자들만은 쫓겨나지 않았기 때문**이다. 가문이 지금 ‘늘 열린 해’를 만드는 물길 기술은 그 여자들의 손기술이 이름을 잃고 억류의 도구가 된 것이다.
- **왜 강한가:** 마녀(가해자 → 함께 살던 사람들), 첫 번째 침묵(괴물의 광기 → 사람이 만든 재난), 대토벌(인류의 방어 → 박해의 결과를 덮은 전쟁), 가문(구원자 → 빼앗은 손기술로 가둔 자), 억류(가둠 → 뒤틀린 돌봄)가 **한 사실로 한꺼번에 뒤집힌다.** 새 규칙은 하나다: ‘갈이터는 사람과 함께 유지되던 곳이었다’.
- **마지막 선택의 뜻이 바뀐다:** 문제는 ‘풀어 줄 것인가 가둘 것인가’가 아니라 **‘누가, 어떻게 다시 손을 댈 것인가’**가 된다. 사람의 손을 완전히 거두면 갈이터는 막혀 무리가 끝나고, 가문의 손에 두면 지쳐 끝나고, 여러 나라의 사람들이 손을 나눠 맡으려면 박해의 역사를 마주해야 한다.
- **진실 2 ‘가문의 피는 마녀의 피’**는 새 규칙 없이 강한 중간 반전이 될 수 있다(최종 진실 1과 함께 쓸지는 작가 판단).

## 1. 다섯 후보

### 진실 1. 갈이터를 지키던 여자들 — 추천 (사람과 환류종의 상호작용 · 첫 번째 침묵의 원인 · 여성들의 선택이 남긴 결과)

| 항목 | 설계(후보) |
|---|---|
| 세상이 믿는 사실 | 괴물들이 병들어 조용해졌다 미쳐 돌아왔고, 마녀들이 괴물을 불렀다. 대토벌이 세상을 구했다 |
| 가문이 숨기는 사실 | 마지막 집결지, 감응자 여자들의 이용과 말살, 연구와 껍질 |
| 가문조차 몰랐던 사실 | 갈이터는 감응자 여자들이 대대로 손을 대 유지하던 곳이었다. 첫 박해가 손을 끊었고, 막힌 갈이터의 갈이 실패가 첫 번째 침묵의 재난을 만들었다. 마지막 집결지가 남은 것은 그곳의 여자들이 남았기 때문이다. 가문의 물길 기술은 그 여자들의 손기술이다 |
| 왜 몰랐나 | 첫 박해는 가문이 일어서기 전, 교단 중앙이 다른 골짜기에서 한 일이었다. 가문은 첫 번째 침묵을 자연의 재난으로 믿었다. 물길 기술은 ‘가문의 비법’으로 전해졌고, 그것을 가르친 여자들(전쟁 뒤 이름을 바꿔 들인 며느리들 포함)은 침묵했다. 무너진 갈이터의 돌 물길은 광물에 묻혀 자연 지형처럼 보였다 |
| 독자가 이전에 확인한 단서 | 가문 관리인의 물길 다듬기가 고원 마을 할머니들의 우물 손질과 똑같은 손놀림이다. 마녀 노래에 ‘물을 고른다’는 말이 반복된다. 무너진 갈이터 터에서 광물에 덮인 반듯한 돌 턱이 나온다. 첫 박해와 첫 번째 침묵 사이가 꼭 한 세대다(교단 고원 교구의 기록). 마지막 집결지에만 아주 오래된 돌 계단이 있다 |
| 주인공이 진실에 닿는 방식 | 마녀의 역사를 쫓다(을의 급여 장부, 요양원의 묘비, 편지) 여자들이 전쟁 전에 무엇을 하던 사람들이었는지 묻게 됨 → 무너진 갈이터 터에서 손댄 흔적을 찾음 → 가문 관리인의 기술과 마을 할머니의 손이 같다는 것을 봄 |
| 잘못 추론하게 하는 증거 | 첫 박해 기록에 ‘여자들이 샘에 독을 풀었다’는 고발이 있다 → 독자는 마녀가 실제로 재난을 일으켰다고 의심함. 또는 가문의 물길 기술이 자비로운 발명이라고 믿게 됨 |
| 결정적 사건 | 무너진 갈이터 하나를 사람들이 손질하자, 그다음 ‘열린 해’에 떠도는 개체가 그곳으로 와서 갈이를 마침. 동시에 마지막 집결지에서 관리인들이 손을 놓자 웅덩이가 몇 달 만에 막히기 시작함 → 갈이터가 손에 기대고 있다는 것이 양쪽에서 드러남 |
| 뒤집히는 장면 | 첫 장면에서 마을 노인이 무심히 하던 샘 손질, ‘마녀가 샘에 손을 대면 괴물이 온다’는 아이들 노래, 가문 관리인이 웅덩이를 다듬던 장면, 공식 역사의 첫 번째 침묵 |
| 마지막 선택의 대안 | ① 여러 나라의 마을이 갈이터를 다시 맡도록 손기술을 내놓고, 마지막 집결지의 ‘늘 열린 해’를 끝낸다 ② 가문의 손에 그대로 둔다 ③ 모든 사람의 손을 거둔다(자연에 맡긴다) |
| 각 대안의 대가 | ① 봉인과 비밀이 깨지고, 박해의 역사가 드러나며, 교단 중앙과 국가의 정당성이 흔들림. 갈이터가 되살아나기까지 수십 년, 그사이 많은 개체가 죽을 수 있음. 손을 맡을 사람들이 다시 ‘마녀’로 몰릴 수 있음 ② 무리가 지쳐 끝남 ③ 갈이터가 막혀 무리가 끝남. 사람은 더 이상 아무것도 하지 않음 |
| 이해관계의 변화 | 교단 중앙: 전쟁의 뿌리가 자기 박해였음. 고원 교구: 기억해 온 것이 옳았음. 갑의 왕실: 전쟁의 명분. 을: 자기 땅의 갈이터를 되살릴 권리와 책임. 가문: 영웅담과 기술의 출처를 잃음 |
| 기존 설정과의 충돌 | P결정-004 B ‘가문이 의도적으로 숨긴 덕분에 살아남은 마지막 집결지’ — 숨긴 것은 사실로 두되, **살아남은 원인이 하나 더 있었다**는 해석(작가 확인 필요) |
| 필요한 추가 규칙 | **하나**: 공존 시대의 갈이터는 사람의 손질로 유지되었고, 손이 끊기면 몇십 년 안에 막힌다(실제로 버려진 계단식 논과 수로가 자연 지형보다 빨리 무너지는 것과 같음). 선택 규칙 하나 더: 무리가 손질하는 사람들의 소리를 철의 신호로 익혔다(소가 목동의 부름에 오는 것처럼). 쓰면 첫 장면을 더 강하게 다시 읽게 하지만 비용이 늘어남 |

### 진실 2. 가문의 피는 마녀의 피 (사라진 여성들 · 유전)

| 항목 | 설계(후보) |
|---|---|
| 세상이 믿는 사실 | 영웅 가문의 순결한 피와 바깥의 ‘흔들리는 피’는 다르다 |
| 가문이 숨기는 사실 | 바깥 여자들을 쓰고 지웠다 |
| 가문조차 몰랐던 사실 | 감응은 어머니로만 전해진다. 가문의 남자들은 그 줄에 아무것도 보태지 않았다. 처음 조상은 여자였고, 지금 가문의 가장 강한 딸들은 전쟁 뒤 이름을 바꿔 들인 ‘마녀’들의 딸들이다. 가문의 피는 처음부터 끝까지 마녀의 피다 |
| 왜 몰랐나 | 남자의 족보로 기록함. 딸들이 아버지의 피를 이었다고 믿음. 들인 여자들이 출신을 숨김 |
| 단서 | 남자 족보와 ‘딸의 책’의 어긋남. 을의 급여 장부에 ‘가문 측 인도’로 적힌 이름이, 같은 해 가문 며느리의 새 이름 곁에 있음 |
| 결정적 사건 | 가문의 의례에 선 딸이 을 장부의 여자의 손녀임이 드러남 |
| 마지막 선택 | ① 가문의 여자들이 스스로 마녀의 후손임을 밝힌다 ② 숨긴다 |
| 대가 | ① 가문의 정당성 붕괴, 가문 안 여자들의 안전 ② 거짓의 지속 |

| 약점 | 생태와 마지막 선택에 직접 닿지 않음 → **최종보다 중간 반전**에 알맞음 |

### 진실 3. 마지막 껍질 (생태와 사람이 이해한 생존 조건의 차이)

| 약점 | 6단계에서 검토한 ‘죽은 것이 요람을 채운다’와 결이 비슷함. 의미의 뒤집힘이 작음(가문이 더 해로웠다는 쪽) |

### 진실 4. 땅의 맥박 (인간의 근본적 오해 — 감응의 대상)

| 항목 | 설계(후보) |
|---|---|
| 가문조차 몰랐던 사실 | 감응자는 환류종만 듣는 것이 아니다. 광천을 크게 솟게 하는 ‘열린 해’는 땅속의 큰 맥박이고, 환류종도 감응자도 같은 땅의 맥박에 반응한다. 다음 큰 ‘열린 해’가 다가오고 있다. 그때 세 나라의 모든 먼 딸이 물들고, 마지막 집결지의 무리가 한꺼번에 떠나려 한다 |
| 왜 몰랐나 | 큰 맥박은 수십 년에 한 번. 가문은 집결지 안의 신호만 쟀다 |
| 마지막 선택 | 그해를 대비해 무리를 내보낼 길을 연다 / 막는다 |
| 추가 규칙 | 큼(감응의 대상과 열린 해의 원인을 다시 정의) |
| 약점 | 감응 설정을 크게 바꾸고, 다가오는 자연재해라는 익숙한 구조에 기댐 |

### 진실 5. 마지막 집결지가 막고 있는 것 (마지막 집결지가 세계에서 차지하는 역할)

| 항목 | 설계(후보) |
|---|---|
| 가문조차 몰랐던 사실 | 가문이 ‘늘 열린 해’를 만들려고 모아 끌어 쓰는 땅속의 뜨거운 물은, 산맥 너머 을의 옛 갈이터들로 가던 물이었다. 마지막 집결지를 쉬게 하면 몇 해 안에 을의 옛 갈이터들이 다시 열린다. 마지막 집결지는 무리를 지키는 곳이 아니라 다른 갈이터들이 깨어나지 못하게 막는 둑이었다 |
| 왜 몰랐나 | 땅속의 연결을 알 길이 없었음. 을의 광천이 마른 것은 전쟁 탓으로 여김 |
| 단서 | 가문이 물길 공사를 늘린 해마다 을의 고원 광천이 약해진 기록 |
| 마지막 선택 | 마지막 집결지를 쉬게 하고 무리를 국경 너머 을의 되살아날 갈이터로 보낸다 / 그대로 둔다 |
| 대가 | 무리가 다른 나라의 것이 됨, 국경을 넘는 위험한 이동 / 다른 갈이터들이 영영 잠듦 |
| 추가 규칙 | 하나(땅속 물의 연결) |
| 약점 | 강하지만 ‘손의 역사’ 없이 지질에만 기댐. 진실 1과 결합하면 강해지나 자동 결합은 피함 |

## 3. 추천 진실이 주인공의 선택에 미치는 영향 (인물 미정)

| 질문 | 답(진실 1 기준) |
|---|---|
| 처음 원했던 것 | 한 개체 또는 가까운 사람을 지키는 것, 혹은 사라진 여자들의 진실을 아는 것 |
| 그 목표가 변하는 이유 | 진실을 알리는 것만으로는 아무도 살아나지 않는다. 갈이터에는 손이 필요하다 |
| 가문의 비밀을 폭로하면 | 봉인이 깨지고, 갈이터 손질의 책임이 누구에게도 없게 됨. 무리는 처리 법과 시장에 노출 |
| 환류종을 해방하면 | 늘 열린 해가 끝나면 갈이 중이던 개체가 죽음. 바깥 갈이터는 손이 없으면 열리지 않음 |
| 지워진 감응자들의 진실을 공개하면 | 교단 중앙과 국가가 전쟁의 뿌리를 마주함. 그러나 같은 손기술을 맡을 여자들이 다시 ‘마녀’로 몰릴 위험 |
| 다른 나라와 종교가 개입하는 이유 | 갈이터는 여러 나라에 있었다. 을은 자기 땅의 갈이터를 되살릴 권리를, 교단은 박해의 책임을 둘러싸고 움직임 |
| 주인공이 포기하는 것 | 진실을 혼자 쥐고 끝내는 것. 자기 삶의 계획. 가문이나 국가에 맡기는 쉬운 길 |
| 주인공이 책임지는 것 | 손기술을 내놓아 여러 사람에게 나누는 일, 그 사람들이 다시 박해받지 않게 하는 일 |
| 다른 인물에게 미치는 영향 | 가문 관리인(자기 손이 무엇이었는지 알게 됨), 고원 교구, 을의 마을들, 가문 안의 딸들 |
| 결말 이후의 세계 | (후보) 괴물은 ‘멸종한 적’이 없었고, 사람도 그들을 돌보던 시절이 있었다는 것을 알게 된 세계. 쉬운 공존이 아니라, 손을 나눠 맡는 불편한 약속 |

- 주인공의 특별한 혈통이 해결의 열쇠가 아니다: 갈이터의 손질은 누구나 배울 수 있다. 감응은 ‘열린 해’의 때를 알리는 도움일 뿐이며, 가문 밖의 수많은 모르는 딸들과 감응하지 못하는 사람들의 손이 함께 필요하다.
