## 1. 작가가 승인할 핵심 사항 (다섯)

| 순위 | 결정 | 추천 | 근거 |
|---|---|---|---|
| 1 | 감응자 식별 기전 | **‘울림앓이’:** 큰 박동 가까이에서 아이는 낮에 앓고(철앓이) 밤에 박동 쪽으로 걷는다(밤걸음). 사춘기 무렵 걸음이 멎고 어른은 두통과 방향감만. 환류종이 없으면 증상 없음. 생물은 감응자를 부르지 않는다(사람 몸의 방향 반사) | [sensing-identification-v2.md](sensing-identification-v2.md) |
| 2 | 아르바넬 비정상 생태의 축 | **‘쉬지 못한 집결지’:** 수십 년 비어 쉬어야 할 땅이 두 세기 가까이 쉬지 못해 쌓인 변화. 현상 여섯 중 채택 범위를 고름. 탈출 욕구의 근거는 맞춘 뒤의 ‘흩어짐의 충동’ | [arbanel-ecology.md](arbanel-ecology.md) |
| 3 | 억류 구조 | **‘겹친 관리’:** 둑·수문, 빈 땅·불 띠, 안쪽 먹이, 되몰이, 실패 개체의 사살과 기록 조작. 새 감응 기술 불필요. 안 3(지형 공명 유지)은 위상 기술 경계라 쓰려면 따로 승인, 안 4(어린 개체 볼모)는 작가 판단 | [containment.md](containment.md) |
| 4 | 첫 만남 골격 | **결합안:** 산 너머 발파(외부) → 주기의 해의 큰 탈출(관리 실패) → 쏘지 못한 실무자가 빼낸 개체가 상자로 주인공에게(내부 갈등). 대안: 홍수의 해(작고 조용한 시작) | [first-encounter.md](first-encounter.md) |
| 5 | 세계 정치의 축 | **‘비워진 땅’:** 무리의 땅(완충지) 분할 조약이 ‘괴물 위협의 소멸’을 국경 확정 조건으로 둠 → 국가도 선언이 필요했음. 괴물 처리 규정은 아직 살아 있음(공개 = 사살 의무). 열 세력으로 시작 | [world-powers.md](world-powers.md), [silence-and-hunt-v2.md](silence-and-hunt-v2.md) |

- 함께 확인할 것: 이름 표기 ‘아르바넬’을 공식 명칭으로 쓸지(P결정-004부터 대기)
- 뒤로 미룬 것: 연표, 이점 체계, 위상 기술, 종의 수와 주기, 인물

## 2. 인과적 모순과 해결 방안

| 모순 | 해결 방안(후보) | 상태 |
|---|---|---|
| 공존 시대에 무리가 늘 가까이 있었다면 감응자 아이는 늘 앓았어야 함 | 증상은 **집결형 종의 큰 무리**에만, 그것도 이동 철과 집결 때만 세게 나온다. 홀로 지내는 개체·비집결형 종의 박동은 약함 | 해결 후보 |
| 밤걸음이 ‘생물이 사람을 부른다’로 읽히면 원격 조종 금지와 충돌 | 생물은 아무것도 하지 않는다. 사람 몸의 방향 반사가 잠결에 번진 것. 원고에서 생물의 무관심을 함께 보여 줌 | 해결 후보(표현 주의) |
| ‘정상 집결 기능을 되찾을 가능성’과 ‘두 세기의 억류’ | 집결지 자체(지형과 물)는 살아 있고, 막힌 것은 흩어짐이다. 흩어질 땅과 휴식이 주어지면 되돌아갈 수 있음. 다만 박자가 섞인 세대의 문제(현상 6)가 남음 | 부분 해결 |
| 두 세기 동안 하류에 단서(숨 쉬는 강, 꽃씨, 흔들림)가 있었는데 왜 몰랐나 | 측정 기술 부재, 빈 땅 관리로 사람이 적음, 민간 해석, 단서가 여러 세력에 흩어짐. 새 측정 기술이 균형을 깸 | 해결 후보 |
| 탈출 개체를 사살해 온 실무자가 ‘보호’를 믿을 수 있나 | ‘나가면 한 개체 때문에 무리 전체가 노출된다’는 논리. 그 논리가 무너지는 순간이 첫 만남 추천안의 사건 | 해결 후보 |
| 가문이 ‘순결한 피’를 내세우면서 아이를 봉인 구역 가장자리에 재워 검사 | 검사를 ‘선조의 땅을 지키는 밤’ 의례로 포장. 걸어 나간 아이는 ‘시련을 받은 아이’로 칭송, 안 걸은 직계는 숨김 | 해결 후보 |
| 분할 조약이 선언을 요구했다면 국가가 공범 → 가문의 책임이 흐려짐 | 국가는 ‘서두름’을 묵인했을 뿐 아르바넬을 몰랐다. 숨긴 것은 가문, 확인하지 않은 것은 국가. 책임이 나뉨 | 해결 후보 |
| 억류 비용이 크다(둑·불 띠·먹이·인력) | 봉인 구역 관리 명목의 국가 예산 + 가문의 사재 + 운송 상가의 계약. 예산 삭감 논쟁이 흔들림의 계기 | 해결 후보 |
| 사춘기 이후 걸음이 멎는다면 대토벌 시대 어른 감응자는 무엇으로 찾았나 | 어른에게 남는 두통과 ‘저절로 깨어 한쪽을 보는’ 방향감을 깨어 있을 때 쓰는 훈련(탐지·해석). 아이만큼 강하지 않아 거리가 짧음 | 해결 후보 |
| 이점 체계 보류 상태에서 가문 독점의 실질 | 연구·식별·관리권·의례 권위·예산. 약초 정원은 후보. 큰 경제적 이익은 보류 상태 그대로 | 남음(보류) |
| 받는 기관의 생리 | 평형 기관 가설을 넓힐지 버릴지 | 남음(미결정) |

## 3. 서사적 재미 검증 (지시서 §11)

| 질문 | 판단 |
|---|---|
| 1. 가문 밖 세력만으로 흥미로운 갈등이 있나 | **있다.** 산 너머 철도, 복원 공원과 토지 수용, 출처 불명의 뼈, 둘레 마을의 땅 반환 청원, 옛 명부 정정 요구([world-powers.md](world-powers.md) §3) |
| 2. 첫 개체의 등장이 강력한 사건을 일으키나 | **그렇다.** 결합안에서 한 번의 탈출이 가문·연합국 회사·본국 정부·지방 신문을 동시에 움직이고, 주인공은 장부 한 장 때문에 물러설 수 없게 됨 |
| 3. 아르바넬은 가 보고 싶으면서 두려운 곳인가 | **그렇다.** 숨 쉬는 샘, 꽃과 서리의 경계, 빛나는 웅덩이, 무늬 그리는 모래. 동시에 무너지는 안개, 우는 땅, 병든 무리, 사살 매장지 |
| 4. 환류종은 인간의 목적과 무관하게 행동하나 | **그렇다.** 흩어짐의 충동, 주기의 해, 서식지 다툼, 박자가 섞임. 감응자를 부르지도 돕지도 않음 |
| 5. 은폐가 보호와 착취를 동시에 뜻하나 | **그렇다.** 아르바넬이 없었으면 모두 사라졌다. 그러나 그 보호는 감금과 사살과 독점이다 |
| 6. 첫 번째 침묵의 진실이 역사 이해를 뒤집나 | **그렇다.** ‘미쳐 돌아온 괴물’은 집으로 가던 무리였고, ‘괴물을 부른 아이들’은 같은 소리를 들은 아이들이었다 |
| 7. 새 설정이 인물의 선택을 바꾸나 | **바꾼다.** 실무자는 쏘지 못하고, 주인공은 신고하지 않고, 둘레 마을 사람은 일자리와 아이 사이에서, 감응자 공동체는 숨을지 나설지 고른다 |
| 8. 생존지를 해방하는 행동에도 위험이 있나 | **있다.** 괴물 처리 규정, 시장, 두 나라의 경쟁, 대중의 공포, 갑자기 열면 굶고 죽는 무리, 박자가 섞여 바깥과 맞추지 못하는 세대 |
| 9. 다른 국가와 가문이 예상 밖의 결과를 만드나 | **만든다.** 연합국이 조약 재협상에 쓰고, 복원 산업이 번식 사업을 제안하고, 옛 무가가 가문 몰락을 노리는 사이 무리는 누구의 계산과도 다르게 움직임 |
| 10. 대사 없이 줄거리만 읽어도 재미있나 | **골격은 그렇다.** ‘떠나려는 무리, 붙잡는 사람들, 그 틈으로 나온 한 개체, 그 개체를 받아 버린 평범한 사람, 조각을 쥔 열 세력’. 다만 주인공의 개인적 욕망이 아직 없다 — 인물 설계의 과제 |

## 4. 통합·삭제 후보 (쓸 이유가 약한 것)

| 요소 | 판단 |
|---|---|
| 현상 3(층층 안개)과 현상 2(겨울과 봄이 붙은 골) | 같은 원인(열의 들고남). 원고에서는 하나의 장면으로 합칠 수 있음 → **통합 후보** |
| 현상 5(박자 빛) | 실무자가 쇠약을 재는 지표로 쓰면 살고, 아니면 장식 → **조건부 유지** |
| 감응 면허 제도 | 멸종 뒤엔 쓸 데가 없음 → **삭제 후보**(감시소 근무 자격으로 축소) |
| 세력 7(기록원)과 세력 6(자유 학회) | 논쟁 짝으로 쓰면 살고, 아니면 하나로 → **조건부 유지** |
| 안 라(떠도는 개체를 첫 개체로) | 두 번째 개체 후보로 이동 |
| 연합국이 국경 산맥 쪽 측량에서 흔들림을 기록 | 자유 학회의 측정 기술과 겹침 → **둘 중 하나로 통합 후보** |

## 5. 다른 설계에 넘길 사항

| 받을 설계 | 넘길 것 |
|---|---|
| 생태 | 집결형 종의 수·주기·수명, 기관의 열·물 작용, 흩어짐의 충동, 박자가 섞이는 정도, 종별로 약한 억류의 겹 |
| 역사 | 밤 길잡이의 시기와 끝낸 동기, 분할 조약의 조항, 흰 골 참사, 연표 |
| 인물 | 주인공의 나이·자리·욕망, 상자를 보낸 실무자와 받을 사람의 관계, 둘레 마을 사람, 감응자 공동체의 인물, 각 세력의 얼굴 |
| 줄거리 | 첫 만남안의 최종 선택, 두 번째 개체(떠도는 개체), 해방의 조건 |
