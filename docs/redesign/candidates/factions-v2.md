## 1. 세력표

| 세력 | 자산 | 정보(안다 / 모른다) | 권한 | 목표 | 하지 못하는 일 |
|---|---|---|---|---|---|
| **가문(전체)** | 영지와 소작 수입, 문서고, 감응 훈련 체계, 생존 개체군, 재료 공급 수입, 후원과 연줄 | 층마다 다름([house-world.md](house-world.md) §2) | 영지의 지주 권한, 구성원의 몫·혼인 결정 | 존속과 지위. 그 방법은 입장마다 다름 | 왕실·판정 기구 조종, 물길·기후 통제, 무리의 쇠약 되돌리기, 원격 탐지, 이탈자의 입 막기 |
| 골지기 집안(가문 소작, 대대로) | 생존지의 일상 지식, 손 | 무리가 살아 있다 / 덮개 이야기를 믿음 | 골짜기 안의 일상 관리 | 무리와 자기 집안의 안녕 | 가문의 결정을 바꾸지 못함 |
| 소작인과 영지 주민 | 좋은 땅의 수확 | 땅이 유난히 좋다 / 이유는 모름 | 없음 | 생계 | 비밀을 알지 못함 |
| 왕실과 국가 | 법, 세금, 판정의 권위, 대체 시설 | 공식 연대기 / 생존지와 가문의 역할 | 법과 공권력 | 질서와 권위 유지 | 산속 사유지의 사정을 알지 못함. 선언을 뒤집으면 권위가 흔들림 |
| 판정 기구(과거)와 그 뒤를 이은 학계 | 조사 기록, 명성 | 공개 지역의 조사 결과 / 가문이 고른 증거라는 것 | 판정과 정정 | 학문의 정확성 | 사유지를 마음대로 조사하지 못함. 감응을 증거로 받지 않음 |
| 복원 산업(협회·시설·사설 연구소·투자자) | 시설, 예산, 공모 제도 | 재료의 겉 출처 / 실제 출처 | 복원 단계의 인정, 공모 | 복원 성과와 수익 | 재료를 스스로 만들지 못함. 출처를 끝까지 따지지 않음(관행·이해관계) |
| 재료를 받는 몇몇 시설 담당자 | 거래 관계 | 가문이 공급자라는 것 / 재료가 살아 있는 무리에서 왔다는 것 | 재료 반입 | 자기 시설의 성과 | 공급을 대신할 곳이 없음 |
| 독립 연구자(W의 에드반 자리, P에서 다시 정함) | 정밀한 측정, 명성 | 재료의 이상 / 출처 | 없음 | 미정(비밀-14) | 조직이 없음 |
| 위쪽 물길 사업의 주체(현재 위협) | 공사, 투자 | 물길 계획 / 골짜기의 존재 | 공사 허가 | 개발 이익 | 가문의 비밀을 모름. 그러나 골짜기의 물을 바꿀 수 있음 |
| 밀렵·불법 거래(둘지 미정) | 사냥 기술, 시장 | 소문 / 위치 | 없음 | 이익 | 가문 땅에 들어가지 못함 |

## 2. 가문 안의 입장 (요약, 세부는 house-world §1-4)

| 입장 | 이익 | 비용 |
|---|---|---|
| 지키는 쪽 | 무리의 존속, 가문의 사명 | 통제의 강화, 딸들의 자유 |
| 부를 지키는 쪽 | 땅과 수입, 소작인의 생계 | 무리를 자원으로 다루는 일 |
| 쓰려는 쪽 | 복원 산업 안의 지위, 더 큰 수입 | 무리의 소모, 발각 위험 |
| 끝내려는 쪽 | 비밀과 통제의 끝 | 가문 경제와 소작인의 생계, 역사적 책임의 노출 |

## 3. 협력·적대·배신이 일어날 조건

| 관계 | 지금 | 배신 조건 |
|---|---|---|
| 가문 ↔ 골지기 집안 | 대대로의 신뢰와 공범 의식 | 무리를 소모하는 결정(재료·도태)을 골지기가 견디지 못할 때 / 덮개 이야기가 거짓임을 알게 될 때 |
| 가문 ↔ 재료를 받는 시설 | 조용한 거래 | 공모의 압박으로 더 많은 재료를 요구할 때 / 분석으로 출처가 드러날 때 |
| 가문 ↔ 복원 산업 전체 | 후원자이자 공급자 | 재료 위조가 드러나 신뢰 위기가 올 때 산업이 가문을 버림 |
| 가문 안 지키는 쪽 ↔ 쓰려는 쪽 | 계승 다툼의 축 | 무리가 쇠약해져 ‘지금 쓸지, 끝까지 지킬지’를 정해야 할 때 |
| 가문 ↔ 왕실·학계 | 서로 모름(가문만 앎) | 선언을 다시 조사할 계기(조사원 일지, 골짜기 밖 개체)가 생길 때 |
| 가문 ↔ 물길 사업 | 서로의 계획을 모름 | 공사가 골짜기의 물을 바꿔 가문이 막으려 나설 때(비밀을 드러내야 막을 수 있음) |

## 4. 결정해야 할 것

1. 밀렵·불법 거래 세력을 둘지
2. 독립 연구자의 목적과 위치(비밀-14)
3. 물길 사업의 주체를 누구로 할지(국가 / 이웃 지방 / 복원 산업)
