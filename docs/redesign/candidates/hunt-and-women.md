# 감응자 여성을 이용한 국제 대토벌, 그리고 정치·종교 `[P 후보]` `[작가 전용]`

> 상태: **P 설계 후보 · 미승인 · 정본 아님.** 작성 2026-10-31(8단계).
> 승인된 방향([P결정-009·010](../p-canon/decisions.md)): 시기별 대토벌(자국 정찰 → 연합 정찰 → 정보 제공과 거래), 가문의 실제 공로, 다른 집결지 정보 제공, 감응자 후손의 이용과 폐기·기록 말살, ‘마녀’ 구전, **감응자 여성은 존중받지 못하고 이용·동원·통제당함**, 왕권과 종교의 병존.
> 원칙: 다른 나라와 교단이 모두 가문의 비밀에 협조한 것으로 만들지 않는다. 가문의 공로는 실제였지만 감응자 여성들의 착취 위에 섰을 수 있다. 나라는 임시로 갑(가문의 나라)·을·병이라 부른다(수와 이름은 보류).

## 0. 결론 먼저

- **가문의 ‘비법’은 산 미끼였다.** 감응자 소녀와 여자를 덮인 수레에 태워 데려가, 숨은 무리 가까운 물가나 젖은 땅에 밤새 재우거나 앉혔다. 그 되울림에 새끼를 찾는 어른들이 숨은 곳에서 나왔고, 기다리던 군이 쳤다. 정찰보다 훨씬 효과가 컸다.
- **이용 가치는 커졌고 처우는 나빠졌다.** 쓸모가 클수록 더 많이, 더 어린 아이가, 더 위험한 자리에 놓였다. 기록에서 여자들은 사람이 아니라 ‘장비’나 ‘수레의 짐’으로 적혔다. 공은 ‘가문의 유인술’이라는 이름으로 가문에 돌아갔다.
- **나라마다 달랐다.** 갑에서는 가문이 직접, 을에서는 을 군이 ‘가문의 관리인’을 빌려, 병에서는 교단과 군이 함께. 을의 장교 일부와 고원 교구는 반대했다.
- **공식 역사에서 사라진 이유:** 괴물이 아이를 찾아왔다는 사실은 ‘괴물이 사람을 덮쳤다’는 명분을 무너뜨렸다. 미끼의 기술은 가문의 독점이었다. 교단 중앙은 ‘정화’에 소녀들의 희생이 들어간 것을 지우고 싶었다. 나라들은 영웅담이 필요했다.
- **전쟁 뒤:** 약한 미끼는 버려지거나 가둬졌고, 아는 것이 많은 여자는 사라졌다. **가장 센 여자들은 ‘죽었다’고 기록된 뒤 마지막 생존지로 옮겨졌다**([last-site-v4.md](last-site-v4.md)). 폐기와 말살과 감금이 한 체계였다.

## 1. 시기별 역할과 여성 동원

| 시기 | 가문의 역할 | 여성들에게 일어난 일 |
|---|---|---|
| 첫 번째 침묵 뒤 | 갑의 군에 ‘그 피의 딸을 데려가면 무리가 스스로 온다’고 제안 | 미끼 사냥을 하던 집안의 딸들과 길목 마을의 소녀들이 먼저 끌려감 |
| 초기(자국 정찰) | 갑의 군관구에서 정찰과 미끼 매복 | 덮인 수레, 밤의 물가, 깊은 잠. 깔리거나 얼어 죽은 아이들 |
| 중기(연합 정찰) | 교단이 묶은 연합에서 ‘유인 부대’를 맡음 | 갑의 소녀들만으로 모자라 을·병의 ‘그 피’ 소녀들을 찾음. 익숙해진 무리가 덜 오자 새 아이가 더 필요해짐 |
| 후기(정보와 거래) | 각국에 겨울 터의 위치와 혹한기, 미끼의 방법을 알려 줌(사람은 넘기지 않음) | 각국이 스스로 소녀들을 찾게 됨 → 가문의 손 밖에서 박해가 넓어짐 |
| 말기 | 마지막 원정 | 가장 센 여자들을 앞세움 |

## 2. 보강 질문

| 질문 | 답(후보) |
|---|---|
| 감응자 여성을 직접 데리고 이동했나 | 그렇다. 덮인 수레, 높은 침상(이동 중 되울림을 막으려고), 밤에만 땅에 내림 |
| 환류종이 따라온 군사적 효과 | 숨은 무리를 찾을 필요가 줄어듦. 새끼를 찾는 어른을 하나씩 불러내 죽임 → 무리의 어른이 줄고 새끼가 홀로 남음 → 겨울 터의 무리가 무너짐 |
| 국가별 동원과 통제 | 갑: 가문의 보호령(임시)으로 여자들을 ‘보호 대상’으로 묶음. 을: 을 군이 징집, 가문은 ‘관리인’을 빌려 줌. 병: 교단 수용소와 군이 함께 |
| 외국에서 가문 권한의 한계 | 을·병에서는 가문이 사람을 직접 처분할 권한이 없었음. 을의 장교 일부는 소녀들을 돌려보내거나 숨겼음 |
| 공로를 가문 것으로 바꾼 방법 | 보고서의 ‘가문의 유인술’, 여자들을 장비로 적은 장부, 훈장은 가문 장교에게 |
| 국가와 교단이 실제로 안 것 | 갑의 왕실: 미끼 부대의 존재와 효과, 비용. 을의 군: 방법과 피해(일부 장교는 반대 기록을 남김). 교단 중앙: 알고 ‘정화의 희생’으로 축복. 고원 교구: 알고 반대, 소녀들을 숨김. 병의 상인들: 기관 시장만 앎 |
| 끌어들이는 현상이 공식 역사에서 사라진 이유 | §0 |
| 다른 나라 감응자의 반발 | 을의 감응 여성들과 장교 일부. 전쟁 뒤 을에서 가문의 처분이 막힌 이유 |
| 기술이 국경을 넘어 퍼지지 않은 이유 | 미끼는 쓰기 쉬웠지만 무리가 사라졌다. 쓸 대상이 없어진 기술은 잊혔고, 쓴 나라들은 그것을 자랑하지 않았다 |
| 후대 ‘마녀’ 전설의 지역 차이 | 갑: 괴물을 부르는 여자(공포). 을: 끌려간 딸들(슬픔과 원한). 병: 수용소의 미친 여자. 고원: 돌침상의 아이들(애틋함) |

## 3. 전쟁 뒤의 처리 (국가별)

| 나라 | 처리 | 남은 흔적 |
|---|---|---|
| 갑 | 약한 미끼는 집으로 돌려보내거나 버림(후유증, 낙인). 아는 것이 많은 여자는 사라짐. **가장 센 여자들은 ‘전쟁 중 사망’으로 기록된 뒤 마지막 생존지로** | 고쳐진 사망 기록, 돌아온 여자들의 가족 이야기 |
| 을 | 가문의 손이 닿지 않음. 을 군이 해산. 일부는 가문에 넘겨졌고 일부는 숨음 | 을 군의 장부(여자들의 이름), 반대한 장교의 기록 |
| 병 | 교단 수용소 | 수용소 명부 |

## 4. 정치·종교와 감응자 여성의 지위

| 영역 | 설계(후보) |
|---|---|
| 법적 지위 | 갑: 가문이 받은 ‘보호령’(임시) — 그 피의 여자를 보호한다는 명목의 이동 제한과 후견. 을·병: 일반 백성이지만 등록부에 표시 |
| 국가의 징집·이동 제한·보호 제도 | 대토벌 때 갑의 징집, 전쟁 뒤 보호령이 남음(봉인 구역 관리권과 함께 가문이 쥠) |
| 종교의 정화·구호·등록 | 등록부의 표시, 혼인 특면, 중앙의 정화 설교, 고원 교구의 피난처, 수용소 |
| 귀족 가문의 혼인과 혈통 관리 | 가문은 그 피의 여자들을 혼인과 후견으로 묶음 |
| 국제 대토벌 협정 | 사람이 아니라 정보와 방법을 넘기는 협정(후기) |
| 영웅 가문과 다른 가문의 경쟁 | 갑의 무가(유인술에 공을 빼앗김), 을의 귀족(딸들을 잃은 집안) |
| 강한 감응자 여성의 거주를 둘러싼 이해 | 갑의 왕실은 보호령과 봉인을 함께 연장해 줌(이유: 위험의 관리라는 설명, 가문의 정치적 충성, 다시 미끼 부대가 필요할지 모른다는 계산) |
| 봉인과 관리권, 멸종 선언 | 봉인 구역은 보호령의 땅과 겹침. 멸종 선언에서 면제 |
| 현대 | 산업과 학계는 대부분 모름. 고원 교구와 을의 집안들이 조각을 기억함 |

- **모두가 협조한 것이 아니다:** 을의 장교들과 고원 교구는 반대했고, 병의 상인들은 몰랐고, 갑의 왕실은 일부만 알았다.

## 5. 작가가 고를 것

1. 대토벌에서 감응자 여성을 ‘산 미끼’로 쓴 구조를 둘지
2. 전쟁 뒤 처리를 ‘약한 이는 버림, 아는 이는 사라짐, 가장 센 이는 죽었다고 기록한 뒤 마지막 생존지로’로 둘지
