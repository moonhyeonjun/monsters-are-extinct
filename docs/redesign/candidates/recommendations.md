## 1. 다섯 권고안

### 권고안 1. 감응 소인은 드물게 가족 안에서 이어질 수 있지만, 가문 밖과 남성에게도 있다

| 항목 | 내용 |
|---|---|
| 기존 자료 대조 | W 정본: D-004(혈통·계승자 표식 아님), D-125 2항과 lia-veln §3(감각의 원인을 혈통·마렌의 과거로 설명하지 않음), Q-감각-02·03(열림). W 제안서: maternal-house-design §3, school-witch-connections |
| 채택 시 P에서 정하는 것 | 감응의 가족성(드묾, 비율 미정), 가문 밖·남성 감응자의 존재, 기전은 정하지 않음, 감지와 해석의 구분, 원격 탐지 불가 |
| W에 미치는 영향 | 없음. W의 D-125 2항은 W에서 그대로 유효하다. P에는 별도 P결정을 둔다 |
| 서사적 효과 | 가문 축이 성립한다. ‘피가 아니었다’(비밀-10)가 중반 이후의 강한 재해석 장치가 된다 |
| 위험과 안전장치 | 주인공이 선택받은 혈통으로 기울 위험 → 가문 밖 감응자를 이야기 안에 실제 인물로 두고, 감응을 해결 열쇠로 쓰지 않는다(AGENTS.md §4-6 유지) |

### 권고안 2. 주인공의 보호자 한 사람(W의 마렌 자리)은 감응자 가문 출신으로, 선별과 통제에 반대해 탈출했다

| 항목 | 내용 |
|---|---|
| 기존 자료 대조 | W: Q-인물-06과 character-design의 안 A·B, maren-opposition-and-departure, maternal-house-design §6. 제안서끼리 출신이 엇갈림(듣는 가문 / 길 닫는 집 근처 / 지키는 고향, conflicts.md §3) |
| 채택 시 P에서 정하는 것 | 이 역할의 존재, 거부한 요구(바깥 자문 계약·정해진 혼인·딸을 가문에 맡기는 약속 후보), 아는 범위(훈련·선별·호칭은 알고, 고용 기록과 말살의 전모는 모름) |
| W에 미치는 영향 | 없음 |
| 서사적 효과 | 가문 축을 주인공의 집으로 가져온다. 출발의 인과(보호자의 반대와 허락)가 강해진다 |
| 위험과 안전장치 | 보호자가 모든 비밀의 설명자가 될 위험 → 아는 범위를 좁게 둔다. **이 역할을 누가 맡을지는 인물 재창조에서 정한다**(W의 마렌을 유지할 의무 없음) |

### 권고안 3. 이르바넬 은폐 조직과 모계 가문은 별개이며, 제한적인 훈련권 거래를 유지해 왔다

| 항목 | 내용 |
|---|---|
| 기존 자료 대조 | W: D-047(장기 은폐), history-secret §4(길을 지운 세 부류), irvanel-concealment-and-last-harvest(혈통형이 아닌 조직), maternal-house-design §3-4(훈련권), witch-name-and-record-erasure §3-5(짐승 없는 공백기, 훈련권과 엇갈림) |
| 채택 시 P에서 정하는 것 | 두 세력의 분리, 〈닫힌 골의 겨울〉 같은 성립 사건, 서로의 비밀 일부 공유, 현재 거래 수단으로서의 훈련권([history.md](history.md) §2-8, [factions.md](factions.md)) |
| W에 미치는 영향 | 없음 |
| 서사적 효과 | 가문 축과 이르바넬 축이 한 고리로 만난다. 〈마지막 채취〉에서 가문이 거래 상대로 들어설 자리가 생긴다 |
| 위험과 안전장치 | 안에서 아는 사람이 늘어 은폐가 약해짐 → 가문은 길과 핵심 샘을 모르게 둔다. 한 조직이 모든 것을 조종하지 않게 한다 |

### 권고안 4. 생태·복원 축과 마녀·역사·가문 축은 공동 주축이지만, 서로를 단일 원인으로 환원하지 않는다

| 항목 | 내용 |
|---|---|
| 기존 자료 대조 | W: D-087(결말 방향, 산의 침묵은 단일 음모가 아님), D-088(최종부 세 단계와 불변 조건), creative-principles. 2026-10-30 재집필 검토는 ‘부플롯’을 권했으나 작가 제안은 공동 주축 |
| 채택 시 P에서 정하는 것 | 두 축의 비중, 만나는 지점(훈련권 거래, 기록의 말살과 정정, 주인공의 선택), 각 축의 독립된 원인 |
| W에 미치는 영향 | 없음 |
| 서사적 효과 | 이야기의 판돈이 생태와 개인 양쪽에서 오른다. ‘생물을 붙잡지 않는다’와 ‘가문에 붙잡히지 않는다’가 짝을 이룬다 |
| 위험과 안전장치 | 가족극이 생태 이야기를 덮을 위험 → 첫 번째 침묵과 피난처의 원인은 자연에 두고, 가문은 그 원인이 아니라 그 위에서 선택한 사람들로 둔다. 권별로 두 축의 장면 비중을 점검한다(7단계) |

### 권고안 5. 주인공을 포함한 모든 인물을 다시 설계할 수 있다

| 항목 | 내용 |
|---|---|

| 채택 시 P에서 정하는 것 | 주인공도 판정 대상(유지 / 핵심 매력만 보존 / 통합 / 삭제 / 대체)에 넣는다 |
| W에 미치는 영향 | 없음 |
| 서사적 효과 | 새 세계관에 가장 맞는 주인공을 고를 수 있다(예: 가문과의 거리, 감응의 강도, 나이) |
