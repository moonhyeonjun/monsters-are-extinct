## 1. 열 질문

| 질문 | 답(후보) |
|---|---|
| 1. 감응자가 차별받던 시대에 국가와 종교는 무엇을 했나 | 국가(아직 느슨한 영지들)는 거의 관여하지 않았다. 차별은 마을의 관습이었다. 교단은 두 얼굴이었다: 깊은 잠에 든 아이를 산 채로 묻지 않도록 **사흘 밤샘**을 정해 아이들을 살렸고, 동시에 ‘물결 든 아이’를 **등록부**에 적어 낙인을 대물림하게 했다. 부유한 집은 철 피난으로 등록을 피했다 |
| 2. 대토벌에서 누가 실제 이익을 얻었나 | 중심 왕국(왕권의 통합), 교단(국경을 넘는 권위와 정화 헌금), 수로 가문(공사와 운하), 영웅 가문(작위와 관리권). 무공 가문은 초기 공만 남기고 밀려남. 손해는 고원 자치령, 샘 영주 가문, 길목 마을, 평민 감응자 |
| 3. 영웅 가문이 권력을 얻자 다른 가문은 | 무공 가문: 원한, 그러나 같은 기념식에 섬. 수로 가문: 동업과 혼인. 철 피난 가문: 혼인과 ‘서로의 아이를 묻지 않는다’는 약속. 샘 영주 가문: 몰락 중이라 관심 밖. 학교 가문: 후원을 주고받음 |
| 4. 집결지 파괴가 주변 환경과 경제를 어떻게 바꿨나 | 집결 때마다 솟던 샘과 데워지던 골이 멎어 고원과 상류 습지가 마름 → 농업 쇠퇴, 이웃 왕국과의 물길 다툼, 샘 영주 가문의 몰락. 길목 목축이 사라지고 운하·철도·개간이 들어섬 |
| 5. 멸종 선언이 신앙과 법을 어떻게 바꿨나 | 교단: ‘끝맺음’ 의례로 정화의 시대를 닫음 → 정화파의 승리이자, 개혁파가 ‘그다음’을 묻기 시작한 계기. 법: 토벌세 폐지, 끝맺음의 날 제정. **괴물 처리 규정은 폐지되지 않음**(아무도 필요를 못 느낌). 사흘 밤샘은 이유를 잃은 관습으로 남음 |
| 6. 가문의 비밀 연구가 외부 산업에 준 영향 | 쉼터 시설(제염소·요양소·치유 성소 후원)로 소금·온천 시장에 들어와 있음. 수로 기술은 수로 가문의 운하로 이어짐. 연구 결과 자체는 바깥에 나가지 않음. 바깥의 복원 산업은 가문이 지운 쉼터를 모르는 채로 되살림 |
| 7. 생존지의 이상 현상이 바깥에 어떻게 알려졌나 | ‘숨샘’(지하 수로가 다른 골짜기로 낸 숨 쉬는 물)은 신기한 자연 샘으로, 흰 안개 덮개는 둘레 마을의 별칭으로, 우는 땅은 옛말 이름(‘울재’ 후보)으로, 성소의 밤 짐승은 교단 안의 기적·저주 논쟁으로. **조각은 알려졌지만 서로 이어지지 않았다** |
| 8. 교단이 선언의 진실을 알게 되면 | 정화파: 교리와 끝맺음 의례를 지키려 은폐하거나 ‘마지막 정화’를 요구. 개혁파: 보호를 주장하며 교단 안의 주도권을 노림. 애도파: 속죄할 대상이 살아 있다는 혼란과 희망. 재정: 영웅 가문의 후원과 치유 성소의 수입이 걸림 |
| 9. 생존 사실이 드러날 때 각 세력이 원하는 것 | 왕실: 세금 정당성과 위신 지키기(은폐 또는 국유화). 교단: 교리와 재정. 귀족: 무공 가문은 영웅 가문의 몰락, 샘 영주 가문은 몰락의 진실과 물, 철 피난 가문은 자기 혈통의 침묵. 산업: 복원 회사는 전시·번식, 수로 가문은 수로 책임의 회피. 처리 사무소: 규정대로 처리. 고원 자치령: 신앙과 자치의 지렛대 |
| 10. 한 가문이 무너져도 세계가 움직이나 | 움직인다. 소금과 철도, 온천 전쟁, 교육권, 고원의 자치, 처리 사무소 폐지 논쟁은 영웅 가문 없이도 계속된다([polity.md](polity.md) §6) |

## 2. 누가 무엇을 아는가 (하나의 음모가 아님)

| 조각 | 가진 쪽 | 그 뜻을 아나 |
|---|---|---|
| 억류 장치의 전체 | 영웅 가문 핵심 | 안다 |
| 지하 수로가 물을 딴 골로 보낸다는 것 | 수로 가문 | 이유를 모른다 |
| 쉼터 시설의 ‘밤 짐승’ 보고 | 성소 사제, 요양소 주인, 제염소 감독 | 모른다 |
| 귀족에도 감응자가 있다는 것 | 철 피난 가문 | 안다(자기 집의 일로만) |
| 대토벌 초기 아이 징발의 실상 | 무공 가문의 기록 | 안다(부끄러운 일로 숨김) |
| 사라진 집결지들의 위치와 최후, ‘물결 집 길잡이’ 증언 | 애도파의 숨은 연대기 | 일부. 생존은 모름 |
| ‘물결 집’ 등록부 | 교단 교구 | 옛 기록으로만 |
| 숨샘의 박자 | 숨샘 골짜기 사람들, 자유시 학회의 측정 | 모른다 |
| 선언 당시의 서두름 | 왕실 기록소, 교단 문서고 | 일부 관료와 성직자가 의심했지만 묵인 |

## 3. 4단계 설계가 함께 푸는 것

- **식별(물결 피·깊은 잠) → 종교(사흘 밤샘, 등록부) → 대토벌(아이 징발, 깊은 잠 지도로 집결지 발견) → 가문(선조의 밤 선별 의례) → 주인공(오해되는 작은 감각, 숨겨진 어린 시절의 잠 후보).**
- **억류(물길과 쉼터) → 종교(치유 성소가 쉼터) → 산업(제염소·온천·복원) → 첫 만남(제염소 폐업이 쉼터를 엶) → 해방의 순서(물길을 먼저 풀면 재난, 쉼터를 먼저 되살리면 단계적 해방).**
- **정치(토벌세, 교단의 끝맺음) → 선언의 필요가 여러 세력에 흩어짐 → 전능한 한 가문의 조작이 아님.**

1. 이웃 왕국과 고원 자치령의 구체적 역사(언제 어떻게 복속·연합했나)
2. 교단의 중심이 어느 나라에 있나
3. 무공 가문과 처리 사무소의 관계가 얼마나 공식적인가
4. 연표 전체(‘약 200년’은 여전히 가설)
