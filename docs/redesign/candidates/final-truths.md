> 작가 요구([P결정-007](../p-canon/decisions.md) B): 가문이 마지막 집결지를 사유화했다는 진실(두 번째 층)이 최종 반전의 전부가 아니다. 가문조차 알지 못했던 더 근본적인 진실이 있어야 하고, 그것이 주인공의 마지막 선택을 결정적으로 바꿔야 한다.

## 0. 결론 먼저

| 층 | 독자가 알게 되는 것 |
|---|---|
| 첫 번째 층(공식) | 괴물은 멸종했다. 영웅 가문이 마지막 원정으로 끝냈다 |
| 두 번째 층(가문의 비밀) | 가문은 마지막 집결지를 숨기고 사유화했다. 보호이자 억류이자 독점이었다 |
| **세 번째 층(가문도 모른 것)** | 아래 네 후보 가운데 하나 |

- **추천: 진실 B ‘바깥의 무리’.** 가문은 바깥은 죽음이라 믿고, 바깥에서 발견되는 개체를 모두 ‘탈출 개체’로 여겨 거두거나 죽여 왔다. 그러나 대토벌 뒤 떠돌던 개체들의 후손이 소수지만 살아남아, 사람이 지은 돌 구조물(돌다리의 아치, 성당 지하의 궁륭, 수로 터널, 옛 요새의 우물)이 박자를 모아 울린다는 것을 써서 **사람의 땅 한가운데에서 작게 맞추고 번식해 왔다.** 가문이 지킨다고 믿은 ‘마지막 번식 집단’은 마지막이 아니었고, 가문이 처리해 온 ‘탈출 개체’ 가운데 일부는 이 바깥 무리였다.
  - 보조 근거로 진실 A의 일부(마지막 집결지의 박자가 두 세기 동안 틀어졌다)를 쓰면, 두 무리를 합치는 것이 왜 위험한지가 생긴다. 그래서 ‘모두를 하나로 구한다’는 해결이 마지막에 불가능해진다.
- 진실 B를 고르면 첫 개체는 **안쪽에서 탈출한 개체가 아니라 바깥 무리의 개체**일 수 있다. 독자는 내내 탈출 개체라고 믿게 된다.

## 1. 네 후보

### 진실 A. 맞춰진 박자가 틀려 있었다 (보존이 변형이었다)

| 항목 | 설계(후보) |
|---|---|
| 독자가 처음 믿는 사실 | 마지막 집결지는 사유화되었지만, 그래도 종을 그대로 지켜 온 방주다 |
| 가문이 아는 사실 | 집결지의 박자 속에서 새끼가 태어나 맞추고 번식한다. 쇠약은 늙음과 밀집 탓 |
| 가문이 잘못 이해한 핵심 | 집결지의 큰 박자를 종의 **기준 박자**로 믿었다 |
| 실제 진실 | 쉬지 않는 울림과 광물 쌓는 종의 돌 빗살이 두 세기 동안 지형의 공명을 천천히 바꿔, 기준 박자 자체가 틀어졌다. 그 안에서 태어난 세대의 생체 시계는 틀어진 박자에 굳었다. 열 운반 종이 먼저 쇠약해진 진짜 이유도 이것이다. 집결지는 종을 지킨 것이 아니라 **다른 무엇으로 바꾸고 있었다** |
| 발견하지 못한 원인 | 비교할 바깥 표본이 없었다. 가문 감응자는 집결지 박자로만 훈련받아 그 박자가 ‘정상’이었다. 변화가 세대에 걸쳐 느렸다. 옛 기록은 박자의 결은 적었지만 빠르기는 재지 않았다 |
| 잘못 해석된 과거 증거 | 대토벌 때 군이 아이의 물결을 세던 ‘세는 노래’가 지금 아이들의 놀이 노래로 남았는데 빠르기가 다르다. 열 운반 종의 쇠약을 ‘늙어서’로 읽음. 옛 감응자 기록의 ‘박자 사이 숨 셋’이 지금은 ‘숨 둘’ |
| 주인공이 발견할 단서 | 놀이 노래와 지금 박자의 차이. 가장 늙은 우두머리(볼모)의 박자만 다른 개체와 어긋남 |
| 공개되는 사건 | 가장 늙은 우두머리가 죽기 전, 새 흔들림 기록 장치가 그 박자와 나머지 무리의 박자를 함께 기록함 |
| 마지막 선택 | ① 집결지를 쉬게 한다(무리를 안쪽 고향에서 내보내 지형이 수십 년 쉬며 원래 공명으로 돌아가기를 기다림) ② 지금 형태를 새 종으로 받아들이고 영원히 관리한다 ③ 사람이 돌 빗살을 깎아 공명을 되돌린다 |
| 대가 | ① 맞출 곳을 잃은 많은 개체가 죽고 번식이 끊길 수 있음 ② 억류의 영구화 ③ 더 깊은 통제, 실패하면 집결지 자체를 잃음 |
| 가장 강하게 충돌하는 욕망 | 보호를 믿는 실무자(자기 손으로 바꿔 왔다), 통제로 해결하려는 가문 연구자 |
| 추가·수정량 | 작음. 현 규칙(생체 시계, 지형의 공명) 그대로 |
| 독창성·공정성 | 중간~높음 / 단서가 숫자와 노래라 공정 |

### 진실 B. 바깥의 무리 (추천)

| 항목 | 설계(후보) |
|---|---|
| 독자가 처음 믿는 사실 | 바깥에서 나타나는 개체는 모두 마지막 집결지에서 빠져나온 탈출 개체다. 바깥은 죽음이다 |
| 가문이 아는 사실 | 탈출 개체를 추적해 거두거나 처리해 왔다 |
| 가문이 잘못 이해한 핵심 | 바깥의 개체가 모두 집결지 출신이라고 믿었다 |
| 실제 진실 | 대토벌 뒤 떠돌던 개체들의 후손이 소수지만 살아남았다. 진동을 모으는 바위 분지 대신, 사람이 지은 돌 구조물이 박자를 모아 울린다는 것을 써서 사람의 땅 안에서 작게 맞추고 번식해 왔다. 흩어진 작은 집결의 그물. 가문이 처리해 온 ‘탈출 개체’ 가운데 일부는 이 무리였다 |
| 발견하지 못한 원인 | ‘바깥은 죽음’이 억류의 근거였으므로 의심할 이유가 없었다. 가문 감응자는 집결지 박자로만 훈련받아 바깥 개체의 다른 박자를 ‘병든 박자’로 읽었다. 처리 장부에 적힌 바깥 개체 수가 안쪽에서 사라진 수보다 많았지만 ‘세기 착오’로 넘겼다. 구조물은 사람 사이에 있어 가문이 들여다보지 않는 곳이었다 |
| 잘못 해석된 과거 증거 | 장부의 불일치. 교단 기록 속 특정 다리 마을에서 수십 년 간격으로 아이들이 쓰러진 일(‘다리 병’). 성당 궁륭의 밤 울음(‘유령’). 처리 사무소에 신고된 출처 불명 사체를 가문이 조용히 거둬 감 |
| 주인공이 발견할 단서 | 첫 개체가 마지막 집결지 쪽으로 끌리지 않음(안쪽 고향의 각인이 없음). 그 개체가 해마다 같은 다리나 궁륭으로 감. 주인공이 느끼는 ‘두 번째 박동’의 결이 다름. 옛 기록의 주기 |
| 공개되는 사건 | 바깥 무리의 맞춤 철에, 철도 다리의 철거와 성당의 보수와 수로 터널의 개축이 겹쳐 바깥 무리의 맞춤 자리가 사라지려 함. 같은 때 가문이 그 개체들을 ‘탈출 개체’로 거두러 옴 |
| 마지막 선택 | ① 바깥 무리를 드러내 법으로 보호받게 싸운다 ② 비밀로 두고 사람 세상의 일로 구조물을 지킨다(철거를 막는 정치) ③ 마지막 집결지의 어린 개체를 바깥 구조물에 각인시켜 두 무리를 잇는다 ④ 바깥 무리를 마지막 집결지로 데려간다(가문의 답) |
| 대가 | ① 처리 규정·정화파·시장·공포에 노출. 지킬 법과 기관이 없음 ② 마지막 집결지의 쇠약은 그대로, 가문의 사냥을 막을 힘이 없음 ③ 틀어진 박자를 가진 안쪽 개체가 바깥 무리의 박자를 흐트러뜨릴 수 있음(진실 A를 보조로 쓸 때), 사람 땅에 개체가 늘어남 ④ 마지막 남은 자유로운 무리를 가두는 것 |
| 가장 강하게 충돌하는 욕망 | 가문(유일한 수호자라는 정체성, 자기들이 죽여 온 것), 수로 가문과 국가(철도·다리·터널), 교단(성당 궁륭, 정화파), 처리 사무소 |
| 추가·수정량 | 중간. ‘사람이 지은 돌 구조물도 박자를 모아 울릴 수 있다’는 규칙 하나 |
| 독창성·공정성 | 높음 / 목격담, 장부, 아이들의 쓰러짐, 첫 개체의 행동이 모두 단서 |

### 진실 C. 물의 빚

| 항목 | 설계(후보) |
|---|---|
| 독자가 처음 믿는 사실 | 마지막 집결지를 열면 생물도 살고 정의도 선다 |
| 가문이 아는 사실 | 쉬지 못한 집결지의 물과 열의 변화는 분지 안의 일 |
| 가문이 잘못 이해한 핵심 | 그 변화가 분지 안에 갇혀 있다고 믿었다 |
| 실제 진실 | 얽힌 박자로 불어난 물 운반 종이 두 세기 동안 끌어올린 물이 단층을 따라 산 너머로 스며, 큰 평야의 샘과 우물, 교단의 큰 치유 성소의 온천, 왕실 영지의 관개를 키웠다. 그 지역의 번영은 억류의 산물이다. 집결지를 쉬게 하면 몇 해 안에 그 샘들이 마른다 |
| 발견하지 못한 원인 | 산 너머 다른 골이고, 수십 년에 걸친 느린 변화였다. 교단은 축복으로 봤다. 가문은 바깥을 재지 않았다 |
| 잘못 해석된 과거 증거 | 성소의 샘 수위 기록이 봉인 뒤부터 오름. ‘축복받은 물’ 교리. 샘물이 하루 몇 번 미세하게 오르내림 |
| 주인공이 발견할 단서 | 샘의 오르내림과 집결지 박자의 일치. 오래된 우물 기록 |
| 공개되는 사건 | 큰 가뭄의 해, 물 운반 종이 크게 줄자 평야의 샘이 함께 약해짐 |
| 마지막 선택 | ① 해방(평야의 물이 마름) ② 억류 유지(생물의 쇠약과 감금) ③ 단계적 해방과 사람 쪽 물길 공사(막대한 비용, 국가·교단의 협조 필요) |
| 대가 | ① 이주와 굶주림 ② 감금의 지속 ③ 시간과 권력이 필요하고 그사이 무리가 버티지 못할 수 있음 |
| 가장 강하게 충돌하는 욕망 | 교단(성소 수입), 왕실(영지), 평야 주민 |
| 추가·수정량 | 작음~중간(지하수 연결) |
| 독창성·공정성 | 중간(물에 기대는 딜레마는 흔함) / 공정 높음 |

### 진실 D. 감응은 피가 아니라 어린 시절의 노출이었다

| 항목 | 설계(후보) |
|---|---|
| 독자가 처음 믿는 사실 | 감응은 대물림되는 소인이고, 영웅 가문에 짙다 |
| 가문이 아는 사실 | 피로 이어진다. 바깥 감응자는 엷은 피. 입양으로 보충한다 |
| 가문이 잘못 이해한 핵심 | 피 |
| 실제 진실 | 약한 소인은 흔하다. 감응이 자라는 것은 일곱 살 무렵까지 살아 있는 박동에 거듭 노출될 때다(발달 창). 가문의 아이가 감응자인 것은 집결지 곁에서 자라기 때문이고, 수도에서 자란 직계가 비감응자인 것도 같은 이유다. 가문 밖 감응자가 사라진 것은 피가 엷어져서가 아니라 박동이 사라져서다 |
| 발견하지 못한 원인 | 가문 아이는 늘 집결지 곁에서 자람(원인이 겹침). 비감응 직계를 ‘엷은 피’로 설명. 입양한 감응자는 이미 노출된 둘레 마을 아이. 피의 믿음이 가문의 정체성 |
| 잘못 해석된 과거 증거 | 수도에서 자란 직계의 비감응. 혈연이 없는 둘레 마을 아이들의 감응. 교단 등록부에서 무리 길목 마을의 서로 다른 집 아이들이 같은 세대에 몰려 물결이 든 일. 이주해 온 집 아이가 길목에서 자라 물결이 든 일 |
| 주인공이 발견할 단서 | 주인공의 집안에 감응 내력이 없다. 그러나 어릴 때 어떤 개체 가까이에서 자랐다 |
| 공개되는 사건 | 같은 피를 가진 형제가 다른 곳에서 자라 하나는 감응자, 하나는 아님 |
| 마지막 선택 | ① 해방(개체가 퍼진 땅의 아이들이 다시 감응자가 되고, 물결과 깊은 잠의 위험과 옛 낙인이 돌아옴. 독점은 끝남) ② 억류 유지(아이들은 안전, 독점 지속) ③ 해방하되 사람과 개체의 거리를 법으로 정함(교단의 옛 ‘공존의 계율’을 되살리는 큰 사회 변화) |
| 대가 | ① 아이들의 위험, 정화파의 ‘병든 피’ 교리 부활 ② 생물의 감금 ③ 사람 사회의 큰 비용과 저항 |
| 가장 강하게 충돌하는 욕망 | 가문의 정체성, 교단의 등록·혼인 교리, 아이를 가진 부모들 |
| 추가·수정량 | 중간. 감응 소인 모델을 D로 바꿔야 함([sensing-incidence.md](sensing-incidence.md)) |
| 독창성·공정성 | 높음 / 등록부와 가계의 단서가 공정. 다만 생태보다 사회의 반전 |

## 2. 비교

| 기준 | A 박자가 틀려 있었다 | **B 바깥의 무리** | C 물의 빚 | D 노출이 감응을 만든다 |
|---|---|---|---|---|
| 기존 생태에서 나오나 | 예 | 예(규칙 하나 추가) | 예 | 감응 모델 교체 |
| 앞선 사건을 다시 읽게 하나 | 중간(쇠약, 노래) | **높음**(모든 바깥 목격, 첫 개체, 처리 장부) | 중간(샘) | 높음(가계, 등록부) |
| 알아도 저절로 풀리지 않나 | 예 | 예 | 예 | 예 |
| 양립할 수 없는 대안 | 셋 | **넷** | 셋 | 셋 |
| 혈통이 열쇠가 아닌가 | 예 | 예 | 예 | **오히려 혈통을 부숨** |
| 국가·가문·종교와 충돌 | 가문 | **셋 모두**(철도·다리, 성당, 가문의 정체성과 사냥) | 교단·왕실 | 가문·교단 |
| ‘가문이 더 나빴다’를 넘나 | 예(선의의 보존이 변형) | 예(지킨다고 믿은 것이 마지막이 아니었고, 지키려다 다른 무리를 죽여 옴) | 예(정의로운 해방이 사람을 굶김) | 예(피의 신화 자체가 오해) |
| 독창성 | 중간~높음 | **높음** | 중간 | 높음 |

- **결합에 대해:** B를 중심으로 A의 일부를 보조로 쓰는 것을 권한다(두 무리의 박자가 갈라져 ‘합치기’가 위험해짐). C와 D는 각각 단독으로도 서는 후보이므로, 하나의 결말에 둘 이상을 겹치면 반전의 힘이 흩어진다.

## 3. 주인공의 마지막 선택 구조 (인물 미정)

| 질문 | 답(진실 B 기준, 다른 후보는 §1의 선택 칸) |
|---|---|
| 처음에 무엇을 구하려 했나 | 한 개체, 또는 그 개체 때문에 곤경에 빠진 가까운 사람 |
| 후반에 그 목표만으로 부족한 이유 | 한 개체를 구하는 것은 그 개체가 속한 무리를 구하는 것이 아니다. 그 개체는 가문이 말한 ‘탈출 개체’가 아니었다 |
| 은폐를 폭로하면 생기는 피해 | 처리 규정의 사살 의무, 시장, 공포, 교단의 분열, 실무자들의 처벌. 보호할 장치가 없음 |
| 환류종을 해방하면 생기는 문제 | 안쪽 무리의 고향은 안쪽(각인)이라 나가지 않거나, 볼모가 풀린 종은 고향 없이 쏟아짐. 얽힌 박자는 순서에 따라 무너짐 |
| 생존지를 유지하면 희생하는 것 | 쇠약과 감금, 그리고 바깥 무리에 대한 가문의 사냥이 계속됨 |
| 마지막에 불가능하다고 알게 되는 해결 | 두 무리를 합쳐 하나의 건강한 종으로 되살리는 것(박자가 갈라져 있음) |
| 다른 인물에게 선택권을 돌려줄 수 있나 | 있다. 바깥 무리의 맞춤 자리(다리, 궁륭, 터널)는 각각 다른 사람들의 것이다. 철거를 막을지, 숨길지, 공개할지를 그 장소의 사람들과 나눠 정하는 구조가 가능 |
| 주인공이 직접 치르는 대가 | 처음 구한 그 개체를 바깥 무리에 돌려보내고 다시 만나지 못함, 법적 책임, 관계의 손상, 자기 감응을 드러내는 것 |
| 선택을 가능하게 하는 것 | 운명적 능력이 아니라 그동안 쌓은 관계(실무자, 장소의 사람들), 지식(장부, 노래, 기록), 자기 실수의 책임 |

## 4. 첫 만남에 요구되는 조건 (최종 진실별)

| 진실 | 독자가 첫 만남에서 오해할 것 | 기억해야 할 작은 행동 | 개체가 주인공의 생활권에 나타난 이유 |
|---|---|---|---|
| A | 개체가 늙거나 아파서 박자가 이상하다 | 개체가 어떤 노래나 일정한 소리에 멈칫함 | 가장 늙은 우두머리 무리에서 놓친 개체 |
| **B** | 마지막 집결지에서 도망친 개체다 | 개체가 마지막 집결지 쪽이 아니라 **사람이 지은 돌 구조물 쪽**으로 거듭 향함 | 바깥 무리의 맞춤 자리(다리·궁륭·터널)가 주인공의 생활권에 있음 |
| C | 물이 이상해진 것이 개체 때문이다 | 개체가 샘의 오르내림에 맞춰 물을 마심 | 평야의 샘을 따라 내려온 개체 |
| D | 주인공의 감응은 숨은 혈통의 증거다 | 주인공과 같은 피의 다른 사람이 반응하지 않음 | 주인공이 어릴 때 자란 곳 가까이 |

- 상세 사건은 주인공의 개인적 욕망과 관계망을 설계한 뒤 고른다([first-encounter-v2.md](first-encounter-v2.md)의 안들은 거절된 억류안에 기대므로 그대로 쓸 수 없다).
