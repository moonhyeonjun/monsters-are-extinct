# 여성 중심 감응 유전과 네 가지 값 `[P 후보]` `[작가 전용]`

> 상태: **P 설계 후보 · 미승인 · 정본 아님. 유전 방식은 확정하지 않는다.** 작성 2026-10-31(8단계).
> 유지할 조건([P결정-009·010](../p-canon/decisions.md)): 한 조상의 변이, 후손에게 전해짐, 여성에게 감응 반응이 드러나는 방향, 직계에 강한 반응이 몰리는 경향과 먼 후손도 반응할 수 있음, 아동기에 강하고 자라며 줄어듦.
> 채택하지 않은 것: 모델 D′(모계 전달 + 여성 발현).
> 끌림 전제(후보): [attraction.md](attraction.md) — 끌림은 감응의 세기가 아니라 몸이 얼마나 깊게 끌려가는가(증상)에 따른다.
> 현실 과학에서 빌린 것: 성별에 따라 드러나는 형질(성 제한 발현), X 염색체 우성이면서 남성 태아에게 치명적인 실제 질환이 거의 여성에게서만 보이는 것, 부모 가운데 한쪽에게서 받은 유전자만 켜지는 현상(유전체 각인), 같은 변이를 가져도 다른 유전자들이 세기를 바꾸는 것(조절 유전자), 멀미 민감도의 상당 부분이 유전된다는 것.

## 0. 결론 먼저

- **네 모델을 비교했다. 작가의 바람(‘여자아이에게만’)에 가장 가까운 것은 모델 2(X 염색체 우성 + 남성 태아 치명)이고, 가장 유연한 것은 모델 1(상염색체 + 여성 한정 발현 + 조절 유전자)이다.** 어느 쪽도 확정하지 않는다.
- **이야기에서 더 중요한 것은 네 값의 분리다:** 유전적 소인 / 감응 강도(듣는 감각) / 증상(몸이 끌려가는 정도) / 끌어들이는 정도. 가문은 눈에 보이는 증상으로 여자들을 골랐다. 그래서 **가문의 혈통 관리는 끌어들이는 힘은 키웠지만 듣는 힘은 키우지 못했다.** 몇 세대 뒤 가문에는 괴물을 잘 부르는 여자는 많고 잘 듣는 여자는 드물다(가문이 예상하지 못한 결과).
- **직계가 강한 경향:** 본가는 대대로 그 피의 집안끼리 혼인하고 증상이 센 딸을 남겼다. 그래서 세기를 키우는 조절 유전자가 본가에 몰렸다. 먼 후손은 그 조절 유전자가 흩어져 대체로 약하다. 그러나 우연히 모인 먼 후손도 있다(경향이지 법칙이 아님).

## 1. 네 모델 비교

| 질문 | 모델 1. 상염색체 + 여성 한정 발현 + 조절 유전자 | **모델 2. X 염색체 우성 + 남성 태아 치명** | 모델 3. 어머니 쪽만 켜지는 유전(유전체 각인) + 여성 발현 | 모델 4. 여러 유전자의 문턱 |
|---|---|---|---|---|
| 요지 | 남녀 모두 가질 수 있음. 드러나는 것은 딸뿐. 세기는 여러 조절 유전자 | 변이를 가진 남자 태아는 살지 못함 → 사실상 딸만. 어머니가 딸의 절반에게 | 아버지에게서 받은 것은 꺼져 있고 어머니에게서 받은 것만 켜짐. 딸에게서만 드러남 | 주 변이 + 여러 유전자가 쌓여 문턱을 넘을 때 드러남 |
| 남성이 가질 수 있나 | 있다(드러나지 않음) | 없다(태어나지 못함) | 있다(꺼진 채) | 있다 |
| 아버지가 딸에게 | 넘김 | 못 넘김 | 넘기지만 딸에게서 꺼진 채. 그 딸의 자녀에게서 다시 켜짐 | 넘김 |
| 어머니가 아들에게 | 넘김(드러나지 않음) | 그 아들은 태어나지 못함 | 넘김(켜지지만 남자라 드러나지 않음) | 넘김 |
| 감응하지 않는 여성이 감응하는 딸을 | 아버지가 보유자면 가능 | 드묾 | 아버지에게서 받은 딸(꺼짐)이 낳은 딸에게서 가능 | 가능 |
| 자매 사이의 차이 | 조절 유전자의 조합 | 다른 X의 차이 | 받은 쪽 | 조합 |
| 가문 밖에서 유지되는 이유 | 남녀 모두를 타고 넓게 퍼짐 | 딸의 줄로 | 남자를 거쳐 숨었다가 다시 나타남 | 넓게 |
| 여러 세대 사라지지 않는 이유 | 해롭지 않음 | 딸의 줄이 있는 한 | 숨은 보유자 | 넓게 퍼짐 |
| 남성 후손의 위치 | 보유자로서 혼인이 관리됨 | 아들이 적은 집. 가문의 남자는 그 피가 아님 | 숨은 보유자로서 혼인이 관리됨 | 보유자 |
| ‘여자아이에게만’과의 거리 | 중간 | **가장 가까움** | 가까움 | 멂 |
| 직계가 강한 경향 | **쉽게 설명됨**(조절 유전자의 집중) | 다른 X의 차이로 약하게 설명됨 | 중간 | 쉽게 설명됨 |
| 한 조상의 기원 | 맞음 | 맞음 | 맞음 | 약해짐 |
| 현실 유전학 | 현실에 있는 방식 | 현실 질환과 같은 방식 | 현실에 있는 현상이나 설명이 복잡 | 현실 |
| 이야기의 그늘 | 혼인 관리 | **아들을 잃는 집.** 강제 출산 제도에서 남자 태아의 상실이 겹쳐 매우 어두움 | 복잡해 독자가 따라가기 어려움 | 혈통 이야기가 흐려짐 |

- 모델 2를 고르면: 가문의 남자들은 그 피를 넘기지 못한다. 가문의 정치적 계승(남자)과 능력의 계승(여자)이 처음부터 갈라진다.
- 모델 1을 고르면: 가문의 남자들도 숨은 보유자로서 혼인 관리의 대상이 된다. 강제 출산 제도에서 ‘누구의 아이를 낳게 하는가’가 가문 정책이 된다.

## 2. 강한 감응과 혈통 관리의 실제 효과

| 질문 | 답(후보) |
|---|---|
| 감응 강도는 유전되나 | 일부. 소인과 조절 유전자는 유전되지만, 실제로 드러나는 세기는 나이·노출·몸 상태에 크게 흔들림 |
| 가문의 선별은 정확했나 | 아니다. 눈에 보이는 증상(물결, 멈춤, 깊은 잠)으로 골랐다. 증상은 끌어들이는 힘과 맞물리지만 듣는 감각과는 따로 움직임 |
| 강제 출산과 혈통 관리가 목표에 도움이 되었나 | 끌어들이는 딸은 늘었지만 듣는 딸은 늘지 않았다. 그리고 증상이 센 딸일수록 아이 때 위험이 큼 → 잃는 아이도 늘었다. **가문이 믿은 효과와 실제 효과가 다르다** |
| 혈통 관리가 실패할 가능성 | 있다. 모델 2라면 아버지는 아무것도 보태지 못하므로 ‘순결한 아버지’ 고르기는 헛수고. 모델 1이라면 보탤 수 있지만 조절 유전자의 조합은 운에 크게 좌우됨 |
| 아동기 발현과 성인기 완화 | 평형 감각이 자율신경을 흔드는 반사를 뇌가 누르는 힘이 자라 줄어듦. 받는 감각은 남음 |
