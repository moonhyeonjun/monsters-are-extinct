## 2. 의존 관계

- **01(기관 규칙)이 무너지면 03·05·07·08·11이 함께 흔들린다.** 01을 먼저 승인받아야 한다.
- **02(소인 모델)와 11(최종 진실)은 서로를 바꾼다.** 11에서 D를 고르면 02의 실제 규칙이 모델 D가 되고, 가문의 믿음이 모델 A가 된다.
- **08(억류)과 11-B는 맞물린다.** ‘안쪽 고향’ 각인이 있어야 첫 개체가 집결지 쪽으로 끌리지 않는 것이 단서가 된다.
- **07(얽힌 박자)과 11-A는 맞물린다.** 광물 쌓는 종의 돌 빗살이 공명을 바꾼다는 것이 A의 원인이다.
- 12(첫 개체)는 11과 인물 설계를 기다린다.

## 3. 후보끼리의 충돌 (숨기지 않음)

| 충돌 | 내용 | 처리 제안 |
|---|---|---|
| 11-B와 09의 ‘마지막 원정’ | 바깥에 무리가 있었다면 마지막 원정이 친 ‘다른 집결지의 마지막 무리’ 말고도 떠돌던 개체가 있었음 → 원정의 ‘마지막’은 이중으로 거짓 | 충돌이 아니라 강화. 다만 원정 당시 떠돌이 개체를 어떻게 보고했는지 정해야 함 |
| 11-C와 08 | 물의 빚은 물 운반 종의 과밀에 기대는데, 안쪽 고향 억류가 그 과밀을 만든 원인과 맞물려야 함 | 맞물림 가능. 그러나 C를 고르면 해방의 주된 대가가 생물이 아닌 사람 쪽으로 감 |
| 11-D와 02 | 모델 C(추천)와 모델 D는 동시에 참일 수 없음 | D를 고르면 02를 D로 교체 |
| 11-A와 11-B를 함께 쓸 때 | 바깥 무리의 박자가 ‘원래 기준’에 가깝다고 할지, 바깥도 다르게 변했다고 할지 | 작가 결정 필요 |
| 03의 깊은 잠 기간 | 4단계 ‘하루~사흘’과 5단계 ‘데리고 나오면 몇 시간’ | 5단계로 고침(사흘 밤샘의 기원은 길목 마을이 신호 속에 있었기 때문으로 유지) |

## 4. 미결정 (작가도 모름)

- 집결형 종의 수, 주기, 수명, 박동의 실제 간격
- 감응 소인의 빈도와 유전 방식
- 진동을 모으는 지형과 구조물의 정확한 조건(11-B를 고를 때 중요)
- 흰 골 참사의 의도 여부, 선언의 서두름을 묵인한 사람
- 연표(‘약 200년’ 가설)

## 5. 폐기 (거절된 후보, 다시 쓰지 않음)

- 눈 떨림 식별, 증거 경로 조작 + 죽은 개체 제출, 영지 위 골짜기·일곱 층·덮개 이야기
- 억류 ‘겹친 관리’, ‘떠나는 길을 지운다’
- 첫 만남 결합안(발파 → 실무자 → 상자)
- 정치 축 ‘비워진 땅’과 분할 조약
