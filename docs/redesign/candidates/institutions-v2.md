# 복원 협회와 아카데미 — 승인 구조의 세부 보강 `[P 후보]` `[작가 전용]`

> 상태: **P 설계 후보 · 미승인 세부 · 정본 아님. 이름과 세부 조직은 확정하지 않는다.** 작성 2026-10-31(10단계).
> 승인된 방향([P결정-012](../p-canon/decisions.md)): 협회는 대토벌 뒤 실제 복원 성과를 낸 기관. 아카데미는 여러 나라의 평화 협약에서 출발한 교육기관. 가문은 두 기관에 서로 다른 방식으로 영향력을 행사.
> 이전 후보: [restoration-society.md](restoration-society.md), [academy.md](academy.md)(방향 채택). 나라는 임시로 갑·을·병.
> 원칙: 협회는 현장 문제를 풀려 하고, 학원 연구자는 사실을 밝히려 하고, 가문은 필요한 사실만 내놓으려 한다. 그러나 구성원의 입장을 이 셋으로만 고정하지 않는다.

## 1. 복원 협회

| 항목 | 설계(후보) |
|---|---|
| 설립 시기와 법적 지위 | 공식 멸종 선언 뒤 몇 해 안. 갑의 왕실 칙허를 받은 공익 법인(왕실·교단·상인 조합의 공동 이사회). 을·병에는 각국 법에 따른 협력 지부 |
| 국가별 사업과 감독 | 갑: 불탄 비탈의 숲, 물길, 독 묻은 땅, 이주 마을(왕실 감사). 을: 고원의 습지와 목초지(을 정부 감독, 가문과 냉담). 병: 평야의 수로(상인 조합 감독) |
| 성과 | 산사태와 홍수의 감소, 다시 일군 밭, 이주 마을의 정착 |
| 실패 | 한 가지 나무만 심은 숲의 병, 목초지를 잃은 목동들, 이주 마을의 땅 분쟁. **그리고 이주 마을 상당수가 옛 무리의 길목과 분지에 세워짐**(다음 무리 짓기의 길) |
| 예산·인사·계약 | 세금·헌금·조합 부담금·가문 기부. 이사회의 한 자리는 가문. 봉인 구역 관리 계약과 남은 위험 신고 창구는 가문이 추천한 사람이 맡음 |
| 시료와 신고의 처리 | 현장 직원이 이상한 뼈·흔적·짐승을 신고 → 지역 사무소 → ‘남은 위험 신고 창구’ → 그 가운데 환류종과 관련된 것은 ‘특수 신고’로 봉인 구역 관리 쪽에 넘어감(직원들은 위험물 처리로 앎) |
| 내부 비밀 접근 | 현장 직원: 모름. 창구 담당: 규정만. 계약 담당과 이사 하나: 앎 |
| 가문과 독립적인 구성원의 목표 | 산림 감독(숲의 성공), 수리 기술자(물길), 이주 담당(마을의 안정), 을 지부 조사원(고원의 회복과 갑에 대한 의심) |
| 다른 나라 지부와의 갈등 | 을 지부는 특수 신고를 넘기지 않으려 함. 병 지부는 예산 다툼 |

## 2. 아카데미

| 항목 | 설계(후보) |
|---|---|
| 멸종 이후에도 교육·연구가 필요한 이유 | 무너진 땅의 재건(복원학·수리·농학), 병(의학), 광산과 길(공학·지질), 세 나라의 평화(행정·법·외교), 잃어버린 기록(역사·언어). 자연사는 ‘멸종한 생물의 기록’으로 남음 |
| 학문 분야와 진로 | 복원학(→ 협회), 지질·자연사(→ 협회·광산·학원 연구소), 의학(→ 교단 병원·각국), 공학·수리(→ 각국 공공사업), 행정·법(→ 각국 관청), 역사·언어(→ 문서고·교단·학원) |
| 입학·장학·실습 | 시험과 추천, 귀족 정원, 평민 장학생, 외국 학생 정원. 영웅 장학금. 현장 실습은 협회 현장과 봉인 구역 둘레 연구 분원 |
| 감응자 선별과 이어진 숨은 조사 | 장학 위원회의 지역 우선(옛 ‘그 피’의 땅), 봉인 구역 둘레 실습의 ‘건강 조사’(가까이에서만 반응이 드러날 수 있음) |
| 연구 결과와 문서 접근 통제 | 닫힌 서고(공개 명목: 전쟁 기록 보존), 논문과 출판 심사 위원회 |
| 비밀을 모르는 교수·학생의 독립적 행동 | 자연사관 정리(두 형태의 발견), 지질 조사(되풀이되는 층), 언어 연구(옛 연대기), 을 학생들의 다른 이야기 |
| 협회와의 관계 | 연구 분원 공동 운영, 실습, 졸업생 채용, 협회 기술자의 강의 |
| 운영진과 가문의 이해 충돌 | 학장은 학원의 명성(발표)을 원함, 가문 이사는 덮기를 원함. 을 이사는 가문을 견제 |

## 3. 두 기관 사이의 갈등과 독립적 의사결정

| 사람 | 무엇을 원하고 무엇을 할 수 있나 |
|---|---|
| 협회 산림 감독 | 숲의 성공을 지키고 싶음. 진실을 알면 이주 마을의 안전 때문에 움직일 수 있음 |
| 협회 신고 창구의 젊은 직원 | 규정의 이유를 모름. 넘긴 신고의 행방을 궁금해함 |
| 협회 을 지부 조사원 | 갑을 의심. 특수 신고를 넘기지 않음 |
| 학원 자연사관의 학생 | 두 형태가 같은 생물이라는 것을 처음 봄 |
| 학원 지질학자 | 되풀이되는 층에 학자로서 흥분. 출판 심사에 막힘 |
| 학원 학장 | 학원의 독립. 가문 이사와 충돌 |
| 연구 분원의 교사 | 가문에 진 빚과 연구자의 양심 사이 |

- 입장은 셋(현장·사실·가문)으로 고정되지 않는다: 산림 감독이 사실을 덮으려 할 수도, 가문 이사의 가족이 사실을 밝히려 할 수도 있다.

## 4. 작가가 고를 것

1. 협회의 실패 가운데 ‘이주 마을이 옛 무리의 길목에 세워짐’을 둘지(최종 진실 후보와 이어짐)
2. 학원의 진로와 학문 구조, 숨은 조사의 범위
