# 감응 소인의 발생과 가문의 독점 `[P 후보]` `[작가 전용]`

> 상태: **P 설계 후보 · 미승인 · 정본 아님.** 작성 2026-10-31(5단계).
> 작가 요구([P결정-007](../p-canon/decisions.md) A): 가문 밖에서도 감응자가 생긴다는 설정이 영웅 가문의 능력 활용·독점과 어떻게 양립하는지 다시 설계한다. 근거 없는 혈통 우월성을 사실로 만들지 않는다. 유전 법칙은 확정하지 않는다.
> 생리 전제(후보): [sensing-physiology.md](sensing-physiology.md), [organ-and-gathering.md](organ-and-gathering.md).

---

## 0. 결론 먼저

- **추천: 모델 C ‘복합형’.** 감응 소인은 어느 집에서나 드물게 나타난다. 영웅 가문에 더 짙은 이유는 우월한 피가 아니라 **차별 시대에 강요된 내혼**이다. ‘물결 집’끼리만 혼인할 수 있었던 몇 세대가 소인을 한 가계에 모았다.
- **가문이 독점하는 것은 피가 아니다. 네 가지다.**
  1. **살아 있는 개체에 대한 접근** — 소인을 확인하고 훈련할 수 있는 유일한 곳.
  2. **해석의 전통** — 박자의 결을 읽는 말과 교본. 살아 있는 개체 곁에서만 전해진다.
  3. **법적 자격** — 봉인 구역 관리권에 딸린 ‘청취자’ 지위.
  4. **기록** — 대토벌 징집 명부와 교단 등록부의 사본. 누가 소인을 가졌을 집안인지 안다.
- 그래서 가문 밖에도 감응자는 태어나지만, **자기가 감응자라는 것을 알 길이 없고, 안다 해도 쓸 데와 배울 곳이 없다.**
- 작가 참고: 최종 진실 후보 D([final-truths.md](final-truths.md))를 고르면 이 문서의 실제 규칙은 모델 D(발달 창)로 바뀌고, 가문은 모델 A(혈통)를 믿는 것이 된다.

## 1. 네 모델 비교

| 기준 | 모델 A. 가계 집중형 | 모델 B. 보편적 희소형 | **모델 C. 복합형(추천)** | 모델 D. 발달 창형 |
|---|---|---|---|---|
| 요지 | 여러 가계에 있지만 영웅 가문에 크게 몰림 | 사회 전반에 드물게 고루. 가문은 훈련·접근·법만 독점 | 어디서나 드물게. 특정 가계는 강도와 발현 시기가 다름(내혼으로 짙어짐). 가문이 제도로 이용 | 약한 소인은 흔하고, **어린 시절 박동에 노출되어야** 감응이 자람(절대음감처럼) |
| 차별의 역사 | 몇몇 집안에 낙인 집중 | 낙인이 흩어져 ‘집안’ 단위가 약함 | 무리 길목의 여러 집 + 짙은 몇 가계. 강요된 내혼이 다시 소인을 모음 | 무리 길목 마을 전체에 낙인. 노출이 곧 원인이라 지역 낙인이 강함 |
| 대토벌 기여 | 가문이 주력 | 징집된 평민이 주력, 가문은 지휘 | 짙은 가계(가문)가 강한 수색자를, 평민이 머릿수를 | 길목 마을 출신이 주력 |
| 가문의 권력 획득 | 피의 희소성 | 훈련과 지휘 | 강한 수색자 + 지휘 + 아이 징발을 끝낸 제안 | 노출 환경(가문의 땅이 집결지 곁) |
| 현대의 독점 | 피 | 접근·훈련·법 | **접근·해석·법·기록** | 접근(노출 자체) |
| 혈통 우월성의 위험 | **높음**(피했던 구조) | 낮음 | 낮음. 짙음의 원인이 차별 | 없음 |
| 주인공의 성장 가능성 | 가문 밖이면 약함 | 높음 | **높음.** 주인공은 드문 소인을 가진 평범한 집의 사람일 수 있음 | 높음. 어린 시절의 노출 이력이 이야기의 고리 |
| 약점 | 혈통 판타지로 기울기 쉬움 | 가문이 짙은 이유가 없음 | 설명이 하나 더 필요(내혼) | 멸종 뒤 감응자가 거의 생기지 않음 → 주인공의 노출 이력이 꼭 필요 |

## 2. 추천 모델 C의 답

| 질문 | 답(후보) |
|---|---|
| 누구에게 생기나 | 낮은 진동을 몸으로 받는 감각이 유난히 예민하고, 그 신호가 자율신경으로 강하게 이어진 사람. 남녀와 집안을 가리지 않는다. 뚜렷한 소인은 드물다(빈도는 정하지 않음) |
| 가족 안에서 확률이 높아지나 | 높아진다. 부모가 둘 다 소인을 가진 집에서 더 자주, 더 강하게 |
| 가문 밖에도 독립적으로 생기나 | 생긴다. 소인은 영웅 가문이 만든 것이 아니다 |
| 실제 기술을 쓸 수 있는 비율 | 소인을 가진 사람 가운데 ① 어릴 때 살아 있는 개체 곁에서 자기 감각을 알았고 ② 청소년기에 살아 있는 개체 곁에서 훈련받은 사람만. 셋 중 하나에도 못 미침 |
| 선천과 후천의 차이 | 소인은 **받는 몸**이다. 훈련은 **결을 읽는 말**(쉼·긴장·이동 채비·개체 수·방향)과 **몸을 다잡는 법**(숨 고르기로 남은 물결과 졸음 누르기)이다. 훈련 없는 감응자는 막연한 불편만 느낀다 |
| 가문이 독점하는 것 | 소인 X. 접근·해석·법적 자격·기록(§0) |
| 가문 밖 감응자가 조직을 유지하지 못한 이유 | 무리 길목의 가난한 집들에 흩어져 서로를 몰랐다. 교단 등록부의 낙인 때문에 숨겼다. 대토벌 때 징집되어 가문 지휘의 수색대로 흡수되었다. 전쟁 뒤엔 해산되고 뛰어난 사람은 입양·혼인으로 가문에 들어갔다. 멸종 뒤엔 신호가 없어 다음 세대는 자기 소인조차 모른다. **해석은 살아 있는 개체 곁에서만 전해지므로, 개체를 잃은 순간 전통이 끊겼다** |
| 대토벌 때 다른 감응자의 대우 | 초기: 군이 아이를 징발해 측정기로 씀(많이 죽음). 중기: 가문이 ‘아이 대신 훈련된 어른’을 제안해 평민 감응자를 가문 지휘의 수색대로 받아들임. 생존율은 나아졌지만 공은 가문의 이름으로. 후기: 다른 집결지 수색에 앞세움. 전후: 일부 입양, 나머지는 해산과 침묵 |
| 멸종 뒤 가문은 어떻게 찾고 고르나 | 가문의 아이: 열 살 전후 마지막 집결지 가장자리에서 하룻밤(‘선조의 밤’, 임시). 바깥: 봉인 구역 둘레 마을과 옛 기록의 집안을 조용히 지켜보다, 소인이 보이면 장학·하인 채용·입양으로 데려감. 그 밖의 땅에서는 찾지 못함 |
| 감응 능력이 없는 가문 구성원 | 행정·재산·정치를 쥔다. 가주가 비감응자일 수도 있다(공개하지 않음). 의례에는 감응자 친척을 내세움. ‘순결한 피’ 선전 속에서 가장 힘 있고 가장 감춰진 사람들 |

## 3. 가문이 믿는 것과 실제

| 가문의 믿음 | 실제(모델 C 기준) |
|---|---|
| 우리 피가 짙은 것은 선조의 시련과 순결 때문 | 차별 시대의 강요된 내혼 때문 |
| 바깥의 감응자는 약한 피의 흔적 | 소인은 바깥에도 같은 세기로 생긴다. 다만 확인·훈련받을 곳이 없다 |
| 비감응 직계는 ‘피가 엷어진 것’ | 소인은 집 안에서도 고르지 않게 나온다 |

## 4. 작가가 고를 것

1. 모델 C(복합형, 짙음의 원인은 강요된 내혼)를 둘지
2. 가문 독점을 ‘접근·해석·법적 자격·기록’의 네 겹으로 둘지
3. 최종 진실로 후보 D를 고를 경우 모델 D로 바꿀지
