## 2. 추천 조합의 흐름 (2 + 3, 배경 4)

1. 대토벌 말기, 가문이 이끈 ‘마지막 원정’이 남은 바깥 무리를 쓰러뜨리고 끝을 알린다(안 3의 겉모습). 실제 마지막 날엔 큰 싸움이 없었다. 남은 무리는 이미 집결지로 들어갔기 때문이다.
2. 흰 골의 참사 뒤 봉인 구역이 지정될 때, 가문의 권고로 ‘위험해서 조사단이 들어갈 수 없는 봉인 구역은 관리 기관의 보고로 갈음한다’는 규정이 판정 규칙에 들어간다(안 2의 빈틈). 이 규정 자체는 조사원의 목숨을 지키려는 합리적인 규칙처럼 보였다.
3. 수십 년 뒤 판정 기구는 규정대로 공개 지역 조사와 봉인 구역의 연례 보고를 합쳐 ‘전역에 살아 있는 개체 없음’을 결론짓는다. 왕실은 이를 영웅 가문의 승리와 함께 기념한다.
4. 모두가 끝을 원했다(안 4). 의심한 학자의 의견서는 각주가 되고, 병사의 편지는 집 안에 남는다.

## 3. 조작이 실제로 가능했는가 — 반론과 답

| 반론 | 답 |
|---|---|
| 1. 왜 봉인 구역을 조사에서 빼는 규정이 받아들여졌나 | 흰 골의 참사로 원정대를 잃은 직후였다. 그 땅의 위험은 실제였다. 위험 징후를 읽을 수 있는 것은 감응자뿐이었고, 감응자를 가진 것은 가문뿐이었다 |
| 2. 아무도 봉인 구역에 들어가 보지 않았나 | 정기 감사는 감시소 바깥과 장부만 봤다. 감사관을 안으로 들일 때는 가문이 길과 시기를 정했다(재난 철을 이유로) |
| 3. 감시소 직원은 왜 말하지 않았나 | 직원 대부분은 ‘남은 환류 흔적’을 감시한다고 믿었다. 진실을 아는 사람은 적었다([refuge-secrecy.md](refuge-secrecy.md)) |
| 4. 바깥에서 목격이 전혀 없었나 | 봉인 구역 둘레의 이상한 현상과 목격은 ‘남은 흔적’과 ‘구역의 위험’으로 설명되었다 |
| 5. 판정 이후 수백 년 동안 아무도 다시 묻지 않았나 | 판정이 왕실과 학계의 권위가 되었고, 봉인 구역은 위험한 땅으로 남았으며, 가문은 영웅이었다. 다시 물을 이유와 방법이 없었다 |
| 6. 가문이 기관 전체를 쥔 것은 아닌가 | 아니다. 규정 한 줄, 보고 한 장, 기념 한 번. 그리고 그것을 받아들인 사람들의 바람 |

## 4. 작가가 고를 것

1. 조합: **2 + 3, 배경 4(추천)** / 1 / 다른 조합
2. 면제 규정에 반대한 학자와 그 의견서를 단서로 쓸지
3. ‘마지막 원정’의 실제 날(싸움이 없었던 날)을 비밀로 쓸지
