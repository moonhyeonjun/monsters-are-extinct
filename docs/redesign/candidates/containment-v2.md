# 떠나지 못하는 무리 — 억류 구조 전면 재설계 `[P 후보]` `[작가 전용]`

> 상태: **P 설계 후보 · 미승인 · 정본 아님.** 작성 2026-10-30(4단계).
> 작가 결정([P결정-006](../p-canon/decisions.md)): ‘겹친 관리’(둑·수문·불 띠·먹이·되몰이·사살)는 채택하지 않는다. 처음부터 다시 설계한다. ‘흩어짐의 충동’은 유지한다.
> 전제: 집결을 마친 환류종은 본능에 따라 떠나려 하고, 가문은 의도적으로 그것을 막는다. 억류는 반드시 불완전하며, 탈출과 실패가 실제 역사에 있었다.
> 지키는 선: 위상 맞춤·압력 몰이 같은 미승인 감응 기술은 쓰지 않는다. 감응자는 탐지하고 해석할 뿐이다. 가문이 통제하는 것은 **물과 땅과 사람의 시설**이지 생물의 의지가 아니다.

## 0. 결론 먼저

- **핵심 착상: 벽으로 가두지 않는다. 떠나는 길을 지운다.**
  - 집결형 종은 아무 데로나 흩어지지 않는다. **밖으로 흐르는 물을 따라 내려가고**, 먼 길에서는 **쉼터의 사슬**(따뜻한 샘, 소금 바위, 특정 광물이 있는 물가)을 하나씩 디디며 원래의 땅으로 돌아간다. 길은 길을 아는 늙은 개체에게서 배운다(작업 가정).
- **추천: 안 5 ‘종마다 다른 그물’** — 지금 작동하는 것은 둘이다.
  1. **도는 물길:** 분지에서 밖으로 흐르던 물을 지하 수로로 빼내 다른 골짜기로 보내고, 땅 위에는 분지 안으로 되돌아 흐르는 물길만 남겼다. 물을 따라 나가려는 개체는 분지 안을 돈다.
  2. **끊긴 쉼터 사슬:** 바깥 길의 쉼터들을 대토벌이 부수었고, 남은 곳은 가문이 사들이거나 후원해 온천 요양소·치유 성소·제염소·채석장으로 바꾸었다. 나가도 디딜 곳이 없어 지쳐 돌아오거나 죽는다.
  - 여기에 역사적 원인 하나가 깔려 있다: **길을 아는 늙은 개체들은 대토벌 말기에 출구 근처에서 먼저 죽었다**(안 3). 지금 무리는 충동은 있고 길은 모른다.
- **틈은 늘 있다:** 큰물이 지하 수로를 넘쳐 옛 물길이 잠시 살아나는 해, 쉼터 하나가 바깥 사정으로 다시 열리는 때(제염소 폐업, 온천의 복원), 물과 쉼터에 덜 기대는 작은 종. 탈출은 대개 **가문이 통제하지 않는 바깥 세계의 변화**에서 생긴다.
- **나가려는 행동이 사건을 만든다:** 도는 물길의 둑을 끝없이 깎는 무리, 밤마다 온천 성소에 나타나는 짐승의 그림자, 큰물의 해마다 되풀이되는 출구 쪽 행렬.

## 1. 떠나려는 행동의 생태 (작업 가정)

| 단계 | 개체가 따르는 것 |
|---|---|
| 흩어짐의 충동 | 맞춤과 번식이 끝나면 겹친 박동이 괴로워짐([arbanel-ecology.md](arbanel-ecology.md) §1) |
| 첫 방향 | 분지에서 **밖으로 흐르는 물**을 따라 내려감. 물은 기관의 작용에 필요하고, 물길은 가장 오래된 길이다 |
| 먼 길 | **쉼터의 사슬**을 하루 이틀 거리마다 디딤. 쉼터에서 열·물·광물을 채우지 못하면 몇 번째 쉼터에서 지쳐 돌아서거나 죽음 |
| 길의 기억 | 늙은 개체를 따라간 경험. 길을 아는 개체가 없으면 어린 개체는 물과 쉼터의 단서만으로 더듬음 |
| 종마다 다름 | 크고 멀리 가는 종일수록 쉼터에 기댐. 작은 종은 짧게 움직이며 쉼터 없이도 버팀. 물에 덜 기대는 종은 능선을 따라감 |

## 3. 추천안의 역사 — 실제로 있었던 탈출과 실패 (후보)

| 때 | 일 | 남은 흔적 |
|---|---|---|
| 대토벌 말기 | 출구를 지키던 토벌대가 길잡이 늙은 개체들을 먼저 쏨. 가문이 그 순서를 권함(가문 연구자가 ‘길잡이’를 알아봄) | 원정 기록의 한 줄 |
| 봉인 초기 | ‘홍수 방지와 관개’ 명목으로 지하 수로 공사. 시공은 대토벌 공병 출신 가문([polity.md](polity.md)) | 공사 기록, 다른 골짜기에 갑자기 생긴 샘 |
| 그 뒤 백여 년 | 바깥 쉼터들을 차례로 사들이거나 후원. 몇 곳은 교단 치유 성소, 몇 곳은 가문 소유 제염소와 요양소 | 성소 연대기의 ‘밤 짐승’ 이야기 |
| 큰물의 해들 | 수로가 넘쳐 옛 물길이 며칠 살아남 → 출구 쪽 행렬 → 몇 개체가 빠져나가 하류 마을 피해 | 공식 기록은 ‘큰물 피해’ |
| 어느 제염소의 폐업 | 쉼터 하나가 열려 몇 해 동안 그 길로 새는 개체 → 가문이 땅을 다시 사들임 | 가문 장부, 그 일대의 괴담 |
| 멸종 선언 이후 | 탈출은 줄었지만 끝나지 않음. 탈출 개체는 대개 쉼터에서 지쳐 죽거나 사람 땅에서 ‘이상한 짐승’으로 죽음 | 수장고의 출처 불명 뼈, 지방의 괴담 |

## 4. 나가려는 행동이 만드는 사건

- 도는 물길의 바깥 굽이를 무리가 밤마다 파고들어 둑이 무너진다 → 끝없는 보수, 보수꾼들 사이의 소문.
- 치유 성소의 순례자들이 새벽에 샘가의 흰 짐승을 본다 → 기적인가 저주인가를 두고 교단 안의 논쟁([faith.md](faith.md)).
- 큰물의 해마다 출구 쪽으로 몰려드는 행렬 → 가문 안에서 ‘한 번은 내보내자’는 목소리와 ‘절대 안 된다’는 목소리.
- 바깥의 복원 사업이 옛 온천을 되살리면, 그 사업은 모르는 채로 **억류의 그물을 하나 끊는다** → 가문은 복원 사업을 막아야 하지만 이유를 댈 수 없다.

## 5. 실무자는 무엇을 아나 (두 겹 비밀과의 연결)

| 사람 | 아는 것 | 모르는 것 |
|---|---|---|
| 가문 핵심 | 수로와 쉼터가 억류 장치라는 것, 길잡이를 먼저 죽인 일 | — |
| 안쪽 관리 직원 | 무리가 출구로 몰리는 철, 물길 둑의 보수 | 바깥 쉼터의 뜻 |
| 수로 시공 가문의 감독 | 수로가 물을 ‘엉뚱한 골’로 보낸다는 것 | 왜 그래야 하는지 |
| 쉼터 관리인(성소 사제, 요양소 주인, 제염소 감독) | 가문의 후원과 ‘밤 짐승이 보이면 알리라’는 부탁 | 그 짐승이 무엇인지 |

## 6. 작가가 고를 것

1. 억류의 원리를 ‘떠나는 길을 지운다’(물을 따라가는 첫 방향 + 쉼터의 사슬 + 길의 기억)로 둘지
2. 추천안 ‘도는 물길 + 끊긴 쉼터 사슬’(길잡이의 죽음은 역사적 배경)을 채택할지
3. 번식 고리(안 4)를 더할지
