## 1. 역사가 생태에게 요구하는 것

| 역사의 사건 | 생태가 답해야 할 것 |
|---|---|
| 시대 A: 감응자가 무리 곁에서 아팠다 | 박동이 매질에 남기는 진동의 성질, 무리가 많을 때의 겹침과 과부하 |
| 시대 A: 공존 사회는 감응 없이도 무리를 알았다 | 무리의 계절 움직임이 사람 눈에 읽히는 징후 |
| 첫 번째 침묵: 무리가 떠남 | 집결의 이유, 주기의 길이(사람의 기억보다 길게), 어떤 종이 함께 움직이는지 |
| 대토벌의 실제 피해 | 집결 길목에서 긴장한 무리의 기관 작용이 사람에게 주는 실제 피해 |
| 사슬 수색 | 감응 거리(수십 걸음)와 숨는 습성 |
| 포획 연구의 성과 | 박동의 위상과 기관 반응의 대응, 사로잡힌 개체가 버티는 조건 |
| 흰 골의 참사, 봉인 구역의 위험 | 몰린 무리의 기관 작용이 겹쳐 만드는 재난(냉기·안개·물·땅)의 종류와 빈도 |
| 무리가 집결지에서 흩어지지 않음 | 바깥에 갈 곳이 없는 이유, 주기가 깨졌는지 |
| 두 세기를 버팀 | 수명, 세대, 번식, 집결지의 수용력, 근친과 병의 진행 속도 |
| 이점을 얻는 기술 | 위상 맞춤으로 거둘 수 있는 것(분비, 열, 물의 변화, 조직 등)과 그 비용 |
| 가문의 약재·시약 | 거둔 것이 사람에게 어떤 쓸모가 있는지, 성분 분석으로 드러날 수 있는지 |
| 현재의 흔들림 | 다음 주기, 쇠약의 한계 |

## 2. 생태가 역사에게 요구하는 것

| 생태의 설정 | 역사가 맞춰야 할 것 |
|---|---|
| 종별 수명·세대 | 연표의 간격(‘약 200년’을 쓸지) |
| 집결 주기의 길이 | 첫 번째 침묵과 대토벌의 시점, 선언 뒤 몇 번의 주기가 봉인 구역에서 일어났는지 |
| 어떤 종이 살아남았나 | 대토벌의 강도와 길목의 위치, 집결지에 닿은 무리 |
| 집결지가 주는 조건 | 봉인 구역의 지형과 위치, 사람이 그 땅을 어떻게 썼었는지(옮겨 간 마을) |
| 거두기의 비용 | 가문의 이익 규모의 상한, 무리의 쇠약 속도 |
| 감응의 물리적 한계 | 가문의 권력이 어디까지 갈 수 있는지(전능하지 않음의 근거) |

## 3. 생태 설계의 선행 조건 (작가 결정)

- 집결 원인의 방향(추천 안 3 긴 주기의 집결을 출발점으로 할지)
- 연표 가설(‘약 200년’의 읽기 가·나)
- 이점 체계의 방향(무엇을 얻는가 — 약재, 땅을 살리는 기술, 재료)
- 등장 종을 고르는 기준(집결하는 종 / 봉인 구역의 핵심 무리 / 바깥 시설의 종 / 상징 종)
