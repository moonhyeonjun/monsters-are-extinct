# 감응 기술의 발전과 대가 `[P 후보]` `[작가 전용]`

> 상태: **P 설계 후보 · 미승인 · 정본 아님.** 작성 2026-10-30.
> 승인된 것: [P결정-003](../p-canon/decisions.md) 9항 — 감응 훈련은 감지를 넘어 **환류종으로부터 이점을 얻는 방향**으로도 발전했다. 설계 제약: 정신 지배·예지·원격 탐지·무제한 에너지가 되지 않는다.
> 구체적인 기전은 환류종 생태 설계와 함께 검증한다. 이 문서는 단계와 경계만 정한다.

---

## 1. 감응의 실체 (사회적 인식과 구분)

- 사회의 인식(시대 A): 유전되는 병, 발작, 미친 증세
- 설계상의 실체(후보): 환류기관의 주기적 박동이 땅·물·나무 같은 매질에 남기는 미세한 진동을 남보다 선명하게 느끼는 **드문 선천적 감각 소인**. 가족 안에서 이어질 수 있지만 가문 밖에도 있다(정도와 비율은 미정). 무리 곁에서 과부하가 오는 것이 ‘병’처럼 보인 이유다.
- 의학적 실체(유전 방식, 원인)는 정하지 않는다.

## 2. 발전 단계

| 단계 | 시대 | 할 수 있는 것 | 필요한 것 |
|---|---|---|---|
| 1. 훈련되지 않은 감각 | A | 무리가 가까우면 ‘무언가 있다’를 느낌. 과부하, 혼동(기계·물소리) | — |
| 2. 구별하는 기술 | A 후반 | 개체의 박동과 환경의 울림을 구별, 박자의 유형(쉼·긴장·이동 채비) 구분 | 가문 안의 작은 전통, 오랜 연습 |
| 3. 탐지 기술 | B | 수십 걸음 안 개체의 위치와 상태. **사슬 수색:** 감응자 여럿을 일정 간격으로 세워 줄을 만들고 신호(손짓·북)로 이어 넓은 땅을 훑음 — 한 사람의 거리는 늘지 않고, 사람이 늘어 넓어짐 | 많은 감응자, 군의 조직, 신호 체계 |
| 4. 새 활용법의 발견 | C | 포획 개체 연구로 박동과 기관 작용의 관계를 알게 됨. 박동의 위상(한 주기 안의 때)마다 기관이 다르게 반응한다는 것 | 생체 실험, 기록, 도구 |
| 5. 이점을 얻는 기술 | D | **위상 맞춤:** 박동의 특정 위상에 맞춰 다가가고, 만지고, 옮기고, 거두면 개체가 덜 놀라고 기관에서 원하는 반응(분비, 열, 물의 변화 등 — 생태 설계에서 정함)을 얻음. **압력 몰이:** 사람의 위치와 움직임으로 무리를 원하는 쪽으로 걷게 함(양치기처럼 물리적 압력, 마음을 조종하지 않음) | 훈련된 감응자, 듣는 도구(땅에 대는 막대·판 후보), 시설, 살아 있는 개체 |
| 6. 현재의 비밀 훈련과 독점 | D 후반~현재 | 4·5단계를 비밀 교과로 묶어 가문 안에서만 가르침 | 봉인 구역, 연구 기록, 선별된 훈련생 |

## 3. 꼭 구분할 것

| 구분 | 내용 |
|---|---|
| 감응자가 실제로 감지하는 것 | 수십 걸음 안 기관 박동의 진동(매질을 통해). 그 세기, 간격, 흐트러짐 |
| 훈련으로 정확해지는 것 | 해석(박자 유형, 위상). 거리는 늘지 않음 |
| 도구와 시설이 있어야 하는 것 | 넓은 범위 수색(사람의 사슬), 정밀한 위상 측정, 기록과 비교, 거둔 것의 가공 |
| 환류종이 실제로 반응하는 것 | 사람의 접근 거리와 속도, 소리와 진동, 다루는 때. 감응자의 ‘마음’에는 반응하지 않음 |
| 감응으로 절대 할 수 없는 것 | 마음 읽기와 명령, 미래 예지, 멀리서 찾기, 무제한 에너지, 기관을 마음대로 켜고 끄기 |
| 감응자가 치르는 비용 | 과부하(두통, 잠, 귀울림), 오래 쓰면 청력·균형의 손상 후보, **괴로워하는 개체의 박동을 몸으로 듣는 고통**(잔혹한 연구에 끌려간 아이들의 상처) |
| 환류종이 치르는 비용 | 잦은 접근과 거두기로 인한 스트레스, 번식 저하, 기관의 손상, 무리 질서의 붕괴 |
| 잘못 해석했을 때의 위험 | 무리의 공황, 몰린 곳에서 기관 작용이 겹쳐 재난(냉기·물·땅), 사람과 개체의 죽음. ‘괜찮다’는 해석이 거짓 안심이 됨 |

## 4. 잔혹한 연구 — 왜 성과를 냈고, 무엇을 망가뜨렸나

| 구분 | 내용(후보) |
|---|---|
| 무엇을 했나 | 포획 개체의 해부와 생체 실험, 일부러 놀라게 하거나 굶겨 박동 변화 기록, 새끼를 떼어 반응 관찰, 강제 번식 |
| 왜 성과를 냈나 | 살아 있는 개체에서만 얻을 수 있는 자료(박동과 기관 반응의 대응표)를 많이 모았다. 감응자가 그 변화를 ‘들을 수’ 있어 측정 도구가 없던 시대에 정밀한 기록이 가능했다 |
| 무엇을 망가뜨렸나 | 연구에 쓰인 개체와 그 무리의 질서 / 길을 기억하던 늙은 개체들(집결의 길을 아는 지식이 사라짐 — 후보) / 연구에 동원된 어린 감응자들의 마음 / 가문의 ‘순결’ 이야기와 실제의 간격 / 일부 종의 회복 가능성 |
| 지금 남은 것 | 대응표와 기록(가문 비밀 문서고), 그 지식으로 만든 기술, 상처를 기억하는 몇몇 사람 |

## 5. 생태 설계에서 검증할 것

1. 박동이 매질에 남기는 진동의 성질과 거리
2. 위상마다 기관이 어떻게 다르게 반응하는지, 거둘 수 있는 것이 무엇인지
3. 사람의 접근이 무리의 움직임에 주는 영향(압력 몰이가 가능한 범위)
4. 몰린 무리의 기관 작용이 겹칠 때 생기는 재난
5. 거두기가 개체와 무리에 주는 비용
