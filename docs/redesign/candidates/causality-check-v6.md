## 1. 생물학적 검증

| 질문 | 판단 | 남은 점 |
|---|---|---|
| 집결의 필요성과 주기가 설득력 있나 | **예.** 정해진 곳에서 함께 낳는 동물(바다거북, 누 떼)과 같아 세 문장으로 설명됨 | 종마다 주기 수치 |
| 환류기관의 기능이 명확한가 | **예.** 열과 물을 저장·교환하는 주머니. 새끼의 기관 벽이 광천에서 굳는다는 규칙 하나가 낳는 장소를 정함 | — |
| 감응자와 환류종이 연결되나 | **예.** 기관의 느린 수축 → 땅과 물의 낮은 진동 → 변이된 평형 감각 → 자율신경 반사 | — |
| 두 세기 전후의 생존과 번식 | **추천 진실(1)과 함께라면 ‘약 200년’은 어렵다.** 갇힌 세대가 번식하지 못하므로, 바깥에서 자란 어미들이 아직 살아 있어야 함 → 봉인 이후 약 120년 안팎(수명 백 년 안팎)이 자연스러움. 진실 1을 고르지 않으면 200년도 가능 | 작가의 연표 결정 |
| 억류와 탈출이 모순되지 않나 | **예.** 문은 새끼만 붙잡고, 새끼 없는 어른은 혼자 떠날 수 있음 → 떠도는 개체와 맞음. 진실 1에서는 혼자 떠난 어린 개체가 어른이 되는 유일한 경로가 됨 | 떠날 철과 산길의 정확한 시기 |

## 2. 역사적 검증

| 질문 | 판단 | 남은 점 |
|---|---|---|
| 한 가문의 변이가 여러 세대 유지되나 | **예.** 불리하지 않은 형질은 남고, 열몇 세대면 후손이 수백~수천(현실의 창시자 효과) | 실제 비율의 수치 |
| 가문 밖 감응자의 출현 | **예.** 모르는 후손(옛 분가, 피난, 혼인). 독립 돌연변이를 쓰지 않음 | — |
| 국제적 공로 | **예.** 국경 양쪽의 먼 친척, 교단이 묶은 연합, 지도의 집중, 후기의 정보 중개 | 연합의 구체적 사건 |
| 국가마다 다른 이해 | **예.** 갑(정보를 동맹의 값으로), 을(자기 골을 잃음), 병(돈줄, 평야의 피해) | — |
| 멸종 선언 조작의 현실성 | **예.** 지도가 가문에서만 합쳐짐 + 갑 왕실의 토벌세 + 교단 중앙의 정화의 끝 + 봉인 구역 면제 | 면제 규정의 문구(이전 후보 참고) |

## 3. 서사적 검증

| 질문 | 판단 |
|---|---|
| 설정이 사건을 만드나 | **예.** 떠날 철의 문, 혼자 떠나는 어른, 덜 굳은 새끼, 두 벌 아이의 위험, 국경을 넘는 길 |
| 가문 밖 세력도 매력적인가 | 을의 국경 영주(잃은 골을 모름), 병의 상가(고원의 광산), 고원 교구(공존의 기억), 갑의 무가 |
| 종교가 갈등과 선택에 영향을 주나 | **예.** 교단 중앙의 정화 vs 고원 교구의 기억. 여정이 지나는 땅의 교구가 길을 열지 막을지 |
| 최종 진실이 놀라운가 | **예.** 지켜 온 ‘마지막 번식 집단’이 다음 세대를 낳지 못하고 있었다 |
| 마지막 선택을 바꾸나 | **예.** 해방이 ‘풀어 줌’에서 ‘죽음을 무릅쓴 성장의 허락’으로 |
| 클리셰를 피하나 | 비밀 혈통: 주인공은 먼 후손일 수 있지만 그것이 열쇠가 아님. 선택받은 영웅: 감응이 여정의 조건이 아님 |
| 첫 장면과 마지막 장면의 연결 | **예.** 북쪽으로 가려던 어린 개체 → 어른이 되어 돌아옴 |

## 4. 설정을 지키려 억지 사건을 만들지 않았나

- 문 고장, 혼자 떠나는 어른, 덜 굳은 새끼, 늙은 어미의 죽음은 모두 추천 규칙에서 저절로 생긴다.
- 억지가 될 위험: 진실 1의 결정적 사건(놓아준 개체가 어른이 되어 돌아옴)은 시간 간격이 필요하다(어른이 되는 데 몇 해 이상). 권 구성 단계에서 시간을 배치해야 한다.
