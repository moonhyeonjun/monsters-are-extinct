## 1. 열 개의 시간축 (상대 순서와 범위)

| 축 | 범위·순서(후보) | 기대는 것 |
|---|---|---|
| 1. 감응 유전 변이의 발생 | 이전 무리 짓기 무렵 또는 그 뒤(첫 번째 침묵보다 몇 세기 앞). 이전 무리 짓기의 생존자였을 수 있음(후보) | 한 조상의 변이(승인) |
| 2. 감응자 여성에 대한 차별의 형성 | 변이 뒤 몇 세대. 고요한 세기에 무리 길목 마을에서 | 되울림과 새끼 잃은 어미 |
| 3. 정상 집결이 되풀이된 고대 | 300~500년(변동) 간격으로 여러 번. 옛 왕국 시대에 한 번 이상 | 모델 1 |
| 4. 첫 번째 침묵 | 이전 무리 짓기로부터 300~500년 뒤 | 3 |
| 5. 국제 대토벌 | 첫 번째 침묵 직후 수십 년 | 4 |
| 6. 공식 멸종 선언 | 대토벌 말기 | 5 |
| 7. 마지막 생존지의 봉인과 억류 | 선언 무렵부터 현재까지. 처음엔 개체 수가 적어 억류가 거의 필요 없었고, 분지가 다시 차면서 ‘문턱 아래에 묶어 두기’가 시작됨(수십 년 뒤부터) | 6 |
| 8. 복원 협회 설립과 사업 확장 | 선언 뒤 몇 해 안 설립. 이주 마을은 그 뒤 몇십 년에 걸쳐 | 6 |
| 9. 아카데미 설립과 운영 | 대토벌을 끝낸 평화 협약 직후 | 5·6 |
| 10. 현재 주인공 세대 | 선언으로부터 ‘약 200년’(가설) 또는 그보다 짧게 | 7 |

## 2. 반드시 해결하거나 표시할 모순

| 모순 | 상태 |
|---|---|
| 초장주기 집결과 개체 수명 | **해결 후보.** 개체가 기억하지 않음. 몸속 프로그램을 밀도가 깨움 |
| 긴 주기에도 개체군이 유지되는 이유 | **해결 후보.** 평소에 번식. 무리 짓기 뒤 줄었다가 천천히 회복 |
| ‘재동기화·번식’과 새 원리의 충돌 | **보류 표시.** 무리 짓기를 ‘재동기화’로 읽을 여지는 있으나 문구는 작가 결정 |
| 여러 집결지의 역사적 분포 | **해결 후보.** 고개 앞의 큰 분지마다(지형) |
| 당시 사람들이 처음이라고 믿은 이유 | **해결 후보.** 다섯 겹(옛 왕국, 흩어진 기록, 두 형태의 오인, 비어 있던 분지에 세운 마을, 교단의 비유) |
| 고대 증거의 보존 가능성 | **해결 후보.** 호수 바닥의 연층, 차가운 동굴, 나이테. 마른 비탈과 밭에는 남지 않음 |
| 되울림과 대규모 집결의 독립성 | **해결 후보.** 무리 짓기는 밀도가 일으킴. 되울림은 근거리에서 개별 개체를 끌 뿐(최종 진실 후보 1에서만 ‘마주침’으로 더해짐) |
| 근거리 유인술의 군사적 활용 | **해결 후보.** 원거리 탐지·경로 추정·근거리 유도·토벌의 구분 |
| 마지막 생존지의 장기 억류와 번식 | **해결 후보.** 어른은 텃세로 머물고 번식. 젊은 개체는 거둬짐 |
| 가문이 몰랐던 진실을 지금 주인공이 발견하는 이유 | **해결 후보.** 세 조사 경로가 이제야 한자리에 모임(학원과 협회의 자료, 을의 문서), 주인공이 생존지의 여자들과 닿음 |
| 최종 진실과 중후반 반전의 독립성 | **해결 후보.** 중후반 반전(어미들의 찾음)은 생물의 동기, 최종 진실(대답이 무리를 깨움)은 그 찾음과 사람의 제도가 무리 짓기에 미친 영향 |
| 약 200년과 억류 | **표시.** 분지가 다시 차는 데 걸린 시간과 억류가 시작된 때를 맞춰야 함(생태 설계) |
