## 0. 결론 먼저

- **추천: 진실 1 ‘복원이 지운 풀숲’.**
  - 독자는 중후반까지 이렇게 믿는다: 가문이 생물을 가뒀고, 여자들을 착취했고, 어미들은 새끼를 찾고 있었다. 그러니 **여자들을 풀어 주고, 어미와 새끼를 잇고, 생존지를 열어 바깥으로 돌려보내면 된다.**
  - 최종 진실: **돌려보낼 바깥이 없다.** 열매 풀숲은 수십 년에 한 번 열매를 맺고 함께 말라 죽은 뒤, 빈 비탈에서 씨앗으로 다시 자란다. 대토벌 뒤 복원 협회는 불타고 말라 버린 비탈마다 빨리 자라는 나무를 심어 산사태를 막았다. 그 그늘 아래에서 풀숲의 씨앗은 다시 자라지 못했다. **사람이 세상을 고친 그 방법이, 그들이 돌아갈 곳을 영영 지웠다.**
  - 가문도 몰랐다. 가문은 생존지 안의 풀숲만 지켰고, 바깥의 풀숲은 ‘열매 뒤의 자연스러운 고사’ 뒤에 다시 자라고 있으리라 믿었다. 학원의 식물 표본실에는 ‘열매 뒤 고사, 재생 없음’이라는 꼬리표가 수십 장 있었고, 협회의 산림 기록에는 같은 비탈에 심은 나무의 해가 적혀 있었다. **아무도 두 기록을 나란히 놓지 않았다.**
- **구원의 방식이 바뀐다:** 해방은 문을 여는 일이 아니라, **사람이 스스로 고친 땅의 일부를 다시 내주는 일**이 된다. 협회가 자랑하는 숲을 베어야 하고, 그 숲 덕분에 살아난 마을들이 다시 위험해진다. 그리고 풀숲이 열매 맺기까지 수십 년 — 그동안 생존지는 누군가 지켜야 한다(이번엔 가문이 아니라 누가?).
- **첫 장면과 교류 장면이 다시 읽힌다:** 처음 만난 개체가 협회의 묘목밭을 파헤쳤던 것(해로운 짐승으로 신고됨), 교류 장면에서 어미가 떠난 뒤 멈춰 섰던 비탈(지금은 협회의 숲).

## 3. 진실 1이 만드는 마지막 선택

| 질문 | 답(후보) |
|---|---|
| 처음에 원했던 것 | (인물 설계) 예: 학원에서 복원 일을 배우는 것, 자기 몸의 이상함을 이해하는 것 |
| 왜 환류종을 구하려 하나 | 처음 만난 개체와의 일, 생존지의 여자들 |
| 어미들과 교류한 뒤 달라진 것 | 곁에 있는 것보다 놓아주는 것을 배움(교류 장면) |
| 가문의 비밀 공개가 충분하지 않은 이유 | 공개해도 생물이 갈 곳이 없음 |
| 여자들을 해방하는 것만으로 안 되는 이유 | 떠날 철의 발 묶기는 끝나도, 생물은 생존지 밖에서 살 수 없음 |
| 생존지 밖으로 내보내는 것만으로 안 되는 이유 | 바깥의 풀숲이 없음 |
| 협회와 학원의 선택 | 협회: 자기 숲을 일부 베어 풀숲이 다시 설 빈 비탈을 내줄 것인가. 학원: 표본실과 서고의 기록을 공개하고, 풀숲을 다시 세우는 연구를 맡을 것인가 |
| 국가와 종교의 책임 | 갑의 왕실: 땅. 교단: 박해의 책임과 구호의 자원. 을: 국경 너머의 옛 풀숲 비탈 |
| 주인공이 감수하는 손실 | 자신이 사랑하게 된 일(복원)의 의미, 숲 덕분에 살아난 사람들과의 관계, 어쩌면 그 숲에서 자란 친구 |
| 다른 인물에게 돌려줄 선택권 | 숲 아래 마을 사람들(어느 비탈을 내줄지), 생존지의 여자들(남아서 풀숲이 설 때까지 지킬지, 떠날지), 을의 지부 |
| 결말 이후의 세계 | (후보) 사람이 고친 땅 일부를 그들에게 돌려주고, 풀숲이 열매를 맺을 수십 년을 함께 기다리는 세계. 쉬운 해방이 아니라 오래 걸리는 내어 줌 |

- 혈통은 열쇠가 아니다: 진실은 식물학과 기록과 숲 아래 사람들의 선택에서 풀린다.
