## 0. 결론 먼저

- **추천: 진실 1 ‘대답이 무리를 깨운다’.**
  - 무리 짓기는 밀도 그 자체가 아니라 **동족과 얼마나 자주 마주치느냐(동족의 신호를 얼마나 자주 받느냐)**에 따라 일어난다(메뚜기도 서로의 몸이 닿고 보이는 빈도로 상이 바뀐다).
  - 감응자 소녀의 되울림은 새끼의 울림을 닮은 신호다. 생물에게 그것은 **또 한 번의 마주침**이다. 가문은 두 세기 동안 수십 명의 여자를 분지 가장자리에 두고, 젊은 개체를 거두는 데 그 되울림을 써 왔다. 그리고 젊은 개체를 거둘수록 새끼를 잃은 어미가 늘어 여자들 곁을 맴돌았다. **가문의 제도가 생물을 매일 밤 더 많은 마주침 속에 두었다.**
  - 그래서 분지는 개체 수보다 훨씬 ‘가득 찬’ 상태였다. 밤 행진이 해마다 길어진 것은 기후 탓이 아니었다. 가문은 따라잡으려 더 많은 젊은 개체를 거뒀고, 그 일이 다시 마주침을 늘렸다. **가문이 막으려던 무리 짓기를, 가문의 제도가 깨우고 있었다.**
- **주인공이 준비한 해결책의 뜻이 바뀐다.** 주인공은 가문을 폭로하고 여자들을 풀어 주고 거두는 일을 멈추면 된다고 생각한다. 그러나 거두는 일을 멈추면 개체 수가 늘고, 여자들이 그대로 있으면 마주침은 그대로다 → 몇 해 안에 무리 짓기 → 고개 너머, 협회가 세운 이주 마을들이 있는 옛 길목으로 행진.
- **유일한 길은 주인공이 혼자 했던 일을 모두가 하는 것이다:** 여자들이 함께 대답하지 않기(물가를 떠나고, 높은 침상에서 자고, 거두는 일을 멈춤). 그러면 마주침이 줄고 생물은 혼자 사는 몸으로 가라앉는다. 그동안 사람들이 작은 무리를 멀리 빈 고원으로 옮겨 밀도를 낮춘다. **‘대답하지 않는 밤’은 결말의 모형이 된다.** 감동은 무효가 아니라 커진다.

## 1. 네 후보

### 진실 1. 대답이 무리를 깨운다 — 추천

| 항목 | 설계(후보) |
|---|---|
| 1. 실제 진실 | 무리 짓기의 방아쇠는 동족 신호를 받는 빈도. 되울림도 그 빈도에 들어감. 가문의 제도(여자들의 집단 거주, 되울림을 쓴 젊은 개체 거두기, 그로 인한 새끼 잃은 어미들의 맴돎)가 무리 짓기를 앞당겨 왔다 |
| 2. 가문이 알던 것 | 무리 짓기가 일어나면 모든 것이 드러난다. 그래서 개체 수를 문턱 아래로 묶어야 한다. 되울림은 어미를 붙잡고 젊은 개체를 거두는 데 쓸모 있다 |
| 3. 가문이 몰랐던 이유 | 상 변화라는 현상 자체를 몰랐다(옛 기록의 ‘걷는 산의 짐승’을 다른 생물로 여김). 밤 행진을 계절의 들뜸으로 읽음. 거둬야 할 수가 늘어나는 것을 좋은 기후 탓으로 돌림. 여자들의 되울림을 ‘어미를 붙잡는 힘’으로만 이해함 |
| 4. 기존 사건과 단서 | 해마다 길어지는 밤 행진, 몸 색이 바뀌는 개체, 여자들 거처에 가까운 터일수록 행진에 일찍 나서는 개체들, 돌침상을 지키는 여자 곁의 개체들이 덜 들썩임, 주인공이 물러선 뒤 그 어미가 다시 혼자 사는 몸처럼 차분해짐 |
| 5. 독자가 예상할 가능성 | 낮음. 독자는 되울림을 ‘어미의 슬픔’의 문제로 이해한 상태 |
| 6. 세계를 다시 이해하는 정도 | 큼. 여자들의 착취 → 생물의 슬픔 → 무리 짓기 → 사람의 마을이 한 고리였음 |
| 7. 주인공이 검증하는 방식 | 학원 자연사(두 형태), 협회 지질(되풀이되는 층), 고문서(걷는 해)로 무리 짓기를 알고, 생존지의 여자들과 함께 돌침상을 지킨 터와 지키지 않은 터의 행진을 비교 |
| 8. 학원·협회의 기여 | 학원: 상 변화의 증거와 이론. 협회: 이주 마을이 길목에 있다는 지도, 작은 무리를 옮길 현장 인력 |
| 9. 마지막 선택에 미치는 영향 | ‘풀어 줄 것인가’에서 ‘함께 대답을 거둘 수 있는가’로 |
| 10. 대안과 실제 희생 | §2 |
| 11. 새 세계관 규칙 | **하나**: 동족 신호를 닮은 되울림도 무리 짓기의 마주침으로 센다(메뚜기의 상 변화가 접촉·시각 신호 빈도로 일어나는 것에서 착상) |
| 12. 기존 승인과의 충돌 | 없음. ‘재동기화와 번식’ 문구는 보류 상태 그대로 |

## 2. 진실 1이 만드는 마지막 선택

| 질문 | 답(후보) |
|---|---|
| 주인공이 원래 이루고 싶었던 것 | (인물 설계) 예: 복원 일, 자기 몸의 이상함의 이유 |
| 중후반 이후 달라진 목표 | 어미들의 찾음을 끝내고, 여자들을 풀어 주는 것 |
| 지금까지 준비한 해결책 | 가문의 폭로, 여자들의 해방, 거두는 일의 중단, 생존지의 개방 |
| 그것이 불충분해지는 이유 | 거두는 일을 멈추면 개체 수가 늘고, 여자들이 남아 있으면 마주침이 그대로 → 무리 짓기 → 이주 마을들로 행진 |
| 충돌하는 실제 선택 | ① 여자들이 함께 대답을 거두고, 한 세대에 걸쳐 작은 무리를 먼 빈 고원(국경 너머 포함)으로 옮긴다 ② 무리 짓기가 일어나게 두고 길목의 마을들을 비운다 ③ 가문의 제도를 계속한다(거두는 일은 늘고 문턱은 가까워짐) |
| 구할 수 있는 사람과 생물 | ①: 생물 대부분과 마을, 그러나 여자들의 협력이 전제 ②: 생물의 자연스러운 길, 그러나 많은 개체와 이주민의 삶이 희생 ③: 아무도 오래 구하지 못함 |
| 각 선택으로 잃는 것 | ①: 여자들이 아는 어미들과의 곁(모두가 대답을 거둬야 함), 수십 년의 비용과 국경을 넘는 협상, 비밀의 공개 ②: 이주 마을과 협회의 성과 ③: 여자들의 삶과 생물의 미래 |
| 감응자 여성들의 선택권 | **핵심.** ①은 여자들의 동의 없이는 불가능. 착취당한 사람들에게 또 한 번의 희생을 요청하는 일 — 주인공은 그것을 명령할 수 없고 요청할 수만 있다. 거부하는 여자도 있다 |
| 국가와 지역 주민 | 갑: 생존지와 이주 마을. 을: 옮길 고원의 땅. 이주민: 집 |
| 종교와 가문의 책임 | 교단: 정화의 기원과 박해. 가문: 두 세기의 제도 |
| 학원과 협회가 감수할 결과 | 학원: 닫힌 서고와 심사의 공개, 가문 이사와의 결별. 협회: 이주 마을의 재배치, 특수 신고의 공개 |
| 주인공 자신의 대가 | 다른 여자들에게 희생을 청해야 하는 짐, 자기가 처음 가졌던 꿈(예: 복원 일)의 뜻이 바뀜, 그 어미와 다시 만나지 않는 것 |

- 혈통이나 특별한 힘으로 풀리지 않는다: 해결은 여자들의 선택, 학원과 협회의 증거와 인력, 이주민과 나라들의 동의에 달려 있다.
