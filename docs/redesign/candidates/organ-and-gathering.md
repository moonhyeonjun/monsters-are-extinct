# 환류기관과 집결 — 끝까지 쓸 수 있는 작동 규칙 `[P 후보]` `[작가 전용]`

> 상태: **P 설계 후보 · 미승인 · 정본 아님.** 작성 2026-10-31(5단계).
> 승인된 방향([P결정-007](../p-canon/decisions.md)): 일부 환류종의 재동기화·번식 집결 모델, 마지막 기능 집결지와 마지막 번식 집단, 쉬지 못한 집결지와 흩어짐의 충동.
> 목적: 지금까지 ‘박동’이라는 말로 미뤄 온 것을 **규칙**으로 만든다. 신비한 표현이 아니라, 다른 설계(감응, 생태, 억류, 최종 진실)가 끝까지 기댈 수 있는 작동 체계를 고른다.
> 참고: W의 환류기관 설계 기준(creatures/return-organ-design.md의 조절 기관형·맥동형·층판과 관의 해부 모델, 에너지 보존 원칙)을 출발점으로 빌렸다. P를 구속하지 않는다.
> 실제 생물에서 빌린 원리: 심장의 박동 조율 조직, 생체 시계와 바깥 신호에 의한 재설정, 반딧불이·심근 세포의 집단 동기화, 코끼리의 땅 진동 통신, 연어·비둘기의 귀소 각인.

## 0. 결론 먼저 — 다섯 줄 규칙

1. **환류기관은 펌프다.** 층판 조직이 수축·이완해 체액을 관으로 밀어 열과 물과 광물을 몸 안팎으로 옮긴다. 무한한 에너지를 만들지 않고, 먹이로 값을 치른다.
2. **박동은 기관 속 ‘박동 조율 조직’이 만든다.** 심장의 박동처럼 스스로 뛰지만 훨씬 느리다(몇 초에 한 번). 이 조율 조직은 **혼자 두면 조금씩 어긋나는 생체 시계**다.
3. **박동은 몸이 땅이나 물에 닿을 때 매질로 퍼지는 낮은 진동**이다. 젖은 땅·바위·물에서 잘 퍼지고, 공기로는 거의 퍼지지 않는다. 감응자가 받는 것은 이 진동이다.
4. **집결은 생체 시계의 재설정이다.** 진동을 모아 울리는 지형에서 많은 동족이 함께 뛰면 하나의 크고 안정된 박자가 생긴다. 그 박자가 각 개체의 어긋난 시계를 종의 기준 박자로 되돌린다. 기준 박자가 맞은 개체끼리만 짝을 알아보고, 새끼는 그 박자 속에서 자기 시계를 처음 맞춘다.
5. **흩어짐은 맞춤이 끝났다는 신호다.** 시계가 맞으면 겹친 박동이 오히려 괴롭고 먹이도 바닥나 무리는 흩어진다. 어린 개체는 처음 흩어져 간 곳을 ‘고향’으로 몸에 새긴다(귀소 각인).

## 1. 영역별 규칙

| 영역 | 규칙(후보) |
|---|---|
| 기관의 생물학적 역할 | 몸과 환경 사이의 열·물·광물 교환을 조절한다. 종마다 주로 옮기는 것이 다르다(열을 끌어오는 종, 물을 모으는 종, 광물을 쌓는 종) |
| 박동의 발생 | 기관 속 조율 조직이 스스로 뛰는 리듬. 대사 상태, 체온, 나이에 따라 조금씩 빨라지거나 느려진다 |
| 외부 환경과의 상호작용 | 박동마다 체액이 몸 표면의 관으로 밀려 나가 열과 물을 주고받는다. 많은 개체가 오래 머물면 그 곳의 물·열·흙이 바뀐다 |
| 감응자가 받는 신호 | 매질을 거쳐 온 아주 낮은 진동의 **박자와 겹침의 결**. 소리처럼 듣는 것이 아니라 몸으로 받는다([sensing-physiology.md](sensing-physiology.md)) |
| 매질과 거리 | 젖은 땅·바위·물이 좋고 마른 모래·공기는 나쁨. 한 개체: 수십 걸음. 무리: 수백 걸음. 집결지의 울림: 수 리 |
| 도구로 잴 수 있는 조건 | 가까운 무리는 바위 위 물그릇의 잔물결, 땅에 박은 막대의 떨림으로 보인다. 먼 박자를 재려면 아주 예민한 흔들림 기록 장치가 필요하다(현재 기술로 막 가능해지는 수준) |
| 기관의 성장과 노화 | 어릴 때 조율 조직은 무르고 쉽게 맞춰진다. 자라면서 굳어 덜 어긋나지만, 늙으면 다시 빨리 어긋난다 |
| 종마다 다른 구조 | ① 박동 없는 기관(스며드는 방식): 집결하지 않음 ② 박동하지만 혼자서도 버티는 기관: 집결하지 않음 ③ **박동이 어긋나면 기능이 떨어지는 기관: 집결형** — 일부 종만 |
| 재동기화의 의미 | 어긋난 생체 시계를 집단의 큰 박자로 다시 맞추는 것. 지형이 박자를 키우고 안정시켜, 수많은 개체의 제각각인 박자가 하나로 끌려 모인다(실제 집단 동기화 현상과 같은 원리) |
| 집결과 번식의 관계 | 짝은 맞춰진 박자로 서로를 알아본다. 새끼의 조율 조직은 태어나 처음 겪는 집단 박자에 맞춰 굳는다. 그래서 집결지에서 낳고 키운다 |
| 집결 실패의 결과 | 개체: 시계가 계속 어긋나 기관 효율이 떨어지고, 혹한·가뭄 같은 극한기를 버티지 못해 일찍 죽는다. 다음 세대: 짝을 알아보지 못해 번식 실패. 맞추지 못한 새끼는 기관이 불안정해 살아남기 어렵다. 집결지를 잃은 종은 한두 세대 안에 기능적으로 멸종 |
| 집결지의 조건 | 진동을 모아 울리는 바위 분지(일정한 크기와 모양, 물을 머금은 지층) + 물 + 많은 개체를 몇 달 먹일 땅 |
| 세대 간 경로 전달 | 두 겹: 어른을 따라 걷는 학습 + 첫 흩어짐에서 새긴 귀소 각인. 길은 몸에 새긴 땅의 연속(물길, 바위, 냄새)으로 기억된다 |

## 2. 정상 집결의 한 주기

| 단계 | 일어나는 일 |
|---|---|
| 흩어진 삶(수십 년) | 각자의 고향에서 산다. 시계가 천천히 어긋난다 |
| 채비 | 어긋남이 쌓여 몸이 불편해짐. 무리 안에서 서로의 박자에 끌려 비슷한 때에 들뜸 |
| 이동 | 늙은 개체를 따라 옛 길로 |
| 맞춤 | 지형의 큰 박자 속에서 시계가 되돌아감. **가장 약한 때** |
| 번식 | 맞춰진 개체끼리 짝을 알아봄. 새끼가 집단 박자 속에서 태어나 시계를 굳힘 |
| 흩어짐 | 맞춤이 끝나면 겹친 박자가 괴롭고 먹이가 바닥남. 어른은 고향으로, 어린 개체는 어른을 따라가며 첫 고향을 새김 |
| 휴식(수십 년) | 집결지가 비어 물과 흙과 식생이 회복됨 |

## 3. 재동기화가 생리적으로 성립하지 않는다면 — 대안 규칙

| 대안 | 내용 | 얻는 것 | 잃는 것 |
|---|---|---|---|
| 대안 1. 짝 알아보기만 | 박자는 시계가 아니라 종과 개체를 알리는 신호. 집결은 넓게 흩어진 짝을 찾는 번식 모임 | 생리 설명이 단순 | 집결 실패가 ‘기관 효율’로 이어지지 않아 쇠약의 이유가 약해짐 |
| 대안 2. 새끼의 발달 조건만 | 어른은 맞출 필요가 없고, 새끼만 집단 박자 속에서 자라야 기관이 제대로 굳음 | 집결지 = 육아 터로 단순 | 어른의 ‘채비’와 ‘흩어짐의 충동’ 설명이 약해짐 |
| **추천 규칙(시계 재설정 + 짝 알아보기 + 새끼의 첫 맞춤)** | 세 기능을 하나의 조율 조직으로 묶음 | 쇠약·번식·각인·흩어짐이 한 원리 | 설정이 조금 더 정교해야 함 |

## 4. 흩어짐과 이동 (억류 설계의 전제)

| 질문 | 답(후보) |
|---|---|
| 집결을 마친 개체가 떠나는 이유 | 맞춤이 끝나면 겹친 박자가 괴로워짐(과잉 끌림), 먹이 고갈, 어린 개체가 고향을 새겨야 함 |
| 어떤 종이 어디로 | 종마다 고향의 성격이 다름: 물을 모으는 종은 강의 상류 습지로, 열을 끌어오는 종은 추운 고원으로, 광물을 쌓는 종은 특정 바위 지대로. 흩어지는 거리는 며칠 길에서 몇 주 길까지 |
| 길을 고르는 감각과 학습 | 어른을 따름 + 귀소 각인. 물길과 바위, 냄새의 연속을 기억 |
| 경로가 사라졌을 때 | 고향이 사라졌거나 길이 끊기면 새긴 곳을 찾아 같은 방향으로 거듭 나섬. 실패해도 그 방향을 버리지 못함(각인은 지워지지 않음) |
| 떠나지 못하면 | 맞춰진 뒤의 겹친 박자가 계속 괴로움 → 지침, 먹이 다툼, 병, 번식 리듬의 혼란. 집결지는 쉬지 못해 물·흙·식생이 바뀜(쉬지 못한 집결지) |

## 5. 다른 설계에 주는 것

- 감응: 감응자가 받는 것 = 매질을 거친 낮은 진동의 박자와 겹침([sensing-physiology.md](sensing-physiology.md)).
- 생태: 종마다 옮기는 것(열·물·광물)이 다르다는 규칙이 생태계 구성안의 바탕([gathering-ecosystems.md](gathering-ecosystems.md)).
- 억류: 귀소 각인과 사회적 결속이 억류 후보의 바탕([containment-v3.md](containment-v3.md)).
- 최종 진실: 생체 시계의 어긋남, 기준 박자, 각인이 모든 후보의 재료([final-truths.md](final-truths.md)).

## 6. 아직 정하지 않은 것

- 집결형 종의 수(셋에서 다섯 정도를 권함), 각 종의 주기(수십 년 범위), 수명
- 박동의 실제 간격과 진동의 세기
- 진동을 모으는 지형의 정확한 지질
