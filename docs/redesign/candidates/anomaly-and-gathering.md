# 환류종의 이상 현상과 집결, 첫 번째 침묵의 재해석 `[P 후보]` `[작가 전용]`

> **[일부 채택·대체됨 · 2026-10-30 · P결정-004]** 안 3(긴 주기의 집결)은 **일부 종의 현상**으로만 채택되었다. 집결의 목적과 다중 집결지는 [gathering-ecology.md](gathering-ecology.md)가 대체한다. 첫 번째 침묵의 공식·실제 비교도 그 문서 §6이 새로 쓴다.
> 상태: **P 설계 후보 · 미승인 · 정본 아님.** 작성 2026-10-30.
> 승인된 것: [P결정-003](../p-canon/decisions.md) — 가문이 이상 현상을 추적하다 **특정 지역으로 몰려드는 현상**을 발견했다. 첫 번째 침묵은 **공식 기록과 실제 역사가 다른 구조**다.
> 승인되지 않은 것: 이상 현상의 실제 원인, 집결의 이유, 가문의 책임 정도. 아래는 복수 후보이며 생태 설계에서 검증한다.
> 원칙: 첫 번째 침묵을 ‘가문이 지어낸 소문’으로 단정하지 않는다. **이상 현상 자체는 실제였고, 가문이 원인과 의미를 왜곡했을 가능성**을 중심으로 본다.

## 1. 안별 설계

### 안 1. 환경 변화로 인한 피난

| 질문 | 답 |
|---|---|
| 어떤 이상 | 기관 작용이 불안정해짐(갑작스러운 냉기나 열, 물의 솟구침), 이동 경로 이탈, 번식지 포기 |
| 범위 | 일부 종(물과 바닥 환경에 민감한 종) |
| 집결지가 주는 것 | 변화가 덜 닿은 안정된 물과 바닥 |
| 집결의 성격 | 생존을 위한 선택 |
| 가문이 원인을 쫓은 이유 | 수색 성과, 감응의 원리 |
| 왜 숨겼나 | 집결지를 독차지하려고. 그리고 ‘짐승이 미쳤다’는 명분이 무너지면 토벌의 공로가 흔들리므로 |
| 약점 | W의 첫 번째 침묵과 거의 같다. 새로움이 적다 |

### 안 2. 사람의 개발이 부른 피난

| 질문 | 답 |
|---|---|
| 어떤 이상 | 안 1과 비슷하나, 원인이 사람의 물길·개간·광산 |
| 집결지가 주는 것 | 개발이 닿지 않은 땅 |
| 가문이 숨긴 이유 | 원인이 사람(왕실의 사업)이라는 사실은 왕실에도 가문에도 불편함 |
| 약점 | 사람만 나쁜 이야기로 기울 수 있음. 현재의 위기와 같은 구조를 되풀이 |

### 안 3. 긴 주기의 집결 (추천)

| 질문 | 답 |
|---|---|
| 어떤 이상 | 여러 종의 무리가 수십 년에 한 번, 사람의 한 생애보다 긴 주기로 원래의 땅을 떠나 한 곳으로 모인다(번식, 털갈이·기관의 갱신 같은 생애 주기 사건 후보 — 생태 설계에서 정함). 떠나는 동안 무리는 긴장하고, 기관 작용이 커지며, 낯선 사람의 땅을 지난다 |
| 사람이 본 것 | 익숙한 땅에서 무리가 갑자기 사라짐(‘침묵’), 지나가는 길목의 마을과 충돌, 이상한 날씨. 앞선 주기는 기록되지 않았거나 전설로만 남음 |
| 범위 | 여러 종이 같은 시기에(서로 다른 종이 같은 장소를 쓰는 이유도 생태 설계에서) |
| 집결지가 주는 것 | 따뜻한 샘, 광물, 넓은 물가 같은 특별한 조건(후보) |
| 집결의 성격 | **위협도 광기도 아닌, 생애의 일부.** 그 시기가 무리에게 가장 약한 때였다 |
| 가문이 언제 알았나 | 사슬 수색 중 무리의 박동이 ‘한 방향을 향한 긴장’이라는 것을 감응자들이 먼저 느꼈다. 포획 개체의 연구로 확인했다(대토벌 중반 후보) |
| 가문이 원인을 쫓은 이유 | 처음엔 수색을 위해, 뒤에는 그 집결이 무엇을 뜻하는지(생물의 가장 귀한 시기와 장소) 깨닫고 |
| 왜 공개하지 않았나 | ① ‘미쳐서 덮쳤다’는 명분이 무너지면 토벌의 공로와 가문의 영웅성이 흔들림 ② 집결지를 가진 자가 남은 생물 전체를 가짐 ③ 공개하면 토벌대가 집결지를 덮쳐 끝장날 수 있다는 판단(일부 감응자의 보호 동기) |
| 가문의 책임 | 원인은 아니다. 그러나 집결 시기에 토벌이 겹치도록 수색을 이끌었고, 그 의미를 숨겼다. **선택지:** 사슬 수색이 무리를 쫓아 길목을 막으면서 충돌을 키웠다(안 4를 보조로 섞음) |
| 반전 잠재력 | 가장 크다. ‘미친 괴물’ → ‘어딘가로 가던 무리’ → ‘그곳에 가야만 하는 이유’ 순서로 독자의 이해가 바뀐다. 결말에서 생물의 자율적 움직임이 다시 사건을 만들 수 있다(다음 주기) |
| 약점 | 생태 설계가 주기·장소·이유를 단단히 받쳐야 한다. 주기가 지금 다시 돌아온다면 현재 사건과 너무 편리하게 맞물리지 않게 해야 한다 |

### 안 4. 가문의 실험과 수색이 만든 반응

| 질문 | 답 |
|---|---|
| 어떤 이상 | 가문의 수색과 실험(무리를 몰고, 새끼를 떼고, 놀라게 함)이 무리를 흩고 한 곳으로 몰리게 함 |
| 가문의 자리 | 원인 제공자 |
| 판단 | 단독으로는 비추천. 가문이 모든 사건의 원인이 되고, 생물이 사람의 음모에 종속된다. 안 3에 ‘악화 요인’으로만 섞을 수 있다 |

## 2. 첫 번째 침묵의 공식 역사와 실제 역사 (안 3 기준)

| 항목 | 공식 기록 | 실제(후보) |
|---|---|---|
| 첫 번째 침묵 | 대토벌 직전, 여러 지방에서 환류종이 조용해지고 사라졌다가 병들고 미쳐 돌아와 사람을 덮친 시기 | 무리들이 긴 주기의 집결을 위해 원래의 땅을 떠난 시기. ‘조용해졌다’는 감응자들의 말(박동이 들리지 않음)이 공식 기록에 들어감 |
| 대토벌 시기의 이상 현상 | 광기와 공격 | 집결지로 가는 길의 긴장, 커진 기관 작용, 낯선 땅에서의 충돌. 일부 피해는 실제였다 |
| 가문이 발견한 생물학적 사실 | — | 무리가 한 방향, 한 시기에 향한다. 그 시기가 무리의 가장 약한 때다. 집결지의 위치 |
| 가문이 숨기거나 왜곡한 것 | — | 집결의 의미(‘광기’로 둠), 집결지의 위치, 앞선 주기의 흔적(옛 민속에 남은 ‘짐승들의 큰 길’ 같은 이야기를 미신으로 정리) |
| 대토벌의 명분 | 미친 괴물로부터 나라를 지킴 | 실제 피해 + 땅과 통합과 값. 가문의 왜곡이 명분을 굳힘 |
| 대토벌의 결과 | 괴물의 퇴치 | 집결 시기의 무리를 길목에서 대부분 잃음. 집결지에 닿은 무리만 남음(생존지의 기원) |

- 첫 번째 침묵은 **실제 현상(무리가 떠남)**에 **틀린 이름과 틀린 의미**가 붙은 사건이다. 그 의미를 굳힌 것이 가문이다.

## 3. 생태 설계에 넘길 질문

1. 집결의 이유(번식, 기관의 갱신, 다른 생애 사건)
2. 주기의 길이(사람의 기억보다 길어야 함)
3. 어떤 종이 집결하는지, 서로 다른 종이 왜 같은 곳에 모이는지
4. 집결지가 주는 조건(샘, 광물, 물가 등)
5. 몰린 무리의 기관 작용이 만드는 실제 위험(위험지역 선포의 근거)
6. 대토벌 뒤 집결지에 남은 무리가 왜 흩어지지 않았나(바깥에 갈 곳이 없음, 주기의 붕괴, 가문의 관리)
7. 다음 주기가 언제인지, 그것이 현재 이야기에 쓰일지
