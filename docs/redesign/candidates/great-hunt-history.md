## 0. 결론 먼저

- **추천: 모델 D ‘시기별로 달라진 역할’.** 자국의 정찰병 → 교단이 묶은 연합군의 전문 부대 → 각국에 정보를 주고 대가를 받는 중개자. 가문이 직접 죽인 것은 일부이고, **가문이 정말로 쥔 것은 모든 나라의 정찰 보고가 모이는 ‘한 장의 지도’**였다.
- **국경을 넘은 이유는 피에 있었다.** 같은 조상의 후손은 고원 골짜기에서 국경 양쪽으로 퍼져 있었다. 가문은 이웃 나라의 먼 친척 감응자들을 불러 모을 수 있었고, 그 나라 사람들도 ‘자기 고향 출신 정찰병’을 받아들였다.
- **마지막 집결지를 숨길 수 있었던 이유:** 지도는 가문의 손에서만 합쳐졌다. 그 집결지는 가문의 옛 골짜기 곁, 가문이 지휘하던 자국의 고원 군관구 안에 있었다. 아무도 대조할 수 없었다.

## 1. 정치 지도의 가정 (대토벌 이전)

| 요소 | 가정(후보) |
|---|---|
| 지형 | 큰 산맥 하나와 그 양쪽의 고원. 환류종의 땅은 이 고원들이고, 따뜻한 광천 골(낳는 골)은 산맥 곳곳에 다섯에서 일곱 곳 |
| 나라 | 산맥을 나눠 가진 왕국 둘(갑·을), 하류의 평야 왕국 하나(병). 고원 공동체들은 반쯤 독립적 |
| 나라 사이 | 국경 다툼과 무역. 큰 전쟁은 없지만 서로 믿지 않음 |
| 교단 | 세 나라에 걸친 하나의 교단 |
| 가문의 고향 | 갑과 을의 국경 고원에 있는 골짜기. 그 곁에 낳는 골 하나(뒤의 마지막 집결지) |
| 집결지의 분포(후보) | 갑에 둘(가문 고향 곁 하나 포함), 을에 둘, 국경에 걸친 하나, 병에 가까운 산자락에 하나 |
| 환류종과 국경 | 무리는 국경을 모름. 갑의 고원에서 살다 을의 골에서 낳는 무리도 있음 |

## 3. 추천 모델 D의 흐름

| 시기 | 일어난 일 | 가문이 실제로 한 일 | 후대의 영웅담 |
|---|---|---|---|
| 첫 번째 침묵 | 여러 무리의 낳는 해가 겹쳐 큰 무리들이 사람의 땅을 가로지름. 각국이 따로 대응 | 갑의 군에 어른 감응자 몇이 정찰병으로 들어감 | “영웅 가문이 홀로 괴물의 행군을 막았다” |
| 초기(자국) | 갑의 고원 군관구에서 정찰과 매복 | 가문의 본가가 흩어진 감응자들을 모아 정찰대를 꾸림. 아이를 징발하던 군에 ‘훈련된 어른’을 대신 제안 | “가문이 아이들을 구했다”(절반은 사실) |
| 중기(연합) | 교단이 ‘정화’를 선포해 세 나라의 연합을 묶음. 외국 군이 국경을 넘을 명분이 생김 | **을의 먼 친척 감응자들을 불러 모음.** 을 사람들은 고향 출신 정찰병을 받아들임. 가문은 연합군의 정찰 부대를 이끔. 포획한 개체를 연구해 ‘언제·어디서 낳는지’를 알아냄 | “가문이 세 나라를 누볐다” |
| 후기(정보) | 연합이 다툼으로 흔들림. 각국은 자기 땅의 낳는 골을 자기 군으로 치고 싶어 함 | **각국에 낳는 골의 위치와 해를 알려 줌.** 각국 군이 낳는 철에 매복해 무리를 끝냄. 가문은 각국에서 훈장·땅·무역 특권을 받음. 갑의 왕실은 이 정보를 동맹의 값으로 씀 | “가문이 괴물의 둥지를 하나하나 찾아냈다” |
| 말기 | 마지막 원정: 국경에 걸친 낳는 골의 마지막 무리를 연합의 이름으로 침 | 가문이 원정을 이끎(가문이 직접 지휘한 몇 안 되는 작전) | “세상의 마지막 괴물” |
| 은폐 | 고향 곁의 낳는 골은 지도에 없음. 가문이 지휘하던 갑의 고원 군관구 안 | 숨김. 뒤에 사고(흰 골 참사 후보)와 봉인, 관리권 | — |

## 4. 열한 가지 질문의 답

| 질문 | 답(후보) |
|---|---|
| 대토벌 이전에 여러 나라가 있었나 | 있었다. 왕국 셋과 반쯤 독립된 고원 공동체들 |
| 대토벌 때 전쟁이나 동맹 | 교단이 묶은 연합. 그 안에서도 지휘권과 몫을 두고 다툼 |
| 환류종과 국경 | 무리는 국경을 모름. 한 나라에서 살고 다른 나라의 골에서 낳음 |
| 집결지는 어느 나라에 | 여럿에 흩어짐(§1) |
| 각 나라의 위험 인식 | 갑과 을(고원을 가진 나라)은 크게, 병(평야)은 행렬이 내려온 해에만 |
| 외국 군의 진입 | 중기의 연합 동안만, 교단의 선포를 명분으로 |
| 가문은 지휘권을 가졌나 | 정찰 부대장. 전투 지휘는 각국 군 |
| 감응자들이 다른 나라에 파견되었나 | 그렇다. 그 나라 출신의 먼 친척이 많았음 |
| 직접 토벌했나 | 일부(초기 매복, 마지막 원정). 대부분은 정보와 정찰 |
| 외국이 가문을 필요로 한 이유 | 감응자 없이는 숨은 무리를 찾지 못했고, 가문만이 흩어진 감응자들을 조직하고 해석의 말을 가졌다 |
| 성과가 가문의 나라로 돌아온 경로 | 갑의 왕실이 정보를 동맹의 값으로 씀 → 갑의 위상. 가문은 갑에서 작위와 고원 관리권, 외국에서 훈장과 땅 |
