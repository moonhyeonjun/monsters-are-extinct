## 0. 결론 먼저

- **인과 하나:** 변이의 비율(세기) → 평형 감각이 낮은 진동에 예민해짐 → 아이 때는 자율신경이 끌려감(붉은 물결 → 멈춤 → 깊은 잠) → 자라며 반사가 눌림 → 어른은 받되 휩쓸리지 않아 해석할 수 있음.
- **세기와 증상:** 비율이 높을수록 약한 신호에도 깊은 단계까지 간다. 본가의 딸들이 가장 위험했고, 가문은 그것을 ‘시련’이라 불렀다.
- **판별 절차(대토벌):** 가문의 ‘딸의 책’(어머니에서 딸로 이어진 기록)과 교단 등록부의 어머니 이름으로 후보 집안을 좁힌 뒤, **사로잡은 환류종을 우리에 실어 마을을 도는 ‘승전 행렬’**에서 구경하는 여자아이들의 얼굴을 지켜봤다. 붉게 물든 아이가 표시되었다.

## 1. 검증 항목

| 항목 | 답(후보) |
|---|---|
| 여성 감응자의 아동기 반응 | 붉은 물결(박자 맞춘 홍조와 따라가는 숨), 멈춤(박동 쪽을 향해 굳음, 창백한 입술과 손끝 — 산소 부족이 아님), 깊은 잠(맥과 숨이 느려지고 몸이 식음, 신호에서 데리고 나오면 몇 시간 안에 깸) |
| 강한 감응과 심한 증상 | 같은 원인(비율). 강한 아이일수록 더 먼 신호에, 더 깊은 단계로 |
| 직계·먼 후손의 전형적 차이 | 직계(본가가 고른 줄): 한 개체 곁에서도 멈춤, 무리 곁에서 깊은 잠. 먼 후손 대부분: 무리 곁에서 붉은 물결 정도. 드물게 먼 후손도 직계만큼 |
| 반응을 일으키는 신호 | 살아 있는 개체의 기관 수축. 갈이 중이라 기관이 없는 개체는 신호가 없음. 갓 벗은 기관은 신호를 내지 않음(살아 있는 조직이 아님) |
| 반응이 가장 강한 시기 | 대략 네 살에서 열 살 |
| 사춘기 이후 줄어드는 이유 | 평형 감각이 자율신경을 흔드는 반사를 뇌가 누르는 힘이 자람(멀미가 나이와 함께 주는 것과 같음) |
| 어른이 탐지·해석할 수 있는 이유 | 받는 감각은 그대로. 훈련으로 결(쉼·긴장·갈이의 시작과 끝·이동 채비, 개체 수, 방향)을 읽음 |
| 감응자가 아닌데 오인되는 경우 | 열꽃, 군중 속의 실신, 추위로 파래진 입술, 간질. 승전 행렬의 혼잡과 공포 속에서 많은 아이가 잘못 표시됨 |
| 강한 감응자의 실제 위험 | 아이 때 깊은 잠이 추위·물·방치와 겹치는 것. 어른이 되어도 강제로 오래 신호 곁에 두면 어지럼·구토·탈진, 반복되면 오래가는 평형 장애 |
| 강제 사용의 피해 | 아래 §3 |

## 2. 판별 절차의 변화

| 시기 | 장소와 방법 | 비용과 오류 |
|---|---|---|
| 공존 시대 | 판별이 아니라 낙인: 무리 철에 앓는 딸들의 집 | 가난한 고원 집에 낙인이 몰림 |
| 대토벌 초기(자국) | 가문의 ‘딸의 책’으로 후보 집안을 찾아, 군이 잡아 둔 개체 곁에서 시험 | 시험받은 아이의 깊은 잠, 추위 |
| 중기(연합) | **승전 행렬:** 사로잡은 개체를 우리에 실어 마을과 도시를 돌며 구경시킴. 군중 속의 감응자 여자아이와 여자를 지켜보는 가문의 관찰자. 교단 등록부의 어머니 이름과 대조 | 잘못 표시된 아이들. 행렬은 각국의 허가가 필요했음(을·병에서는 그 나라 관리가 함께) |
| 후기(정보) | 행렬이 줄고, 이미 모은 사람들을 씀 | — |
| 멸종 선언 이후 | 살아 있는 개체가 있는 곳은 마지막 집결지뿐 → 본가의 딸과 입양할 아이만 그 가장자리에서 시험(의례로 포장) | 바깥의 후손은 찾을 수 없음 |

## 3. 대토벌 중 강제 사용의 피해

| 쓰임 | 피해 |
|---|---|
| 무리 곁의 정찰 | 강한 사람일수록 멈춤에 가까운 상태로 몇 시간씩 버팀 → 어지럼과 구토, 넘어짐 |
| 집결지 가까이 두기(갈이의 시작과 끝을 알리게 함) | 깊은 잠의 위험, 추위 속 사망 |
| 포획 개체 곁의 연구 보조 | 날마다 반복되는 노출 → 오래가는 평형 장애 |
