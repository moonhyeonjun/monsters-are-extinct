# 세계의 세력과 국제 정치·경제 — 관계망 초안 `[P 후보]` `[작가 전용]`

> **[거절 · 2026-10-30 · P결정-006]** ‘비워진 땅’과 완충지 분할 조약을 축으로 한 정치 구조는 채택되지 않았다. 세력표도 새 설계의 전제로 쓰지 않는다. 새 후보는 [polity.md](polity.md), 종교는 [faith.md](faith.md).

> 상태: **P 설계 후보 · 미승인 · 정본 아님.** 작성 2026-10-30(3단계). 이전 세력표 [factions-v2.md](factions-v2.md)는 [보류] 상태 그대로 두고, 이 문서가 새 출발점이다.
> 작가 요구([P결정-005](../p-canon/decisions.md) E): 세계를 한 가문의 배경으로 설계하지 않는다. 주변 국가, 다른 귀족 가문, 지방 세력, 연구기관, 상업 조직, 지역 공동체가 각자 목적과 갈등을 가진 독립 세력이어야 한다. 모두 악역이거나 가문을 폭로하려는 사람들이어서는 안 된다.
> 이름: 국가·가문·기관 이름은 정하지 않는다. 아래 이름은 모두 **기능을 설명하는 임시 표기**다. W의 국가와 지역(하벨, 세르딘, 라스텐 등)은 참고일 뿐 P를 구속하지 않는다.

## 0. 결론 먼저

- **열 세력으로 시작한다.** 지시서의 유형 열 가지를 겹치는 기능끼리 묶었다(영웅 가문을 경쟁자로 보는 세력 = 옛 무가, 가문 덕에 이익을 본 가문 = 운송·공사 상가).
- **세계의 축은 ‘비워진 땅’이다.** 대토벌은 괴물을 없앤 전쟁이자 **무리의 땅(완충지)을 사람의 땅으로 바꾼 전쟁**이었다. 그 땅의 분할·개간·철도·복원을 두고 세력들이 다툰다. 가문의 비밀은 이 다툼 한가운데 떨어지는 폭탄이지, 다툼의 이유가 아니다.
- **멸종 선언은 가문만의 거짓이 아니었다.** 두 나라의 완충지 분할 조약이 ‘괴물 위협의 소멸’을 국경 확정의 조건으로 두었다. 본국 정부도 선언이 필요했고, 일부 관료는 의심하면서도 서둘렀다. 가문은 그 필요에 맞춰 마지막 원정을 내놓았다. **한 가문이 세계를 조작한 것이 아니라, 여러 세력의 필요가 한 거짓 위에서 맞아떨어졌다.**
- **공개가 곧 보호가 아니다.** 대토벌 시대의 ‘괴물 처리 규정’이 아직 폐지되지 않았고, 살아 있는 개체는 최고의 상품이며, 두 나라는 조약을 다시 다툴 것이다.

## 1. 세력별 설계

### 세력 1. 본국 왕실과 정부 (봉인 구역을 가진 나라)

| 항목 | 설계(후보) |
|---|---|
| 기원 | 대토벌 전엔 여러 영지의 느슨한 왕국. 대토벌을 공식화하며 군과 세금을 한데 모아 중앙 왕권을 세움 |
| 자산·권한 | 봉인 구역의 소유권, 관리 위임 칙허, 멸종 선언의 공식 주체, 완충지 대부분 |
| 경제적 이해 | 토벌 채권의 상환(아직 다 갚지 못함), 개간지 세수, 철도·광산 허가 |
| 문화·가치 | 대토벌 승리가 나라의 정체성. 기념일, 교과서, 영웅 서사 |
| 대토벌 당시 | 주도국 |
| 선언에 대한 태도 | 국가의 업적이자 국경의 법적 근거. 뒤집히면 국내 위신과 조약이 함께 무너짐 |
| 가문과의 관계 | 공신이자 견제 대상. 관리 위임 갱신이 왕실의 지렛대. 가문이 너무 커지는 것을 경계 |
| 아르바넬 지식 | 공식적으로 없음. 고위 관료 일부는 선언 당시 ‘서둘렀다’는 것을 앎(의심했지만 묵인한 기록) |
| 협력·대립 | 연합국과 국경·채권으로 긴장. 옛 무가와 상가를 저울질. 기록원을 통해 서사를 지킴 |
| 할 수 없는 일 | 선언을 공개적으로 철회(조약과 위신), 봉인 구역에 직접 들어가 관리(전문가 없음) |
| 독립 목표 | 재정 안정, 철도로 나라 묶기, 연합국과의 국경 확정 유지 |

### 세력 2. 연합국 (대토벌을 함께한 인접국)

| 항목 | 설계(후보) |
|---|---|
| 기원 | 완충지 반대편의 나라. 무리의 땅과 맞닿아 대토벌에 군과 돈을 보탬 |
| 자산·권한 | 국경 산맥의 반대편 사면(봉인 구역 산 너머 포함 후보), 광산, 철도 기술 |
| 경제적 이해 | 산을 뚫는 철도와 광산. 바다로 나가는 길 |
| 문화·가치 | 실용과 기술. 대토벌은 ‘같이 피 흘렸는데 땅은 본국이 가져간 전쟁’으로 기억 |
| 대토벌 당시 | 공동 참여. 비용 분담에 비해 받은 땅이 적음 |
| 선언에 대한 태도 | 조약상 필요했으니 받아들였지만, 분할 비율엔 지금도 불만 |
| 가문과의 관계 | 가문의 공로가 본국 몫을 키운 명분이 되었다고 봄. 경계 |
| 아르바넬 지식 | 없음. 국경 산맥 쪽 측량에서 ‘이상한 흔들림’을 기록한 기술자가 있을 수 있음 |
| 협력·대립 | 복원 산업 연합에 자본을 대며 기술 경쟁. 본국과는 국경 공사 문제로 대립 |
| 할 수 없는 일 | 본국 영토 안의 봉인 구역 조사, 조약을 일방으로 깨기 |
| 독립 목표 | 산 너머 철도 완공, 조약 재협상의 명분 찾기 |

### 세력 3. 변경 지방 (대토벌의 전장, 옛 집결지들이 있던 땅)

| 항목 | 설계(후보) |
|---|---|
| 기원 | 공존 시대에 무리의 길과 집결지 곁에서 살던 사람들의 땅. 대토벌 뒤 본국에 편입된 자치 지방(후보) |
| 자산·권한 | 지방 의회와 자치 관습, 옛 집결지 터, 공존 시대의 구전 |
| 경제적 이해 | 땅 되살리기. 집결지가 무너지며 솟던 샘이 멎어 하류 습지가 마르고 농업이 쇠퇴함 |
| 문화·가치 | 공존의 기억과 피해의 기억이 함께 있음. ‘괴물’보다 ‘무리’라는 옛말이 남음 |
| 대토벌 당시 | 징발과 전장, 학살의 현장. 일부는 토벌에 앞장섰고 일부는 무리를 숨겼음 |
| 선언에 대한 태도 | 복잡함. 피해 보상을 받으려면 ‘괴물의 피해’가 필요하고, 땅을 살리려면 ‘사람이 망가뜨렸다’는 진실이 필요함 |
| 가문과의 관계 | 가문이 자기 땅의 집결지를 군에 알려 준 일을 모름. 영웅으로 알지만 가깝지 않음 |
| 아르바넬 지식 | 없음. 다만 집결지가 어떤 곳이었는지에 대한 구전과 터의 흔적은 이들에게만 있음 |
| 협력·대립 | 복원 산업과 협력(사업비)하면서 대립(토지 수용). 본국 정부와 자치권 다툼 |
| 할 수 없는 일 | 옛 집결지를 혼자 되살리기(돈과 기술 부족), 본국 법을 거스르기 |
| 독립 목표 | 물길과 습지의 회복, 자치권, 피해의 공식 인정 |

### 세력 4. 옛 무가 (영웅 가문의 부상으로 밀려난 귀족)

| 항목 | 설계(후보) |
|---|---|
| 기원 | 대토벌 초기 군을 지휘한 명문 무가. 봉인 구역 일대가 원래 그 가문의 사냥터·여름 목초지였을 수 있음(후보) |
| 자산·권한 | 상원 의석, 군 안의 인맥, 옛 영지 문서와 지도 |
| 경제적 이해 | 줄어든 영지와 군 납품 수입의 회복 |
| 문화·가치 | 무공과 명예. 감응자를 ‘전장에 끌려 나온 병자’로 보던 옛 시선이 남음 |
| 대토벌 당시 | 초기 주력. 수색이 감응자 중심으로 바뀌며 지휘권이 영웅 가문 쪽으로 넘어감. 공의 상당 부분을 빼앗겼다고 여김 |
| 선언에 대한 태도 | 지지(자기 조상의 공도 걸려 있음) |
| 가문과의 관계 | 오랜 경쟁자. 혼인으로 화해하려던 시도도 있었음 |
| 아르바넬 지식 | 없음. 옛 지도에 봉인 구역 분지의 샘과 ‘울림의 해’ 기록이 있을 수 있음(단서) |
| 협력·대립 | 운송 상가와 계약 다툼. 왕실 안에서 가문의 관리 위임 갱신을 문제 삼을 수 있는 세력 |
| 할 수 없는 일 | 증거 없이 가문을 공격(명예 훼손, 반역 의심) |
| 독립 목표 | 가문의 재정·군사적 위상 회복, 옛 영지 일부의 반환 |

### 세력 5. 운송·공사 상가 (가문 덕에 이익을 본 가문)

| 항목 | 설계(후보) |
|---|---|
| 기원 | 대토벌의 군수 운송과 토벌 채권으로 귀족이 된 상인 가문 |
| 자산·권한 | 강과 길의 운송망, 공사 인력, 토벌 채권의 큰 몫 |
| 경제적 이해 | 감시소 물자 납품과 둑·수문 공사의 독점 계약. 철도 사업 진출 |
| 문화·가치 | 묻지 않는 것이 거래의 조건 |
| 대토벌 당시 | 군수로 부를 쌓음. 가문과 손잡고 성장 |
| 선언에 대한 태도 | 지지. 개간과 철도의 시대가 열림 |
| 가문과의 관계 | 오랜 동업자. 둑이 무엇을 막는지 일부 감독은 짐작함 |
| 아르바넬 지식 | 부분적(공사 감독, 설계도). 무리가 살아 있다는 것을 확신하지는 않음 |
| 협력·대립 | 옛 무가와 경쟁. 연합국의 철도 사업과 경쟁(같은 노선을 두고). 복원 산업에 투자 |
| 할 수 없는 일 | 가문의 계약 없이 봉인 구역 일을 계속하기, 비밀을 팔기(자기도 공범) |
| 독립 목표 | 철도와 복원 산업으로 사업을 옮겨 가문에 기대지 않는 상가가 되는 것 |

### 세력 6. 자유 학회 (독립 연구기관)와 측정 기술자들

| 항목 | 설계(후보) |
|---|---|
| 기원 | 멸종 선언 때 ‘조사하지 않은 곳을 없다고 쓸 수 없다’는 의견서를 낸 학자들의 흐름이 왕립 기관 밖에서 모인 학회(후보) |
| 자산·권한 | 학술지, 표본 소장, 새 측정 기술(멀리서 땅 흔들림을 기록하는 장치) |
| 경제적 이해 | 후원자(복원 산업, 연합국 자본)에 기댐 |
| 문화·가치 | 기록과 증거. 대토벌을 다시 읽으려는 세대 |
| 대토벌 당시 | 없음(뒤에 생김). 뿌리는 반대 학자 |
| 선언에 대한 태도 | 회의적이지만 증거가 없음 |
| 가문과의 관계 | 가문은 후원자이기도 함(학회 안에 가문의 돈을 받은 사람이 있음) |
| 아르바넬 지식 | 없음. 하류 강의 박자, 출처 불명의 뼈 같은 조각을 따로따로 가짐 |
| 협력·대립 | 왕립 기록원과 역사 해석 논쟁. 복원 산업과는 후원과 독립 사이의 줄다리기 |
| 할 수 없는 일 | 봉인 구역 출입, 법적 조사권 |
| 독립 목표 | 새 측정 기술의 인정, 대토벌 역사의 재해석 |

### 세력 7. 왕립 기록·기념원 (기록과 공식사)

| 항목 | 설계(후보) |
|---|---|
| 기원 | 대토벌 공식사를 엮고 공훈록과 기념 의례를 맡으려 세운 기관 |
| 자산·권한 | 국가 기록의 보관과 열람 허가, 기념비와 의례, 교과서 감수 |
| 경제적 이해 | 왕실 예산 |
| 문화·가치 | 국가 서사의 수호. 그러나 기록관 개인은 기록의 정확성을 중시함 |
| 대토벌 당시 | 기록 편찬. 첫 번째 침묵을 ‘병들어 조용해졌다가 미쳐 돌아옴’으로 기록 |
| 선언에 대한 태도 | 선언을 기록한 당사자. 지킬 이유가 큼 |
| 가문과의 관계 | 가문의 공훈록을 보관. 가문이 고쳐 쓴 족보도 여기에 있음 |
| 아르바넬 지식 | 없음. 그러나 연례 보고의 베낀 문장, 마지막 원정 보고서의 판본 차이, 옛 ‘밤병 집’ 명부가 모두 여기에 있음(본인들이 그 뜻을 모름) |
| 협력·대립 | 자유 학회와 논쟁. 감응자 공동체의 옛 명부 공개 요구와 대립 |
| 할 수 없는 일 | 기록을 없애기(규정상 폐기 금지), 현장 조사 |
| 독립 목표 | 기념 사업의 유지, 기록 보존 |

### 세력 8. 복원 산업 연합 (상업)

| 항목 | 설계(후보) |
|---|---|
| 기원 | 멸종 뒤 생긴 산업들의 연합: 유골과 표본 거래, 박제·전시, 땅 되살리기 사업, 복원 박람회 |
| 자산·권한 | 자본(상가·연합국 자본 포함), 전시관과 수장고, 변경 지방의 사업권 |
| 경제적 이해 | ‘사라진 생태’를 파는 것. 살아 있는 개체는 최고의 상품이자 산업의 판도를 바꿀 것 |
| 문화·가치 | 진보와 회복의 언어를 쓰지만 이윤이 움직임. 내부엔 진심으로 생태를 되살리려는 사람도 있음 |
| 대토벌 당시 | 없음(뒤에 생김). 전리품 시장이 앞선 형태 |
| 선언에 대한 태도 | 선언이 산업의 바탕(멸종했으니 복원이 필요함) |
| 가문과의 관계 | 가문의 이름을 광고에 씀. 가문은 투자자이기도 함 |
| 아르바넬 지식 | 없음. 봉인 구역을 ‘마지막 땅의 남은 재료’로 보고 출입을 요구할 수 있음 |
| 협력·대립 | 변경 주민과 토지 문제, 자유 학회와 연구 독립 문제, 연합국과 본국 자본 사이의 경쟁 |
| 할 수 없는 일 | 법을 바꾸기, 봉인 구역에 들어가기 |
| 독립 목표 | 옛 집결지 터를 ‘복원 공원’으로 만드는 사업, 표본 시장의 독점 |

### 세력 9. 봉인 구역 둘레 마을과 지방 관청

| 항목 | 설계(후보) |
|---|---|
| 기원 | 봉인령으로 분지와 출구 바깥 땅에서 옮겨 간 마을들 |
| 자산·권한 | 감시소 일자리와 납품, 지방 관청의 세금, 민간 신앙 |
| 경제적 이해 | 일자리 유지와 땅 반환이 서로 부딪힘. ‘빈 땅’ 관리로 경작 제한 |
| 문화·가치 | ‘골이 숨을 쉰다’, ‘땅이 운다’, ‘골이 아이를 부른다’. 두려움과 경외 |
| 대토벌 당시 | 원래의 땅을 잃음 |
| 선언에 대한 태도 | 무관심에 가까움. 선언보다 봉인령이 그들의 삶을 바꿈 |
| 가문과의 관계 | 고용주. 충성과 원한이 섞임. 마을 아이가 ‘장학’으로 가문에 간 집도 있음 |
| 아르바넬 지식 | 부분적. 위험의 날짜, 불 띠, 둑, 밤걸음 아이. 무리가 살아 있다고 확신하는 사람은 적음 |
| 협력·대립 | 지방 관청은 땅을 되찾아 세수를 늘리고 싶고, 마을 사람은 일자리를 잃고 싶지 않음 |
| 할 수 없는 일 | 봉인 구역에 들어가기, 국가에 직접 청원하기(지방 관청을 거쳐야 함) |
| 독립 목표 | 빈 땅의 일부 경작 허가, 아이들의 안전 |

### 세력 10. 가문 밖 감응자 공동체 (옛 ‘밤병 집’의 후손)

| 항목 | 설계(후보) |
|---|---|
| 기원 | 박해 때 흩어져 산간과 변경에 숨어 산 감응자 집안들. 일부는 변경 지방에 섞여 삶 |
| 자산·권한 | 공존 시대의 무리 길과 노래, 밤 문 규정의 기억, 서로를 알아보는 옛말 |
| 경제적 이해 | 없음. 평범한 생업 |
| 문화·가치 | ‘우리 집엔 옛날 밤병이 있었다’. 수치와 자부가 섞인 기억 |
| 대토벌 당시 | 아이를 빼앗기고(밤 길잡이), 어른은 징집됨. 공은 가문의 지휘 아래 묻힘 |
| 선언에 대한 태도 | 안도. ‘이제 우리 아이들은 앓지 않는다’ |
| 가문과의 관계 | ‘우리 중에서 올라가 우리를 버린 집’. 가문에 아이를 잃은(입양된) 집도 있음 |
| 아르바넬 지식 | 없음. 그러나 봉인 구역 둘레에서 아이가 밤에 걸어 나간다는 이야기를 들으면 그 뜻을 알아챌 수 있는 유일한 사람들 |
| 협력·대립 | 왕립 기록원에 옛 명부의 정정을 요구. 변경 지방과 문화적 연대 |
| 할 수 없는 일 | 자기 정체를 증명(증상이 없음), 공개적으로 조직하기(옛 낙인) |
| 독립 목표 | 낙인 없이 사는 것, 옛 이야기를 지키는 것 |

## 2. 관계망 요약

| | 협력하는 이유 | 대립하는 이유 |
|---|---|---|
| 본국 ↔ 연합국 | 조약 유지, 무역 | 완충지 분할 비율, 국경 산맥의 공사 |
| 본국 ↔ 변경 | 세수, 안정 | 자치권, 피해 인정 |
| 본국 ↔ 영웅 가문 | 공신, 봉인 관리 | 가문의 비대화, 위임 갱신 |
| 옛 무가 ↔ 영웅 가문 | 혼인 동맹의 역사 | 공과 지휘권, 옛 영지 |
| 옛 무가 ↔ 운송 상가 | — | 군 납품·공사 계약 |
| 운송 상가 ↔ 연합국 | 투자 | 같은 철도 노선 |
| 자유 학회 ↔ 기록원 | 기록의 정확성 | 역사 해석, 열람권 |
| 복원 산업 ↔ 변경 | 땅 되살리기 사업비 | 토지 수용, 터의 상품화 |
| 복원 산업 ↔ 자유 학회 | 후원 | 연구의 독립 |
| 둘레 마을 ↔ 지방 관청 | 같은 지역 | 일자리 vs 땅 |
| 감응자 공동체 ↔ 기록원 | — | 옛 명부의 정정 |
| 감응자 공동체 ↔ 변경 | 공존의 기억 | — |

## 3. 가문 없이도 일어나는 갈등 (예시)

1. **산 너머 철도:** 연합국의 터널 공사가 국경 산맥을 뚫는다. 본국은 국경 문제로 항의하고, 운송 상가는 경쟁 노선을 밀고, 변경은 물길이 또 바뀔까 두려워한다(첫 만남 추천안의 계기, [first-encounter.md](first-encounter.md)).
2. **복원 공원:** 복원 산업이 변경의 옛 집결지 터를 ‘복원 공원’으로 사들이려 한다. 습지를 되살리겠다는 약속과 토지 수용, 공존 시대의 터를 구경거리로 만드는 것에 대한 반발.
3. **출처 불명의 뼈:** 자유 학회가 박물관 수장고의 뼈 하나가 선언 뒤의 것이라고 주장한다. 기록원은 출처 문서를 내놓지 않고, 복원 산업은 그 뼈의 시장 가치를 계산한다.
4. **둘레 마을의 땅 반환 청원:** 지방 관청은 땅을 되찾으려 하고, 마을 사람 절반은 감시소 일자리를 잃을까 반대한다.
5. **옛 명부:** 감응자 공동체가 기록원의 ‘밤병 집’ 명부 정정을 요구한다. 기록원은 폐기 금지 규정으로 거절하고, 옛 무가는 이를 정쟁에 쓴다.

## 4. 국제 정치·경제의 인과

| 질문 | 답(후보) |
|---|---|
| 대토벌의 비용은 누가 냈나 | 본국 왕실(전쟁세와 토벌 채권. 채권의 큰 몫을 운송 상가가 쥠), 연합국(군과 돈), 변경(징발과 전장, 아이와 사람). 채권은 아직 다 갚지 못해 본국 재정의 짐 |
| 국경과 영토 | 두 나라 사이의 무리의 땅(완충지)이 비워져 분할됨. **분할 조약은 ‘괴물 위협의 소멸’을 국경 확정의 조건으로 둠** → 멸종 선언이 국경의 법적 근거. 본국이 가문의 공로와 군 기여를 명분으로 대부분을 가져감 |
| 작위와 관리권으로 손해 본 쪽 | 옛 무가(지휘권과 영지 일부), 둘레 마을(땅), 가문 밖 감응자(공로), 연합국(분할 몫), 군 지휘부(공의 귀속) |
| 쇠퇴한 산업 | 토벌 용역·성벽 경비·용병, 전리품 시장(초기 호황 뒤 쇠퇴), 무리 길을 따라 하던 목축·채집, 집결지의 샘에 기대던 하류 농업 |
| 생겨난 산업 | 완충지 개간, 철도와 광산(괴물 없는 산), 기념 관광, 유골·표본 시장, 복원 산업 |
| 복원 산업의 주도자 | 운송 상가의 자본 + 자유 학회의 기술 + 변경의 땅 되살리기 사업 + 연합국 자본. 하나의 주인이 없는 연합이라 내부 경쟁이 큼 |
| 살아 있다는 것을 알게 되면 | 본국: 숨기자는 쪽과 가문을 처벌하고 봉인 구역을 국유화하자는 쪽으로 갈림. 연합국: 조약 재협상, 국제 조사단 요구, 몰래 개체 확보. 변경: 옛 집결지 복원에 개체를 요구. 복원 산업: 전시·번식 사업. 자유 학회: 연구 접근권. 기록원: 공식사 방어. 둘레 마을: 공포와 일자리 걱정. 옛 무가: 가문 몰락의 기회. 감응자 공동체: 자기 아이들이 다시 앓게 될 것에 대한 두려움 |
| 공개가 곧 보호가 아닌 이유 | ① 대토벌 시대의 **괴물 처리 규정**(발견 즉시 처치 의무)이 아직 폐지되지 않았다 — 멸종했으니 아무도 폐지할 필요를 못 느꼈다. 공개되는 순간 법은 사살을 요구한다 ② 살아 있는 개체의 시장 가치 ③ 두 나라의 확보 경쟁과 조약 분쟁 ④ 첫 번째 침묵을 기억하는 대중의 공포 ⑤ 아르바넬 생태가 사람의 관리에 기대고 있어 갑자기 열면 무리가 죽는다([arbanel-ecology.md](arbanel-ecology.md) §6) ⑥ 보호할 법과 기관이 없다(복원법은 ‘멸종한’ 생태를 다룸) |

## 5. 작가가 고를 것

1. ‘비워진 땅(완충지)’과 분할 조약의 ‘괴물 위협 소멸’ 조항을 세계 정치의 축으로 둘지
2. 열 세력 가운데 줄이거나 합칠 것
3. 대토벌 시대의 괴물 처리 규정이 아직 살아 있다는 설정을 쓸지(공개 = 사살 의무)
