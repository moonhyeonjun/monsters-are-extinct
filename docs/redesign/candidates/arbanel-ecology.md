# 아르바넬의 비정상 생태 — 쉬지 못한 집결지 `[P 후보]` `[작가 전용]`

> 상태: **P 설계 후보 · 미승인 · 정본 아님.** 작성 2026-10-30(3단계).
> 작가 결정([P결정-005](../p-canon/decisions.md)): 재동기화·번식 모델 유지(원리 미확정). 아르바넬은 정상 집결 기능을 유지할 가능성이 있는 마지막 장소이자 마지막 번식 집단의 터. 장기 상시 집결은 **대토벌과 가문의 관리가 만든 비정상 상태**. 새 요구 B(경이로우면서 원인이 실제 생태와 이어질 것), C(본래 떠나야 하는데 떠나지 못하고 계속 나가려 함).
> 작업 가정(원리 미확정): 집결형 종의 환류기관은 낮은 박동을 매질에 남기고, 주변의 **열과 물을 끌어들이고 내보내는 작용**을 한다. 혼자 오래 지내면 박동이 어긋나고, 동족과 진동을 모으는 지형 속에서 다시 맞춘다([gathering-ecology.md](gathering-ecology.md)). 종 이름, 종의 수, 주기의 길이는 정하지 않는다.
> 탈출 방지 구조는 [containment.md](containment.md).

## 0. 결론 먼저

- **핵심 원리: 아르바넬은 ‘쉬어야 할 땅이 두 세기 가까이 쉬지 못한 결과’다.** 정상의 집결지는 수십 년에 한 번 몇 주에서 몇 달 붐비고 나머지 세월은 비어 회복한다. 아르바넬은 대토벌 말기 이후 한 번도 비지 못했다. 겹친 박동과 열·물의 작용이 끊이지 않고 쌓여, 바깥 상식으로는 설명되지 않는 지형·물·식생·빛이 생겼다.
- **경이 현상 후보 여섯:** ① 숨 쉬는 샘과 계단 웅덩이 ② 겨울과 봄이 몇 걸음 사이에 붙은 골 ③ 층층이 떠서 오르내리는 안개 ④ 저절로 무늬를 그리는 모래와 우는 돌 ⑤ 박자에 맞춰 깜박이는 물빛 ⑥ 서로의 박자에 물든 종들.
- **낙원이 아니다:** 먹이 부족, 습한 병, 좋은 골을 둔 다툼, 번식률 저하, 쉬지 못하는 쇠약. 그러나 모든 현상이 재난은 아니다. 꽃과 빛과 무늬는 그냥 아름답다.
- **떠나려는 이유:** 정상 생태에서는 맞춤과 번식이 끝나면 **겹친 박동이 괴로워져 흩어지는 충동**이 생긴다. 아르바넬의 무리는 그 충동이 꺼지지 않은 채 갇혀 있다. 그래서 늘 가장자리를 밀어 댄다.

## 1. 정상 집결·분산 과정 (후보)

| 단계 | 개체에게 일어나는 일 | 집결지에 일어나는 일 | 사람에게 보였던 것(공존 시대) |
|---|---|---|---|
| 1. 흩어진 삶 | 각자의 땅에서 수십 년. 박동이 조금씩 어긋남 | 비어 있음. 물과 식생이 원래대로 돌아감 | 평소의 무리 |
| 2. 채비 | 어긋남이 쌓여 몸이 불편해짐. 무리 안에서 박동이 서로 끌려 비슷한 때 들뜸 | — | 무리가 들뜨고 낯설어짐. 감응자 아이들이 앓기 시작 |
| 3. 이동 | 길을 아는 늙은 개체를 따라 옛 길로 몇 주~몇 달 | — | 무리가 사람 땅을 가로지름. 밤걸음 아이들 |
| 4. 도착과 맞춤 | 진동을 모으는 지형 속에서 동족과 박동을 맞춤. **가장 약하고 불안정한 때** | 샘이 박자에 맞춰 솟고, 땅이 울리고, 안개가 낌 | 다가가면 안 되는 땅. 감응자는 쓰러짐 |
| 5. 번식 | 맞춰진 상태에서 짝짓기·산란·출산(종마다) | 물가와 따뜻한 골이 번식 터가 됨 | — |
| 6. 어린 개체의 첫 맞춤 | 어린 개체가 무리의 박동에 처음 맞추고, 지형의 울림과 길을 몸에 새김 | — | — |
| 7. 회복 | 몇 주 먹고 쉼 | 먹이가 줄기 시작 | — |
| 8. **흩어짐의 충동** | 맞춘 뒤에는 동족의 겹친 박동이 오히려 괴롭게 느껴짐(과밀 신호). 먹이도 줄어 무리는 각자의 땅으로 흩어짐 | 무리가 빠져나감 | 무리가 돌아옴. 아이들의 앓음이 멎음 |
| 9. 집결지의 휴식 | — | **수십 년 비어 회복.** 솟던 샘이 가라앉고, 데워진 땅이 식고, 식생이 원래 계절로 돌아감 | 조용한 땅(가문 조상이 살 수 있었던 이유, [arbanel-survival.md](arbanel-survival.md) §1) |

- **8단계가 열쇠다.** 흩어짐의 충동은 무리가 집결지를 다 먹어 치우고 망가뜨리기 전에 떠나게 하는 장치다. 이 충동이 있어서 집결지는 휴식을 얻고, 다음 세대도 그 땅을 쓸 수 있다.
- 종마다 단계의 길이와 순서는 다를 수 있다(생태 설계에서 정함).

## 2. 아르바넬은 어떻게 비정상이 되었나

| 순서 | 원인 | 결과 |
|---|---|---|
| 1 | 대토벌이 다른 집결지와 무리들의 원래 땅을 무너뜨림 | 아르바넬에 평소보다 많은 종과 무리가 몰림(다른 집결지를 잃은 무리의 일부가 길을 바꿈) |
| 2 | 대토벌 말기, 무리가 흩어져 나가는 길목마다 토벌대가 기다림 | 나간 무리가 죽거나 되돌아옴. 무리가 흩어지지 못함 |
| 3 | 가문이 은폐와 관리를 위해 출구 골짜기를 막고 바깥을 비움([containment.md](containment.md)) | 흩어짐 자체가 구조적으로 막힘 |
| 4 | 가문이 분지 안에 먹이를 보충 | 굶어서 나가는 압력이 줄어 무리가 더 오래 머묾 |
| 5 | 아르바넬에서 태어난 세대는 바깥 길을 모름 | 흩어짐의 충동은 있는데 갈 방향이 없음 |
| 결과 | 두 세기 가까이 ‘4~8단계’가 끝나지 않는 상태 | 박동·열·물의 작용이 쉬지 않고 쌓임 → §3의 현상들 |

- 그래서 아르바넬은 **정상 집결 기능을 되찾을 가능성**이 있다. 흩어짐이 다시 허락되고, 무리가 돌아갈 땅이 있고, 몇십 년 비어 쉴 수 있다면. 이것이 마지막 질문(해방)의 생태적 조건이다.

## 3. 경이 현상 여섯

### 현상 1. 숨 쉬는 샘과 계단 웅덩이 (물)

| 항목 | 설계(후보) |
|---|---|
| 독자가 보는 장면 | 분지 바닥의 샘 수십 개가 하루 몇 번 **동시에** 부풀어 올랐다가 가라앉는다. 넘친 물이 비탈의 하얀 돌 턱을 넘어, 수십 층의 계단 웅덩이를 차례로 채운다. 가만히 서 있으면 물이 숨 쉬는 것처럼 보인다 |
| 일으키는 것 | 무리 전체의 겹친 박동이 지하수가 고인 바위층을 주기적으로 눌렀다 풀어 샘을 뿜게 한다(진동을 모으는 지형 + 물). 정상 집결 때도 있었지만 몇 주뿐이었다 |
| 장기 변화 | 두 세기 동안 쉬지 않고 넘친 물이 광물을 쌓아 **계단 웅덩이 지형**을 만들었다. 정상 집결지에는 이런 지형이 없다(한 번 쌓이다 휴식기에 깎임) |
| 생물에게 이익 | 늘 물이 있고, 웅덩이마다 수온이 달라 종마다 쓰는 웅덩이가 나뉨. 어린 개체가 지내는 얕은 웅덩이 |
| 생물에게 피해 | 무리의 박자가 흐트러지는 철엔 솟구침이 불규칙해져 웅덩이가 넘치거나 말라붙음. 광물이 쌓여 물길이 막힘 |
| 사람의 이용·오해 | 감시소는 수위 막대로 이 숨을 재어 ‘위험 기록’을 쓴다(진짜 기록). 둘레 마을: ‘골이 숨을 쉰다’. 바깥 학자들은 기록만 보고 ‘간헐천 지대’로 분류 |
| 바깥에 미치는 영향 | **하류 강의 수위가 하루 몇 번 아주 조금 오르내린다.** 하류 방앗간 사람들이 아는 ‘숨 쉬는 강’ — 측정 기술로 박자가 드러날 수 있는 단서 |
| 붕괴 조건 | 무리의 수가 줄면 숨이 얕아져 웅덩이가 마름. 무리가 흩어지면 몇 년에 걸쳐 숨이 멎고 계단은 휴식기의 침식을 받음(정상으로의 복귀이기도 함) |

### 현상 2. 겨울과 봄이 붙은 골 (식생·온도)

| 항목 | 설계(후보) |
|---|---|
| 독자가 보는 장면 | 한겨울, 서리가 내려앉은 은빛 숲을 몇 걸음 지나면 갑자기 발밑이 따뜻하고 꽃이 핀 풀밭이 나온다. 경계가 칼로 자른 듯하다. 같은 나무의 한쪽 가지에만 꽃이 핀다 |
| 일으키는 것 | 기관이 주변의 열을 끌어들이고 내보내는 작용. 무리가 오래 쉬는 골은 열을 받아 따뜻해지고, 열을 빼앗긴 바로 옆 골은 더 차가워진다. 종마다 열을 다루는 방향이 다르다(후보) |
| 장기 변화 | 사철 자라는 풀, 두 번 피는 꽃, 바깥에 없는 변종 군락. 서리 쪽엔 차가운 이끼만 남음. 계절의 시계를 잃은 식물 |
| 생물에게 이익 | 겨울 먹이와 쉼터. 정상 집결지의 짧은 기간엔 없던 혜택 |
| 생물에게 피해 | 쉬지 않고 자라 흙의 양분이 바닥남. 계절 신호가 사라져 일부 종의 번식 시기가 흐트러짐. 따뜻한 골을 두고 다툼 |
| 사람의 이용·오해 | 가문의 약초 정원(약재 가능성은 이점 체계 보류와 함께 판단). 바깥 전설: ‘저주받은 골에 겨울꽃이 핀다’ |
| 바깥에 미치는 영향 | 하류로 떠내려간 씨앗이 이상한 철에 꽃을 피움 → 약초상과 식물 수집가가 아는 단서 |
| 붕괴 조건 | 열 작용이 약해지면 하룻밤 서리로 군락 전체가 죽음. 무리가 떠나면 몇 해에 걸쳐 바깥과 같은 계절로 돌아감 |

### 현상 3. 층층이 떠서 오르내리는 안개 (안개·습도·빛)

| 항목 | 설계(후보) |
|---|---|
| 독자가 보는 장면 | 바람이 불어도 흩어지지 않는 안개가 분지 위에 서너 겹의 층으로 떠 있다. 층들은 아주 천천히, 함께 오르내린다. 해 질 녘엔 층 사이로 빛이 갈라져 여러 줄의 색 띠가 생긴다 |
| 일으키는 것 | 따뜻한 골과 차가운 골이 맞닿아 늘 김이 오르고, 찬 공기와 더운 공기가 분지에 갇혀 층을 이룬다. 무리의 박자에 맞춘 열의 들고남이 층을 들어 올렸다 내림 |
| 장기 변화 | 분지가 늘 습하고 그늘짐. 햇빛을 좋아하던 풀이 사라지고 이끼와 버섯이 늘어남 |
| 생물에게 이익 | 숨을 곳. 수분. 바깥 눈에 띄지 않음 |
| 생물에게 피해 | 습기로 인한 피부·기관의 병, 곰팡이. 햇빛 부족 |
| 사람의 이용·오해 | 바깥 초소는 안개 층의 높이로 위험 철을 기록. 둘레 마을: ‘흰 지붕’, 안개가 높이 서면 아이를 집에 들임 |
| 바깥에 미치는 영향 | 둘레 마을의 아침 안개, 서늘한 여름. 높은 산에서 내려다보면 분지 위에 늘 흰 덮개가 보임 |
| 붕괴 조건 | 열 작용의 균형이 깨지면 안개가 한꺼번에 무너져 내려 찬 안개가 출구 골로 쏟아짐(실제 위험, 흰 골 참사의 한 원인 후보) |

### 현상 4. 저절로 무늬를 그리는 모래와 우는 돌 (소리·진동·땅)

| 항목 | 설계(후보) |
|---|---|
| 독자가 보는 장면 | 넓은 돌판 위에 깔린 고운 모래가 저절로 움직여 동심원과 격자 무늬를 그렸다가, 박자가 바뀌면 지우고 다른 무늬를 그린다. 돌기둥에 손을 대면 소리라기보다 가슴으로 오는 낮은 울음이 느껴진다 |
| 일으키는 것 | 진동을 모으는 지형이 끊이지 않는 박동에 공명함. 판 위 모래가 진동의 마디에 모여 무늬가 됨(실제 물리 현상인 진동판 무늬와 같은 원리) |
| 장기 변화 | 쉬지 않는 울림이 지반에 미세한 금을 내고, 비탈을 느슨하게 함. 돌기둥이 진동에 깎여 홈이 패임 |
| 생물에게 이익 | 정상 집결에서 이 울림은 흩어진 무리가 서로를 찾고 박자를 맞추는 **신호망**이다 |
| 생물에게 피해 | 울림이 쉬지 않아 개체가 ‘꺼지지’ 못함(휴면·깊은 쉼을 하는 종에게 치명적). 흩어짐의 충동을 계속 자극함 |
| 사람의 이용·오해 | 감응자는 분지 가까이 가면 앓음(식별 기전과 연결, [sensing-identification-v2.md](sensing-identification-v2.md)). 감시소는 흔들림 막대로 기록. 둘레 마을: ‘땅이 운다’. 가문의 의례 장소가 무늬 돌판 앞일 수 있음 |
| 바깥에 미치는 영향 | 멀리서도 기록될 만한 아주 약한 땅 흔들림이 박자를 가짐 → **새 측정 기술의 단서**([seal-declaration-v4.md](seal-declaration-v4.md) §7) |
| 붕괴 조건 | 비탈의 산사태, 돌판의 균열. 무리의 박자가 둘로 갈라지면 무늬가 어지러워지고 울림이 서로 부딪쳐 땅이 크게 흔들림 |

### 현상 5. 박자에 맞춰 깜박이는 물빛 (빛·미생물)

| 항목 | 설계(후보) |
|---|---|
| 독자가 보는 장면 | 밤, 계단 웅덩이 수십 개가 한꺼번에 푸른빛으로 깜박인다. 샘이 숨을 쉴 때마다 빛의 고리가 웅덩이에서 웅덩이로 번진다. 분지 전체가 느린 맥박처럼 빛난다 |
| 일으키는 것 | 따뜻하고 늘 흔들리는 물에서 번성한, 흔들리면 빛을 내는 아주 작은 물속 생물(실제 바다의 발광 플랑크톤과 같은 원리). 샘의 박자가 물을 흔들 때마다 빛남 |
| 장기 변화 | 정상 집결지엔 휴식기에 사라지던 미생물이 두 세기 동안 쌓여 웅덩이마다 짙어짐 |
| 생물에게 이익 | 물속 먹이망의 바탕. 일부 작은 생물이 빛을 따라 모임 |
| 생물에게 피해 | 늦여름엔 지나치게 불어나 물속 숨이 모자라 물고기와 작은 생물이 떼로 죽음(냄새와 썩음의 철) |
| 사람의 이용·오해 | 안쪽 실무자들은 **빛의 세기로 무리의 기운을 가늠한다.** 해마다 조금씩 어두워지는 것을 알고 있다(쇠약의 지표). 바깥엔 보이지 않음 |
| 바깥에 미치는 영향 | 거의 없음. 하류로 흘러가면 빛을 잃음 |
| 붕괴 조건 | 샘의 숨이 약해지면 빛도 약해짐. 무리가 떠나면 몇 해 안에 꺼짐 |

### 현상 6. 서로의 박자에 물든 종들 (종간 상호작용·동물)

| 항목 | 설계(후보) |
|---|---|
| 독자가 보는 장면 | 몸집도 생김도 전혀 다른 두 종이 같은 걸음, 같은 숨으로 나란히 물을 마신다. 작은 종이 큰 종의 등이나 그늘에 붙어 겨울을 난다. 사슴과 새 같은 보통의 동물도 박자에 맞춰 물가로 내려온다 |
| 일으키는 것 | 정상 집결에선 종마다 쓰는 구역과 시기가 조금씩 달라 서로의 박자를 피한다. 아르바넬에선 여러 종이 두 세기 동안 같은 울림 속에 있어 **종의 고유 박자가 서로 끌려 비슷해졌다** |
| 장기 변화 | 바깥에 없던 종간 공생(열을 나누는 짝 관계). 보통의 동물(철새·사슴·박쥐)이 분지에 눌러앉아 겨울을 남 |
| 생물에게 이익 | 서로 기대어 겨울을 버팀. 다툼이 줄어드는 관계도 생김 |
| 생물에게 피해 | **종의 고유 박자가 흐려져, 바깥의 같은 종(떠도는 개체)과 다시 맞추기 어려워짐.** 번식 시기 혼선. 철새가 떠나지 않아 바깥의 철새 길이 바뀜 |
| 사람의 이용·오해 | 실무자들은 이를 ‘사이좋은 골’로 여겨 보호의 성과로 자랑함. 가문의 연구자는 박자가 섞이는 것을 우려함 |
| 바깥에 미치는 영향 | 인근 지역의 철새가 줄어듦(둘레 마을 사냥꾼과 농부가 아는 변화) |
| 붕괴 조건 | 한 종이 크게 줄면 기대던 다른 종도 무너짐 |

- **현상 6이 해방의 위험을 만든다:** 무리를 풀어 줘도 박자가 섞인 아르바넬 세대는 바깥 동족과 맞추지 못할 수 있다. 문을 여는 것만으로는 정상으로 돌아가지 않는다.

## 4. 밀집이 만든 문제 (재난만은 아닌 것)

| 문제 | 실제 | 이야기의 결 |
|---|---|---|
| 먹이 부족 | 분지의 풀과 물속 생물로는 모자라 가문이 겨울 먹이를 보충함. 먹이 보충이 무리를 붙잡는 끈이 됨 | 보호이자 사슬 |
| 질병 | 습기와 밀집으로 피부·기관의 병. 병든 개체를 격리하는 골이 있음 | 실무자의 손에서 죽어 가는 개체 |
| 서식지 다툼 | 따뜻한 골과 좋은 웅덩이를 두고 종 사이·종 안에서 다툼. 진 개체가 가장자리로 밀려나 **탈출을 가장 자주 시도함** | 첫 탈출 개체의 후보 |
| 번식 | 번식률이 해마다 조금씩 떨어짐. 어린 개체가 ‘정상 주기’를 겪어 보지 못함. 근친 | 시간이 없다는 압박 |
| 쇠약 | 쉬지 못해 수명이 줄고 늙은 개체가 빨리 지침 | 물빛이 어두워짐 |
| 아름다움 | 꽃, 빛, 무늬, 함께 걷는 종들은 재난이 아니다 | 경이와 공포를 함께 |

## 5. 바깥으로 새는 단서 (두 세기 동안 왜 몰랐나 포함)

| 단서 | 아는 사람 | 왜 진실에 닿지 못했나 |
|---|---|---|
| 숨 쉬는 강 | 하류 방앗간, 뱃사람 | 박자를 잴 도구가 없었음. ‘골의 숨’이라는 민간 해석 |
| 철 모르는 꽃씨 | 약초상, 식물 수집가 | 하류 강변은 ‘빈 땅’ 관리로 사람이 적음. 표본은 ‘변종’으로 분류됨 |
| 흰 지붕 안개 | 둘레 마을, 산사람 | 봉인 구역이라 들어가지 못함. 땅의 위험으로 공식 설명됨 |
| 박자 있는 땅 흔들림 | 아무도(지금까지) | 새 측정 기술이 생기기 전엔 기록 불가 |
| 철새 길의 변화 | 사냥꾼 | 다른 원인(개간·사냥)과 섞임 |
| 둘레 마을 아이의 밤걸음 | 둘레 마을 | ‘골이 아이를 부른다’는 이야기로 남음. 감시소가 조용히 파악함 |

## 6. 붕괴와 해방의 생태적 조건

- **그대로 두면:** 번식률 저하와 쇠약으로 수십 년 안에 한계(정확한 속도는 미정). 물빛이 꺼지는 것이 그 끝의 신호.
- **갑자기 열면:** 흩어짐의 충동대로 무리가 쏟아져 나가지만 돌아갈 땅이 없고, 길을 모르고, 바깥은 사람의 땅이다. 박자가 섞여 바깥 개체와 맞추지 못한다. 많은 수가 굶거나 죽임당할 수 있다. 하류의 숨 쉬는 강이 멎고 안개가 무너져 둘레 마을에도 피해.
- **정상으로 돌아가려면(후보):** 무리가 흩어질 땅(옛 집결지 터나 원래의 땅의 일부 회복), 단계적인 열림, 몇십 년의 휴식. 사람 사회의 협력이 필요하다 → 세력들의 이해관계가 이 질문에 걸림([world-powers.md](world-powers.md)).

## 7. 작가가 고를 것

1. ‘쉬지 못한 집결지’를 아르바넬 비정상 생태의 축으로 둘지
2. 여섯 현상 가운데 채택할 것(전부 쓰지 않아도 됨. 이야기에 쓸 이유가 약한 것은 [decisions-pending-v5.md](decisions-pending-v5.md) §4에서 통합 후보로 분류)
3. 흩어짐의 충동(맞춘 뒤 겹친 박동이 괴로워짐)을 탈출 욕구의 생태적 근거로 쓸지
