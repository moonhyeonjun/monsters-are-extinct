## 1. 작가가 승인할 핵심 사항 (다섯)

| 순위 | 결정 | 추천 | 근거 |
|---|---|---|---|
| 1 | 아동기 식별 기전 | **단계형 ‘물결 피’:** 아이의 심장과 혈관이 박동에 끌림. 한 개체 = 피부의 붉은 물결과 따라가는 숨, 무리 = 온몸의 물결과 멈춤, 집결기 = 죽은 듯한 ‘깊은 잠’. 감응은 그대로이고 끌림만 자라며 줄어듦. 잔류 신호는 갓 적출한 기관뿐 | [sensing-identification-v3.md](sensing-identification-v3.md) |
| 2 | 생존지 현상의 선별 | **핵심 셋**(숨 쉬는 물, 우는 땅, 물든 박동) + **통합 하나**(열의 골과 안개 지붕). 물빛은 숨 쉬는 물의 밤 장면이자 쇠약 지표로 축소 | [gathering-wonders-review.md](gathering-wonders-review.md) |
| 3 | 억류 구조 | **‘떠나는 길을 지운다’:** 도는 물길(지하 수로로 물을 딴 골에 빼냄) + 끊긴 쉼터 사슬(제염소·요양소·치유 성소). 길잡이의 죽음은 역사적 배경. 번식 고리는 작가 판단. 새 감응 기술 불필요 | [containment-v2.md](containment-v2.md) |
| 4 | 첫 만남 | **‘돌아오는 도둑’:** 제염소 폐업 → 드러난 쉼터 → 밤마다 돌아오는 개체 → 누명을 벗기려 덫을 놓은 주인공의 선택. 대안: ‘사흘 밤샘의 성소’ | [first-encounter-v2.md](first-encounter-v2.md) |
| 5 | 정치·종교 구조 | **‘두 개의 권위’**(왕권 + 국경을 넘는 교단), 가문 여섯, **‘층을 이룬 신앙’**(옛 흐름 신앙, 교단의 정화파·개혁파, 애도파, 국가 영웅 의례). 선언의 필요 = 토벌세 폐지 압력 + 교단의 끝맺음. 초자연은 실재하지 않음 | [polity.md](polity.md), [faith.md](faith.md) |

- 함께 확인할 것: 마지막 집결지의 이름 구조(옛말·교단·행정의 여러 이름)와 후보(추천 **울재 / 오세르**, [site-naming.md](site-naming.md)). 확정하지 않았다.
- 뒤로 미룬 것: 연표, 이점 체계, 종의 수와 주기, 인물, 결말과 권수

## 2. 해결된 모순과 남은 문제

| 문제 | 상태 |
|---|---|
| 강렬한 아동기 증상 vs 주인공의 일상 | **해결 후보.** 증상은 신호가 있을 때만, 끌림은 자라며 줄어듦. 주인공에겐 작은 감각만 |
| 공존 시대에 구별할 기회가 충분했나 | **해결 후보.** 무리는 물길을 따라 마을 곁을 지났고, 피하면 물 좋은 땅을 버려야 했음 |
| 차별이 특정 지역·계층에 몰렸나 | **해결 후보.** 철 피난으로 부유층은 피함 → ‘가난한 시골의 대물림 병’ |
| 멸종 뒤의 식별 불가와 가문의 선별 | **해결 후보.** 신호가 없으니 증상도 없음. 가문은 마지막 집결지 가장자리의 ‘선조의 밤’으로 선별 |
| 억류가 완벽한 감옥이 되지 않는가 | **해결 후보.** 큰물, 쉼터의 재개(폐업·복원), 작은 종, 길을 익힌 개체 |
| 숨 쉬는 강이 두 세기 동안 왜 알려지지 않았나 | **해결 후보.** 물이 지하 수로로 딴 골에 나와 봉인 구역과 이어지지 않음 |
| 한 가문의 전능한 조작 | **해결 후보.** 선언의 필요가 왕실과 교단에 있었고, 조각이 여러 세력에 흩어짐 |
| 종교가 악역이 되는가 | **해결 후보.** 같은 교단이 아이를 살렸고(사흘 밤샘), 등록부로 넘겼음. 내부 세 갈래 |
| 받는 기관과 심장·혈관 끌림의 생리 | **남음** |
| 재동기화 원리, 종의 수, 박동이 섞인 세대의 회복 가능성 | **남음**(생태 설계) |
| 4단계 억류안에 맞춘 감사 세부 | **남음**(수로와 쉼터 시설이 장부에 숨는 방식) |
| 이웃 왕국·고원 자치령·교단 중심의 구체 역사 | **남음** |
| 주인공의 욕망 | **남음**(인물 설계) |

## 3. 다른 설계에 넘길 사항

| 받을 설계 | 넘길 것 |
|---|---|
| 생태 | 갓 적출한 기관의 수축 기간, 쉼터의 종류와 간격, 물을 따라가는 첫 방향, 종별 이동성, 박동이 섞인 세대 |
| 역사 | 교단의 공존의 계율과 정화 교리의 전환, 사흘 밤샘의 성립, 아이 징발의 시기, 깊은 잠 지도의 주인, 지하 수로 공사, 연표 |
| 인물 | 주인공의 나이·과거(어린 시절의 깊은 잠 후보)·욕망, 누명 쓴 사람, 제염소의 늙은 감독, 개혁파 성직자, 애도파 필사자, 철 피난 가문의 사람, 각 가문의 얼굴 |
| 줄거리 | 첫 만남의 선택 방향, 개체의 반복 귀환이 만드는 초반 구조, 해방의 순서(쉼터 먼저 / 물길 먼저) |
