## 2. 사건별 설계

### 2-1. E1 공존 시대 (대토벌 수백 년 전까지)

| 칸 | 내용 |
|---|---|
| 원인 | 환류종의 기관 작용이 땅·물·온도를 바꾸어, 그 둘레가 농사와 정착에 유리했다. 사람들은 환류종을 길들이지 않고 장소와 시기를 맞추었다(W의 D-131을 출발점으로 둠). 드물게 박동의 결을 느끼는 사람(감응자)이 있었고, 무리가 지나는 철과 상태를 미리 알려 주는 일이 보수를 받는 직능이 되었다 |
| 직접 결과 | 마을마다 공존 관습이 생김. 감응자가 자주 나던 노르바 산록의 몇 집이 혼인으로 묶여 **모계 가문**이 됨(처음부터 한 핏줄이 아님). 보수로 땅을 모음 |
| 장기 결과 | 감응 지식이 한 가문에 쏠림(독점의 씨앗). 가문 밖 감응자는 이름 없이 흩어짐. 민간에서 감응자를 부르는 말 ‘마녀’가 지역마다 다른 뜻으로 자리 잡음 |
| 이득 | 공존 마을, 감응자 가문 |
| 피해 | 값을 치르지 못한 마을, 가문 밖의 감응 아이들(이해받지 못함) |
| 흔적 | 지명, 민속(밭의 몫, 길 금기, 문 위의 쇠), 옛 농서의 그림, 가문에 남은 옛 계약 조각 |
| 결정할 것 | 공존의 시작 시기, 종별 기관 작용(→ 생태 설계), 가문 형성의 구체 경위 |

### 2-2. E2 첫 번째 침묵 (대토벌 약 80~120년 전부터 수십 년)

| 칸 | 내용 |
|---|---|
| 원인 (핵심 비밀) | **선택지** — 가. 자연의 장기 변화만(지하수·기후·바닥 환경의 변화. W의 작가 내부 우선안) / 나. **가 + 일부 지역에서 사람의 초기 물길 사업이 변화를 거듦** / 다. 질병 단독(권하지 않음). **추천: 나.** 자연 변화가 바탕이고 사람은 일부를 악화했을 뿐이라 한 악당이 없다. 동시에 현재의 산록 물길 사업과 거울이 된다(E12) |
| 직접 결과 | 일부 환류종이 이동 경로를 벗어나고 번식지를 버림. 굶주림과 스트레스로 기관 작용이 강해지거나 약해지거나 불규칙해짐. 낯선 곳에 나타나 충돌과 실제 인명·재산 피해가 늘어남. 감응자는 박동이 흐트러진 것을 먼저 느꼈지만 **‘짐승이 미쳐 간다’로 잘못 읽었다.** 그 해석은 공포에 보태졌다(원인은 아님) |
| 장기 결과 | 대토벌의 명분이 생김. 조건이 남은 곳(이르바넬)으로 일부 무리가 몰리기 시작함 |
| 이득 | 경고를 판 가문(영향력 상승), 땅을 넓히려던 개간 세력 |
| 피해 | 환류종, 공존 마을, 실제 피해를 입은 사람들 |
| 흔적 | 관찰 수첩(이동 방향의 일치), 수위표, 가문의 ‘경고 장부’(뒤에 말살 대상), 물길 사업의 옛 공사 기록 |
| 결정할 것 | 원인(가/나), 시작 연도, 지역, 사람 물길 사업의 규모와 주체 |

### 2-3. E3 감응자와 ‘마녀’의 사회적 역할 (E1~E9를 가로지름)

| 시기 | 감응자의 자리 | ‘마녀’라는 말 |
|---|---|---|
| 공존 | 철과 무리를 알려 주는 직능. 가문 안에서는 명예로운 존칭 | 존중, 고마움, 값에 대한 반감이 지역마다 다름 |
| 첫 번째 침묵 | 경고를 팖. 틀린 해석이 공포를 키움 | 경고가 늦거나 틀린 곳에서 원망의 말이 됨 |
| 대토벌 | 일부가 ‘찾는 이’로 고용됨(가까운 거리의 확인). 공식 장부엔 감각을 지운 중립어(예: 길잡이) | 공포와 경멸의 말이 됨 |
| 잔존기·판정 이후 | 직능이 사라짐. 가문은 비밀 훈련으로 버팀. 가문 밖 감응자는 고립 | 미신을 뜻하는 낡은 말, 아이 겁주는 옛말 |
| 복원 시대 | 공식 자격 없음(감각은 증거가 아님). 비공식 자문으로 다시 쓸모를 얻음 | 아직 노인들의 말속에 남음 |

- 결정할 것: 가문 안 존칭과 공식 직능명(후보만, [../../proposals/witch-name-and-record-erasure.md](../../proposals/witch-name-and-record-erasure.md) §2), 가문 밖 감응자와 남성 감응자의 호칭

### 2-4. E4 대토벌의 시작과 확산 (약 640~500년 전)

| 칸 | 내용 |
|---|---|
| 원인 | 첫 번째 침묵이 부른 실제 피해, 농지와 도시의 팽창, 환류기관을 기준으로 한 보상금 제도, 왕국의 통합 정치(공동의 적), 공포와 선전. 여기에 **‘찾는 이’ 고용이 몰이를 빠르게 했다(가속 요인일 뿐 원인 아님)** |
| 직접 결과 | 환류종의 급감, 지역 멸종, 생태 기능의 상실. 보상 경제의 성장 |
| 장기 결과 | 사람이 만든 대체 시설이 필요해짐. **가문의 분열:** 고용을 이어 간 쪽과 거부하고 떠난 딸들. 왕국 권력의 강화 |
| 이득 | 왕국과 영주(통합, 땅), 사냥꾼과 상인(보상금, 부산물), 고용된 가문(보수, 땅) |
| 피해 | 환류종, 공존 마을의 생업, 거부하고 떠난 감응자(몫과 이름을 잃음), 생태 |
| 흔적 | 보상금 장부, 원정 보급 장부, 병사의 편지, 기념비와 영웅담 |
| 결정할 것 | 결정 주체(왕·회의), 기간, 보상 제도의 지역 차이, 가문이 고용된 규모 |

### 2-5. E5 대토벌 말기의 길 폐쇄 (약 500년 전)

| 칸 | 내용 |
|---|---|
| 원인 | 마지막 무리가 산속 피난처로 몰림. 추격대가 따라옴. 현장 지휘관, 생태 기록자, 산길을 아는 변경 주민이 서로 다른 이유(산사태, 전쟁의 끝, 생물을 죽일 수 없음)로 추격을 멈추게 함. **선택지: 토벌을 거부하고 떠난 감응자가 여기에 섞였는가** — 섞였다면 E8의 출발이 자연스러움(추천), 아니라면 E8을 다른 경로로 짜야 함 |
| 직접 결과 | 계절길과 옛길 일부를 닫음. 추격 중지. 왕국엔 ‘마지막 괴물 토벌’이라는 거짓 승전 보고. **바깥에 처진 무리는 들어가지 못했다(희생)** |
| 장기 결과 | 이르바넬 피난처의 성립과 고립. 길을 지키는 몇몇 집이 생김(은폐 조직의 씨앗). 영웅담의 탄생 |
| 이득 | 피난한 개체군, 승전을 선언한 왕국, 지휘관의 명예 |
| 피해 | 처진 무리, 진실, 장기적으로는 피난 개체군 자신(고립의 비용) |
| 흔적 | 전투일지의 모순(교전·소모가 거의 없음), 미사용 보급품, 무명 병사의 편지, 수위표, 은폐 조직의 ‘닫는 날’ 결정 기록 |
| 결정할 것 | 역사 인물을 이름 있는 인물로 쓸지, 감응자의 참여, 처진 무리의 운명 |

### 2-6. E6 은폐와 기록 말살 (약 500년 전 ~ 잔존기)

- **네 집단이 서로 공모하지 않고 각자의 이유로 같은 방향으로 지웠다.**

| 집단 | 동기 | 방법 |
|---|---|---|
| 왕국 | 영웅담과 통합의 상징, 실패를 인정하지 않음 | 공식 연대기 단순화, 승전 기념 |
| 토벌대·보상 사무소 | 거짓 신고와 셈의 엉킴을 덮음 | 장부 정리, 사본 수정 |
| 길 지기(은폐 조직의 선대) | 피난처를 감춤 | 지도 흐림, 길 금기 일부 유지, 목격담을 민담으로 흘림 |
| 모계 가문 | ‘찾는 이’ 공모 은폐, 구성원 보호, 재산 보전, 해석 기술 독점 | 직능명 변경, 계약·지급 장부 일부 폐기, 족보 재편집, 구전을 미신으로 낮춤. 훈련 자료는 비밀로 보존 |

| 칸 | 내용 |
|---|---|
| 직접 결과 | 공식 기록에서 감응자와 피난처가 사라짐. 장부엔 중립어만 남음 |
| 장기 결과 | 복원 시대의 ‘출처 빈칸’과 기록 불일치. ‘마녀’ 이야기의 미신화. 가문 밖 감응자가 전통 없이 고립됨 |
| 이득 | 네 집단 각각 |
| 피해 | 진실, 후대 복원학(지식이 늦어짐), 가문 밖 감응자 |
| 흔적 | 기관마다 다른 장부의 어긋남, 쪽 번호와 합계의 빈칸, 민간 편지, 은폐 조직의 자료, 가문의 훈련 자료 |
| 결정할 것 | 말살을 이끈 인물(역설 후보: 감응자 여성, 보호에서 통제로), 남은 기록의 종류와 소재 |

### 2-7. E7 이르바넬의 생존 개체군 (약 500년 전 ~ 현재)

| 칸 | 내용 |
|---|---|
| 원인 | 안정된 수원, 다양한 고도, 오래된 바닥 환경이 남은 곳(피난 조건). 사람의 봉쇄는 몰림을 거들었을 뿐 피난처를 만들지 않았다 |
| 직접 결과 | 몇몇 종이 살아남음. 좁은 곳에 몰린 무리 사이의 국지적 되먹임 위험(한 종의 기관 변화가 이웃 종을 흔듦) |
| 장기 결과 | 고립에 따른 다양성 감소, 계절길 의존, 바깥 물길 변화에 대한 취약성 |
| 이득 | 생물 자신, 관리 권한을 가진 은폐 조직, 훗날 공급망 |
| 피해 | 생물 자신(고립의 비용), 바깥에 남은 무리 |
| 흔적 | ‘확인 불가’로 처리된 바깥 목격담, 물길 수량의 이상, 복원 시설의 출처 빈칸 |
| 결정할 것 | 종 목록, 개체 수, 환경 세부, 바깥 잔존 개체의 유무 → **다음 단계(생태 설계)** |

### 2-8. E8 은폐 조직과 모계 가문의 타협, 제한적 감응 훈련권 (잔존기, 약 450~350년 전 후보)

> 대토벌에 가담한 가문이 피난처에 들어갈 수 있게 된 과정을 사건으로 설계한다. 사건 이름은 임시.

**사건 후보 〈닫힌 골의 겨울〉**

1. **떠난 딸들의 후손:** 토벌을 거부하고 가문을 떠난 감응자 몇이 길 지기 집들과 혼인해 피난처 가까이 살았다(E5의 선택지와 이어짐). 후손 가운데 소인이 있는 아이가 드물게 태어났다. 훈련은 받지 못했다.
2. **밀렵꾼의 침입:** 잔존기 어느 겨울, 밀렵꾼 무리가 계절길 하나를 찾아 들어왔다. 길 지기들은 몰린 무리가 얼마나 위태로운지 모른 채 정면으로 막으려 했다.
3. **보호의 증명:** 그 집의 감응자 후손이 무리 가까이에서 박동이 흐트러진 것을 읽고 “지금 흔들면 무너진다”고 말렸다. 길 지기들은 싸우는 대신 밀렵꾼을 다른 골로 유인했다. 무리는 무너지지 않았다. 감응이 피난처를 지키는 데 쓰인 첫 사례였다. 그러나 그 후손은 혼자 배워 해석이 약했다.
4. **본가의 발견:** 같은 무렵 본가는 떠난 딸들의 자녀를 오래 지켜보는 관행(이탈 통제)을 이어 오다가, 그 집안이 산속 무언가를 지킨다는 것을 알아챘다. 본가는 그것을 왕국이나 수집가에게 알릴 수 있는 위치에 섰다.
5. **타협:** 본가는 **침묵**(피난처를 누구에게도 알리지 않음, ‘찾는 이’ 일을 바깥에 팔지 않음)과 **감응 경보**(정해진 구역에서 무리의 이상을 알려 줌)를 내주었다. 은폐 조직은 **제한 구역·정해진 철·길잡이 동반**의 훈련 출입을 허락했다. 떠난 딸들의 후손을 본가가 혼인으로 다시 받아들이는 조건이 붙었다.
6. **서로의 비밀:** 은폐 조직은 가문의 대토벌 협력과 위치를 안다. 가문은 피난처의 존재와 훈련 구역을 안다. 어느 쪽도 상대의 전부를 알지 못한다. 가문은 길과 핵심 샘을 모르고, 은폐 조직은 가문의 훈련 체계와 말살의 전모를 모른다.

| 칸 | 내용 |
|---|---|
| 직접 결과 | 훈련권 성립. 가문은 살아 있는 개체로 훈련할 수 있게 됨. 은폐 조직은 경보 수단을 얻음 |
| 장기 결과 | 가문은 ‘살아 있는 개체로 훈련한 집단’이 됨(한 구역에서 익힌 해석을 지나치게 일반화하는 약점). 떠난 딸들의 상처가 봉합된 것처럼 보이지만 이탈 통제는 더 강해짐. 은폐 조직 안에서 가문을 경계하는 쪽(수호파의 뿌리)이 생김. 안에서 아는 사람이 늘어 은폐가 약해짐 |
| 이득 | 양쪽 지도부 |
| 피해 | 떠난 딸 후손의 자유(본가로 흡수), 은폐의 견고함 |
| 흔적 | 은폐 조직의 출입 장부, 가문 훈련 자료의 구역 표시, 혼인 기록 |
| 결정할 것 | 시기, 약속의 형태(문서·증표·구두), 조건의 갱신 방식, 지금 그 약속을 지키는 사람 |

### 2-9. E9 공식 멸종 판정 (멸종력 원년, 300여 년 전)

| 칸 | 내용 |
|---|---|
| 원인 | 잔존기 목격의 감소, 조사 예산의 종결, 정치적 종결의 욕구, 은폐 조직의 목격담 흐림, 가문의 침묵. 판정은 **설계된 거짓이 아니라 정치적 종결과 불완전한 조사의 산물**이다(W의 D-087 가설을 출발점으로 둠) |
| 직접 결과 | 공식 멸종 선언, 보상 제도 종료, 새 연호의 시작 |
| 장기 결과 | 대체 시설의 국가 체계화. 복원학의 출발점. ‘멸종’이 모두의 상식이 됨 → 이르바넬의 가장 두꺼운 보호막 |
| 이득 | 왕국(종결), 은폐 조직(수색 종료), 가문(‘찾는 이’의 역사 매장) |
| 피해 | 보호받지 못한 바깥의 잔존 개체, 진실 |
| 흔적 | 선언문, ‘확인 불가’로 묶인 목격 보고 |
| 결정할 것 | 선언의 주체, 마지막 확인 목격, 선언을 주도한 사람의 사정 |

### 2-10. E10 대체 시설의 시대 (멸종력 원년 ~ 약 180년)

- 사람은 잃어버린 생태 기능을 탑과 수로와 시설로 메웠다(W의 D-133을 출발점으로 둠). 이 시대에 산록의 물길 사업이 커지고, 피난처로 가던 물의 일부가 돌아가기 시작한다(E12의 뿌리).
- 결정할 것: 시설의 종류, 물길 사업의 주체와 시기

### 2-11. E11 복원 산업과 현재의 갈등 (멸종력 약 180년 ~ 현재)

| 칸 | 내용 |
|---|---|
| 원인 | 대체 시설의 한계와 비용, 생태 회복 요구, 보존 생체 재료의 존재(기원은 비밀), 협회의 설립과 복원 성공 |
| 직접 결과 | 시설·학교·서식국·공모 제도. 재료 수요의 증가 |
| 장기 결과 | 은폐 조직이 가장자리 샘에서 소량을 ‘오래된 보존분’으로 공급하기 시작함(‘조금이면 괜찮다’) → 수입이 집들을 묶고 **사업파**가 자람. 가문은 비공식 자문으로 다시 쓸모를 얻음. 연구자들 사이의 경쟁(에드반 등) |
| 이득 | 은폐 조직의 사업파, 사설 연구소, 투자자, 가문의 ‘쓸모를 되찾자는 쪽’ |
| 피해 | 가장자리 샘의 개체, 복원 기록의 신뢰(출처 위조가 드러나면), 산마을의 장기적 안전 |
| 흔적 | 이관 서류의 출처 빈칸, 시설 생존율의 차이, 운송 짐표 |
| 결정할 것 | 출처 위조를 쓸지와 범위, 에드반의 목적(P에서 다시 정함) |

### 2-12. E12 〈마지막 채취〉가 일어나는 조건 (현재 ~ 몇 해 안)

| 조건 | 내용 |
|---|---|
| 1 | 시설 배양 재료의 쇠퇴(대를 거듭할수록 약해짐) |
| 2 | 협회 공모의 요건(서로 독립된 계통, 여러 해의 공급 계획) |
| 3 | 가장자리 샘이 마름(산록 물길 사업과 가뭄) |
| 4 | 원래 조건이 남은 핵심 샘은 계절길이 열리는 이동철에만 닿을 수 있음 — 가장 위험한 때가 유일하게 갈 수 있는 때 |
| 5 | 투자자의 기한 |
| 6 | 감응자를 확보하려는 시도 — 사업파는 ‘흔들지 마라’의 빈칸을 감응자의 확인으로 메우려 함. 가문의 훈련권이 거래 대상이 됨 |

- 실제 위험: 몰린 무리를 흔들어 국지적 붕괴가 일어날 수 있음. 감응자의 ‘괜찮다’가 거짓 안심이 될 수 있음.
- 가문 없이도 채취는 진행된다(조건표, 길잡이, 운송, 기한이 있음). 감응자는 속도와 안심을 더할 뿐이다.
- 결정할 것: 일정, 규모, 결과, 주인공이 어디에 서는가(→ 줄거리 단계)

## 4. 설계 품질 점검

| 기준 | 이 설계에서 |
|---|---|
| 복잡해지기만 하지 않는가 | 사건은 열둘이지만 사슬은 한 줄이다(§0). 새 집단은 기존 후보(은폐 조직, 가문, 왕국)뿐이다 |
| 설정이 사건과 선택을 만드는가 | E8의 타협이 현재의 거래 대상(훈련권)을 만들고, E10의 물길 사업이 E12의 기한을 만든다 |
| 역사에서 현재로 인과가 분명한가 | E2(사람 물길 사업의 거듦) ↔ E12(산록 물길 사업): 같은 실수가 되풀이되는 구조 |
| 한 조직이 모든 것을 조종하지 않는가 | 은폐(E6)는 네 집단이 따로 한 일이다. 채취(E12)는 가문 없이도 진행된다 |
| 생태가 음모에 종속되지 않는가 | 첫 번째 침묵의 바탕은 자연 변화, 피난처는 자연 조건, 붕괴 위험은 생물의 반응이다 |
| 혈통이 만능 열쇠가 아닌가 | 감응은 수십 걸음 안의 해석일 뿐이고, 가문 밖에도 있다. 훈련권은 피가 아니라 거래로 생겼다 |
| 비밀의 진실이 미리 정해졌는가 | 핵심 비밀마다 추천안이 있다([secrets-ledger.md](secrets-ledger.md)). 승인 전이다 |

2. 토벌을 거부한 감응자가 길 폐쇄에 섞였는가(E5) — 섞였다면 E8이 자연스러움
