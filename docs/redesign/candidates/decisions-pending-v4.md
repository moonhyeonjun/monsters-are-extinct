## 1. 작가가 승인할 핵심 사항 (다섯)

| 순위 | 결정 | 추천 | 근거 |
|---|---|---|---|
| 1 | 감응자 식별 기전 | **환류종 가까이에서 저절로 일어나는 눈 떨림·균형 반응(평형 기관 가설) + 보는 관습·징집 검사 + 기록과 계보.** 선천적 신체 표식은 쓰지 않음. 귀결: 멸종 뒤엔 가문만 감응자를 가려낼 수 있음 | [sensing-identification.md](sensing-identification.md) |
| 2 | 긴 주기 집결의 목적 | **박동의 재동기화와 번식의 결합.** 대안: 번식만 / 기관의 갱신 / 극한기의 피난 | [gathering-ecology.md](gathering-ecology.md) |
| 3 | ‘아르바넬만 살아남았다’의 범위 | **마지막으로 기능하는 집결지 + 그곳을 쓰는 집결형 종의 마지막 번식 집단.** 떠도는 개체와 비집결형 종은 따로 | [gathering-ecology.md](gathering-ecology.md) §3 |
| 4 | 아르바넬 생존의 인과 | **가문 조상의 ‘조용한 땅’ 곁 집결지 + 다른 집결지는 군에 넘기고 이곳만 숨김(보호이자 계산) + 갈 곳 잃은 무리가 머물러 위험이 상시** | [arbanel-survival.md](arbanel-survival.md) |
| 5 | 봉인·선언 제도의 보강 | **봉인령과 관리 위임, 면제 규정, 고요한 철의 바깥 점검, 마지막 원정 = 다른 집결지의 실제 학살 + ‘세상의 마지막’이라는 허위, 실무자가 손수 쓰는 거짓 보고** | [seal-declaration-v4.md](seal-declaration-v4.md) |

- 함께 확인할 것: 이름 표기 ‘아르바넬’을 공식 명칭으로 쓸지(W 자료의 ‘이르바넬’과 다름)
- 뒤로 미룬 것: 감응 면허·입양 위선·비감응 계승자([sensing-society.md](sensing-society.md)), 연표, 위상 기술

## 2. 설정 완결성과 재미 검증

| 기준 | 판단 |
|---|---|
| 새 설정 하나가 여러 의문을 푸는가 | **예.** 박동의 재동기화 하나로 첫 번째 침묵(박동 약화), 대이동, 집결지의 위험, 감응자의 과부하, 떠도는 개체가 설명된다. 눈 떨림 하나로 차별, 수색의 쓸모, 강제 동원, 멸종 뒤의 비가시성, 식별의 독점이 설명된다 |
| 설명을 위해 설정을 계속 더해야 하나 | 생태 설계에서 ‘진동을 모으는 지형’과 ‘맞춤과 번식의 관계’만 더 필요하다 |
| 차별과 상승의 인과 | 같은 몸의 반응이 시대에 따라 낙인과 바늘이 됨. 법(징집법, 보상 규정, 면허)으로 뒤집힘 |
| 집결지 파괴와 대토벌 | 집결 중의 매복이 가장 효율적인 사냥이었고, 그 정보를 가문이 줌 |
| 아르바넬 생존이 기적이나 우연에 기대나 | 기대지 않는다. 조상의 땅, 계산된 은폐, 재난과 봉인, 상시 위험의 연쇄 |
| 멸종 선언의 허위가 증거로 드러날 수 있나 | 있다. 두 벌 장부, 의견서, 빠진 정찰 기록, 참사 증언, 새 측정 기술, 다른 집결지 터 |
| 가문의 명성을 뒤집는 반전이 공정한가 | 공정하다. 공로는 실제였고, 같은 공로가 학살의 길잡이였다 |
| 살아 있는 환류종의 행동이 선택을 바꾸나 | 바꾼다. 주기의 해, 떠도는 개체, 머무는 무리의 쇠약 |
| 비밀이 알려지면 생물이 새 위험에 처하나 | 처한다. 상시 집결 중인 무리가 사냥꾼과 시장에 노출됨 |
| 시작과 결말을 강하게 잇는가 | 잇는다. 처음 감응자가 드러나는 순간(눈의 떨림)과 마지막의 선택(집결지를 어떻게 할 것인가)이 같은 박동 위에 있다 |

## 3. 해결된 구멍과 남은 구멍

| 이전 구멍 | 상태 |
|---|---|
| 집결의 이유와 주기 | **방향 해결**(재동기화와 번식, 주기 범위는 생태) |
| 작은 무리가 두 세기를 버틴 근거 | **부분 해결**(시작한 무리가 넓은 지역에서 모여 작지 않았음, 가문의 관리) — 수치는 생태 |
| 면제 규정이 들어간 경위 | **해결 후보**(참사 직후의 안전 규칙) |
| 감사가 안쪽을 보지 못한 이유 | **해결 후보**(고요한 철, 바깥만, 순환 검증) |
| 가문 밖 감응자가 둘레에서 느낀 것 | **해결 후보**(멸종 뒤엔 드러날 계기가 없음, 봉인 구역 가까이 가면 드러남) |
| 낙인이 지금 남은 정도 | **해결 후보**(옛말로만 남음, 가문 안에서만 살아 있음) |
| 위상 맞춤으로 거두는 것 | **남음**(보류) |
| 약재가 늘어도 묻지 않은 이유 | **남음**(이점 체계가 보류라 함께 보류) |
| 지금 흔들리는 직접 계기 | **남음**(후보 여섯, 줄거리 단계) |
| 독점을 끝내는 행동의 새 위험 | **방향 해결**(상시 집결 무리의 노출) |
| 새로 생긴 구멍 | 진동을 모으는 지형의 성질 / 맞춤과 번식의 관계 / 흰 골 참사의 의도 여부 / 가문 조상이 ‘울림의 해’에 어떻게 살아남았나 |

## 4. 다른 설계에 넘길 미결정 사항

| 받을 설계 | 넘길 것 |
|---|---|
| 생태 | 집결형 종의 수와 주기, 진동을 모으는 지형, 맞춤과 번식, 집결 중의 위험, 머무는 무리의 쇠약 속도, 떠도는 개체의 수명, 비집결형 종의 운명, 위상 기술의 가능성 |
| 역사 | 가문 조상이 조용한 땅에 정착한 시기, 흰 골 참사의 의도 여부, 다른 집결지를 넘긴 순서와 규모, 징집법·보상 규정·면허의 시기, 연표 |
| 인물 | 공적 이상을 믿는 후손, 영웅적 보호 활동을 믿는 실무자, 자기가 감응자인지 모르는 가문 밖 아이, 비감응 계승자, 몰래 입양된 감응자, 반대 학자의 후손 |
| 줄거리 | 지금 흔들리는 계기, 떠도는 개체의 첫 등장, 주기의 해를 이야기에 쓸지 |
