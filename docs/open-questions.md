# Open Questions — 미확정 설정

확정되지 않은 설정과 검증 과제를 등록한다. 질문이 해결되면 `docs/decisions.md`에 결정으로 옮긴다. 완전히 해결된 질문은 맨 아래 '해결된 질문'으로 옮긴다.

## 운영 규칙

- **우선도**
  - `P0`: 제2화 집필 전에 결정해야 함
  - `P1`: 첫 모험(1권) 집필 중에 결정해야 함
  - `P2`: 후속 모험 이전
  - `P3`: 장기 과제
- **상태**
  - `열림`: 결정 없음
  - `제안 있음`: 권장안은 있으나 승인 전
  - `일부 해결 → D-xxx`: 방향은 결정되었고, 질문 칸에는 남은 부분만 적는다
  - `확정하지 않음 (D-022)`: 정본에서 의도적으로 열어 두는 항목. 필요하면 작업 가정으로만 쓴다
  - `해결 → D-xxx`: 완전히 해결됨. '해결된 질문'으로 옮긴다
- 출처 표기는 [docs/canon.md](canon.md)의 '출처 표기' 규칙을 따른다. (`§I-n` = 마스터 첫머리 통합 본문, `§n-m` = 제n장)
- 작중 날짜는 `D` = 제1화 당일 기준이다. 서사 장(1~14장)과 연재 회차(제n화)는 따로 적는다. (D-015)
- 이 문서는 질문과 선택지만 기록한다. AI가 제안한 답은 사용자 승인 전까지 확정 설정이 아니다.
