# Open Questions — 미확정 설정

확정되지 않은 설정과 검증 과제를 등록한다. 해결되면 `docs/decisions.md`에 결정으로 옮기고 이 표에서는 `해결 → D-xxx`로 표시한다.

## 운영 규칙

- **우선도**
  - `P0`: 제2화 집필 전에 결정해야 함
  - `P1`: 첫 모험(1권) 집필 중에 결정해야 함
  - `P2`: 후속 모험 이전
  - `P3`: 장기 과제
- **상태**: `열림` / `제안 있음` / `해결 → D-xxx`
- 출처 표기는 [docs/canon.md](canon.md)의 '출처 표기' 규칙을 따른다. (`§I-n` = 마스터 첫머리 통합 본문, `§n-m` = 제n장)
- 이 문서는 질문과 선택지만 기록한다. AI가 제안한 답은 사용자 승인 전까지 확정 설정이 아니다.
