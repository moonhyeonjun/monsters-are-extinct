# tools — 저장소 검증 도구

## verify.py

원고와 문서를 **읽기만** 하는 검증 도구다. 파일을 고치지 않는다.

### 실행

```bash
python3 tools/verify.py
```

- 저장소 안 어디서 실행해도 된다. 경로는 이 파일의 위치에서 찾는다.
- 다른 사본(예: 다른 브랜치를 풀어 놓은 폴더)을 검사할 때는 `--root`를 쓴다.

```bash
python3 tools/verify.py --root /path/to/checkout
```

- 파이썬 3 표준 라이브러리만 쓴다.
- 종료 코드: `0`은 통과, `1`은 오류가 하나 이상 있음이다.

### 검사 항목

| 항목 | 범위 | 오류로 보는 것 |
|---|---|---|
| 링크 | `docs/**/*.md`, `manuscript/**/*.md`, 최상위 `*.md` | 상대 링크가 가리키는 파일이 없음 (`http`, `mailto`, 앞부분 없는 `#앵커`는 건너뜀) |
| 결정 번호 | `docs/decisions.md`의 `## D-NNN.` 제목 | 같은 번호가 두 번 나옴. 마지막 번호를 함께 알려 준다 |
| D·Q 참조 | `docs/**/*.md`, `manuscript/book*/*.md` | 본문에 나온 `D-NNN`이 decisions.md 제목에 없음, `Q-분류-NN`이 `docs/open-questions.md` 표에 없음 |
| 원고 파일 | `manuscript/book*/ep*.md` (권 폴더를 스스로 찾는다) | 파일명이 `epNN-제목.md`가 아님, `## 제N화` 제목이 없거나 번호가 파일 번호와 다름, 머리 주석(`<!-- -->`)이 닫히지 않음 |
| 원고 본문 | 머리 주석과 `#` 제목 줄을 뺀 본문 | 금지어(`환수`, `거생종`), 기획 표기(`[제안]`, `[작가 비밀]`, `[초안]`, `[보류]`), 회차 표기(`제N화`), 권 표기(`제N권`), 곧은 큰따옴표(`"`), 곧은 작은따옴표(`'`, **제2권부터**) |
| 기록장 블록 | 머리 주석과 `#` 제목 줄을 뺀 본문에서 `>`로 시작하는 줄의 묶음 ([style-guide.md](../docs/plot/style-guide.md) §10) | 첫 줄이 `> **리아의 기록장**`이 아님, 둘째 줄이 빈 인용 줄 `>`이 아님, 기록 줄이 없음, 기록 줄이 `> *기록*` 꼴이 아님, 기록 줄 사이에 빈 인용 줄이 없음, 꼬리표가 블록 안에서 되풀이되거나 블록 밖에 있음, 블록 앞뒤에 빈 줄이 없음. 기록 문구 자체는 검사하지 않는다. 권마다 블록 수를 알려 준다 |
| 회차 번호 | 권마다 따로 | **같은 권 안에서 번호가 겹칠 때만** 오류다. 권이 다르면 같은 번호여도 된다. 빠진 번호는 알려만 주고 오류로 보지 않는다 |

- 머리 주석 안의 과거 문장, 기획 표기, 결정 번호는 본문 검사에서 빠진다. 머리 주석의 D·Q 번호는 'D·Q 참조' 검사에서 본다.
- 곧은 작은따옴표(`'`)는 `manuscript/book2`부터(권 번호 2 이상) 본문에 하나라도 있으면 오류다. 칸 이름이나 낱말 인용은 굽은 작은따옴표(`‘ ’`)로 쓴다. 제1권 본문에는 곧은 작은따옴표가 남아 있어 개수만 알리고 오류로 보지 않는다(제1권은 이 검사 때문에 고치지 않는다. 정리는 따로 할 과제). 기준 권 번호는 `verify.py`의 `STRAIGHT_SINGLE_QUOTE_FROM_BOOK`이다.

### 출력 예

```
링크: 깨진 링크 0
결정 번호: 마지막 D-123, 중복 없음
미정의 D·Q 참조: 0
원고 book1: 21편 (1~21화)
원고 book2: 20편 (1~20화)
원고 book1: 본문 곧은 작은따옴표(') 48개 (이 권은 오류로 보지 않음, 따로 정리할 과제)
기록장 블록: book1 N개, book2 M개
원고 본문 오류: 0
결과: 통과
```
